# 精简设计：修验证噪声 / 收窄模型矩阵 / 砍掉零成功链路

- 日期：2026-10-30
- 依据：复盘数据包 `retro-2026-10-30`（CI 红率 22%、生成成功率 59%、50% 失败来自参数组合）
- 原则：先去掉噪声与死面，再谈结构重构；**不拆 flowStore**（分层零违规，风险 > 收益）

## 背景（证据）

| 事实 | 数字 |
|---|---|
| CI 红率（近 3 周） | 30/139 = **22%**，其中 e2e 占失败 job 的 **87%** |
| 生成成功率 | 64 成功 / 32 失败 / 13 未知 = **59%** |
| 生成失败主因 | 「参数/参考图组合不支持」16 次 = **50%** |
| 视频生成 | 3 次运行，**0 成功** |
| 教程 / 素材库 | 领取 4 人 / 素材 8 条 |
| 模型长尾 | 4 个模型占 92%；seedream-pro 0 次、qwen-pro 1 次、flux 2 次 |

## 第 1 项：修验证噪声（本轮已实施）

### 范围
- 新增 `e2e/helpers/interaction.ts`：`openCombobox`（键盘优先 + 有界重试）、`waitForAnimationsSettled`、`expectNotCollapsed`（以计算样式 min-width 为硬门，几何值只作诊断）。
- `e2e/workbench.spec.ts` 的「数量」下拉迁移到助手，替换原 20s 盲轮询。
- `e2e/vis06-tokens.spec.ts` 保持指针点击并注明原因（该控件的键盘路径不渲染 listbox，实测）。

### 验收
- `workbench.spec.ts --project=desktop-1280` **21 passed**；
- `vis06-tokens.spec.ts --project=vis06` **2 passed**；
- `tsc --noEmit` rc 0；全量单测 113/113。

### 不做
- 不动 `waitForTimeout` 的全部 28 处（多数是动画/落盘稳定点，逐条改收益低于风险）；
- 不动 `r87-ux` 的画布坐标双击（那是缩放语义本身，不是遮挡问题）。

## 第 2 项：收窄模型矩阵（待拍板）

### 提案
默认面板只展示 4 个主力模型（`gpt-image-2.5-flare` / `gpt-image-2.5-sunburst` / `gemini-3.1-flash-image` / `gemini-nano-banana-2.1`），
长尾 5 个（`doubao-seedream-5-0-pro` / `-lite` / `qwen-image-3.0` / `-pro` / `flux-3-image`）移入「实验模型」分组。

### 需要用户决定
1. 长尾模型是「隐藏」还是「删除」？
2. `seedream-pro`（0 次使用）是否直接删？
3. 隐藏后是否仍接受旧草稿里已选的模型（静默回落为默认模型，照现有规则）？

### 验收
- 面板默认组 = 4 个；实验组需显式展开；
- 旧草稿回落有测试；
- 生成失败率（「参数组合不支持」）在 30 天内下降。
