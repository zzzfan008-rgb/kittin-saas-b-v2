# 沉浸式翻譯

沉浸式翻譯是一款優秀的瀏覽器翻譯擴充套件，支援網頁雙語對照閱讀。通過整合 API易，您可以使用強大的 AI 模型獲得更準確、更自然的翻譯效果。

## 快速安裝

### 支援的瀏覽器

* Chrome / Edge / Brave
* Firefox
* Safari

### 安裝步驟

1. 訪問對應瀏覽器的擴充套件商店
2. 搜尋"沉浸式翻譯"或"Immersive Translate"
3. 點選安裝並新增到瀏覽器

或訪問 [官網](https://immersive-translate.owenyoung.com/) 獲取安裝連結。

## 配置 API易

### 1. 開啟設定

點選瀏覽器工具欄的擴充套件圖示，選擇"設定"。

### 2. 配置翻譯服務

1. 在左側選單選擇"翻譯服務"
2. 找到"OpenAI"服務
3. 點選"管理"或"設定"
4. 選擇"自定義 API Key"

### 3. 填寫配置

* **APIKEY**：輸入您的 API易 金鑰
* **自定義 API 介面地址**：`https://api.apiyi.com/v1/chat/completions`
* **自定義模型**：`gpt-3.5-turbo`（可選）

## 核心功能

### 網頁翻譯

#### 自動翻譯

1. 訪問外文網頁
2. 擴充套件自動檢測語言
3. 點選翻譯按鈕開始

#### 手動翻譯

1. 點選工具欄擴充套件圖示
2. 選擇"翻譯本頁"
3. 等待翻譯完成

### 翻譯模式

#### 雙語對照（推薦）

* 保留原文格式
* 譯文顯示在原文下方
* 便於對照學習

#### 僅譯文

* 完全替換原文
* 適合快速閱讀
* 可隨時切換回雙語

### 劃詞翻譯

1. 選中需要翻譯的文本
2. 點擊出現的翻譯按鈕
3. 在彈窗中檢視翻譯結果

3. 檢視翻譯建議

## 效能最佳化

### 快取設定

* 開啟翻譯快取
* 設定快取時長：24小時
* 定期清理快取

### 批次翻譯

* 調整批次大小：5-10 段落
* 設定合理併發數：2-3
* 最佳化長文本處理

### 觸發條件

* 最小翻譯長度：10 個字元
* 忽略特定元素：導航選單、廣告
* 延遲翻譯：200ms

## 常見問題

### 翻譯失敗

**可能原因：**

* API 金鑰無效
* 網路連線問題
* 頁面結構特殊

**解決方案：**

1. 驗證 API 金鑰
2. 檢查網路連線
3. 嘗試重新整理頁面
4. 檢視瀏覽器控制台錯誤

### 翻譯速度慢

**最佳化方法：**

1. 使用更快的模型
2. 減少單次翻譯文本量
3. 開啟快取功能
4. 檢查網路延遲

### 格式錯亂

**處理方式：**

1. 嘗試不同翻譯模式
2. 調整譯文顯示設定
3. 針對特定網站自定義規則
4. 反饋問題給開發者

## 高階技巧

### 自定義翻譯指令碼

使用 JavaScript 增強功能：

```javascript theme={null}
// 自動檢測並翻譯特定內容
if (document.querySelector('.article-content')) {
    window.immersiveTranslate.translate({
        selector: '.article-content',
        fromLang: 'auto',
        toLang: 'zh-CN'
    });
}
```

### 開發者模式

## 故障排除指南

### 擴充套件無法載入

1. 檢查瀏覽器版本相容性
2. 停用其他衝突擴充套件
3. 清除瀏覽器快取
4. 重新安裝擴充套件

### 翻譯結果不顯示

1. 檢查網頁是否支援翻譯
2. 確認翻譯服務配置正確
3. 檢視是否被廣告攔截器阻止
4. 嘗試其他翻譯服務

### 記憶體佔用過高

1. 定期清理翻譯快取
2. 減少同時翻譯的頁面數
3. 調整批次翻譯設定
4. 關閉不必要的標籤頁
