## 充值階梯加贈

充值金額越大，加贈比例越高。大額充值的加贈會由平臺方自動新增，無需特別申請。

<Info>
  **政策更新時間**：2025 年 12 月 18 日起執行新的充值加贈政策
</Info>

### 加贈比例表

| 充值金額（單次充值）             | 加贈比例    | 實際到賬倍數   | 充值示例                    |
| ---------------------- | ------- | -------- | ----------------------- |
| \$100 ≤ X \< \$500     | **10%** | 1.1 倍餘額  | 充值 \$100 → 到賬 \$110     |
| \$500 ≤ X \< \$1,000   | **12%** | 1.12 倍餘額 | 充值 \$500 → 到賬 \$560     |
| \$1,000 ≤ X \< \$3,000 | **15%** | 1.15 倍餘額 | 充值 \$1,000 → 到賬 \$1,150 |
| X ≥ \$3,000            | **20%** | 1.2 倍餘額  | 充值 \$3,000 → 到賬 \$3,600 |

<Note>
  **重要說明**：加贈比例按**單次充值金額**計算，而非累計充值金額
</Note>

### 加贈發放說明

<Info>
  **自動發放**：充值 \$100 及以上的階梯加贈，平臺方會自動識別並新增，無需您主動申請。每天 23:00 - 次日 01:00（UTC+8）由財務人員統一加贈，採用「系統自動化 + 人工複核」流程，**次日檢視即可，到賬無需催促**。
</Info>

### 對公充值加贈

對公充值同樣享受階梯加贈，
所有支付方式（含對公）均可參與充值加贈活動。

**示例**：對公轉賬 2 萬元，
確認到賬後完成充值 20000 元和加贈 15%。

### 額度有效期（2026-08-02 起執行）

賬戶餘額自充值之日起 **365 天**內有效，規則如下：

| 專案            | 規則                                   |
| ------------- | ------------------------------------ |
| **有效期**       | 充值餘額自充值之日起 365 天內有效                  |
| **再次充值**      | 重置**全部可用餘額**的有效期，重新恢復為滿一年            |
| **贈送 / 促銷額度** | 與充值餘額規則一致，同為 365 天，同樣被新充值重置          |
| **存量餘額**      | 統一自生效日（2026-08-02）起算 365 天，不按歷史充值日倒推 |
| **到期處理**      | 到期餘額自動失效，不退款、不恢復、不兌換                 |
| **到期日查詢**     | 可在控制台檢視當前餘額的到期日                      |

<Warning>
  **充值金額請按實際用量規劃**：只要保持正常的充值使用節奏，再次充值就會把全部餘額的有效期重置為滿一年，實際上不會受影響；但如果預計一年內用不完，請不要為了拿更高加贈比例而超額充值。到期餘額不予退款或恢復。

  完整條款以 [使用者協議](https://cf-index.apiyi.com/terms) 與 [退款政策](https://cf-index.apiyi.com/refund) 為準。
</Warning>

## 常見問題

<AccordionGroup>
  <Accordion title="首充加贈可以和階梯加贈疊加嗎？">
    **可以疊加！**

    例如：首次充值 \$700

    * 首充加贈：\$1（或教育使用者 \$2）
    * 階梯加贈：\$700 × 12% = \$84
    * 總到賬：\$700 + \$1 + \$84 = **\$785**（普通使用者）

    記得[聯絡企業微信客服](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec)申請首充加贈哦！
  </Accordion>

  <Accordion title="充值後多久到賬？">
    **到賬時間**：

    * **線上支付**：即時到賬（充值本金立即到賬）
    * **階梯加贈**：每天 23:00 - 次日 01:00（UTC+8）由財務統一加贈（系統自動化 + 人工複核），次日檢視即到賬
    * **首充加贈**：[聯絡企業微信客服](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec)後人工新增，通常 1 個工作日內

    **對公轉賬**：到賬後 1 個工作日內處理
  </Accordion>

  <Accordion title="首充贈禮沒有到賬怎麼辦？">
    請[聯絡企業微信客服](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec)核實，
    客服會協助處理首充贈禮的發放事宜。
  </Accordion>

  <Accordion title="充值金額有最低限制嗎？">
    **沒有最低限制**，但建議：

    * 最低充值 \$10 以上，避免頻繁充值
    * 充值 \$100 以上可享受階梯加贈優惠
    * 一次性充值更多金額可享受更高加贈比例，同時請結合 365 天有效期評估用量
  </Accordion>

  <Accordion title="充值額度會過期嗎？">
    **會**。自 2026 年 8 月 2 日起，賬戶餘額有 **365 天有效期**：

    * 充值餘額自充值之日起一年內有效
    * **再次充值會把全部可用餘額的有效期重置為滿一年**，因此保持正常充值使用節奏不會受影響
    * 贈送與促銷額度適用同一規則
    * 存量餘額統一自 2026-08-02 起算 365 天
    * 到期餘額自動失效，不退款、不恢復、不兌換

    當前餘額的到期日可在控制台查詢。完整條款見 [使用者協議](https://cf-index.apiyi.com/terms) 與 [退款政策](https://cf-index.apiyi.com/refund)。
  </Accordion>

  <Accordion title="充值額度可以退款嗎？">
    根據平臺政策：

    * **未使用的充值額度**：特殊情況可申請退款
    * **加贈額度**：不支援退款
    * **已使用額度**：不支援退款

    如需退款請聯絡客服說明情況。
  </Accordion>

  <Accordion title="我充值了 \$600，為什麼只加贈了 12% 而不是分段計算？">
    **加贈比例是按充值總額區間計算的，不是分段累加。**

    **正確計算**：

    * 充值 \$600 屬於 \$500 ≤ X \< \$1,000 區間
    * 加贈比例 12%
    * 加贈金額：\$600 × 12% = \$72
    * 實際到賬：\$672

    **不是分段計算**（錯誤方式）：
    ❌ 前 \$500 × 12% + 後 \$100 × 10%
  </Accordion>

  <Accordion title="如何申請開具發票？">
    **線上提交開票資料**：

    1. 登入 API易 網站後臺
    2. 點選頂部導航「提交開票」
    3. 填寫開票資料（最少需要：開票主體和稅號）
    4. 提交後等待 3-5 個工作日

    **線上開票表單**：`https://xinqikeji.feishu.cn/share/base/form/shrcns8TS3alZTN2Av1JfkOvmqh`
  </Accordion>
</AccordionGroup>
