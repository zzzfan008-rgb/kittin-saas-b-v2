# パスワードを忘れた場合は？

> メールによるリセット、カスタマーサポートなどを使って、APIYIアカウントのパスワードを再設定する方法

## クイックアンサー

メールアドレスで登録した場合は、ログインページでパスワードをリセットできます。メールアドレスを紐付けていない場合は、アカウントを復旧するために、ユーザー名、支払い履歴、または API Key を添えてサポートまでご連絡ください。

## オプション 1: メールでリセット

**メールアドレス**で登録した場合は、ご自身でパスワードをリセットできます:

<Steps>
  <Step title="ログインページを開く">
    APIYI のログインページにアクセスし、メールアドレスを入力します。
  </Step>

  <Step title="リセットリンクをトリガーする">
    メールアドレスを入力して任意のパスワードを入力し、ログインをクリックします。ログインに失敗すると、ページに**赤い「パスワードをリセット」リンク**が表示されます。
  </Step>

  <Step title="パスワードをリセットをクリックする">
    赤い「パスワードをリセット」テキストをクリックします。システムはパスワード回復ページにリダイレクトし、登録済みのメールアドレスにリセットリンクを送信します。
  </Step>

  <Step title="リセットを完了する">
    メール受信箱でリセットメールを確認し、リンクをクリックして新しいパスワードを設定します。
  </Step>
</Steps>

<Info>
  リセットメールが届かない場合は、迷惑メールフォルダを確認するか、数分待ってからもう一度お試しください。
</Info>

## オプション 2: サポートに連絡

**メールをまだ紐付けていない**、または登録メールアドレスを忘れた場合は、サポートに連絡してご相談ください。本人確認のため、以下のいずれか1つをご提供ください:

<CardGroup cols={3}>
  <Card title="ユーザー名" icon="user">
    覚えていれば、APIYI のユーザー名をご提供ください
  </Card>

  <Card title="支払い記録" icon="receipt">
    Alipay または WeChat の支払い領収書のスクリーンショットをご提供ください
  </Card>

  <Card title="API Key" icon="key">
    ご利用いただいた API Key をご提供ください
  </Card>
</CardGroup>

<Warning>
  上記のうち少なくとも1つをご提供ください。サポートが本人確認を行い、アカウントの復旧をお手伝いします。
</Warning>

## オプション 3: 回復後にメールアドレスを紐付ける

ログインに成功した後は、アカウント設定でメールアドレスを紐付けることを**強く推奨**します。

<Steps>
  <Step title="アカウント設定に移動">
    ログイン後、「アカウントセンター」ページに移動します。
  </Step>

  <Step title="メールアドレスを紐付ける">
    メールアドレスの紐付けオプションを見つけ、メールアドレスを入力して、認証を完了します。
  </Step>

  <Step title="パスワードを設定する">
    メールアドレスを紐付けた後、安全なパスワードを設定します。その後は、今後メールアドレスとパスワードでログインできます。
  </Step>
</Steps>

<Tip>
  メールアドレスを紐付けると、サポートに連絡しなくても、いつでもメールでパスワードをリセットまたは変更できます。
</Tip>

## よくある質問

<AccordionGroup>
  <Accordion title="赤い「パスワードをリセット」リンクはどこにありますか？">
    ログインページでメールアドレスと誤ったパスワードを入力し、ログインをクリックしてください。ログイン失敗のメッセージが表示されると、赤色のクリック可能な「パスワードをリセット」というテキストが表示されます。
  </Accordion>

  <Accordion title="サードパーティ（GitHub/WeChat）経由でログインしました。どうすればよいですか？">
    サードパーティログインを利用しているユーザーは、対応するプラットフォームから直接ログインしてください。サードパーティログインで問題が発生している場合は、[GitHubログインの問題](/ja/faq/github-bindng-bindng-error)を参照するか、サポートにお問い合わせください。
  </Accordion>

  <Accordion title="メールアドレスを紐付ける必要があるのはなぜですか？">
    メールアドレスを紐付けると、次のことができます。

    * いつでもメールでパスワードをリセットする
    * メールアドレスとパスワードを予備のログイン方法として使用する
    * 重要なアカウント通知を受け取る
  </Accordion>
</AccordionGroup>
