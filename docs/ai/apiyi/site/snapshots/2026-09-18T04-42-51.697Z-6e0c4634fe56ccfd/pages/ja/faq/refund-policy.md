# APIYIの返金ポリシーとは？

> APIYIの返金条件、手続き、手数料、請求書関連の考慮事項について学びます

## クイックアンサー

APIYIはチャージ後30日間の**理由を問わない返金ポリシー**を提供しています。未使用の残高は元の支払い方法に返金されます。プロモーションのボーナスクレジットは返金額から差し引かれます。WeChatとAlipayの返金には手数料がかかりませんが、その他の支払い方法では1%の処理手数料が発生します。また、2026年8月2日以降、アカウント残高には**365日間の有効期限**があります。期限切れの残高は返金も復元もされません。詳しくは[残高の有効期限](/ja/faq/recharge-promotions)をご覧ください。

<Info>
  **返金の約束**: すべてのお客様に安心してチャージしていただきたいと考えています。30日以内であれば、満足いただけない場合でもいつでも返金を申請できます。未使用の残高は全額返金されます。
</Info>

## 返金手数料

| 支払方法             | 返金手数料   | 備考                              |
| ---------------- | ------- | ------------------------------- |
| **WeChat Pay**   | ✅ 手数料なし | WeChatウォレットまたは連携済みの銀行カードに返金されます |
| **Alipay**       | ✅ 手数料なし | Alipayアカウントに返金されます              |
| **銀行振込**         | 1% 手数料  | 会社の銀行口座に返金されます                  |
| **USDT**         | 1% 手数料  | 元のウォレットアドレスに返金されます              |
| **Wise**         | 1% 手数料  | Wiseアカウントに返金されます                |
| **Mercury Bank** | 1% 手数料  | Mercuryアカウントに返金されます             |
| **PayPal**       | 1% 手数料  | PayPalアカウントに返金されます              |

<Tip>
  **手数料を節約**: WeChatまたはAlipayでチャージすると、手数料無料の返金をご利用いただけます。
</Tip>

## 返金計算

返金額 = チャージ額 - 使用額 - ボーナスクレジット - 手数料（該当する場合）

**例**:

\$100をチャージし、\$10のプロモーションボーナスを受け取り、\$30を使用した場合:

* チャージ額: \$100
* ボーナスクレジット（差し引き）: \$10
* 使用額: \$30
* 返金可能額: \$100 - \$30 - \$10 = **\$60**
* WeChat/Alipayで支払った場合: 実際の返金額 **\$60**（手数料なし）
* PayPalで支払った場合: 実際の返金額 \$60 - \$60 × 1% = **\$59.40**

## 返金手続き

<Info>
  **無条件返金の約束**: 条件（30日以内かつ請求書未発行）を満たしている限り、ご希望のチャネルで返金処理を行います。理由は不要です。
</Info>

<Steps>
  <Step title="任意のサポートチャネルからご連絡ください">
    以下のいずれかのチャネルからご連絡ください。**アカウントのユーザー名**を記載し、「返金」と明記してください。

    * **法人WeChat**: [ここに追加](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec)
    * **Telegram**: `@apiyi001`
    * **メール**: [support@apiyi.com](mailto:support@apiyi.com) （件名: 「返金依頼 + ユーザー名」）
  </Step>

  <Step title="サポートが返金額を確認します">
    当チームがアカウントの残高、チャージ履歴、ボーナスクレジット、請求書の発行状況を確認し、返金可能額を算出してご案内します。
  </Step>

  <Step title="返金は元の支払い方法に戻されます">
    確認後、返金は元の支払い方法に送金されます。処理時間は次のとおりです:

    * **WeChat/Alipay**: 通常1～3営業日
    * **銀行振込/その他の方法**: 通常3～7営業日
  </Step>
</Steps>

<Warning>
  **先にご連絡いただかずに決済異議申し立てを行わないでください**: サポートチームに先にご連絡いただかずに、決済チャネル（WeChat、Alipay、PayPal、クレジットカードなど）を通じて苦情、異議申し立て、またはチャージバックを開始された場合、返金申請は**処理いたしません**。また、当社はさらなる対応を行う権利を留保します。

  対象となる返金はすべて対応いたします。まずは上記のサポートチャネルからご連絡ください。
</Warning>

## よくある質問

<AccordionGroup>
  <Accordion title="30日後に返金を受けられますか？">
    通常、30日後の返金はできません。最初の30日以内にサービスをお試しいただくことをおすすめします。特別な事情がある場合は、サポートに連絡して対応方法をご相談ください。
  </Accordion>

  <Accordion title="期限切れの残高は返金できますか？">
    **いいえ。** 2026年8月2日より、アカウント残高には365日間の有効期間があり、期限切れの残高は **返金、復元、変換なし** で自動的に失効します。

    新たにチャージすると、利用可能な残高全体の有効期間が1年にリセットされるため、通常のチャージと利用のサイクルには影響しません。30日間の返金期間は有効期間より短いため、両者は矛盾しません。詳細なルールは [残高の有効期間](/ja/faq/recharge-promotions) をご覧ください。
  </Accordion>

  <Accordion title="ボーナスクレジットが差し引かれるのはなぜですか？">
    プロモーションのボーナスクレジットは無料特典であり、実際にお支払いいただいた金額には含まれません。返金の対象は実際のお支払いの未使用分のみなので、ボーナスクレジットは差し引かれます。ボーナスの詳細は [チャージ特典](/ja/faq/recharge-promotions) をご覧ください。
  </Accordion>

  <Accordion title="請求書発行後に返金を受けられないのはなぜですか？（中国本土）">
    中国本土では、VAT請求書が発行されると税務処理が関わるため、返金は不可能になります。返金が必要ないと確信できるまで、請求書の発行依頼は控えることをおすすめします。
  </Accordion>

  <Accordion title="返金後もアカウントは引き続き使用できますか？">
    はい。返金されるのは未使用の残高のみで、アカウントと API keys はそのまま有効です。サービスの利用を続ける必要があるときに、再度チャージするだけで構いません。
  </Accordion>

  <Accordion title="一部返金を依頼できますか？">
    はい。残高の一部だけを返金することもできます。返金したい金額をサポートにお知らせください。
  </Accordion>

  <Accordion title="返金にはどのくらいかかりますか？">
    WeChat と Alipay の返金は通常1〜3営業日で届きます。銀行振込、USDT、Wise、PayPal の返金は通常3〜7営業日かかります。この期間を過ぎても返金が届かない場合は、サポートに連絡して状況を確認してください。
  </Accordion>
</AccordionGroup>
