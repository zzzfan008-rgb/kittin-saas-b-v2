# APIYI はどの支払い方法に対応していますか？

> APIYI は、セルフサービスのオンラインチャージ（WeChat / Alipay / USDT / Stripe 海外クレジットカード）と、手動チャージ（PayPal / Wise / Mercury Bank / 銀行振込）に対応しています。請求書は、当社の中国法人または米国法人を通じて発行できます。

## クイックアンサー

APIYI は現在、2つのカテゴリに分けて **7種類の主要な支払い方法** をサポートしています。

* **🟢 セルフサービスのオンラインチャージ**（リアルタイム反映）：**WeChat, Alipay, USDT, Stripe（海外クレジットカード）**
* **🛠️ 手動チャージ**（送金後にサポートが反映）：**PayPal, Wise, Mercury Bank, 法人銀行電信送金**

請求書は、**中国の法人（VAT 増値税発票）** または **米国の法人（PDF請求書）** のいずれからでも発行でき、国内・海外の両方の会計フローに対応しています。

| **Alipay**       | サイト内オンライン、**Alipay International** と海外アカウントに対応                                               | セルフサービス                             | 中国 + 海外の中国系ユーザー |
| **USDT**         | サイト内オンライン、暗号資産、**世界中のユーザー**、手数料は送金1回あたり約 **2 USDT**（ご自身でTRONエネルギーを用意すると安くなります。高額でも同じ定額手数料です） | セルフサービス                             | 世界中 / 暗号資産ユーザー  |
| **Stripe**       | サイト内オンライン、**外貨建てクレジットカード**（リアルタイム、3D Secure）；**1回の取引につき最低 \$50**                             | セルフサービス                             | 海外の個人 / 企業      |

| **Wise**         | 指定のWiseアカウントへ送金                                                                              | Wiseの詳細についてはサポートへお問い合わせ、手動チャージ      | 越境の個人 / 企業      |

## 🟢 セルフサービスのオンラインチャージ（リアルタイム）

<CardGroup cols={2}>
  <Card title="WeChat Pay" icon="wechat" iconType="brands">
    コンソール内でワンクリックのQRコード決済です。**中国本土のユーザーのみ。** 国内の個人向けでは最速の選択肢です。
  </Card>

  <Card title="Alipay" icon="alipay" iconType="brands">
    サイト内でオンライン決済できます。**Alipay International** と海外アカウントの両方に対応しており、グローバルな中国語ユーザーにやさしいです。
  </Card>

  <Card title="USDT (Crypto)" icon="bitcoin">
    サイト内でオンライン決済でき、**世界中から利用可能、24時間365日**です。手数料は**送金1回あたり約2 USDT**で、金額にかかわらず一律です。さらに手数料を抑えるには、ご自身のTRON energyをご用意ください。

    対応ネットワーク: **TRC20**（推奨）、**Solana**、およびその他の主要チェーンです。
  </Card>

  <Card title="Stripe (Foreign Credit Cards)" icon="credit-card">
    サイト内でオンライン決済でき、**外貨建てクレジットカード**、**即時反映**に対応し、3D Secure によって保護されています。会社 / ご本人 / 学校名義で発行された実名カードをご利用ください。

    ⚠️ **\$50 の最低金額**: チャージ額が \$50 未満の場合、Stripe はご利用いただけません。

    📖 [最低額変更のお知らせ](/en/live/2026-07/stripe-minimum-topup-50) · [公開のお知らせ](/en/live/2026-05/stripe-payment-launch)
  </Card>
</CardGroup>

<Warning>
  **Stripe のセキュリティに関するお知らせ**: Stripe は厳格なリスク管理を実施しており、**安全でないカードや実名でないカードは即座に拒否されます**。**不正決済**（盗難カード、チャージバック、不正テスト）を試みたアカウントは**利用停止**されます。他人名義のカードやテスト用カードを使って再試行しないでください。
</Warning>

## 🛠️ 手動チャージ（サポートによる反映）

<CardGroup cols={2}>
  <Card title="PayPal" icon="paypal" iconType="brands">
    サポートが案内する PayPal ハンドルへ送金します。**手数料は約 6% で、ユーザー負担**（つまり、送金額で手数料もまかなう必要があります）。少額の海外個人チャージに最適です。
  </Card>

  <Card title="Wise (formerly TransferWise)" icon="globe">
    サポートが案内する Wise アカウントへ送金します。為替が透明で、国際送金の着金も速く、**フリーランスや海外企業**に最適です。
  </Card>

  <Card title="Mercury Bank (recommended for overseas companies)" icon="landmark">
    サポートが案内する銀行口座 / 支払いリンクへ送金します。**通常は手数料なし**で、着金時に **請求書が自動発行** されるため、海外企業にとって最も会計処理しやすい方法です。
  </Card>

  <Card title="Corporate Wire (Bank Transfer)" icon="building">
    **中国法人のお客様**、または **中国の取引先経由で支払う海外事業者** 向けです（下記の越境フローを参照してください）。
  </Card>
</CardGroup>

<Tip>
  **手動チャージのワークフロー**: 1️⃣ 受取口座についてサポートに連絡する → 2️⃣ 送金を完了する → 3️⃣ 証明 / ハッシュ / 支払いリンクのスクリーンショットを送る → 4️⃣ サポートが確認して、APIYI の残高に反映します。
</Tip>

## 🌏 越境 / 海外顧客のワークフロー

中国の取引パートナーを通じて支払いが必要な海外のお客様（例: **ロシア、中央アジア、東南アジア**）向けに、完全なコンプライアンス準拠のワークフローをご用意しています:

<Steps>
  <Step title="中国法人と契約を締結">
    海外のお客様は、APIYI の **中国法人** と調達 / サービス契約を締結し、金額、通貨、および支払い条件を明記します。
  </Step>

  <Step title="法人口座へ銀行送金">
    法人送金（**SWIFT / 越境 CNY / RUB 決済**）により、当社指定の法人口座へサービス料をお支払いください。
  </Step>

  <Step title="APIYI 残高へ手動反映">
    経理が支払いを確認した後、**APIYI コンソール残高を手動でチャージ**し、すぐに API 呼び出しにご利用いただけるようにします。
  </Step>

  <Step title="請求書 / インボイスの発行">
    **中国 VAT 請求書**（中国法人）または **US Invoice**（米国法人）を発行できます。お客様の現地の会計および精算ワークフローに合う方をお選びください。
  </Step>
</Steps>

<Info>
  **法人構成に関する注意**: APIYI は **中国企業 + 米国企業** の二法人構成で運営しています。お客様の所在地と経理上の要件に応じて、請求書発行を柔軟に調整できます。正確な請求名義と税IDについてはサポートまでお問い合わせください。
</Info>

## 🧾 請求書発行

| 請求書の種類                 | 発行主体 | おすすめ用途                    |
| ---------------------- | ---- | ------------------------- |
| **中国VAT請求書 (普通 / 专用)** | 中国企業 | 中国国内企業の精算                 |
| **米国請求書 (PDF)**        | 米国企業 | 海外事業者 / 国境をまたぐ取引 / 為替管理市場 |

<Tip>
  **請求書のヒント**: 請求書が必要な場合は、**支払い時点（またはそれ以前）** にサポートへお知らせください。請求先名 / 税ID / メールアドレスを共有いただければ、一度にまとめて発行できます。遅い依頼は跨期処理が必要になる場合があります。
</Tip>

## チャージ特典

さまざまなチャネルと金額を組み合わせることで、**初回チャージボーナス / 段階的チャージ特典** が適用され、実質最大約80%の割引になります。

📖 参照: [チャージ特典](/ja/faq/recharge-promotions)

## よくある質問

<AccordionGroup>
  <Accordion title="Stripe の支払い / クレジットカードが拒否されました — どうすればよいですか？">
    Stripe のリスク管理は厳格です。考えられる原因は次のとおりです:

    * **チャージ金額が \$50 未満です** (Stripe は1回の取引あたり \$50 以上でのみ選択できます)
    * **CNY建てのカードを使用しました** (このチャネルでは Stripe は CNY カードを受け付けません)
    * カードが **実名登録されていない** か、あなた / あなたの会社 / あなたの学校名義ではありません
    * **3D Secure 認証に失敗しました**
    * カードまたはアカウントが上流のリスク管理でフラグ付けされています

    別のチャネル (Alipay International / Wise / Mercury Bank) に切り替えるか、適法な実名登録済みの海外クレジットカードを使用してください。**他人のカードやテストカードで再試行しないでください — 繰り返し試行するとアカウントレベルのリスク管理が発動します。**
  </Accordion>

  <Accordion title="法人送金の着金確認にはどれくらいかかりますか？">
    通常、手動チャージの場合は**当営業日中**です (銀行の決済状況によります — 一部の国際間 SWIFT 送金は T+1 から T+3 かかる場合があります)。送金後に**証憑をサポートへ先回りで送付**していただくと、チャージが早くなります。
  </Accordion>

  <Accordion title="USDT にはどのネットワークを使えばよいですか？">
    **TRC20** (TRON) を推奨します — 手数料が低く、着金が速いです。**Solana** やその他の主要チェーンにも対応しています。**必ずサポートまたはサイト内のチャージページで最新の受取アドレスを取得してください** — 第三者ソースは絶対に信用しないでください。
  </Accordion>

  <Accordion title="中国のVAT専用発票 (专用发票) を発行できますか？">
    はい。当社の中国法人は、**一般VAT発票 (普通发票)** と **専用VAT発票 (专用发票)** の両方に対応しています。お支払い時に、**会社名、納税者番号、銀行名 + 口座、登記住所 / 電話番号** をサポートへお送りください。
  </Accordion>

  <Accordion title="クレジットカードや Alipay をお持ちでないロシア / 中央アジアのお客様？">
    法人送金フローをご利用ください: 当社の中国法人と契約を締結し、SWIFT (または現地の取引パートナー) 経由で CNY / USD / RUB を法人口座へ送金してください。着金後、**APIYI コンソールの残高へ手動でチャージ**し、中国のVAT発票または米国請求書を発行します。手続きの詳細はサポートへお問い合わせください。
  </Accordion>

  <Accordion title="他の暗号資産も対応していますか？ BTC / ETH ですか？">
    標準では **USDT** (TRC20 / Solana) をサポートしています。USDC、BTC、ETH、その他の token については、個別審査のためサポートへお問い合わせください。
  </Accordion>

  <Accordion title="チャージの最小 / 最大額はいくらですか？">
    **最小チャージ額:**

    * **Stripe**: **\$50** 1回の取引あたり (2026/7/28 に Stripe の手数料および決済構造の都合で変更されました。これ未満ではこのチャネルは利用できません)
    * **その他のすべての支払い方法**: 1回の取引あたり **\$5**、変更なし

    **最大額**: チャネル全体で共通の厳格な上限はありませんが、PayPal / Stripe には上流側の1回あたりのリスク閾値があります。**高額 (≥ ¥10,000 / \$1,500)** の場合は、法人送金または Mercury Bank をご利用いただくことをおすすめします — 手数料が少なく、請求書発行も簡単です。
  </Accordion>
</AccordionGroup>
