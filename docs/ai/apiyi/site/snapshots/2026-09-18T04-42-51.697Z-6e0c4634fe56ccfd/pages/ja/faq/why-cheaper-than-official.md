# APIYIはなぜ公式レートより安くできるのですか？

> 一部のモデルが公式の一覧価格より安いのは、使用量ベースの一括購入とベンダーの流通提携によるもので、制限されたモデルや逆解析したエンドポイントではありません。さらに、価格だけではなぜ判断基準として不十分なのか、そして不自然に安い見積もりの実質コストをどう見極めるかも説明します。

## 簡潔な回答

**それは、モデル自体に手を加えることではなく、取扱量と流通によって生まれます。**

モデル提供元、とくに中国系の提供元は、開発者に届くための流通チャネルを必要とします。安定したトラフィックを持つチャネルとして、APIYI は一定の取扱量または最低利用額を約束する代わりに、限定的な仕入れ割引を受け、その割引をそのまま還元しています。当社は提供元から**広告費も有料掲載も一切受け取っておらず**、価格は上流で当社が支払う金額だけで決まります。

明確にすると、**すべてのモデルが公式より安いわけではありません。** OpenAI、Anthropic、Google は実質的に再販割引を提供していないため、それらのモデルは公式料金と**同額**で設定されており、割引分は代わりに[チャージ特典](/ja/faq/official-pricing-advantages)から生まれます。実際に公式定価を下回るモデルは、主に中国系モデルと一部のパートナーグループです。

## 割引はどこから来るのか

<CardGroup cols={3}>
  <Card title="ボリュームと支出のコミットメント" icon="chart-column">
    集約されたトラフィックにより、ボリュームまたは最低支出をコミットし、段階的な仕入れ価格を得られます — これが主な源泉です
  </Card>

  <Card title="流通パートナーシップ" icon="handshake">
    ベンダーはチャネル割引をマーケティング予算ではなく流通コストとして扱います。広告費はいただかないため、割引は価格表にそのまま反映されます
  </Card>

  <Card title="共通の運営コスト" icon="layers">
    1つのゲートウェイ、1つの課金システム、そして1組のドキュメントで、あらゆるモデルに対応できます — ベンダーごとに個別に立ち上げるより、限界費用ははるかに低くなります
  </Card>
</CardGroup>

<Note>
  **有料掲載はありません。** モデルが掲載されるかどうか、またどの位置に表示されるかは、当社のテスト結果とユーザー需要によって決まります — ベンダーは掲載順位を買えません。まさにそれが、価格を説明可能にしている理由です。
</Note>

## ベンダーの視点から見た、ルーターの価値

ベンダーがチャネルディスカウントを提供するのには理由があります。アグリゲーションゲートウェイは、自社で対応するよりも高くつく作業を引き受けるからです。

<CardGroup cols={2}>
  <Card title="増分開発者へのリーチ" icon="users">
    小規模チームや個人開発者は、単一ベンダーのためだけに登録し、カードを追加し、コンプライアンス対応を済ませることはしません。チャネルが、彼らにとって唯一の入口であることも少なくありません
  </Card>

  <Card title="最前線サポートの吸収" icon="headset">
    連携に関する質問、パラメータのデバッグ、障害の切り分けは当社が引き受けます。ベンダーは、少数の小口アカウント向けにサポート要員を抱える必要がありません
  </Card>

  <Card title="実際のフィードバックループ" icon="microscope">
    私たちは新しいモデルを、パラメータ互換性、課金の意味づけ、フィールドの完全性、安定性で検証し、その結果を上流に戻します。ばらばらのチケットよりも、はるかに実行に移しやすい知見になります
  </Card>

  <Card title="決済の簡素化" icon="file-text">
    1つの契約主体と1通の請求書で、何千もの小さな国際送金に置き換えられます
  </Card>

  <Card title="公平な競争条件" icon="scale">
    新しいモデルは、既存のモデルと正面から比較できる位置に置かれます。開発者に選ばれることは、どんな広告費よりも強い証明です
  </Card>

  <Card title="コールドスタートのボリューム" icon="rocket">
    立ち上げたばかりのモデルに最も必要なのは実トラフィックであり、チャネルは実用的な負荷とフィードバックをすぐに提供できます
  </Card>
</CardGroup>

<Tip>
  言い換えると、ディスカウントは**パートナーシップを通じて獲得する**ものであり、モデル品質を削り取って得るものではありません。同じモデル、同じ上流です。
</Tip>

## 価格は唯一の変数ではありません: 極端に安い見積もりが招くもの

当社より安い見積もりは実際にあります。安いこと自体が問題ではありません。問題なのは、その安さがどこから来ているかです。よくある出どころとそのリスクは次のとおりです。

| 安い価格の出どころ                                    | 典型的な兆候                                      | 想定されるコスト                                    |
| -------------------------------------------- | ------------------------------------------- | ------------------------------------------- |
| リバースエンジニアリングされた / Webエンドポイントを API としてラップしたもの | 適切な使用量フィールドがない、キャッシュ課金がない、一部のパラメータが黙って無視される | 上流側が変わった瞬間に壊れ、デバッグする方法も公式レベルの課金記録もありません     |
| 共有アカウントや出自不明のアカウント                           | 入手経路の説明がないまま公式コストを大きく下回る価格                  | アカウントはいつでも停止される可能性があり、コンプライアンス上のリスクもあり得ます   |
| サイレントなダウングレード                                | モデル A として課金されているのに、より小さいモデルや抑えた設定で提供される     | 出力が期待に届かず、証明もしにくいです                         |
| お客様のデータの収益化                                  | 無料またはほぼ無料で、ログ保持についてあいまいな説明しかない              | リクエスト内容が保持されたり、学習に使われたりする可能性があります           |
| 集客目的の価格設定                                    | 仕入れコストを明らかに下回り、大きな前払いを促す                    | 後から値上げされたり、制限がかかったり、前払いしたクレジットを使い切れなかったりします |

<Warning>
  **データセキュリティを非常に重視してください。** 価格は交渉できますが、データ漏えいは元に戻せません。導入前に、プロバイダーのログ保持ポリシー、コンテンツが学習に使われるかどうか、秘密保持契約に署名してくれるかを確認してください。特に、コード、顧客記録、社内文書を送る場合は重要です。
</Warning>

### 見積もりを自分で検証する方法

<Steps>
  <Step title="まず小さく始める — 先に数量交渉をしない">
    大きな前払いに踏み切る前に、最小限のチャージをエンドツーエンドで一度試してください。
  </Step>

  <Step title="使用量フィールドを公式の意味と照合する">
    返ってきた token 数とキャッシュヒットフィールドをベンダー側のものと比較してください。フィールドが欠けている、または 0 のままになっている場合は、通常、公式の直接接続ではありません。
  </Step>

  <Step title="呼び出しが成功するかだけでなく、安定性も確認する">
    継続的な負荷をかけ、その後は長いコンテキストウィンドウと高い同時実行数での挙動、最初の token までの時間やテールレイテンシも確認してください。
  </Step>

  <Step title="データ保持について確認する">
    ログをどれくらい保持するのか、誰がアクセスできるのか、コンテンツは学習に使われるのか、NDA に署名してもらえるのかを確認してください。
  </Step>

  <Step title="責任を持てる書面を確認する">
    請求書を発行できるか、契約を結べるか、返金と補償のルールを明示できるかを確認してください。何か壊れたとき、頼れるのはここです。
  </Step>
</Steps>

価格はあくまで一項目です。長期的なコストは、何か問題が起きたときに何が起こるかで決まります:

  </Card>

## では、APIYI は実際にどのように価格を設定しているのでしょうか

<AccordionGroup>
  <Accordion title="OpenAI / Claude / Gemini などの海外主要モデル">
    公式料金と**同額**で設定されています。これらのベンダーには再販マージンがないため、同額が通常の下限です。公式コストを下回る見積もりは、たいてい非公式ソースを示しています。割引の原資は**チャージボーナス**で、一部のグループではそれに加えてさらに追加割引が上乗せされます。
  </Accordion>

  <Accordion title="中国系モデルおよび一部の提携グループ">
    これらは**公式リストより安く**設定できる場合があります。正確な差額は現在の仕入れ条件によって異なります。コンソールの Model Pricing ページが正式な基準です。
  </Accordion>

  <Accordion title="RMB 建ての価格設定">
    スポットFXに連動しない**固定の 1:7 レート**で換算するため、予算管理と照合が予測しやすくなります。[RMB がクレジットにどう換算されるか](/ja/faq/rmb-to-computing-power)をご覧ください。
  </Accordion>

  <Accordion title="どこでも最安値だと主張するわけではありません">
    私たちが約束するのは、**すべての価格に説明がつき、すべての割引の出どころを追跡できる**ことです。説明できない安値に合わせることはしません。
  </Accordion>
</AccordionGroup>

## よくある質問

<AccordionGroup>
  <Accordion title="私より安い見積もりを出されたのですが、それは優位性がないということですか？">
    その相手が単により良い仕入れ条件を持っているだけかもしれませんし、それはごく普通のことです。あるいは、調達先が異なるだけかもしれません。上記の検証手順を実施してください — 利用項目がすべて埋まっているか、負荷がかかったときにどう持ちこたえるか、保持条件には何と書かれているかを確認してください。すべて問題なければ、それは正当な価格差です。調達元を説明できない場合、その差額はリスクプレミアムです。
  </Accordion>

  <Accordion title="価格が安いとモデルの品質も低いのですか？">
    いいえ。私たちは公式エンドポイントへ直接転送しているだけで、スロットリングも、モデルの差し替えも、設定の引き下げもありません。出力はご自身で確認できます。詳細は[APIYI の企業向けサービスは信頼できますか](/ja/faq/enterprise-trust)をご覧ください。
  </Accordion>

  <Accordion title="割引が一夜にして消えることはありますか？">
    価格は上流の仕入れ条件に従っており、変更があればサイトで告知します。アカウントにすでにあるクレジットには影響しません — 前払い残高を使い切るために一方的に値上げすることはありません。
  </Accordion>

  <Accordion title="なぜすべてのモデルを公式より安くしないのですか？">
    提供できないものを偽らないからです。海外の大手ベンダーは再販マージンをほとんど残さないため、無理に価格を下げると、安定性とデータセキュリティを犠牲にして別の調達経路へ切り替えることになります。私たちはむしろそこでは同水準を維持し、その節約分をチャージ特典に回したいと考えています。
  </Accordion>

  <Accordion title="では、どうやって収益を得ているのですか？">
    仕入れ価格と販売価格の適切な差に加え、規模拡大で生まれる運営効率によって成り立っています。いくつかのモデルは、提供を継続するためだけにほぼゼロマージンで運用しており、私たちはそれを受け入れています — 1つのモデルのマージンよりも、完全なモデルラインナップのほうが私たちには重要だからです。
  </Accordion>
</AccordionGroup>
