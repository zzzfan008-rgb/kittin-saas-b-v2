# エージェント・ミニプログラムにはアルゴリズム届出が必要ですか?

> 大規模モデル上に構築されたミニプログラムは、通常アルゴリズム届出が必要です。このページでは、一般的な手順と実践的なヒントを紹介します。

## 簡単な回答

お使いのミニプログラムが大規模モデルの機能を基盤としている場合、通常はプラットフォームおよび規制要件に従ってアルゴリズムの届出を完了する必要があります。手続きと必要資料は公開されており、公式手順に沿って申請を提出できます。

必要な資料がそろっていれば、提出後の審査は通常 1〜2 営業日以内に完了します。

## 実践的なヒント

* **準備**: ミニプログラムの機能、モデルタイプ、データソース、ユーザーシナリオを文書化します
* **提出**: 公式テンプレートを使ってアルゴリズムの説明を記入し、適切なプラットフォームから提出します
* **審査**: 通常は1～2営業日で完了します
* **承認後**: プラットフォームのルールに従って、ミニプログラム内に必要な届出ラベルを追加します

<Tip>
  **ヒント**: 届出で難しいのはコードではなく、文書とシナリオ説明です。わかりやすい文章にすると、たいてい一度でスムーズに審査が通ります。
</Tip>

## 開発者でなくても大丈夫

提出作業は、主に手順と文章作成です。

* 仕事の大半は、流れを整えることと文章を書くことです
* コーディングは全体の中では小さな部分です
* 資料がそろえば、残りはエンジニアが仕上げられます
