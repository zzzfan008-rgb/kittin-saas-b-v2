# エージェント提携はどう申し込めますか？友達を招待して還元を受けられますか？

> APIYI には組み込みの紹介還元プログラムがあります。友達を招待すると、継続的に 5% のクレジット還元を受けられます。別途のエージェント申請は不要です。

## Quick Answer

APIYIには、別個の「エージェント提携」申請チャネルはありません。代わりに、すべてのユーザーが組み込みの**紹介還元**プログラムを利用できます。アカウントセンターから招待リンク / 招待コードを取得すれば、招待に成功した友だち1人ごとに**継続的な5%のクレジット還元**を受け取れます。

<Info>
  還元は**プラットフォーム内クレジット**（API利用残高）として付与されます。**引き出すことはできず**、ご自身のAPI呼び出しにのみ使用できます。
</Info>

## 招待リンクと招待コードはどこで確認できますか？

<Steps>
  <Step title="アカウントセンターを開く">
    サインイン後、[アカウントセンター / プロフィール](https://api.apiyi.com/account/profile) ページへ直接移動します
  </Step>

  <Step title="Locate the &#x22;推广信息 / Referral Info&#x22; section">
    ページ上の **紹介情報** カードまでスクロールすると、**招待コード** と **招待リンク** ボタンが表示されます
  </Step>

  <Step title="招待リンク / 招待コードをコピー">
    クリックしてコピーし、友だちに共有します
  </Step>
</Steps>

## リベートはどのように付与され、消費されますか？

招待したユーザーが**チャージを完了**するたびに、あなたの取り分が**報酬（奖励金）残高**に加算されます。その後、**報酬を手動でメインのAPI残高へ振り替え**ることができ、振り替え後は通常のAPI呼び出しに利用できます。

<Info>
  **リベート履歴を確認する**: **Logs** ページで **Type = 奖励金划转 (Reward Transfer)** で絞り込むと、各リベートの記録とその発生元、金額を確認できます。
</Info>

## 招待リンクがサインアップ時に紹介関係を失った場合はどうなりますか？

一部のブラウザ、プライベート/シークレットモード、またはリダイレクトされるフローでは、招待リンクの cookie/parameter が失われることがあり、その結果、紹介関係が自動的に確立されない場合があります。その場合は、友だちが手動で紐付けできます:

<Steps>
  <Step title="登録ページを開く">
    友だちに APIYI のサインアップページへアクセスしてもらいます
  </Step>

  <Step title="Fill in the &#x22;Invite Code&#x22; field">
    登録フォームの **Invite Code** フィールドに、あなたの個人用招待コードを入力します
  </Step>

  <Step title="登録を完了する">
    フォームを送信してください — 紹介関係は正常に確立されます
  </Step>
</Steps>

<Tip>
  **Recommendation**: 招待リンクを共有する際は、予備として **招待コードもあわせて送ってください**。リンクの parameter が失われても、関係を引き続き紐付けられます。招待コードなしで登録が完了した後は、紹介関係を **遡って追加することはできません**。
</Tip>

## よくある質問

<AccordionGroup>
  <Accordion title="リベートのクレジットは現金として引き出せますか？">
    **いいえ。** リベートは **プラットフォーム内の API 利用クレジット** として付与され、ご自身の利用にのみ使えます。銀行口座、WeChat、Alipay へ引き出すことはできません。
  </Accordion>

  <Accordion title="リベートは一度だけですか、それとも継続的に発生しますか？">
    **継続的に発生します。** 紹介関係が有効である限り、招待したユーザーによるすべてのチャージと利用に対して、現在のレートで 5% のリベートが継続してアカウントに付与されます。
  </Accordion>

  <Accordion title="以前に登録した友達は 10% と 5% のどちらで精算されますか？">
    精算は常に **現在のルール** に従います。**2026年5月15日 (UTC+8)** 以降に発生したリベートは 5% で計算されます。それ以前にすでに支払われたリベートは、遡って調整されません。
  </Accordion>

  <Accordion title="法人ユーザーはより高いリベート率を受けられますか？">
    **いいえ。** 法人ユーザーと個人ユーザーのどちらも一律で **5%** です。段階別や個別のレートは提供していません。
  </Accordion>

  <Accordion title="自分のサブアカウントを招待してリベートを稼ぐことはできますか？">
    **自己招待は厳しく禁止されています。** プラットフォームは、**IP、デバイスフィンガープリント、支払い情報** を含む複数のシグナルを使って不審なアカウントを識別します。検出された場合:

    * プラットフォームは **紹介関係を一方的に解除する権利を留保します**
    * すでに支払われた不審なリベートは **回収または凍結される場合があります**
    * 悪質なケースではアカウントのリスク管理措置が発動されることがあります

    紹介リベートプログラムは、本物の新規ユーザー獲得に報いるためのものです。いかなる不正利用も行わないでください。
  </Accordion>

  <Accordion title="招待したユーザーとリベート履歴はどのように確認できますか？">
    招待したユーザーのデータを確認するには、[アカウントセンター](https://api.apiyi.com/account/profile) を開いてください。取引ごとのリベート項目は、**ログ** ページで **種類 = 奖励金划转 (報奨金振替)** で絞り込んで確認できます。
  </Accordion>
</AccordionGroup>
