# APIYIから買う理由は？ 公式料金と同じ

> テキストモデルの料金は公式料金と同じですが、最大20%のチャージ特典（実質約17%オフ）がグループ割引と併用でき、さらに公式リレー、キャッシュ課金対応、海外アカウント不要です

## 簡潔な回答

**テキスト（マルチモーダルを含む）モデルの単価は確かに公式レートと同じ**ですが、実際のコストはもっと低くなります。チャージボーナスは最大20%まであり（実質的に定価の約83%を支払うのと同じ、つまり17%オフ）、さらに特定のモデルグループで5%オフなどのグループ別割引と併用できます。そのため、合算すると公式価格のおよそ79%まで下がります。加えて、公式の直接ルーティング、キャッシュ課金対応、全モデル共通の1つのキー、そして海外アカウントやクレジットカード不要といった利点は、直接利用ではまとめて得ることはできません。

## 節約はどこから生まれるか

<Card title="💰 同じ価格 ≠ 同じコスト" icon="calculator">
  APIYI は単価でごまかしません。テキストモデルは公式のリスト価格で課金されるため、課金は透明で、飾り気のない形を保ちます。実際の節約は **チャージボーナス** と **グループ割引** から生まれ、これらは互いに併用できます。
</Card>

### 1. 段階的チャージボーナス（最大20％）

1回の \$100 以上のチャージで、10%-20% の段階的なボーナスが付与されます。

| 1回のチャージ額               | ボーナス    | 実質割引率      |
| ---------------------- | ------- | ---------- |
| \$100 ≤ X \< \$500     | 10%     | 約9%オフ      |
| \$500 ≤ X \< \$1,000   | 12%     | 約11%オフ     |
| \$1,000 ≤ X \< \$3,000 | 15%     | 約13%オフ     |
| X ≥ \$3,000            | **20%** | **約17%オフ** |

20%ボーナスを例にすると、\$3,000 をチャージして \$3,600 分のクレジットを受け取れます。実質的には公式価格の 1/1.2 ≈ 83.3% を支払うことになり、つまり約17%の割引です。

### 2. グループ割引（併用可）

一部のモデルグループには追加割引があります。たとえば、専用グループの一部では **5%オフ** が適用され、この **併用** はチャージボーナスと組み合わせられます。

* 20%のチャージボーナス → 実質コストは公式価格の約83.3%
* さらに5%オフのグループを併用 → 83.3% × 0.95 ≈ **公式価格の約79%**

## テキストモデルの課金方法

テキストモデルは token の使用量に応じて課金されます:

```text theme={null}
Cost per request = input tokens × input price + output tokens × output price
```

各モデルの入力/出力単価は公式レートと同じです — [モデル料金の概要](/ja/pricing)をご覧ください。

<Note>
  **画像と動画モデル** は使用ごとに課金されます（token ごとではありません）。正確な価格はコンソールの「モデル料金」ページでご確認ください。チャージ特典はこれらのモデルにも適用されます。
</Note>

  <Card title="停止リスクを低減" icon="shield">

## よくある質問

<AccordionGroup>
  <Accordion title="なぜ単純に単価を公式レートより安く設定しないのですか？">
    公式の単価に合わせることは、**公式の直ルーティングと透明性のある課金**を保証するものです。公式コストを下回る価格は、たいてい品質の低いリレーや逆解析された経路を示唆します。APIYIでは、その差額を代わりにチャージボーナスに回しています。レートは公開され、すべてのお客様で同一であり、実際の負担額は直契約よりもなお低くなります。
  </Accordion>

  <Accordion title="ボーナスクレジットは元本と何か違いがありますか？">
    利用上の違いはありません。ボーナスクレジットも元本と同様に、**サイト全体で利用でき**、テキスト、画像、動画、その他すべてのモデルに適用され、元本と同じ有効期限ルールに従います（支払い日から365日、追加のチャージで更新）。唯一の違いは、ボーナスクレジットが返金不可である点です。[残高の有効期限](/ja/faq/recharge-promotions)をご覧ください。
  </Accordion>

  <Accordion title="画像モデルと動画モデルはどのように課金されますか？">
    画像モデルと動画モデルは、tokenごとではなく、**利用ごとに課金**されます（1回の生成ごとに固定料金）。正確なレートはコンソールにログインして「Model Pricing」ページでご確認ください。チャージボーナスはこれらのコストも下げます。
  </Accordion>

  <Accordion title="チャージボーナスとグループ割引はどのように重なりますか？">
    それぞれ独立に適用され、併用できます:

    * **20%のチャージボーナス**: \$3,000をチャージすると、\$3,600が付与されます — 実質約17%割引
    * **5%オフのグループ**: そのグループ内の呼び出しは95%で課金されます
    * **併用時**: 83.3% × 0.95 ≈ 79% となり、全体では公式価格の約79%になります
  </Accordion>
</AccordionGroup>
