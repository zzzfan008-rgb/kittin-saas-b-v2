# 利用可能なチャージプロモーションは何ですか？

> 初回ボーナス、段階別ボーナス、法人振込ボーナス、エンタープライズサービス、請求書サービスを含む、APIYIのチャージプロモーションについて説明します

## チャージ特典の概要

APIYIでは、AIサービスをより手頃な価格でご利用いただけるよう、さまざまなチャージ特典をご用意しています。

<Card title="💰 特典のハイライト" icon="star">
  * 🎁 **初回ボーナス**: 初回のチャージで \$1-2 のボーナスを獲得できます
  * 📊 **段階的ボーナス**: チャージ額が高いほど、ボーナスも高くなります (10%-20%)
  * ⏰ **365日有効**: チャージした残高は支払日から1年間有効で、新たなチャージを行うとリセットされます
  * 🌐 **全対応**: プラットフォーム上のすべてのモデルで有効です
  * 🏢 **請求書対応**: オンライン決済と法人振込の両方で請求書発行に対応しています
</Card>

## 段階別チャージボーナス

チャージ金額が大きいほど、ボーナス率も高くなります。高額チャージボーナスは特別な申請なしでプラットフォームにより自動的に付与されます。

<Info>
  **ポリシー更新**: 新しいチャージボーナスポリシーは2025年12月18日より有効です
</Info>

### ボーナス率一覧

| チャージ金額（1回の取引）          | ボーナス %  | 実際の残高付与倍率 | チャージ例                     |
| ---------------------- | ------- | --------- | ------------------------- |
| \$100 ≤ X \< \$500     | **10%** | 残高の1.1×   | \$100をチャージ → \$110を付与     |
| \$500 ≤ X \< \$1,000   | **12%** | 残高の1.12×  | \$560をチャージ → \$600を付与     |
| \$1,000 ≤ X \< \$3,000 | **15%** | 残高の1.15×  | \$1,000をチャージ → \$1,150を付与 |
| X ≥ \$3,000            | **20%** | 残高の1.2×   | \$3,000をチャージ → \$3,600を付与 |

<Note>
  **重要**: ボーナス率は累計金額ではなく、**1回のチャージ金額**に基づきます
</Note>

### ボーナスの付与

<Info>
  **自動付与**: \$100以上のチャージに対する段階別ボーナスは、手動申請なしでプラットフォームにより自動認識・付与されます。ボーナスは、当社の財務チームが「システム自動化 + 人手レビュー」ワークフローを用いて、毎日23:00 - 01:00 (UTC+8)の間に付与します。**翌日を確認するだけでボーナスが届きます。追加の問い合わせは不要です。**
</Info>

### 法人振込ボーナス

法人振込も段階別ボーナスの対象です。
すべての支払い方法（法人振込を含む）がチャージボーナスキャンペーンに参加できます。

**例**: 20,000 CNYの法人振込の場合、
入金確認後、20,000 CNYのチャージと15%のボーナス付与が完了します。

### 計算例

    **実際の残高付与額**: \$700 + \$84 = **\$784** (約1.12×)
  </Tab>

  <Tab title="例3: \$1,500をチャージ">
    **チャージ金額**: \$1,500

    **対象範囲**: \$1,000 ≤ X \< \$3,000

    **ボーナス率**: 15%

    **ボーナス金額**: \$1,500 × 15% = \$225

    **実際の残高付与額**: \$1,500 + \$225 = **\$1,725** (1.15×)
  </Tab>

  <Tab title="例4: \$5,000をチャージ">

### 適用モデル

チャージした残高は、テキスト生成、画像生成、動画生成、音声サービス、音声生成、およびその他すべての種類を含む、**APIYI のすべてのモデル**で有効です。

<Card title="完全なモデル一覧を表示" icon="list" href="/ja/api-capabilities/model-info">
  APIYI でサポートされているすべてのモデルと詳細な料金を表示します
</Card>

### 残高の有効期間（2026-08-02 から有効）

アカウント残高は支払い日から **365日** 有効です。ルールは次のとおりです。

| 項目                    | ルール                                               |
| --------------------- | ------------------------------------------------- |
| **有効期間**              | チャージしたクレジットは支払い日から365日有効です                        |
| **新規チャージ**            | **利用可能な残高全体** の有効期間が再び1年にリセットされます                 |
| **ボーナス／プロモーションクレジット** | チャージしたクレジットと同じルールです。365日有効で、新規チャージにより同様にリセットされます  |
| **既存の残高**             | 過去のチャージ日にはさかのぼらず、適用開始日（2026-08-02）から365日として計算されます |
| **有効期限切れ時**           | 期限切れの残高は自動的に失効します。返金、復元、変換はありません                  |
| **有効期限の確認**           | 現在の残高の有効期限はコンソールに表示されます                           |

<Warning>
  **実際の利用量に合わせてチャージしてください**: 定期的にチャージして消費している限り、新しいチャージのたびに残高全体が1年にリセットされるため、実運用では影響はありません。ただし、1年以内にクレジットを使い切る見込みがない場合は、より高いボーナス階層に到達するためだけに過剰にチャージしないでください。期限切れの残高は返金も復元もされません。

  公式の文言は [利用規約](https://cf-index.apiyi.com/terms) と [返金ポリシー](https://cf-index.apiyi.com/refund) に記載されています。
</Warning>

## 請求書サービス

APIYIは法人ユーザー向けに、財務精算のニーズに対応するための正式な請求書（VAT普通請求書およびVAT特別請求書）の発行をサポートしています。

### 請求書の申請方法

<Steps>
  <Step title="チャージを完了">
    オンライン決済または法人振込でチャージを完了します
  </Step>

  <Step title="オンラインで請求書情報を提出">
    **APIYIダッシュボード** → **トップナビゲーション** → **請求書を提出** にログインします

    請求書情報を入力します（最低限必要な情報：会社名と納税者番号）

    **オンライン請求書フォーム**: `https://xinqikeji.feishu.cn/share/base/form/shrcns8TS3alZTN2Av1JfkOvmqh`
  </Step>

  <Step title="発行を待つ">
    請求書は3〜5営業日以内に発行され、ご提供いただいたメールアドレスに送信されます
  </Step>
</Steps>

<Info>
  **対応する請求書の種類**:

  * VAT普通請求書（小規模納税者向け）
  * VAT特別請求書（一般納税者向け、税控除対象）
</Info>

<Note>
  **請求書処理時間**: 請求書は通常、依頼を受領してから3〜5営業日以内に発行されます。月末や四半期末などの繁忙期には、多少遅れる場合があります。
</Note>

## よくある質問

<AccordionGroup>
  <Accordion title="初回ボーナスは段階式ボーナスと併用できますか？">
    **はい、併用できます！**

    例：700ドルを初回チャージする場合

    * 初回ボーナス：1ドル（教育ユーザーの場合は2ドル）
    * 段階式ボーナス：700ドル × 12% = 84ドル
    * 合計クレジット：700ドル + 1ドル + 84ドル = **785ドル**（一般ユーザー）

    初回ボーナスを受け取るには、[企業版WeChatでお問い合わせください](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec)！
  </Accordion>

  <Accordion title="チャージが残高に反映されるまでどのくらいかかりますか？">
    **反映時間：**

    * **オンライン決済**：即時（チャージ金額は直ちに残高へ反映）
    * **段階式ボーナス**：財務チーム（システムによる自動処理 + 人による確認）が毎日23:00～01:00（UTC+8）の間に反映 — 翌日に確認可能
    * **初回ボーナス**：[企業版WeChatでお問い合わせ](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec)後に手動で追加、通常1営業日以内

    **法人振込**：入金確認後、1営業日以内に処理
  </Accordion>

  <Accordion title="初回ボーナスがまだ反映されない場合はどうすればよいですか？">
    [企業版WeChatでお問い合わせ](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec)いただき、確認してください。
    サポートが初回ボーナスの付与処理をサポートします。
  </Accordion>

  <Accordion title="最低チャージ額はありますか？">
    **最低限度額はありません**が、以下を推奨します。

    * 頻繁なチャージを避けるため、10ドル以上のチャージ
    * 段階式ボーナスの特典を受けるため、100ドル以上のチャージ
    * より高いボーナス率を得るため、1回あたりのチャージ額を大きくする — 365日間の有効期間を考慮してください
  </Accordion>

  <Accordion title="チャージした残高に有効期限はありますか？">
    **はい。** 2026年8月2日より、アカウント残高には**365日間の有効期間**が適用されます。

    * チャージしたクレジットは、支払日から1年間有効です
    * **新たにチャージすると、利用可能な残高全体の有効期限が1年にリセットされる**ため、定期的なチャージと利用のサイクルには影響しません
    * ボーナスおよびプロモーションクレジットにも同じルールが適用されます
    * 既存の残高は、2026-08-02から365日間として計算されます
    * 期限切れの残高は自動的に失効します — 返金、復元、変換はできません

    現在の残高の有効期限はコンソールに表示されます。詳細な規約：[利用規約](https://cf-index.apiyi.com/terms)および[返金ポリシー](https://cf-index.apiyi.com/refund)をご確認ください。
  </Accordion>

  <Accordion title="チャージした残高は返金できますか？">
    プラットフォームポリシーに基づきます。

    * **未使用のチャージ残高**：特別な事情がある場合は返金可能
    * **ボーナス残高**：返金不可
    * **使用済み残高**：返金不可

    返金が必要な場合は、カスタマーサービスまでお問い合わせください。
  </Accordion>

  <Accordion title="600ドルをチャージしたのに、段階式計算ではなく12%のボーナスしか付かないのはなぜですか？">
    **ボーナス率は累積した区分ごとではなく、チャージ総額の段階に基づいて計算されます。**

    **正しい計算：**

    * 600ドルのチャージは、500ドル ≤ X \< 1,000ドルの段階に該当
    * ボーナス率：12%
    * ボーナス額：600ドル × 12% = 72ドル
    * 実際のクレジット：672ドル

    **区分分割ではありません**（誤り）：
    ❌ 最初の500ドル × 12% + 次の100ドル × 10%
  </Accordion>

  <Accordion title="請求書を申請するにはどうすればよいですか？">
    **オンラインで請求書情報を提出：**

    1. APIYIダッシュボードにログイン
    2. 上部ナビゲーションで「請求書を提出」をクリック
    3. 請求書情報を入力（最低限必要な情報：会社名と納税者番号）
    4. 提出後、3～5営業日お待ちください

    **オンライン請求書フォーム**：`https://xinqikeji.feishu.cn/share/base/form/shrcns8TS3alZTN2Av1JfkOvmqh`
  </Accordion>
</AccordionGroup>
