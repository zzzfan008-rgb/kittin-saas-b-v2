# 法人顧客はどのようにチャージしますか？

> APIYIの法人顧客には、法人銀行振込の利用を推奨しています。1,000 CNYを超える単回チャージに適しており、契約は任意で、基本契約の締結にも対応しています。現在、与信枠には対応しておらず、統一されたプリペイドモデルを採用しています。VAT請求書（1%税率）および請求書に対応しています。

## クイックアンサー

**法人のお客様は、企業間銀行振込でのチャージをおすすめします。1回あたりのチャージ額が1,000 CNY以上の場合に適しています。**

手順は簡単です。公式の法人向け WeChat サポートに連絡して、入金先の会社情報と銀行口座情報を受け取る → 振込を完了する → APIYI が入金確認後、指定のアカウントに手動で金額を反映します。**増値税発票（1%税率）** と **請求書** の発行に対応しています。

<Info>
  法人振込は、APIYI の複数あるチャージ方法の1つです。すべてのチャージ方法（WeChat、Alipay、USDT、Stripe など）の全体像については、[APIYI はどのような支払い方法に対応していますか？](/ja/faq/payment-methods) をご覧ください。
</Info>

## 法人振込を使うタイミング

<CardGroup cols={2}>
  <Card title="適用金額" icon="coins">
    法人振込は、**1回のチャージが1,000 CNY以上**のお客様におすすめです。経費精算と請求書発行がしやすくなります。
  </Card>

  <Card title="契約は後から追加可能" icon="file-pen">
    契約は**最初から必要ではありません**。必要になった時点で後から締結できます。締結は双方で合意した契約テンプレートに基づいて行われ、両者を守るための**税務コンプライアンス**対応です。
  </Card>
</CardGroup>

<Tip>
  **契約について**: 契約は、双方で合意した標準テンプレートの内容に基づいてのみ締結され、税務コンプライアンス要件を満たすためのものです。これはお客様とAPIYIの双方を守るためのものであり、追加の障壁ではありません。少額利用のお客様や契約が不要なお客様は、直接法人振込の手続きをご利用いただけます。
</Tip>

## 法人振込の手順

<Steps>
  <Step title="公式企業WeChatサポートにお問い合わせください">
    公式企業WeChatチャネル（本サイトのサポートと**同じ入口**）からご連絡いただき、法人振込によるチャージをご希望の旨をお知らせください。
  </Step>

  <Step title="受取会社名と銀行情報を受け取る">
    サポートが当社の**受取会社名**と**銀行口座情報**をご案内します。
  </Step>

  <Step title="銀行振込を完了する">
    指定口座へ振込を完了してください。送金メモには**ユーザー名を記載しても構いません**し、**記載しなくても問題ありません**。入金前に、連絡いただいたお客様に**送金元の会社情報と金額を確認**いたします。
  </Step>

  <Step title="プラットフォームが手動でアカウントに入金する">
    APIYIが資金を受領後、**手動でチャージ**を行い、金額をお客様の**ご指定のアカウント**へ反映します。これで残高はAPI呼び出しに利用できる状態になります。
  </Step>
</Steps>

<Warning>
  **資金安全の注意**: 当社の法人アカウント情報は**公式企業WeChatサポートチャネルでのみ取得**してください。第三者が提供するいかなる「サポート」や受取口座も信用しないでください。資金損失を避けるためです。
</Warning>

## 契約締結および郵送プロセス

法人向けチャージでは、**事前の契約締結は必要ありません**。契約が必要なエンタープライズ顧客は、**基本契約**を一度締結するだけで、以後のチャージで**契約を再度締結する必要はありません**。

<Steps>
  <Step title="基本契約テンプレートの取得">
    エンタープライズ向けのEnterprise WeChatサポートに連絡し、**基本契約テンプレート**を取得します。
  </Step>

  <Step title="法務レビューおよび修正">
    顧客の法務チームから契約条件について追加の意見
    （返金条項、請求書発行のタイミング、契約違反時の責任、管轄など）がある場合は、
    契約ファイルの**修正モードを直接有効にして内容を修正し、返送**できます。
    プラットフォーム側で確認し、最終確定します。
  </Step>

  <Step title="捺印および郵送">
    契約内容に誤りがないことを確認した後、APIYIが**捺印**を行い、
    顧客が指定した郵送先住所および担当者宛てに**SF Express**で発送します。
  </Step>
</Steps>

<Info>
  **契約の到着を待っている間もサービスを継続して利用できます**

  契約締結のプロセスには通常、約1か月かかります。
  この期間中も、\*\*オンラインチャージ（Alipay / WeChat）\*\*でサービスを継続して利用できます。
  契約締結を待つ必要はありません。法人アカウントからの振込にも対応しています。
</Info>

## 請求書と請求書発行

APIYI は **中国のVAT請求書** と **請求書** の両方の発行に対応しており、国内および海外の財務フローに適しています。

| 請求項目       | 詳細                              |
| ---------- | ------------------------------- |
| **請求書の種類** | VAT一般請求書またはVAT特別請求書             |
| **税率**     | 1%（小規模・零細企業向けの全国一律優遇税率）         |
| **請求書区分**  | 情報技術サービス料（デフォルト。特別な要件がある場合は要相談） |
| **請求書**    | 請求書発行に対応。海外企業 / 越境財務に適しています     |

### オンラインチャージの請求ルール

Webサイト経由でオンラインチャージした金額も請求できますが、**支払いチャネルによって異なります**。

| 支払いチャネル           | 請求方法                                      |
| ----------------- | ----------------------------------------- |
| **Alipay、WeChat** | VAT請求書を発行可能（Alipay と WeChat でチャージした商品に限る） |
| **Stripe**        | 請求書を発行                                    |
| **USDT**          | 請求対象外                                     |

<Tip>
  **請求のご案内**: 請求書 / Invoice が必要な場合は、**支払い時または支払い前までに**サポートへお知らせください。**宛名、税務ID、メールアドレス** をご提供いただければ、一度で完全に発行できます。後日の請求対応では、またぎ処理が発生する場合があります。
</Tip>

## よくあるご質問

<AccordionGroup>
  <Accordion title="法人振込を行うには契約を締結する必要がありますか？">
    いいえ。開始時は**契約なしで**法人振込の手続きを直接利用でき、必要に応じて後から契約を締結できます。契約は双方が合意した標準テンプレートに基づいて締結され、双方を保護するための税務コンプライアンス対策となります。
  </Accordion>

  <Accordion title="振込時にユーザー名を記載し忘れた場合はどうなりますか？">
    問題ありません。ユーザー名を記載するとアカウントとの照合が早くなりますが、記載がない場合でも、手動で残高に反映する前に、**振込元企業の情報と金額を**ご連絡いただいたお客様に確認します。
  </Accordion>

  <Accordion title="法人振込が残高に反映されるまでどのくらいかかりますか？">
    営業日であれば通常、**当日中**に手動で残高に反映されます（銀行の決済処理時間によって異なります。一部の海外送金ではT+1からT+3かかる場合があります）。振込後に**振込明細をサポートへ送信**していただくと、残高への反映が早くなります。
  </Accordion>

  <Accordion title="請求書の税率が1%なのはなぜですか？">
    1%は、**小規模企業および零細企業向けの全国一律の優遇税率**です。請求書の項目はデフォルトで**情報技術サービス料**に設定されています。特別なご要望がある場合は、サポートまでお問い合わせください。
  </Accordion>

  <Accordion title="オンラインチャージは請求書を発行できますか？">
    はい。ただし、チャネルによって異なります。**AlipayまたはWeChat**経由でチャージした商品には**VAT請求書**を発行できます。**Stripe**での支払いには**Invoice**を発行できます。**USDT**での支払いには**請求書を発行できません**。
  </Accordion>

  <Accordion title="クレジットラインや利用量に基づく月次請求には対応していますか？">
    現在は統一された**前払いモデル**（先にチャージしてから利用）を採用しています。
    クレジットラインおよび月次請求には**対応していません**。
    返金条件は緩やかですので、安心してチャージしてご利用ください。
    [返金ポリシー](/ja/faq/refund-policy)をご覧ください。
  </Accordion>

  <Accordion title="特別な場合、支払い前に請求書を発行できますか？">
    はい。**請求書を先に発行し、後から支払うことが特別な場合に可能**です。
    支払いの確認後に金額が残高へ反映されます。
    このようなご要望がある場合は、法人向けWeChatサポートまでお問い合わせのうえ、ご相談・ご確認ください。
  </Accordion>

  <Accordion title="海外法人とも提携できますか？">
    はい。**国内法人および海外法人のいずれとも提携できます**。
    サポートから法人アカウント情報をご案内できます。
  </Accordion>
</AccordionGroup>
