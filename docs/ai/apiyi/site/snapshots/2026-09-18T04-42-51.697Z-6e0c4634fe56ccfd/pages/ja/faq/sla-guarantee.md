# APIYI は SLA 保証を提供していますか?

> APIYI は実用的な SLA 保証を提供しています。大量の画像生成を利用するお客様には異常課金の補償を行い、当社側の問題による損失にはクレジットの再発行を行い、エンタープライズ契約には補償上限付きの SLA 条項を用意しています。

## クイックアンサー

**はい、ご要望に応じて利用可能です。**

客観的に見ても、今日のAI業界で99.99%のSLAを約束できるプロバイダーはありません（OpenAIやClaude自身でさえ同様です）。APIYIは守れない約束はしません。その代わり、実際に機能する**保証**を提供しています。具体的には、大量の画像生成をご利用のお客様向けの異常課金補償、当社側の問題による損失に対するクレジット再発行、そして法人契約で設定できる補償上限付きのSLA条項です。

## 正直な前提

<Info>
  **なぜ単に99.99%を約束しないのですか？**

  AI は急速に進化しており、上流のモデルは頻繁に更新され、レート制限がかかり、ポリシーも調整されます。**OpenAI と Claude 自身でさえ、99.99% の SLA を達成することはできません。** これは業界全体における客観的な事実です。

  達成できない数値を提示する代わりに、問題が発生した際にお客様が損失を被らないよう、**明確で実行可能な**保証メカニズムを提供することを優先しています。
</Info>

### 1. 大容量画像顧客向けの異常課金補償

**Nano Banana Pro / 2** や **GPT-Image-2.5 / 2 系列**などの画像モデルを利用する大容量顧客（**月間利用額 \$10,000 以上**で参加可能）に対して、**明らかに異常な課金**を補償します。

**例えば**、画像リクエストが**異常に長くタイムアウト**（300秒を超える場合など）したにもかかわらず、生成画像として**課金**された場合、このような明らかに異常な課金についてはログを確認して補償します。これにより、大容量顧客が理由なく支払うことのないようにします。

<Note>
  **これは例示的なシナリオであり、生成時間の保証ではありません。**

  **300秒以内に画像を生成できなければ補償する**という約束はできません。AI画像生成は上流サービスの変動の影響を受けるため、生成速度について確約することはできません。この保証の対象は、生成速度ではなく、**明らかに異常な課金による損失**です。正確な対象範囲については、サポートにお問い合わせください。
</Note>

### 2. 当社の問題による損失に対するクレジット再発行

損失が**明らかに当社に起因する**場合、当社は積極的に補償します。代表的なケースは次のとおりです。

* 顧客のクレジット損失を引き起こす**バックエンドサーバーの異常**
* データを返して課金もされた**画像モデルの異常なタイムアウト**

**当社の取り組み**：当社側の明確な問題が顧客に影響を与えた場合、**ログを一律にエクスポートし、影響範囲を確認して、影響を受けた顧客にクレジットを再発行**します。これにより、ユーザーが理由なく損失を被らないようにします。

<Warning>
  **帰属原則**：この再発行は、**明らかに当社に帰属する問題**（プラットフォームのバックエンド異常など）に適用されます。当社の**管理外の要因**（上流サービスによる公式コンテンツモデレーションブロックや上流サービスのレート制限など）については、それぞれの説明に従って処理されます（例えば、一部の上流サービスによるモデレーションブロックは、そもそも課金されません）。
</Warning>

### 3. エンタープライズ契約に規定されるSLA

エンタープライズ顧客については、具体的なSLA条件を**契約内に明示的に規定**できます。これには次の内容が含まれます。

* 対象範囲と可用性指標
* インシデントへの対応および解決までの時間枠
* **補償上限**などの条件

これにより、SLA保証と責任範囲が契約締結時に明確に定義されます。これは、**顧客とAPIYIの双方にとって明確なセーフガード**となります。

  </Accordion>

  <Accordion title="大量の画像利用顧客向けの異常課金補償に参加するにはどうすればよいですか？">
    この保証は、**Nano Banana Pro / 2やGPT-Image-2.5 / 2系列などの画像モデルを大量に利用するお客様**を対象としています。**月額利用額が\$10,000以上**のお客様が参加でき、明らかに異常な課金（たとえば、リクエストがタイムアウトしたにもかかわらず生成画像として課金されるケース）を補償します。**これは「300秒以内に画像を保証できなければ当社が支払う」という約束ではありません**—異常課金による損失を補償するものです。有効化および設定については、サポートまでお問い合わせください。

  </Accordion>

  </Accordion>
