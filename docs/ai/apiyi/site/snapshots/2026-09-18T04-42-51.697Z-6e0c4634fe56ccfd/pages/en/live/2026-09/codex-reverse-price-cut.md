# Codex_Reverse Group Discount Drops from 0.7x to 0.5x

> The billing discount on APIYI's Codex_Reverse group has been lowered from 0.7x to 0.5x, so models such as the GPT-5.6 series are billed at half the official price on this group. Token group and model names are unchanged, no code changes needed. This group runs on Codex reverse-engineered resources and suits personal learning and coding; production workloads should stay on the Default official-relay group.

**2026/9/4 23:57 (UTC+8)** · Price Update · OpenAI

💸 **The `Codex_Reverse` group discount has dropped from 0.7x to 0.5x, half the official price, effective now**

Background: `Codex_Reverse` is the Codex reverse-engineered economy channel, launched in July alongside the GPT-5.6 series at a default 0.7x discount, now lowered to 0.5x. Take `gpt-5.6-sol` as an example: the official price is \$4 input / \$20 output per 1M tokens, and this group now bills at \$2 / \$10. Existing `Codex_Reverse` tokens pick up the new discount automatically with no changes; model names, endpoints and the available model list stay the same.

The two groups keep their positioning, pick by need:

* `default` official-relay group: official OpenAI API resources, priced line for line with the official rate, recharge bonus on top; for production workloads and tasks that need stability
* `Codex_Reverse` group: Codex reverse-engineered resources at a 0.5x discount; for personal learning, coding and other cost-sensitive use, with availability tracking official Codex

See [What is the difference between the Codex, ClaudeCode and Default groups](/en/faq/codex-claudecode-default-groups) for group details, and the [GPT-5.6 Sol](/en/models/gpt-5-6-sol) page for pricing.
