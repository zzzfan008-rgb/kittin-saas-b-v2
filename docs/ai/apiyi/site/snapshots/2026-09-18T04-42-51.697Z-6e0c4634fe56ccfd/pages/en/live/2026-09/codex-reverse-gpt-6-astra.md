**2026/9/5 10:58 (UTC+8)** · New Model · OpenAI

🚀 **`gpt-6-astra` has joined the half-price `Codex_Reverse` group, billed at 0.5x the official rate**

Background: `gpt-6-astra` went live in the `default` / `svip` official-relay groups earlier today, and the `Codex_Reverse` group has now caught up. That group is the Codex reverse-engineered economy channel, billed at a 0.5x discount off the official price since 4 September, which for Astra means \$5 in / \$25 out per 1M tokens and \$0.50 cached reads (official: \$10 / \$50 / \$1). Existing `Codex_Reverse` tokens can call it directly; model name and endpoints are unchanged.

Two groups, pick by need, positioning unchanged:

* `Codex_Reverse` group: 0.5x discount, suited to Codex CLI coding, everyday chat in clients such as Cherry Studio, and agent setups such as OpenClaw, where call volume is high and cost matters; availability tracks official Codex
* `default` / `svip` official-relay groups: official OpenAI API resources, priced line for line with the official rate, recharge bonus on top; for production workloads and tasks that need stability
