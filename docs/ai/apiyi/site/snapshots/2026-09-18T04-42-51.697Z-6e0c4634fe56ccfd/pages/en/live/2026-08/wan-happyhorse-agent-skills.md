**2026/8/10 13:29 (UTC+8)** · Docs Update · Alibaba

📚 **Video Agent Skills, round two: Wan2.7 and HappyHorse**

Following Seedance 2.0, the docs center ships a shared Agent Skill for the two Alibaba video series — drop two files into Codex, Claude Code, or any coding agent and generate clips with a single sentence. One zero-dependency script covers all four modes — text-to-video, first-frame image-to-video, reference-to-video, and video editing — picking the right model ID from the assets you pass, switching series via `--model wan` / `happyhorse` on one shared `Wan&HappyHorse` group token; local images upload directly as base64 in our tests, no image host needed. See the [Wan2.7 / HappyHorse Video Agent Skill](/en/api-capabilities/wan/skills).
