# Why can't I use some models?

> APIYI model permission explanation, learn how to unlock all models and reasons for model unavailability

## User Groups and Model Permissions

### Automatic Upgrade for Recharged Users

After recharging, the platform periodically adjusts recharged users to **VIP** or **SVIP** groups, which unlocks all models.

<Info>
  **Automatic Group Adjustment**

  * Recharged users are automatically assigned to VIP/SVIP groups
  * VIP/SVIP users can use all available models on the platform
  * Group adjustment usually completes automatically after recharging
</Info>

### Manual Group Adjustment

## Specific Reasons for Model Unavailability

### 1. High-Price Model Restrictions

Most models can be used normally, but a few high-price models have restrictions for the `default` group:

* **Example**: `claude-opus-4-20250514` and other newly released high-end models
* **Reason**: Due to high cost, not yet open to default group
* **Solution**: Recharge to upgrade to VIP/SVIP group for access

<Warning>
  **High-Price Models**

  Some latest or high-end models are only available to paying users due to higher costs. Recharge to obtain full model access permissions.
</Warning>

### 2. Platform Discontinued Models

Some models are unavailable because official platforms have discontinued them:

* **Example**: `gpt-4.5-preview`
* **Reason**: OpenAI platform has discontinued this model
* **Result**: We also discontinued it accordingly and cannot continue providing service

<Info>
  **Model Discontinuation Explanation**

  When original AI service providers (such as OpenAI, Anthropic, etc.) discontinue a model, we also synchronously discontinue that model. This ensures service stability and consistency.
</Info>

## User Group Description

### Default Group

* **Permissions**: Basic model access
* **Restrictions**: Some high-price models unavailable
* **Applicable**: Free users and newly registered users

### VIP/SVIP Groups

* **Permissions**: All available model access
* **Advantages**: Including latest and high-end models
* **How to Obtain**: Automatic or manual adjustment after recharging
