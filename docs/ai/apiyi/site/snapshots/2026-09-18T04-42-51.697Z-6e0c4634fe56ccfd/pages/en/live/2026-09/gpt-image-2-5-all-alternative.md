💡 **`gpt-image-2-all` is already the latest `gpt-image-2.5-all` reverse route, a same-price option whenever the `-vip` series fluctuates**

`gpt-image-2-all` reverses ChatGPT web image generation, and the web app has been upgraded end to end to Images 2.5, so it already produces 2.5 images today; the new `gpt-image-2.5-all` name simply reflects that upgrade, and the two are identical in price and behavior and fully interchangeable. Like the `-vip` series it is billed per image at **\$0.03** through the same endpoints (`/v1/images/generations` and `/v1/images/edits`); the difference is that `-all` has no `size` parameter, so it cannot lock a size or output 4K, and the output size is driven by the prompt.

When the `gpt-image-2.5-vip` series is unstable, we suggest switching to `gpt-image-2.5-all`: its image quality and text rendering make it a high-quality choice, and many customers already run on it in production. For parameters, the prompt-to-resolution reference table and integration examples see the [GPT-Image-2.5-All overview](/en/api-capabilities/gpt-image-2-all/overview), and for model selection see the [official vs reverse comparison](/en/api-capabilities/gpt-image-2/vs-gpt-image-2-all).
