🆕 **Nano Banana stable model names (no `-preview`)** —— Google updated its official docs and released stable model names `gemini-3.1-flash-image` (Nano Banana 2) and `gemini-3-pro-image` (Nano Banana Pro). APIYI already supports them. The original `-preview` names still work, **pricing unchanged**, no code changes needed — both old and new names run fine. Google hasn't clarified whether the stable version differs from the preview in output quality or safety behavior, so feel free to test and share feedback.
