# Wan2.7 / Wan2.6 video models launched · Alibaba Cloud Tongyi Wanxiang official-relay · 98% of list by default

> APIYI has launched Alibaba Cloud's Tongyi Wanxiang Wan2.7 (main) + Wan2.6 (historical) video model series, covering four capabilities — text-to-video / image-to-video / reference-to-video / video edit. DashScope passthrough connects directly to Alibaba Cloud Bailian. Default price is 98% of list; with recharge bonuses, top-tier customers can reach ~82%. Token group must be set to Wan.

**2026/5/23 21:45 (UTC+8)** · New Model · Alibaba

🎬 **Wan2.7 / Wan2.6 video models launched · Alibaba Cloud Tongyi Wanxiang official-relay · 98% of list by default** — APIYI launches Alibaba Cloud's [Wan](/en/api-capabilities/wan/overview) (Tongyi Wanxiang) video models: **Wan2.7** ships four main capabilities (text-to-video `wan2.7-t2v` / image-to-video `wan2.7-i2v` with audio-driven lipsync / reference-to-video `wan2.7-r2v` / video edit `wan2.7-videoedit`); **Wan2.6** historical versions remain callable (including `wan2.6-r2v-flash`). **DashScope passthrough** connects directly to Alibaba Cloud Bailian — quality identical to official.

💰 **Pricing & promo**: Default = **98% of Alibaba Cloud list price** — group multiplier **0.14x** × **fixed 1:7 USD/CNY rate** = 0.98. Stacking the [recharge bonus promo](/en/faq/recharge-promotions), **top-tier customers** can drop to **\~81.6% (\~82% of list)** — 0.98 ÷ 1.2 ≈ 0.816.

⚙️ **Setup notes**:

* **Token group must be set to `Wan`** (shared with [HappyHorse](/en/api-capabilities/happyhorse/overview) — one token covers both series)
* **Billing mode**: recommend "usage-priority"; billed by the second
* **Failed = no charge**: tasks in `failed` state (unreachable media URL / sensitive prompt / upstream capacity etc.) are not billed — safe to retry

🎯 **Who it's for**: short-video production, e-commerce assets, digital-human voiceover, creative ops; teams that want a reliable Chinese video model without setting up cross-border infra to call Alibaba Cloud directly.
