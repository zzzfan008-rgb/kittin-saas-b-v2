🚀 **New `GrokOfficial` group — 0.8x multiplier, 20% off the Default group**

A direct official Grok route. Capabilities and call format are identical to the Default group; the group was split out purely to carry a discount — a **0.8x** multiplier (20% off the Default group price), which stacks with top-up bonuses.

`grok-4.5` and other models also work in Codex under this group. Select `GrokOfficial` when creating a token, or add the group to an existing Grok token — no code changes required.

See the [Grok model overview](/en/api-capabilities/grok/overview) to get started, and the [Codex CLI guide](/en/scenarios/programming/codex-cli) for Codex setup.
