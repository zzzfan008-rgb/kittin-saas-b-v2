# gpt-image-2-all Upstream Official Outage, Image Generation Unavailable

> gpt-image-2-all is temporarily unable to generate images due to an issue on OpenAI's side — the ChatGPT website is failing to generate images as well. Waiting for the official fix. Meanwhile gpt-image-2-vip (Codex route) and the official-relay gpt-image-2 both work; switch by changing the model name.

**2026/7/7 14:41 (UTC+8)** · Model Status · OpenAI

⚠️ **`gpt-image-2-all` upstream official outage — image generation temporarily unavailable**

The root cause is on OpenAI's side: the ChatGPT website is currently failing to generate images as well (see screenshot below). This is an official upstream issue, not an APIYI account-pool or channel problem, and service will recover automatically once the official fix lands.

In the meantime you can keep generating images (same Images API code — just change the `model` name; pick as needed, status below):

* `gpt-image-2-vip`: Codex route, seamless switch; somewhat slower, image quality is sometimes even better
* Official-relay `gpt-image-2`: stable and available

Thanks for your patience — we're tracking the official recovery and will post an update once it's restored.
