# Default $30 balance-alert emails disabled — opt in via dashboard

> The default $30 balance-alert email has been turned off platform-wide due to user feedback. To re-enable, configure it under Account → Notification Settings (email, WeCom, Feishu supported). Tech teams can also integrate the Balance Query API for self-managed monitoring.

**2026/4/28 15:59 (UTC+8)** · Service Notice

📣 **Default \$30 balance-alert emails disabled** — The platform-wide default that sent a \$30 balance-alert email to every account has been turned off after user feedback. To re-enable, head to Account → Notification Settings in the dashboard — email, WeCom, and Feishu channels are all supported. Tech teams are also welcome to integrate the `Balance Query API` for self-managed monitoring.

📖 Notification settings: [https://api.apiyi.com/account/notificationSettings](https://api.apiyi.com/account/notificationSettings)

📖 Balance Query API docs: [/en/api-capabilities/balance-query](/en/api-capabilities/balance-query)
