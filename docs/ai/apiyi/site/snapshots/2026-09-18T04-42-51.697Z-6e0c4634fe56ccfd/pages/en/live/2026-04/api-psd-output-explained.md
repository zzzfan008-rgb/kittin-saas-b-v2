# Insight: gpt-5.5 / gpt-image-2 official-relay API can't output PSD directly

> A customer asked whether the gpt-5.5 and gpt-image-2 official-relay APIs can output PSD files. The answer is no — API output is limited to the image itself (PNG/JPEG). ChatGPT web can hand you a PSD only because it's a multi-tool Agent wired to a Photoshop plugin. This also flags a product opportunity: auto-convert AI-generated images into layered, editable PSD files.

**2026/4/28 17:14 (UTC+8)** · Industry News · OpenAI

💡 **gpt-5.5 / gpt-image-2 API can't output PSD directly** — ChatGPT web can hand you a PSD only because it's a multi-tool Agent wired to a Photoshop plugin — that's a product capability, not a model output format. The underlying API for these models returns the image itself (PNG/JPEG) only. Also a product opportunity worth exploring: auto-convert AI-generated images into layered, editable PSD files.
