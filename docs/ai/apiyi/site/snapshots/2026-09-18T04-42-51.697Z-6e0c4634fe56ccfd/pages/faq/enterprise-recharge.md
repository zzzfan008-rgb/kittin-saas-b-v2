# 企业客户如何充值？

> API易企业客户推荐对公转账充值，单次 1000 元以上建议走对公，支持后补合同与框架合同签订。暂不支持授信额度，统一预充值，支持增值税发票（税率 1%）与 Invoice。

## 简短回答

**企业客户推荐使用对公转账（银行电汇）充值，建议单次充值金额在 1000 元以上的客户采用。**

流程很简单：通过官方企业微信客服获取我方收款公司与银行信息 → 完成转账 → API易 收到费用后人工充值入账到你指定的账号。支持开具\*\*增值税发票（税率 1%）\*\*及 **Invoice**。

<Info>
  对公充值是 API易 多种充值方式之一。完整的充值方式总览（微信、支付宝、USDT、Stripe 等）见 [APIYI 支持哪些充值方式？](/faq/payment-methods)。
</Info>

</Tip>

## 对公充值流程

<Steps>
  <Step title="联系官方企业微信客服">
    通过官方指定的企业微信联系方式（与本站客服为**同一入口**）联系我们，说明需要对公充值。
  </Step>

  <Step title="获取收款公司与银行信息">
    客服会提供我方的**转账公司名称**和**银行账户信息**。
  </Step>

  <Step title="完成银行转账">
    向指定账户完成转账。转账时**可以备注你的用户名**作为转账备注；**不备注也没有关系**，我们会与联系的客户**核对转账公司信息和金额**，确认后入账。
  </Step>

  <Step title="平台人工充值入账">
    API易 收到费用后，进行**人工充值**，将金额入账到你**指定的账号**，余额即可用于 API 调用。
  </Step>
</Steps>

<Warning>
  **资金安全提醒**：我方对公账户信息**仅通过官方企业微信客服渠道获取**，请勿相信任何第三方提供的"客服"或收款账户，避免资金损失。
</Warning>

## 合同签订与邮寄流程

对公充值**不强制先签合同**；确有合同需求的企业客户，
签订一次**框架合同**即可，后续充值**无需重复签合同**。

<Steps>
  <Step title="获取框架合同模板">
    联系企业微信客服获取**框架合同模板**。
  </Step>

  <Step title="法务审核与修订">
    客户法务如对条款有补充意见
    （如退还条款、发票开具时间、违约责任、管辖约定等），
    可直接**在合同文件上开启修订模式修改后发回**，
    平台确认后定稿。
  </Step>

  <Step title="盖章与邮寄">
    文本确认无误后，API易 完成**盖章**，并通过**顺丰**寄出至客户指定的收件地址和联系人。
  </Step>
</Steps>

<Info>
  **等待合同期间可以先使用**

  合同签订流程通常需要约一个月。
  期间可先通过\*\*在线充值（支付宝 / 微信）\*\*正常使用，
  无需等合同签订完成；对公账户转账也同步可用。
</Info>

## 发票与 Invoice 开具

API易 同时支持开具**中国增值税发票**和 **Invoice**，适配国内外财务流程。

| 开票项         | 说明                         |
| ----------- | -------------------------- |
| **发票类型**    | 增值税普通发票 或 增值税专用发票          |
| **税率**      | 1%（小微企业国家专属税率）             |
| **开票类目**    | 信息技术服务费（默认，有特殊需求可沟通）       |
| **Invoice** | 支持开具 Invoice，适配海外企业 / 跨境财务 |

### 网站在线充值的开票规则

在网站里自助充值的金额也均可以开票，但**按支付通道区分**：

| 支付通道       | 开票方式                        |
| ---------- | --------------------------- |
| **支付宝、微信** | 可开具**增值税发票**（仅限支付宝和微信充值的商品） |
| **Stripe** | 开具 **Invoice**              |
| **USDT**   | **不开票**                     |

<Tip>
  **开票提醒**：发票 / Invoice 需求请在**付款时或付款前**告知客服，并提供**抬头、税号、邮箱**等信息，方便一次开具完整；后补开票可能涉及跨账期处理。
</Tip>

## 常见问题

<AccordionGroup>
  <Accordion title="一定要签合同才能对公充值吗？">
    不需要。一开始可以**不用合同**直接走对公流程；需要时再后补签订。合同基于双方认可的标准模板内容签署，属于税务合规操作，对双方都是保障。
  </Accordion>

  <Accordion title="转账时忘了备注用户名怎么办？">
    没有关系。备注用户名只是方便快速对应账号；即使不备注，我们也会与联系的客户**核对转账公司信息和金额**，确认后人工入账。
  </Accordion>

  <Accordion title="对公转账多久到账？">
    工作日通常**当日内**人工充值到账（依银行清算时间，部分跨境电汇可能 T+1 \~ T+3）。转账后**主动把凭证发给客服**可加快入账。
  </Accordion>

  <Accordion title="发票税率为什么是 1%？">
    1% 是**小微企业国家专属税率**。开票类目默认为**信息技术服务费**，如有特殊需求可与客服沟通调整。
  </Accordion>

  <Accordion title="网站充值的钱可以开票吗？">
    可以，但按通道区分：**支付宝、微信**充值的商品可开**增值税发票**；**Stripe** 付款开具 **Invoice**；**USDT** 付款**不开票**。
  </Accordion>

  <Accordion title="支持授信额度或按用量月结吗？">
    目前统一采用**预充值模式**（先充值后消费），
    暂**不支持授信额度或月结**。
    退款条件宽松，可放心充值使用，
    详见[退款政策](/faq/refund-policy)。
  </Accordion>

  <Accordion title="特殊情况下可以先开票后付款吗？">
    可以。**特殊情况可先票后款**，
    额度在付款到账后充值入账。
    如有此类需求，请联系企业微信客服沟通确认。
  </Accordion>

  <Accordion title="海外公司主体可以合作吗？">
    可以。**国内主体和海外公司主体均可合作**，
    客服可提供对公账户信息。
  </Accordion>
</AccordionGroup>
