# gpt-image-2.5 两款 -vip 逆向仍缺资源暂不可用，官转与 -all 正常，gpt-image-2-vip 稳定服役

> 9 月 15 日状态同步：gpt-image-2.5-flare-vip 与 gpt-image-2.5-sunburst-vip 两款逆向目前仍缺资源、暂不可用。需要 GPT Image 2.5 请走官转 gpt-image-2.5-flare / sunburst（不带 -vip），官转按 token 用量计费而非按次，按文档接入即可；对 size 与 2K/4K 没有强控需求时，ChatGPT 网页版逆向 gpt-image-2.5-all 也正常可用。上一代 gpt-image-2-vip 正常服役、运行稳定。

**2026/9/15 17:09 (UTC+8)** · 模型状态 · OpenAI

⚠️ **`gpt-image-2.5-flare-vip` / `gpt-image-2.5-sunburst-vip` 两款逆向目前仍缺资源、暂不可用；`gpt-image-2-vip` 正常服役、运行稳定**

`gpt-image-2.5` 的 `-vip` 系列（Adobe Firefly 官逆，别名 `gpt-image-2.5-vip`）9/12 恢复后原厂侧资源再次吃紧，目前仍处于缺供状态，恢复后会在此更新。需要 GPT Image 2.5 的话，当前请走官转 `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst`（即不带 `-vip` 的模型名）——注意官转是**按 token 用量计费**，不是 `-vip` 的按次计费，参数与调用方式按 [GPT-Image-2.5 / 2 概览](/api-capabilities/gpt-image-2/overview) 接入即可。

各线路当前状态（按需自选）：

* 官转 `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst`：正常，按量计费，支持 `size` 锁尺寸与 2K / 4K 输出
* 逆向 `gpt-image-2.5-all`（ChatGPT 网页版出图，已是 Images 2.5）：正常，按次计费，无 `size` 参数、不能锁尺寸出 2K / 4K，对尺寸没有强控需求时可用
* 逆向 `gpt-image-2-vip`（上一代 GPT Image 2，Adobe Firefly）：正常服役，运行稳定，按次计费，支持 `size`，见 [GPT-Image-2-VIP 概览](/api-capabilities/gpt-image-2-vip/overview)
* 逆向 `gpt-image-2.5-flare-vip` / `gpt-image-2.5-sunburst-vip`：缺供中，暂不可用

感谢耐心等待，我们持续运维。
