# 网站瞬时 502：请重新发起调用

> 网站出现瞬时 502，系统会在 1 分钟内自动重启恢复。502 期间 API 请求无法接入、调用会失败但不计费，请重新发起调用；初步定位为异常流量叠加内存占用异常，确切原因仍在排查。

**2026/7/9 16:59 (UTC+8)** · 服务通知

⚠️ **网站偶发瞬时 502 · 系统 1 分钟内自动重启恢复，请重新发起调用**

初步定位为异常流量叠加内存占用异常，确切原因仍在排查。502 期间 API 请求无法接入、调用会失败（失败调用不计费），系统会在 1 分钟内自动重启恢复。

应对方式：

* API 侧：重新发起调用即可；建议客户端启用接口自动 retry 重试机制
* 网页端：刷新页面即可看到正常界面

感谢耐心等待，我们正加紧排查，持续运维。
