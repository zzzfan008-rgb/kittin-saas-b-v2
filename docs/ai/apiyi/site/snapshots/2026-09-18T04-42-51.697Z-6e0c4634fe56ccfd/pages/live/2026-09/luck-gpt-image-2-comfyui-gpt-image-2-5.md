# 社区节点更新：Luck GPT-Image 2 ComfyUI 节点已支持 gpt-image-2.5

> 社区作者 luckdvr 的 Comfyui-Luck-gpt2.0 于 2026-09-10 更新，官转节点模型下拉新增 gpt-image-2.5-flare 与 gpt-image-2.5-sunburst（含日期快照），quality 扩到六档，支持 16 张参考图与 mask 局部重绘；旧工作流不会自动切换模型。本站文档页已同步重写，补齐 vip 节点与三个提示词控制节点。

**2026/9/15 01:11 (UTC+8)** · 文档更新 · OpenAI

🧩 **社区 ComfyUI 节点 `Comfyui-Luck-gpt2.0` 已支持 `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst`，本站文档页已同步重写**

作者 luckdvr 于 2026-09-10 更新插件：官转节点 `Comfyui-Luck gpt-image-2` 的 `model (模型)` 下拉新增两款 2.5 与 `-2026-09-08` 日期快照，`quality` 扩到六档（新增 `xhigh` / `max`），支持最多 16 张参考图与 mask 局部重绘。节点名、ID 与默认模型 `gpt-image-2` 不变，**已有工作流不会自动切换**；切到 2.5 时别照搬 `quality`——2.5 的 `high` 对应旧版 `medium`，`max` 才对应旧版 `high`。

文档页此前停在 4 月的双节点版本，本次按插件现状整页重写：补齐 `gpt-image-2-vip` 节点、三个提示词控制节点（`gemini-3.5-flash` 默认）、五模型对照表、2.5 画质迁移对照与新示例工作流。仓库地址：`github.com/luckdvr/Comfyui-Luck-gpt2.0`。
