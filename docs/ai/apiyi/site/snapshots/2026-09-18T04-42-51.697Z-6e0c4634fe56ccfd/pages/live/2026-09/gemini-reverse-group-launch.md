# 新增 Gemini_Reverse 分组：Gemini 逆向资源，0.5 折扣

> API易 新增 Gemini_Reverse 令牌分组，资源来自 Gemini CLI 与 Antigravity 逆向通道，计费折扣 0.5。默认分组仍是 AI Studio 与 Vertex 官转。逆向分组价格低，适合个人学习与 Coding 编程；生产环境与稳定性要求高的任务请使用 Default 官转分组。

**2026/9/4 23:58 (UTC+8)** · 新模型 · Google

🚀 **新增 `Gemini_Reverse` 分组，Gemini 逆向资源经济通道，0.5 折扣**

背景说明：`Gemini_Reverse` 的资源来自 Gemini CLI 与 Antigravity 的逆向通道（Reverse Sources），计费折扣 0.5，即按官网价五折。以 `gemini-3.8-flash` 为例，官网价输入 \$0.75 / 输出 \$3.75 每百万 tokens，该分组按 \$0.375 / \$1.875 计费。在控制台新建令牌时选择 `Gemini_Reverse` 分组即可使用，模型名与端点与默认分组一致。

Gemini 系列现在有两个分组，按需自选：

* `default` 官转分组：AI Studio 与 Vertex 官方资源，与官网逐项同价；面向生产环境与稳定性要求高的任务
* `Gemini_Reverse` 分组：Gemini CLI / Antigravity 逆向资源，0.5 折扣；面向个人学习、Coding 编程等成本敏感场景，可用性随逆向来源波动

分组机制见 [什么是分组？用户分组与令牌分组解析](/faq/groups-explained)，模型计价见 [Gemini 3.8 Flash](/models/gemini-3-8-flash) 详情页。
