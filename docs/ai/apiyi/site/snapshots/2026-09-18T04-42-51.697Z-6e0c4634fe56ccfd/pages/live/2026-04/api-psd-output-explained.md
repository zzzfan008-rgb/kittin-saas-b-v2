# 经验分享：gpt-5.5 / gpt-image-2 官转 API 不能直接输出 PSD

> 客户问 gpt-5.5 和 gpt-image-2 官转 API 能否输出 PSD？答案是不行——API 输出仅限图片本身（PNG/JPEG）。ChatGPT 网页版能给 PSD 是因为它作为综合 Agent 联动了 Photoshop 插件。这里也提示一个产品机会：把 AI 生成图片自动转为分层可编辑 PSD，感兴趣的开发者可进一步研究。

**2026/4/28 17:14 (UTC+8)** · 行业快讯 · OpenAI

💡 **gpt-5.5 / gpt-image-2 官转 API 无法直接输出 PSD** —— ChatGPT 网页版能给 PSD 是因为它是综合 Agent + Photoshop 插件的产品能力，并非模型本身的输出格式。这两个模型的 API 输出仅限图片本身（PNG/JPEG）。也是一个产品机会：把 AI 生成图片自动转为分层可编辑 PSD 文件，感兴趣的开发者可进一步研究。
