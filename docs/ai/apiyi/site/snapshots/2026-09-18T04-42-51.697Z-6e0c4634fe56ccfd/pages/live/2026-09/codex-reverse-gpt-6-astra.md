# Codex_Reverse 半价分组上线 gpt-6-astra

**2026/9/5 10:58 (UTC+8)** · 新模型 · OpenAI

🚀 **`gpt-6-astra` 已加入 `Codex_Reverse` 半价分组，按官网价五折计费**

背景说明：`gpt-6-astra` 今天上午先在 `default` / `svip` 官转分组上线，现在 `Codex_Reverse` 分组也已补齐。该分组是 Codex 逆向资源经济通道，9 月 4 日起按官网价 0.5 折扣计费，套用到 Astra 就是输入 \$5 / 输出 \$25 每百万 tokens，缓存读取 \$0.50（官网价为 \$10 / \$50 / \$1）。已有 `Codex_Reverse` 令牌直接调用即可，模型名、端点不变。

两个分组按需自选，定位不变：

* `Codex_Reverse` 分组：0.5 折扣，适合 Codex CLI 编程、Cherry Studio 等客户端的日常聊天对话，以及 OpenClaw 等 Agent 场景这类调用量大、成本敏感的用法；可用性与官方 Codex 同步
* `default` / `svip` 官转分组：OpenAI API 官方资源，与官网逐项同价，充值加赠另算；面向生产环境与稳定性要求高的任务

分组差异与用法见 [Codex、ClaudeCode 和 Default 分组有什么区别](/faq/codex-claudecode-default-groups)，模型规格与基准见 [GPT-6 Astra 上线：OpenAI 新旗舰开放调用](/news/gpt-6-astra-launch)。
