# gpt-image-2-vip 恢复支持 4K 输出与 quality 参数

> 官逆模型 gpt-image-2-vip 重新支持 4K 输出与 quality 参数（low / medium / high），文生图与图片编辑两个 Images API 端点均可用，1K / 2K / 4K 常用尺寸直出，按次计费 $0.03 一次。调用请使用默认分组的按次计费令牌。

**2026/7/28 23:03 (UTC+8)** · 模型状态 · OpenAI

✅ **`gpt-image-2-vip` 恢复支持 4K 输出与 `quality` 参数**

`gpt-image-2-vip` 属官逆（逆向）线路，能力随 OpenAI 官方规则调整而起伏：4K 输出与 `quality` 此前一度不可用，本次两项一并恢复生效；`size` 自 [7/11 的播报](/live/2026-07/gpt-image-2-vip-size-restored)起持续生效。逆向线路**不承诺永久可用**，后续官方再调整仍可能失效。

当前已支持的调用方式：

* 文生图：`/v1/images/generations`
* 图片编辑：`/v1/images/edits`
* 模型名：`gpt-image-2-vip`
* 尺寸：1K / 2K / 4K 常用尺寸
* 画质：`quality` 支持 `low` / `medium` / `high`
* 计费：按次计费，\$0.03 一次

🔑 调用 `gpt-image-2-vip` 请使用**默认分组的按次计费令牌**。

感谢关注，我们持续跟进官方变化。
