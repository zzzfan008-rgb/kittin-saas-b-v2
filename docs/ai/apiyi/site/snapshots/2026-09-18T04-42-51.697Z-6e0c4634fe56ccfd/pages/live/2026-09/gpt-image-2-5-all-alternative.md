# gpt-image-2-all 已是 gpt-image-2.5-all 官逆，-vip 波动时同价可用

> gpt-image-2-all 背后已整体升级为 GPT Image 2.5，与新名字 gpt-image-2.5-all 同价同行为，源自 ChatGPT 网页版出图。当 gpt-image-2.5-vip 系列不稳定时，建议改用 gpt-image-2.5-all：同样 $0.03/张按次计费，虽然无法锁尺寸出 4K，但画质与文字还原都是高质量选择，已有大量客户在稳定使用。参数差异与接入方式见文档。

**2026/9/12 13:58 (UTC+8)** · 模型状态 · OpenAI

💡 **`gpt-image-2-all` 已经是最新的 `gpt-image-2.5-all` 官逆，`-vip` 系列波动时可同价改用**

`gpt-image-2-all` 逆向的是 ChatGPT 网页版出图，网页版已整体升级到 Images 2.5，所以它现在出的就是 2.5 的图；新名字 `gpt-image-2.5-all` 只是把升级写进模型名，两者同价、同行为、可互换。与 `-vip` 系列同为 **\$0.03/张** 按次计费，调用方式一致（`/v1/images/generations` 与 `/v1/images/edits`），差别在于 `-all` 没有 `size` 参数、无法锁尺寸出 4K，输出尺寸靠提示词描述。

当 `gpt-image-2.5-vip` 系列不稳定时，建议改用 `gpt-image-2.5-all`：画质与文字还原度都是高质量选择，已经有很多客户在稳定使用。具体参数、提示词到分辨率的对照表与接入示例请见 [GPT-Image-2.5-All 概览](/api-capabilities/gpt-image-2-all/overview)，选型对比见 [官转 vs 官逆对比](/api-capabilities/gpt-image-2/vs-gpt-image-2-all)。
