**2026/9/4 23:57 (UTC+8)** · 价格变动 · OpenAI

💸 **`Codex_Reverse` 分组折扣从 0.7 降到 0.5，按官网价五折计费，已生效**

背景说明：`Codex_Reverse` 是 Codex 逆向资源经济通道，7 月随 GPT-5.6 系列上线时默认 0.7 折扣，本次下调到 0.5。以 `gpt-5.6-sol` 为例，官网价输入 \$4 / 输出 \$20 每百万 tokens，该分组现在按 \$2 / \$10 计费。已用 `Codex_Reverse` 令牌的调用方无需任何改动，新折扣自动生效；模型名、端点与可用模型清单不变。

两个分组的定位不变，按需自选：

* `default` 官转分组：OpenAI API 官方资源，与官网逐项同价，充值加赠另算；面向生产环境与稳定性要求高的任务
* `Codex_Reverse` 分组：Codex 逆向资源，0.5 折扣；面向个人学习、Coding 编程等成本敏感场景，可用性与官方 Codex 同步
