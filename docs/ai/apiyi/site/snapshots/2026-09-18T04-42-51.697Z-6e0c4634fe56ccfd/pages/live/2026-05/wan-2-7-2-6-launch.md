# Wan2.7 / Wan2.6 视频模型上线 · 官转阿里云通义万相 · 默认 98 折

> API易 上线阿里云通义万相 Wan2.7（主力）+ Wan2.6（历史版本）系列视频模型，覆盖文生 / 图生 / 参考生视频 / 视频编辑四种能力，DashScope 透传直连阿里云百炼，默认定价 98 折，叠加充值加赠后大客户最高档可达约 82 折。令牌分组需选 Wan。

**2026/5/23 21:45 (UTC+8)** · 新模型 · Alibaba

🎬 **Wan2.7 / Wan2.6 视频模型上线 · 官转阿里云通义万相 · 默认 98 折** —— 上线阿里云通义万相 [Wan](/api-capabilities/wan/overview) 系列视频模型：**Wan2.7** 主力四能力（文生视频 `wan2.7-t2v` / 图生视频 `wan2.7-i2v` 含音频驱动 / 参考图生视频 `wan2.7-r2v` / 视频编辑 `wan2.7-videoedit`），**Wan2.6** 历史版本仍可调用（含 `wan2.6-r2v-flash`），**DashScope 透传**直连阿里云百炼，质量与官方一致。

💰 **定价与优惠**：默认价格 = 阿里云官方原价的 **98%（98 折）**——分组倍率 **0.14x** × **1:7 固定汇率** = 0.98；叠加 [充值加赠活动](/faq/recharge-promotions) 后**大客户最高档**可降至 **约 81.6%（约 82 折）**——0.98 ÷ 1.2 ≈ 0.816。

⚙️ **配置要点**：

* **令牌分组必须选 `Wan`**（与 [HappyHorse](/api-capabilities/happyhorse/overview) 共用同一分组，一把令牌即可同时调两个系列）
* **计费模式建议「按量优先」**，按秒计费
* **失败不计费**：任务进入 `failed` 状态（媒体 URL 不可达 / prompt 涉敏 / 上游容量等）不扣费，可放心重试

🎯 **适合谁**：短视频生产、电商素材、数字人口播、创意运营；想要稳定可靠的国产视频模型、不想自建出海链路调阿里云的团队。
