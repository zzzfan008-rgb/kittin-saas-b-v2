**2026/8/10 12:39 (UTC+8)** · 文档更新 · ByteDance

📚 **首个视频模型 Agent 技能（Skill）文档上线：Seedance 2.0**

继图片 API 的 Skills 之后，文档中心为 Seedance 2.0 新增开箱即用的 Agent Skill——两个文件放进 Codex、Claude Code、OpenClaw 等任意编码 Agent，一句话即可出视频。零依赖脚本覆盖文生视频、首帧 / 首尾帧图生视频与参考图生视频，`--model` 在 `mini` / `fast` / `std` 间一键切换，默认走最便宜的 `mini` 且自带同步音频；视频是异步任务，脚本会自动轮询并把成片下载到本地。用法见 [Seedance 2.0 Agent 技能](/api-capabilities/seedance2/skills)。
