# 网站新增 Stripe 在线充值 · 支持外币信用卡

> API易 上线 Stripe 在线充值通道，支持外币信用卡支付，安全风控等级高。请务必使用公司 / 个人 / 学校的实名信用卡，恶意支付将触发账号风控（封号）处理。

**2026/5/19 17:01 (UTC+8)** · 服务通知

🎉 **网站新增 Stripe 在线充值 · 支持外币信用卡** —— 好消息：API易 现已上线 **Stripe 在线充值通道**，支持**外币信用卡**支付，到账实时。Stripe 自带较严的风控与 3D Secure 验证，**安全机制等级高**，海外客户结算更顺畅。

⚠️ **使用规则**（请务必阅读）：

* 仅支持**外币信用卡**（人民币卡无法走 Stripe 通道）
* 请使用 **公司 / 个人 / 学校** 名下的**实名信用卡**支付
* **不安全 / 非实名的信用卡**会被 Stripe 风控直接拒绝
* **恶意支付**（盗卡、拒付、欺诈测试等）的账号将被**封号处理**，请勿测试或滥用

💡 **充值入口**：登录后台后在 `api.apiyi.com` 余额 / 充值页面选择 Stripe 通道即可。其他支付方式（微信 / 支付宝 / 对公）不受影响，可继续使用。
