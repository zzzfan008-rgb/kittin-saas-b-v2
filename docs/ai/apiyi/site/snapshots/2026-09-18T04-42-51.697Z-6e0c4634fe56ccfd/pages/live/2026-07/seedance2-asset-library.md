🚀 **Seedance 2.0 素材库开放：真人 + 虚拟人授权均有接口层面支持**

需要 SD2 的人像开白接口？现在有了——通过 icover.ai 素材库开放 API（API易旗下），上传图片入库拿到 `asset://` 素材 ID，再经 APIYI 网关生成人物一致性视频，同一角色跨集、跨镜头保持一致，适合漫剧、短剧等系列内容。虚拟人像全自动入库、无需审核；真人出镜走本人人脸核身授权流程。配套网页工具零代码操作，也支持 REST API 批量接入。

📖 接入文档：[Seedance 2.0 素材库](/api-capabilities/seedance2/asset-library)——可直接发给 Codex / Claude Code 等 Agent，对着文档实现接入。
