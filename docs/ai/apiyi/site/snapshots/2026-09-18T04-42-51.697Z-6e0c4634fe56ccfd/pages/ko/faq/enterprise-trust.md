# APIYI의 엔터프라이즈 서비스는 신뢰할 수 있습니까? 모델은 진짜입니까?

> 우리는 순수하고 투명한 공식 릴레이 프록시입니다 — 경로 변경도, 성능 저하도, 모델 교체도 없습니다. 이 페이지는 가동 시간과 트래픽 데이터부터 요금 체계와 데이터 보안에 이르기까지, 저희를 신뢰할 수 있는 검증 가능한 이유를 제공합니다.

## 간단한 답변

**네 — 그리고 저희는 단순히 저희 말을 믿기보다, 직접 확인해 보시기를 환영합니다.**

APIYI는 **순수하고 투명한 공식 릴레이 프록시**입니다. 요청은 오직 추적 가능한 공식 경로를 통해서만 전달됩니다(예를 들어, Claude는 기본적으로 AWS Bedrock의 공식 액세스를 통해 라우팅됩니다). 저희는 **더 저렴한 모델로 우회하지 않으며, 다운그레이드하지 않고, 모델을 바꾸지 않으며, 귀하의 데이터를 보관하지 않습니다**. 저희는 저가 플랫폼이 아닙니다. 낮은 가격의 진짜 비용은 보통 눈에 보이지 않는 "희석"입니다. 아래에는 저희를 신뢰할 수 있는 **객관적으로 검증 가능한** 몇 가지 이유가 있으며, 언제든지 소액 잔액으로 시작하여 한 단계씩 신뢰를 쌓을 수 있습니다.

<Info>
  **저희는 이 우려를 충분히 이해합니다.**

  "게이트웨이가 제 요청을 몰래 더 저렴한 모델로 우회시키는 것 아닐까요?" — 공급업체 선정을 진지하게 하는 모든 기업이 묻는 질문입니다. 약속보다는 **검증 가능한 증거**와 **직접 테스트할 수 있는 방법**을 제공하는 편을 선호합니다.
</Info>

## 왜 더 저렴한 모델로 “몰래 교체”하지 않는가

핵심 이유는 간단합니다. **저희의 비즈니스 모델은 품질을 희석해서 수익을 내는 방식이 아니기 때문입니다.**

<Warning>
  **“희석”은 저가 플랫폼만 해야 하는 일입니다**

  리버스 엔지니어링된 액세스, 공유 계정, 모델 다운그레이드, 고가 모델을 저가 모델로 조용히 교체하는 행위는 모두 가격을 낮출 수 있지만, 이를 사용하면 채널에 무엇이 섞여 있는지 알 수 없습니다. 출력 품질이 변동하고, 서비스가 언제든 중단될 수 있으며, 대화 데이터가 재판매될 때조차 알아차리지 못할 수 있습니다.

  **가격이 낮을수록 일반적으로 투명성이 떨어집니다.** 저가 플랫폼에는 거의 확실하게 사용자가 볼 수 없는 숨은 비용이 있습니다.
</Warning>

<Info>
  **APIYI는 다른 길을 선택합니다. 순수한 공식 릴레이를 제공합니다. 조금 더 비싸더라도 투명하고 깔끔한 방식을 택합니다**

  Claude를 예로 들어 보겠습니다. 기본적으로 **AWS Bedrock의 공식 액세스**를 통해 라우팅하며, 백업으로 **Anthropic 공식 키 직접 연결**을 사용합니다. 두 채널 모두 순수한 공식 릴레이이므로 추적할 수 있고, 사용량에 따른 종량제 방식이며 데이터를 보존하지 않습니다. 총비용은 공식 가격의 약 \*\*85%\*\*입니다(충전 보너스 적용 후 대략 79%\~86% 범위).

  저희의 비용 절감은 **높은 캐시 적중률**(Claude 네이티브 형식의 프롬프트 캐싱)과 충전 보너스에서 비롯되며, **모델을 다운그레이드하거나 교체해서 얻는 것이 아닙니다**. [Claude API 기본 사항](/ko/api-capabilities/claude)을 참조하십시오.
</Info>

### 1. 가동 시간 및 트래픽 수준

APIYI는 **2년 넘게 온라인 상태를 유지해 왔습니다**. 서둘러 개설한 신규 사이트가 아니라, 장기적으로 재방문하는 고객이 뒷받침하는 플랫폼입니다. 제3자 트래픽 모니터링에 따르면 `api.apiyi.com` **월간 방문 약 145K, 도메인 등록 기간 2년 이상**입니다.

  데이터는 제3자 트래픽 모니터링 도구에서 제공되며, 참고용으로만 사용하시기 바랍니다. 사기를 치거나 「희석」 수법을 사용하는 플랫폼이라면 2년 동안 안정적인 트래픽과 지속적인 고객 유지율을 유지하기 어려울 것입니다.
</Note>

### 2. 전문적인 문서 센터

지금 읽고 계신 문서 자체가 플랫폼이 「세심하게 관리되는지」를 보여 주는 직접적인 증거입니다. 수백 개의 API 가이드, 모델 참고 자료, FAQ를 지속적으로 업데이트하고 있으며, 과금, 과금 규칙, 채널 세부 정보도 모두 투명하게 공개하고 있습니다. **단기적인 수익만 노리는 플랫폼이라면 이러한 내용을 모두 설명하는 데 공을 들이지 않을 것입니다.**

### 3. 과금에 관해 저가 플랫폼이 아닙니다

저희 과금을 한 문장으로 요약하면 다음과 같습니다. **순수 공식 릴레이 AWS Claude의 정가 약 85% 수준이며, 신뢰할 수 있는 품질을 제공하고 캐시 적중률이 높아 비용을 절감할 수 있습니다.**

저희는 일부러 비싸게 책정하는 것이 아닙니다. **안정적이고 신뢰할 수 있는 수준**과 **합리적인 가격** 사이에서 가격을 유지하며, **출처가 불분명한 저가 상품은 취급하지 않습니다**. 플랫폼의 가격이 터무니없이 낮다면 각별히 주의하시기 바랍니다. 눈에 보이지 않는 방식으로 그 차액을 회수하고 있을 가능성이 매우 높습니다.

[Claude API 기본](/ko/api-capabilities/claude)을 참조하시기 바랍니다.

### 4. 데이터 보안: 아무것도 보관하지 않는 투명한 프록시

APIYI는 **투명한 프록시**입니다. 저희의 역할은 업스트림 공식 채널로 요청을 안전하고 효율적으로 전달하는 것이며, **사용자의 대화 내용을 보관하지 않습니다**. 이는 개인정보 보호를 보장할 뿐만 아니라, 근본적으로 요청을 「조작」할 유인이 없다는 의미이기도 합니다.

[APIYI는 데이터 보안을 어떻게 보호합니까?](/ko/faq/data-security)를 참조하시기 바랍니다.

### 5. 신뢰는 단계적으로 쌓입니다

처음부터 큰 금액을 충전하시기를 요구하지 않습니다. **신뢰는 검증을 바탕으로 쌓아야 합니다.**

<Tip>
  **권장 온보딩 방식**

  1. 소액인 **\$10 잔액**을 충전하고 실제 비즈니스 시나리오를 실행합니다.
  2. 공식 출력 결과와 비교하고 호출 로그를 확인하여 품질과 과금이 기대에 부합하는지 검증합니다.
  3. 확인이 완료되면 장기적인 협력을 목표로 점진적으로 규모를 확대합니다.

  이렇게 하면 투자하는 모든 단계가 이미 검증된 결과를 기반으로 하므로 위험을 통제할 수 있습니다.
</Tip>

## “모델 진위” 직접 확인하는 방법

약속에 의존하는 대신 **직접 확인할 수 있습니다**:

<Steps>
  <Step title="소액 잔액으로 나란히 비교 테스트">
    **\$10 잔액**을 사용하여 실제 작업을 실행하고 공식 채널의 결과와 비교합니다 — 품질이 일관되고 안정적인지 확인합니다.
  </Step>

  <Step title="호출 로그 검토">
    콘솔에서 각 호출의 모델, token 사용량 및 과금 세부 정보를 검토합니다 — 투명하고 추적 가능한 정산이 가능합니다. [호출 로그는 어떻게 확인합니까?](/ko/faq/call-logs)를 참조하십시오.
  </Step>

  <Step title="캐싱 및 과금 확인">
    Claude의 **Anthropic 네이티브 형식**(`/v1/messages`)을 사용하면 캐시 과금이 적용될 수 있으며, 긴 컨텍스트 또는 반복되는 시스템 prompt 시나리오에서는 청구 금액이 눈에 띄게 감소합니다 — 이는 공식 릴레이 채널만 제공하는 기능입니다. [Claude API 기본 사항](/ko/api-capabilities/claude)을 참조하십시오.
  </Step>
</Steps>

<Note>
  월간 사용량이 많은 기업 고객인 경우, 당사에 문의하여 SLA 보장 및 크레딧 보상 조건에 합의하고 책임 범위를 계약서에 명시할 수도 있습니다. [APIYI는 SLA를 제공합니까?](/ko/faq/sla-guarantee)를 참조하십시오.
</Note>
