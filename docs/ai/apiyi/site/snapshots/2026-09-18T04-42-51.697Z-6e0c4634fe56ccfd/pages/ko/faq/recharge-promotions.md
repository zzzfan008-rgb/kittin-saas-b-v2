# 이용 가능한 충전 프로모션은 무엇입니까?

> APIYI의 충전 프로모션을 알아보십시오. 최초 충전 보너스, 단계별 보너스, 법인 이체 보너스, 기업 서비스 및 인보이스 서비스를 포함합니다.

## 충전 프로모션 개요

APIYI는 AI 서비스를 더 저렴한 가격으로 이용할 수 있도록 다양한 충전 프로모션을 제공합니다.

## 단계별 충전 보너스

충전 금액이 클수록 보너스 비율이 높아집니다. 대규모 충전 보너스는 별도 신청 없이 플랫폼에서 자동으로 추가됩니다.

<Info>
  **정책 업데이트**: 2025년 12월 18일부터 새로운 충전 보너스 정책이 적용됩니다
</Info>

### 보너스 비율표

| 충전 금액(단일 거래)           | 보너스 %   | 실제 적립 배수 | 충전 예시                   |
| ---------------------- | ------- | -------- | ----------------------- |
| \$100 ≤ X \< \$500     | **10%** | 잔액 1.1배  | \$100 충전 → \$110 적립     |
| \$500 ≤ X \< \$1,000   | **12%** | 잔액 1.12배 | \$560 충전 → \$600 적립     |
| \$1,000 ≤ X \< \$3,000 | **15%** | 잔액 1.15배 | \$1,000 충전 → \$1,150 적립 |
| X ≥ \$3,000            | **20%** | 잔액 1.2배  | \$3,000 충전 → \$3,600 적립 |

<Note>
  **중요**: 보너스 비율은 누적 총액이 아닌 **단일 충전 금액**을 기준으로 합니다
</Note>

### 보너스 지급

<Info>
  **자동 지급**: \$100 이상 충전 시 단계별 보너스는 플랫폼에서 자동으로 인식 및 추가되며, 수동 신청이 필요하지 않습니다. 보너스는 재무팀이 “시스템 자동화 + 수동 검토” 워크플로를 통해 매일 23:00 - 01:00 (UTC+8) 사이에 적립합니다. **다음 날 확인하기만 하면 됩니다 — 보너스가 지급되며, 별도 문의는 필요하지 않습니다.**
</Info>

### 법인 이체 보너스

법인 이체도 단계별 보너스를 받을 수 있습니다.
모든 결제 수단(법인 이체 포함)은 충전 보너스 캠페인에 참여할 수 있습니다.

**예시**: 20,000 CNY 법인 이체의 경우,
입금 확인 후 20,000 CNY 충전과 15% 보너스가 완료됩니다.

### 계산 예시

<Tabs>
  <Tab title="예시 1: \$200 충전">
    **충전 금액**: \$200

    **구간 범위**: \$100 ≤ X \< \$500

    **보너스 비율**: 10%

    **보너스 금액**: \$200 × 10% = \$20

    **실제 적립**: \$200 + \$20 = **\$220** (1.1배)
  </Tab>

  <Tab title="예시 2: \$700 충전">
    **충전 금액**: \$700

    **구간 범위**: \$500 ≤ X \< \$1,000

    **보너스 비율**: 12%

    **보너스 금액**: \$700 × 12% = \$84

    **실제 적립**: \$700 + \$84 = **\$784** (약 1.12배)
  </Tab>

  <Tab title="예시 3: \$1,500 충전">
    **충전 금액**: \$1,500

    **구간 범위**: \$1,000 ≤ X \< \$3,000

    **보너스 비율**: 15%

    **보너스 금액**: \$1,500 × 15% = \$225

    **실제 적립**: \$1,500 + \$225 = **\$1,725** (1.15배)
  </Tab>

  <Tab title="예시 4: \$5,000 충전">
    **충전 금액**: \$5,000

    **구간 범위**: X ≥ \$3,000

    **보너스 비율**: 20%

    **보너스 금액**: \$5,000 × 20% = \$1,000

    **실제 적립**: \$5,000 + \$1,000 = **\$6,000** (1.2배)
  </Tab>
</Tabs>

### 잔액 유효 기간(2026-08-02부터 적용)

계정 잔액은 결제일로부터 **365일**간 유효합니다. 규칙은 다음과 같습니다.

| 항목                 | 규칙                                                    |
| ------------------ | ----------------------------------------------------- |
| **유효 기간**          | 충전된 크레딧은 결제일로부터 365일간 유효합니다                           |
| **새 충전**           | **전체 사용 가능 잔액**의 유효 기간이 다시 1년으로 초기화됩니다                |
| **보너스 / 프로모션 크레딧** | 충전된 크레딧과 동일한 규칙이 적용되어 365일간 유효하며, 새 충전 시 마찬가지로 초기화됩니다 |
| **기존 잔액**          | 과거의 충전일이 아니라 적용일(2026-08-02)부터 365일로 계산됩니다            |
| **만료 시**           | 만료된 잔액은 자동으로 소멸되며, 환불, 복원, 전환이 되지 않습니다                |
| **만료일 확인**         | 현재 잔액의 만료일은 콘솔에 표시됩니다                                 |

<Warning>
  **실제 사용량에 맞게 충전하십시오**: 정기적으로 충전하고 사용하는 한, 새 충전마다 전체 잔액의 유효 기간이 다시 1년으로 초기화되므로 실제로는 영향을 받지 않습니다. 하지만 1년 이내에 이 크레딧을 사용할 계획이 없다면, 더 높은 보너스 등급을 받으려고 과도하게 충전하지 마십시오. 만료된 잔액은 환불되거나 복원되지 않습니다.

  정확한 문구는 [서비스 약관](https://cf-index.apiyi.com/terms)과 [환불 정책](https://cf-index.apiyi.com/refund)에 있습니다.
</Warning>

## 청구서 서비스

APIYI는 기업 사용자의 재무 정산 요구를 충족하기 위해 공식 청구서(VAT 일반 청구서 및 VAT 특별 청구서) 발행을 지원합니다.

### 청구서 신청 방법

<Steps>
  <Step title="충전 완료">
    온라인 결제 또는 기업 이체를 통해 충전을 완료합니다
  </Step>

  <Step title="온라인으로 청구서 정보 제출">
    **APIYI 대시보드** → **상단 내비게이션** → **청구서 제출**에 로그인합니다

    청구서 정보를 입력합니다(최소 필수: 회사명 및 납세자 식별번호)

    **온라인 청구서 양식**: `https://xinqikeji.feishu.cn/share/base/form/shrcns8TS3alZTN2Av1JfkOvmqh`
  </Step>

  <Step title="발행 대기">
    청구서는 영업일 기준 3-5일 이내에 발행되며 제공하신 이메일로 전송됩니다
  </Step>
</Steps>

<Info>
  **지원되는 청구서 유형**:

  * VAT 일반 청구서(소규모 납세자 대상)
  * VAT 특별 청구서(일반 납세자 대상, 세액 공제 가능)
</Info>

<Note>
  **청구서 처리 시간**: 청구서는 보통 요청을 받은 후 3-5영업일 이내에 발행됩니다. 월말이나 분기말 같은 재무 성수기에는 다소 지연될 수 있습니다.
</Note>

  </Accordion>

  <Accordion title="\$600을 충전했는데, 왜 구간별 계산이 아닌 12% 보너스만 적용되나요?">
    **보너스 비율은 누적 구간이 아닌 총 충전 금액 구간을 기준으로 계산됩니다.**

    **올바른 계산 방식**:

    * \$600 충전은 \$500 ≤ X \< \$1,000 구간에 해당합니다
    * 보너스 비율: 12%
    * 보너스 금액: \$600 × 12% = \$72
    * 실제 적립 금액: \$672

    **구간 분할 계산 아님** (잘못된 방식):
    ❌ 첫 \$500 × 12% + 다음 \$100 × 10%
  </Accordion>
