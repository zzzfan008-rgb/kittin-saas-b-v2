# 왜 일부 모델을 사용할 수 없습니까?

> APIYI 모델 권한 설명, 모든 모델의 잠금을 해제하는 방법과 모델을 사용할 수 없는 이유를 알아봅니다

## 사용자 그룹 및 모델 권한

### 충전한 사용자에 대한 자동 업그레이드

충전 후 플랫폼은 주기적으로 충전한 사용자를 **VIP** 또는 **SVIP** 그룹으로 조정하며, 이를 통해 모든 모델을 사용할 수 있게 됩니다.

<Info>
  **자동 그룹 조정**

  * 충전한 사용자는 자동으로 VIP/SVIP 그룹에 배정됩니다
  * VIP/SVIP 사용자는 플랫폼에서 제공되는 모든 모델을 사용할 수 있습니다
  * 그룹 조정은 일반적으로 충전 후 자동으로 완료됩니다
</Info>

## 모델을 사용할 수 없는 구체적인 이유

### 1. 고가 모델 제한

대부분의 모델은 정상적으로 사용할 수 있지만, 일부 고가 모델은 `default` 그룹에 대해 제한이 있습니다:

* **예시**: `claude-opus-4-20250514` 및 기타 새로 출시된 고급 모델
* **이유**: 비용이 높아 아직 기본 그룹에 개방되지 않았습니다
* **해결책**: 충전하여 VIP/SVIP 그룹으로 업그레이드한 뒤 이용하십시오

<Warning>
  **고가 모델**

  일부 최신 또는 고급 모델은 비용이 더 높기 때문에 유료 사용자에게만 제공됩니다. 충전하면 전체 모델 접근 권한을 얻을 수 있습니다.
</Warning>

### 2. 플랫폼에서 중단된 모델

일부 모델은 공식 플랫폼에서 중단되었기 때문에 사용할 수 없습니다:

* **예시**: `gpt-4.5-preview`
* **이유**: OpenAI 플랫폼에서 이 모델의 제공을 중단했습니다
* **결과**: 이에 따라 저희도 해당 모델의 제공을 중단했으며, 더 이상 서비스를 제공할 수 없습니다

<Info>
  **모델 중단 설명**

  OpenAI, Anthropic 등 원래 AI 서비스 제공업체가 모델을 중단하면, 저희도 해당 모델을 동시에 중단합니다. 이를 통해 서비스의 안정성과 일관성을 보장합니다.
</Info>

## 사용자 그룹 설명

### 기본 그룹

* **권한**: 기본 모델 접근
* **제한**: 일부 고가 모델은 사용할 수 없습니다
* **대상**: 무료 사용자 및 신규 등록 사용자

### VIP/SVIP 그룹

* **권한**: 사용 가능한 모든 모델 접근
* **장점**: 최신 및 고급 모델 포함
* **획득 방법**: 충전 후 자동 또는 수동 조정

## 모델 사용 가능 여부 확인

### 현재 그룹 확인

1. 콘솔에 로그인하여 계정 정보를 봅니다
2. 현재 사용자 그룹 수준을 확인합니다
3. 사용 가능한 모델 목록을 봅니다

### 모델 호출 테스트

1. API 문서의 테스트 함수를 사용합니다
2. 특정 모델 호출을 시도합니다
3. 반환된 오류 정보를 봅니다

## 일반적인 해결 방법

1. **충전 업그레이드**: 가장 직접적인 해결 방법으로, 모든 모델을 사용할 수 있습니다
2. **고객 서비스에 문의**: 충전 후 그룹이 조정되지 않았을 때의 처리 방법입니다
3. **대체 모델 선택**: 비슷한 기능을 가진 다른 사용 가능한 모델을 사용합니다
4. **업데이트 대기**: 새로운 모델 출시 정보를 위해 플랫폼 공지를 확인합니다
