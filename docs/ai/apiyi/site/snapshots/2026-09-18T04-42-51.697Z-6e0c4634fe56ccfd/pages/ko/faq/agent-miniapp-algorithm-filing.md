# Agent 미니프로그램은 알고리즘 신고가 필요합니까?

> 대형 모델을 기반으로 구축한 미니프로그램은 일반적으로 알고리즘 신고가 필요합니다. 이 페이지에서는 일반적인 절차와 실무 팁을 공유합니다.

## 짧은 답변

mini-program이 대규모 모델 기능을 기반으로 구축된 경우, 일반적으로 플랫폼 및 규제 요구사항에 따라 알고리즘 등록을 완료해야 합니다. 절차와 필요한 자료는 공개되어 있으며, 공식 절차에 따라 신청을 제출할 수 있습니다.

자료를 준비해 두면, 보통 제출 후 영업일 기준 1-2일 내에 심사가 완료됩니다.

## 실용 참고 자료

준비부터 제출까지 전 과정을 다루는 공개 안내서를 모아 두었습니다:

<Info>
  참고 기사: `mp.weixin.qq.com/s/S4vSooHIhKQUDeQ4tVrWbg`
</Info>

## 실용 팁

* **준비**: 미니프로그램 기능, 모델 유형, 데이터 소스, 사용자 시나리오를 문서화합니다
* **제출**: 공식 템플릿에 따라 알고리즘 설명을 작성하고 올바른 플랫폼을 통해 제출합니다
* **심사**: 보통 1\~2영업일 내에 완료됩니다
* **승인 후**: 플랫폼 규정에 따라 미니프로그램 내부에 필요한 등록 라벨을 추가합니다

<Tip>
  **팁**: 등록에서 어려운 부분은 코드가 아니라 문서와 시나리오 설명입니다. 명확하게 작성하면 보통 한 번에 원활하게 심사를 통과합니다.
</Tip>

## 개발자가 아니어도 괜찮습니다

작성은 대부분 절차와 글쓰기에 관한 일입니다:

* 흐름과 글쓰기가 작업의 대부분을 차지합니다
* 코딩은 작은 부분에 불과합니다
* 자료가 준비되면 엔지니어가 나머지를 마무리할 수 있습니다
