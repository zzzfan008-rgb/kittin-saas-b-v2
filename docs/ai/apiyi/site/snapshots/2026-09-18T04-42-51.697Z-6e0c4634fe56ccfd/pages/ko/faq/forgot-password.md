# 비밀번호를 잊어버렸다면?

> 이메일 재설정, 고객 지원 등으로 APIYI 계정 비밀번호를 복구하는 방법

## 빠른 답변

이메일로 등록하신 경우 로그인 페이지에서 비밀번호를 재설정할 수 있습니다. 이메일을 연동하지 않으셨다면, 계정을 복구할 수 있도록 사용자 이름, 결제 기록 또는 API 키와 함께 지원팀에 문의해 주십시오.

## 옵션 1: 이메일로 재설정

이메일 주소로 등록했다면, 직접 비밀번호를 재설정할 수 있습니다:

<Steps>
  <Step title="로그인 페이지를 엽니다">
    APIYI 로그인 페이지로 이동하여 이메일 주소를 입력합니다.
  </Step>

  <Step title="재설정 링크를 표시합니다">
    이메일을 입력하고 아무 비밀번호나 입력한 다음 로그인합니다. 로그인에 실패하면 페이지에 **빨간색 “비밀번호 재설정” 링크**가 나타납니다.
  </Step>

  <Step title="비밀번호 재설정을 클릭합니다">
    빨간색 “비밀번호 재설정” 텍스트를 클릭합니다. 시스템이 비밀번호 복구 페이지로 이동시키고 등록된 이메일로 재설정 링크를 전송합니다.
  </Step>

  <Step title="재설정을 완료합니다">
    이메일 받은편지함에서 재설정 이메일을 확인한 다음 링크를 클릭하고 새 비밀번호를 설정합니다.
  </Step>
</Steps>

<Info>
  재설정 이메일을 받지 못했다면 스팸 폴더를 확인하거나 몇 분 기다린 뒤 다시 시도합니다.
</Info>

## 옵션 2: 지원팀에 문의

If you **이메일을 아직 연결하지 않았거나** 등록한 이메일을 잊으셨다면, 도움을 받기 위해 지원팀에 문의하십시오. 신원 확인을 위해 아래 항목 중 하나를 제공해 주십시오:

<CardGroup cols={3}>
  <Card title="사용자 이름" icon="user">
    기억나시면 APIYI 사용자 이름을 제공해 주십시오
  </Card>

  <Card title="결제 내역" icon="receipt">
    Alipay 또는 WeChat 결제 영수증 스크린샷을 제공해 주십시오
  </Card>

  <Card title="API 키" icon="key">
    사용한 API 키를 제공해 주십시오
  </Card>
</CardGroup>

<Warning>
  위 항목 중 하나 이상을 제공해 주십시오. 지원팀이 신원을 확인하고 계정 복구를 도와드립니다.
</Warning>

## 옵션 3: 복구 후 이메일 연결

로그인에 성공한 후 계정 설정에서 이메일을 연결하는 것을 **강력히 권장합니다**:

<Steps>
  <Step title="계정 설정으로 이동">
    로그인한 후 "계정 센터" 페이지로 이동합니다.
  </Step>

  <Step title="이메일 연결">
    이메일 연결 옵션을 찾아 이메일 주소를 입력하고 인증을 완료합니다.
  </Step>

  <Step title="비밀번호 설정">
    이메일을 연결한 후 안전한 비밀번호를 설정합니다. 이후에는 이메일과 비밀번호로 로그인할 수 있습니다.
  </Step>
</Steps>

<Tip>
  이메일이 연결되면 지원팀에 연락하지 않고도 언제든지 이메일을 통해 비밀번호를 재설정하거나 변경할 수 있습니다.
</Tip>

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="빨간색 ‘비밀번호 재설정’ 링크는 어디에 있습니까?">
    로그인 페이지에서 이메일과 잘못된 비밀번호를 입력한 다음 로그인을 클릭합니다. 로그인 실패 메시지가 표시되면 빨간색으로 표시된 클릭 가능한 “비밀번호 재설정” 텍스트가 나타납니다.
  </Accordion>

  <Accordion title="타사 서비스(GitHub/WeChat)를 통해 로그인했습니다. 어떻게 해야 합니까?">
    타사 서비스 로그인 사용자는 해당 플랫폼을 통해 직접 로그인해야 합니다. 타사 서비스 로그인에 문제가 있는 경우 [GitHub 로그인 문제](/ko/faq/github-bindng-bindng-error)를 참조하거나 지원팀에 문의하십시오.
  </Accordion>

  <Accordion title="이메일을 연결해야 하는 이유는 무엇입니까?">
    이메일을 연결하면 다음을 수행할 수 있습니다.

    * 언제든지 이메일을 통해 비밀번호 재설정
    * 이메일 + 비밀번호를 보조 로그인 방법으로 사용
    * 중요한 계정 알림 수신
  </Accordion>
</AccordionGroup>
