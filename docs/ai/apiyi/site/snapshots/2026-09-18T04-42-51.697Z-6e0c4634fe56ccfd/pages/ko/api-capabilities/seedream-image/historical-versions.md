# Seedream 과거 버전

> Seedream 5.0 / 4.5 / 4.0 사양 비교, 가격 차이, 그리고 마이그레이션 가이드입니다. 세 버전 모두 계속 호출할 수 있으므로 — 필요에 따라 선택하면 되며, 브레이킹 변경은 없습니다.

<Note>
  이 페이지는 APIYI에서 **아직 호출 가능한** 모든 Seedream 버전을 나열합니다. 세 버전은 동시에 활성화되어 있으며, **완전히 호환되는 파라미터**를 사용합니다 — `model` 필드만 변경하여 전환할 수 있습니다. 최신 버전과 일반 소개는 [Seedream 개요](/ko/api-capabilities/seedream-image/overview)를 참조하십시오.
</Note>

## 버전별 사양

### `seedream-5-0-pro-260628` (5.0 Pro)

* **출시일**: 2026-06-28 (UTC+8); APIYI에서는 2026-07-19부터 사용 가능
* **APIYI 가격**: **\$0.12 / request** (요청당 고정 가격, 요청당 이미지 1장, ≈ ¥0.84 목록가). 공식적으로 이 모델은 두 개의 출력 픽셀 가격 구간(≤2.36M / >2.36M)과 첫 번째를 초과하는 참조 이미지에 대한 요금을 사용합니다. APIYI는 이를 입력 이미지 요금을 포함한 요청당 고정 가격으로 단순화합니다
* **해상도 단계**: 사전 설정 `1K` / `2K` (**3K/4K 사전 설정 없음**) 및 최대 **4.19M** 총 픽셀까지의 정확한 픽셀 `WxH`(최대 2048×2048이며, 16:9에서는 긴 변이 `2720x1530`에 도달하며 ≈ 2.7K로 검증됨)
* **출력 형식**: `png` / `jpeg`
* **프롬프트 최적화**: 표준 / 빠름
* **주요 특징**:
  * 제품군 중 가장 뛰어난 이미지 품질과 지시 준수 성능을 제공합니다. 대화형 편집을 지원합니다(좌표, 선택 박스, 화살표로 편집 위치 지정)
  * 멀티 이미지 융합은 공식적으로 **최대 10장의 참조 이미지**를 지원합니다
* **알려진 제한**:
  * **`sequential_image_generation` / `stream`는 허용되지 않습니다** — 어떤 값이든(`"disabled"` 포함) 400을 반환합니다. 두 매개변수 모두 완전히 생략하십시오
  * 생성 속도가 느립니다: 이미지당 일관되게 **약 2분**(측정값 110-130초) 소요됩니다 — 클라이언트 타임아웃을 ≥ 240초로 설정하십시오
  * 5.0-lite의 단위 가격보다 3.4배 비쌉니다; 일상 작업에는 5.0-lite를 사용하십시오

### `seedream-5-0-260128` (5.0-lite)

* **출시일**: 2026-01-28 (UTC+8)
* **APIYI 가격**: \$0.035 / image (≈ ¥0.245 목록가)
* **해상도 단계**: `2K` / `3K` (**4K 없음**)
* **출력 형식**: `png` / `jpeg` (png 출력을 지원하는 유일한 버전)
* **프롬프트 최적화**: 표준
* **주요 특징**:
  * 전반적으로 가장 뛰어난 경험을 제공합니다. 멀티 이미지 융합 / 편집 / 배치 시퀀스 구현이 가장 성숙합니다
  * `png` 출력을 지원하는 유일한 버전이며, 따라서 투명 배경을 지원합니다
  * 성숙한 스트리밍 출력(`stream: true`)
* **알려진 제한**:
  * 해상도는 3K(\~3072×3072)로 제한됩니다. 4K 자산에는 4.5 / 4.0을 사용하십시오
* **공식 문서**: `docs.byteplus.com/en/docs/ModelArk/1824121`

### `seedream-4-5-251128`

* **출시일**: 2025-11-28 (UTC+8)
* **APIYI 가격**: \$0.04 / image (≈ ¥0.28 목록가)
* **해상도 단계**: `2K` / `4K`
* **출력 형식**: `jpeg`
* **프롬프트 최적화**: 표준
* **주요 특징**:
  * 12억 매개변수의 통합 생성-편집 아키텍처
  * **텍스트 렌더링의 돌파구**: 작은 텍스트도 선명하게 유지됩니다 — 포스터, 광고, UI 스크린샷에 최고 수준입니다
  * 멀티 이미지 융합은 최대 10장의 참조 이미지를 명시적으로 지원합니다
  * 편집 시 조명, 색조, 자연스러운 얼굴 디테일이 보존됩니다
* **알려진 제한**:
  * `jpeg` 출력만 지원합니다(`png` 없음, 투명도 없음)
* **뉴스 기사**: [Seedream 4.5 출시](/en/news/seedream-4-5-launch)

### `seedream-4-0-250828`

* **출시일**: 2025-08-28 (UTC+8)
* **APIYI 가격**: \$0.03 / image (≈ ¥0.21 목록가)
* **해상도 단계**: `1K` / `2K` / `4K` (가장 넓은 커버리지)
* **출력 형식**: `jpeg`
* **프롬프트 최적화**: 표준 / **빠름**
* **주요 특징**:
  * 실전 검증된 안정적인 버전
  * 강한 시각적 일관성, 균형 잡힌 4K 디테일
  * **프롬프트 빠름 모드를 지원하는 유일한 버전** — 비용 민감한 시나리오에서 더 빠른 생성
* **알려진 제한**:
  * 텍스트 렌더링은 4.5보다 약합니다
  * `jpeg` 출력만 지원합니다

## 마이그레이션 가이드

<Steps>
  <Step title="차이점 확인">
    세 버전은 **파라미터 수준에서 완전히 호환됩니다** — 전환하려면 `model` 필드만 변경하면 됩니다. 다음을 다시 확인하십시오:

    * 사용 중인 `size` 등급이 새 버전에서 지원되는지(5.0에는 1K / 4K가 없고, 4.5에는 1K가 없으며, 4.0은 모두 지원합니다)
    * `output_format: "png"`에 의존하는지(5.0에서만 해당)
    * `prompt_optimization: "fast"`를 사용하는지(4.0에서만 해당)
  </Step>

  <Step title="나란히 실행하십시오">
    같은 prompt 배치를 기존 버전과 새 버전에서 실행해 품질과 비용을 비교하십시오. 확대하기 전에 소규모 배치(10-20개 이미지)로 검증하십시오.
  </Step>

  <Step title="점진적으로 배포하십시오">
    트래픽을 단계적으로 전환하십시오(10% / 50% / 100%). 각 단계에서 추가 확대 전에 품질, 실패율, 비용을 관찰하십시오.
  </Step>

  <Step title="폴백을 유지하십시오">
    기존과 새 `model` 설정을 프로덕션 코드에 모두 유지하십시오. 새 버전이 이상 동작을 보이면 즉시 되돌리십시오. 세 버전은 통합 과금을 공유하므로 둘 다 실행해도 추가 비용이 없습니다.
  </Step>
</Steps>

## 레거시 호출 예시

```python theme={null}
{/* Switching versions only changes the model field; other params are compatible */}
from openai import OpenAI

client = OpenAI(api_key="sk-your-api-key", base_url="https://api.apiyi.com/v1")

resp = client.images.generate(
    model="seedream-4-0-250828",   # change this line to switch to 4.5 / 5.0
    prompt="A serene mountain landscape at golden hour, snow-capped peaks, ultra detailed, 4K",
    size="4K",                      # NOTE: 5.0 does not support 4K — use 2K or 3K
    response_format="url",
    extra_body={
        "watermark": False,
    }
)

print(resp.data[0].url)
```
