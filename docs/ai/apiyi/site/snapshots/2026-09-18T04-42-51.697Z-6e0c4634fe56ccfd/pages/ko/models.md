    * **입력 / 출력 / 캐시 읽기**: 사용량 과금 모델의 요금이며 단위는 100만 tokens당 미국 달러(\$/1M)입니다. **캐시 읽기**는 프롬프트 캐싱에 적중했을 때의 입력 요금이고, “—”는 해당 모델에 캐시 배수가 설정되지 않았음을 뜻합니다.
    * **건당**: 호출 횟수로 과금됩니다(이미지·동영상 계열 모델 등). 요금은 1회당 미국 달러입니다.
    * **엔드포인트**: `chat` = /v1/chat/completions; `responses` = /v1/responses; `messages` = /v1/messages; `gemini` = /v1beta 네이티브 API; `images` = /v1/images/generations; `embeddings` = /v1/embeddings.
    * **그룹**: 해당 모델을 사용할 수 있는 과금 그룹입니다. 일부 그룹에는 할인이 있고 충전 혜택과 중복 적용되며, 실제 과금 금액은 콘솔을 기준으로 합니다.
    * **†**: 구간 요금 모델로, 1회 요청의 token 규모에 따라 요금이 달라집니다. 페이지 끝의 “구간 요금 안내”를 참고하십시오.
    * **링크가 있는 모델 이름**: 해당 모델에는 컨텍스트 윈도우, 입출력 모달리티, 엔드포인트 매트릭스, 관련 문서를 담은 전용 상세 페이지가 있습니다.
