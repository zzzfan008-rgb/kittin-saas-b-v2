# token에 사용 가능한 모델을 설정해야 합니까?

> API.YI token의 사용 가능한 모델 메커니즘, 사용 권장 사항 및 일반적인 시나리오에 대한 자세한 설명

## 일반적인 경우: 설정할 필요 없음

<Info>
  **권장 사항**: token을 생성할 때 **사용 가능한 모델을 설정할 필요가 없으며**, 사이트의 모든 모델을 사용할 수 있습니다.
</Info>

사용 가능한 모델은 **화이트리스트 메커니즘**을 사용합니다:

* **미설정**: token은 사이트의 400개 이상의 모든 모델을 호출할 수 있습니다
* **설정**: token은 지정된 모델만 호출할 수 있으며 다른 모델은 사용할 수 없습니다

비즈니스 시나리오가 다양하다면 사용 가능한 모델을 설정하면 token의 사용 범위가 제한되고 유연성에 영향을 줍니다.

## 설정을 권장하지 않는 이유

### 1. 호출 범위를 제한합니다

사용 가능한 모델을 `gpt-4o`, `claude-3-5-sonnet-20241022`로 설정하면 다음과 같습니다.

* ✅ 호출 가능: `gpt-4o`, `claude-3-5-sonnet-20241022`
* ❌ 호출 불가: `gemini-2.5-pro`, `deepseek-v3`, 기타 400개 이상의 모델

이렇게 하면 비즈니스 유연성이 크게 제한됩니다.

### 2. 모델 별칭 문제

<Warning>
  **모델 별칭 함정**: 일부 모델에는 별칭이 있어, 사용 가능한 모델을 설정할 때 쉽게 오류가 발생할 수 있습니다.

  **사례**:

  * **별칭**: `nano-banana-pro` (친숙한 별칭)
  * **공식 이름**: `gemini-3-pro-image-preview` (공식 API 이름)

  사용 가능한 모델을 `nano-banana-pro`로 설정했지만 코드에서는 `gemini-3-pro-image-preview`를 호출하면 오류가 발생합니다.

  ```
  {
    "error": {
      "message": "Model not allowed for this API key",
      "type": "invalid_request_error"
    }
  }
  ```
</Warning>

### 3. 비즈니스 시나리오 변경

비즈니스가 발전함에 따라 서로 다른 모델을 테스트하거나 전환해야 할 수 있습니다.

* GPT-4에서 Claude 3.5로 전환
* DeepSeek, Qwen 같은 국내 모델 테스트
* 새로 출시된 Gemini 2.5 사용해 보기

사용 가능한 모델을 미리 설정해 두면, 매번 허용 목록을 수정해야 하므로 매우 번거롭습니다.

## 언제 설정해야 합니까?

권장되지는 않지만, 다음 시나리오에서는 사용 가능한 모델을 설정하는 것을 고려할 수 있습니다:

### 시나리오 1: 다른 사람과 token 공유

<Card title="팀 협업/친구 공유" icon="users">
  token KEY를 동료나 친구와 공유하고, 그들이 **특정 모델만**(예: `gpt-3.5-turbo`) 사용하여 비싼 모델로 잔액이 소모되는 것을 막고 싶다면, 사용 가능한 모델을 설정할 수 있습니다.

  **예시**:

  * 잔액이 제한적이어서 동료들이 `gpt-3.5-turbo`, `gpt-4o-mini`만 사용하길 원합니다
  * 사용 가능한 모델을 설정한 뒤에는 동료가 `o3`를 호출하려고 해도 거부됩니다
</Card>

### 시나리오 2: 예산 제어

<Card title="엄격한 비용 관리" icon="dollar-sign">
  프로젝트에 대해 엄격한 예산을 설정하고 저비용 모델만 허용하려면, 사용 가능한 모델 화이트리스트를 통해 제한할 수 있습니다:

  **예시**:

  * 프로젝트 예산이 제한되어 있어 `deepseek-v3`(\$0.07/백만 token)만 허용합니다
  * 초과 지출을 방지하기 위해 `o3`(\$20/백만 token) 사용을 금지합니다
</Card>

### 시나리오 3: 보안 규정 준수

<Card title="기업 보안 정책" icon="shield">
  일부 기업은 AI 모델 사용에 대한 엄격한 규정을 두고 있으며, 승인된 모델만 사용하도록 허용합니다.

  **예시**:

  * 회사는 공식 OpenAI 모델만 사용하도록 허용합니다
  * 사용 가능한 모델을 `gpt-4o`, `gpt-4.1`으로 설정하고 다른 벤더 모델 사용을 금지합니다
</Card>

## 사용 가능한 모델을 설정하는 방법은 무엇입니까?

사용 가능한 모델을 반드시 설정해야 하는 경우 다음 단계를 따르십시오.

1. [API.YI 토큰 관리 페이지](https://api.apiyi.com/token)에 로그인합니다.
2. “새 키 추가”를 클릭하거나 기존 토큰을 편집합니다.
3. “사용 가능한 모델” 필드에서 허용할 모델을 선택합니다.
4. 설정을 저장합니다.

<Tip>
  **공식 이름 사용**: 사용 가능한 모델을 설정할 때 호출 실패를 방지하려면 별칭(예: `nano-banana-pro`) 대신 모델의 **공식 이름**(예: `gemini-3-pro-image-preview`)을 사용하는 것이 좋습니다.

  모든 모델의 공식 이름은 [모델 목록 페이지](/ko/api-capabilities/model-info)에서 확인할 수 있습니다.
</Tip>
