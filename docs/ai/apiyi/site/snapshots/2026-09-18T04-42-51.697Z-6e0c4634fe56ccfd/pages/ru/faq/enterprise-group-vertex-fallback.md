# Что такое Enterprise-группа? Когда следует ее использовать?

> В APIYI Enterprise-группа — **для каждой модели отдельно**, а не одна универсальная группа: gpt-image-2 использует image2Enterprise (1.2x), Nano Banana использует NanoBananaEnterprise (1.4x) или NanoBananaReverse (0.8x). В этой статье кратко изложены различия, коэффициенты тарифа и сценарии использования Enterprise-группы каждой модели.

## Краткий ответ

**В APIYI «Enterprise group» — это не одна универсальная группа: у каждой модели есть свой выделенный enterprise-канал резервного переключения.** Обычно он немного дороже группы по умолчанию, но продолжает выполнять генерацию изображений даже при перегрузке группы по умолчанию — поэтому это вариант резервного использования для рабочих нагрузок с высоким процентом успешных результатов.

<Info>
  В этой статье перечислены только факты, которые можно проверить по официальной документации или записям текущего статуса. SLA, лимиты параллельных запросов и другие неопубликованные данные следует запрашивать через службу поддержки.
</Info>

## Корпоративные группы зависят от модели

В отличие от универсальных групп `ClaudeCode`, `Sora2Official` и т. д., корпоративные группы имеют отдельные названия для каждой модели:

| Модель                                                     | Название корпоративной группы | Коэффициент | Характер канала                                                                                                                                                      |
| ---------------------------------------------------------- | ----------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| gpt-image-2.5-flare / gpt-image-2.5-sunburst / gpt-image-2 | `image2Enterprise`            | 1.2x        | **Корпоративный резервный канал OpenAI через вышестоящий сервис** (см. [Обновление в реальном времени · 2026-05-13](/en/live/2026-05/gpt-image-2-default-saturated)) |
| Nano Banana Pro / 2                                        | `NanoBananaEnterprise`        | 1.4x        | Резервный канал Google с высокой доступностью (см. [Модели изображений и видео](/ru/api-capabilities/image-video-models))                                            |
| Nano Banana Pro / 2                                        | `NanoBananaReverse`           | 0.8x        | Канал **Vertex с обратной инженерией** (см. [Обновление в реальном времени · 2026-06](/en/live/2026-06/nanobanana-reverse))                                          |

<Tip>
  **Важное уточнение**: корпоративные группы **НЕ являются синонимом резервного канала Vertex**. `image2Enterprise` — это резервный канал OpenAI через вышестоящий сервис, не связанный с Google Vertex; `NanoBananaReverse` — канал, который действительно проходит через Vertex (с использованием обратной инженерии); `NanoBananaEnterprise` — резервный канал с высокой доступностью, состав которого явно не задокументирован.
</Tip>

## Когда группа по умолчанию была насыщена, корпоративные группы все еще работали

Практический пример для `gpt-image-2`:

* **2026-05-13 14:29–14:31** журналы вызовов: 9 непотоковых вызовов **все были направлены в группу `image2Enterprise`**, с задержкой до первого байта от 35 до 293 секунд при коэффициенте тарифа 1.2x — и все же успешно генерировали изображения (см. [Живое обновление · 2026-05](/en/live/2026-05/gpt-image-2-default-saturated)).
* Когда группа `gpt-image-2` по умолчанию была насыщена, "**некоторые запросы из группы по умолчанию были направлены через запасной путь в корпоративную группу**" — что подтверждает задумку проекта о том, что корпоративные группы служат запасным вариантом (то же живое обновление).

Задумка проекта `NanoBananaReverse` (см. [Живое обновление · 2026-06](/en/live/2026-06/nanobanana-reverse)):

> Чтобы снизить влияние на официальный direct Nano Banana Pro / 2 в часы пик, мы добавили реверс-инженеренную Vertex группу `NanoBananaReverse` по цене 80% от цены группы по умолчанию (коэффициент тарифа 0.8x), с тарификацией за каждый вызов независимо от разрешения.

<Warning>
  **Нет гарантии «корпоративная группа = всегда стабильна».** Официальная документация прямо указывает: корпоративная группа `gpt-image-2` (официальный OpenAI API) также сталкивалась с ошибками "The server had an error while processing your request." 2026-05-07, и первопричиной был сбой на upstream OpenAI (см. [Живое обновление · 2026-05](/en/live/2026-05/gpt-image-2-upstream-error)). Корпоративные группы **снижают** влияние перегрузки группы по умолчанию, но не гарантируют постоянную стабильность upstream.
</Warning>

## Как переключиться на корпоративную группу?

Корпоративные группы настраиваются **на уровне token**:

1. Откройте [https://api.apiyi.com/token](https://api.apiyi.com/token)
2. Найдите нужный token → нажмите «Управление (значок гаечного ключа)» в столбце действий → «Редактировать token»
3. В разделе «Выберите группу» выберите соответствующую корпоративную группу (например, `image2Enterprise`, `NanoBananaEnterprise`, `NanoBananaReverse`)
4. Сохраните

Изменения кода не нужны. Подробный разбор в [Живое обновление · 2026-04 · image2-enterprise](/en/live/2026-04/image2-enterprise-stable) (пример для gpt-image-2; путь тот же и для других моделей).

<Tip>
  **Область NanoBananaReverse**: Поддерживает только `gemini-3-pro-image` (Nano Banana Pro) и `gemini-3.1-flash-image` (Nano Banana 2), **только тарификация за вызов**. Если у вашего token Nano Banana Pro используется тарификация по использованию, эта группа не применяется.
</Tip>

## Часто задаваемые вопросы

<AccordionGroup>
  <Accordion title="Является ли корпоративная группа тем же, что и Vertex?">
    **Не обязательно** — это зависит от корпоративной группы конкретной модели:

    * `image2Enterprise` (только для gpt-image-2) — **НЕ Vertex**, а резервный корпоративный маршрут upstream OpenAI
    * `NanoBananaEnterprise` (только для Nano Banana) — в документации явно не указано, использует ли она Vertex
    * `NanoBananaReverse` (Nano Banana Pro / 2) — **точно использует реверс-инжиниринговый Vertex**

    Не следует приравнивать «корпоративную группу» к «резервному маршруту Vertex».
  </Accordion>

  <Accordion title="У каких моделей есть корпоративная группа?">
    Согласно доступной документации и текущим обновлениям:

    * gpt-image-2.5-flare / gpt-image-2.5-sunburst / gpt-image-2: `image2Enterprise` (1.2x)
    * Nano Banana Pro / 2: `NanoBananaEnterprise` (1.4x), `NanoBananaReverse` (0.8x)
    * Nano Banana OSS (вывод URL): `NB-OSS` (1x, но это бета-версия — для отображения группы необходимо обратиться в службу поддержки; см. [Группа Nano Banana OSS](/ru/api-capabilities/nano-banana-oss-group))

    Точный набор доступных групп **соответствует тому, что отображается в вашей панели управления** — со временем платформа может добавлять или переименовывать группы.
  </Accordion>

  <Accordion title="Когда следует переключаться на корпоративную группу?">
    Типичные сценарии на основе зарегистрированных инцидентов:

    * Группа по умолчанию постоянно перегружена / запросы находятся в очереди / истекает время ожидания (например, gpt-image-2 примерно в 2026-05)
    * Для вашего бизнеса критична доля успешных запросов, и вы не хотите, чтобы сбои группы по умолчанию снижали этот показатель
    * Nano Banana Pro / 2 плохо работает в часы пик — рассмотрите `NanoBananaReverse` (для каждого вызова, 0.8x, дешевле)

    И наоборот, **если группа по умолчанию располагает достаточными ресурсами, не следует переключаться на корпоративную группу**: 2026-05-23, после пополнения группы gpt-image-2 по умолчанию, было указано: «**вызывайте напрямую — нет необходимости специально переключаться на image2Enterprise**» (см. [Текущее обновление · 2026-05](/en/live/2026-05/gpt-image-2-default-restocked-0523-2142)).
  </Accordion>

  <Accordion title="Всегда ли корпоративная группа дороже группы по умолчанию?">
    Не обязательно. Коэффициенты из зарегистрированных данных могут быть разными:

    * `image2Enterprise`: 1.2x (≈ на 20% больше, чем у группы по умолчанию)
    * `NanoBananaEnterprise`: 1.4x (≈ на 40% больше, чем у группы по умолчанию)
    * `NanoBananaReverse`: **0.8x** (≈ **на 20% меньше**, чем у группы по умолчанию)

    Поэтому «корпоративная» не означает «более дорогая» — коэффициент тарифа зависит от конкретной модели и группы.
  </Accordion>

  <Accordion title="Можно ли настроить Default + Enterprise как резервный вариант?">
    Да. Один token поддерживает **1 группу по умолчанию + до 2 резервных групп** (см. [Токены и группы](/ru/faq/token-and-groups)). Когда основная группа перегружена, вызовы автоматически переключаются на резервный канал. Это рекомендуемый подход для рабочих нагрузок, требующих «высокой доли успешных запросов».
  </Accordion>
</AccordionGroup>
