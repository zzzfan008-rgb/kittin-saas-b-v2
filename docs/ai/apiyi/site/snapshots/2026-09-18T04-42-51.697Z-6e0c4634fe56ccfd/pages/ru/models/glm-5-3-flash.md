# GLM-5.3-Flash

> GLM-5.3-Flash на APIYI: $0.15 за входные данные / $0.5 за выходные данные на 1M tokens, контекстное окно 1,000,000, макс. выход 128,000, доступен в 2 группах тарификации.

Первая нативно мультимодальная GLM-5: 320B всего / 18B активных, 84.3 на Terminal-Bench 2.1 — почти на уровне Claude Opus 4.8, при стоимости примерно в десятую часть от стоимости флагманской модели; лицензия MIT.

## Пример запроса

В приведённом ниже примере выполняется вызов `glm-5.3-flash` через Chat Completions OpenAI (`/v1/chat/completions`). Укажите `https://api.apiyi.com/v1` в качестве base\_url — всё остальное соответствует официальному API.

```bash theme={null}
curl https://api.apiyi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $APIYI_API_KEY" \
  -d '{
    "model": "glm-5.3-flash",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

<Tip>Читайте ключ из переменной окружения, никогда не встраивайте его в код напрямую. В рабочей среде создавайте отдельные токены для каждого сценария использования, чтобы при необходимости отзывать их и отдельно связывать с ними использование.</Tip>
