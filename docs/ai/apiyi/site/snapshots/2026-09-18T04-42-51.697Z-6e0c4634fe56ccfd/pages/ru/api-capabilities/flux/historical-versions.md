# Исторические версии FLUX

> Спецификации FLUX.1 [pro] / [pro] 1.1 / [pro] 1.1 Ultra / [dev], тарификация и рекомендации по миграции на FLUX.2

<Note>
  На этой странице описаны модели FLUX.1 \[pro] для генерации изображений по тексту, которые **по-прежнему доступны для вызова** в APIYI. Последнее поколение FLUX.2 и ориентированный на редактирование FLUX.1 Kontext описаны в [Обзоре FLUX](/ru/api-capabilities/flux/overview).
</Note>

## Спецификации по версиям

### `flux-pro-1.1-ultra`

* **Выпущено**: 2024-11 (UTC+0)
* **Цена APIYI**: \$0.0500 (официальная \$0.06, экономия 17%)
* **Макс. выход**: \~4MP (самый высокий в серии FLUX.1)
* **Ключевые особенности**: сверхвысокое разрешение, необязательный режим raw (ближе к candid photography)
* **Известные ограничения**: только один reference, нет управления hex color, нет grounding search
* **Официальная документация**: `docs.bfl.ai/flux_models/flux_1_1_pro_ultra_raw`

### `flux-pro-1.1`

* **Выпущено**: 2024-10 (UTC+0)
* **Цена APIYI**: \$0.0350 (официальная \$0.04, экономия 12.5%)
* **Макс. выход**: \~1.6MP (например, 1024×1536)
* **Ключевые особенности**: улучшенное качество и соблюдение prompt по сравнению с 1.0, отраслевой базовый уровень
* **Известные ограничения**: один reference, короткие prompt (без 32K)
* **Официальная документация**: `docs.bfl.ai/flux_models/flux_1_1_pro`

### `flux-pro`

* **Выпущено**: 2024-08 (UTC+0)
* **Цена APIYI**: \$0.0400 (официальная \$0.04, без изменений)
* **Макс. выход**: \~1.6MP
* **Ключевые особенности**: первый коммерческий Pro от BFL, базовый text-to-image
* **Известные ограничения**: качество и соблюдение prompt ниже, чем у 1.1 — для новых проектов нет смысла

### `flux-dev`

* **Цена APIYI**: \$0.0200
* **Макс. выход**: \~1MP
* **Ключевые особенности**: вариант с открытыми весами (FLUX.1 \[dev], некоммерческая лицензия), self-host на собственном GPU
* **Известные ограничения**: качество ниже уровня \[pro], в основном для исследований, прототипирования, локальной проверки inference
* **Официальные веса**: `huggingface.co/black-forest-labs/FLUX.1-dev`

## Руководство по миграции

<Steps>
  <Step title="Оцените различия">
    FLUX.2 полностью заменяет FLUX.1 \[pro]: вывод 4MP (vs 1.6MP), до 8 множественных reference (vs 1), prompts на 32K tokens (vs short), нативное управление hex-цветом, уровень специалиста по типографике. Тарификация в пределах 1MP примерно такая же или ниже.
  </Step>

  <Step title="Запустите параллельно">
    Сгенерируйте один и тот же набор prompt на `flux-pro-1.1` и `flux-2-pro` в течение недели. Сравните читаемость текста, согласованность нескольких объектов, точность фирменных цветов. FLUX.2 \[pro] в большинстве случаев выигрывает по всем параметрам.
  </Step>

  <Step title="Внедряйте постепенно">
    Сначала переведите 10% трафика на `flux-2-pro`, наблюдайте за качеством и стоимостью в течение недели, затем увеличьте до 100%. Тарификация примерно сопоставима при 1MP и заметно дешевле при 4MP.
  </Step>

  <Step title="Учитывайте различия параметров">
    Большинство параметров переносится, но учтите:

    * FLUX.1 \[pro] принимает одно референсное изображение; FLUX.2 поддерживает несколько референсов (поля JSON `input_image` \~ `input_image_8`, до 8)
    * FLUX.1 не поддерживает `prompt_upsampling`; FLUX.2 \[pro/max/flex] поддерживает
    * Некоторые устаревшие идентификаторы отношения сторон (например, `aspect_ratio`) заменены на `width`/`height` или строку `size` в FLUX.2
  </Step>
</Steps>

## Пример устаревшего вызова

```python theme={null}
{/* Call any historical version by changing only the model field — all other params are OpenAI Images API compatible */}
from openai import OpenAI
import requests

client = OpenAI(api_key="sk-your-api-key", base_url="https://api.apiyi.com/v1")

resp = client.images.generate(
    model="flux-pro-1.1-ultra",
    prompt="A serene mountain landscape at golden hour, raw photo style",
    size="2048x1536"
)

# data[0].url is valid for only 10 minutes
url = resp.data[0].url
with open("legacy.jpg", "wb") as f:
    f.write(requests.get(url, timeout=30).content)
```
