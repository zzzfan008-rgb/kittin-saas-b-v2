# Устаревшие версии GPT-Image

> Линейка версий GPT-Image: текущие gpt-image-2.5-flare / gpt-image-2.5-sunburst / gpt-image-2 и устаревшие GPT-Image-1 / 1-mini / 1.5 — идентификаторы моделей, даты выпуска, цены, эндпоинты и рекомендации по миграции на 2.5 / 2-All.

<Info>
  Для новых проектов используйте [GPT-Image-2.5 / 2](/ru/api-capabilities/gpt-image-2/overview) (официальный; `gpt-image-2.5-flare` для преобразования текста в изображение, `gpt-image-2.5-sunburst` для редактирования) или [GPT-Image-2-All](/ru/api-capabilities/gpt-image-2-all/overview) (обратный канал, фиксированная цена \$0.03 за изображение). На этой странице сохранены основные сведения об устаревших версиях, чтобы существующие интеграции можно было без затруднений диагностировать и перенести.
</Info>

## Линейка версий

| ID модели                                       | Выпуск   | Эндпоинт                                     | Тарификация                                                                    | Статус                                                                                |
| ----------------------------------------------- | -------- | -------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| `gpt-image-2.5-flare` (снимок `-2026-09-08`)    | Сен 2026 | `/v1/images/generations`, `/v1/images/edits` | Входные данные \$5.00 / выходные данные \$30.00 за M tokens, как у gpt-image-2 | **Текущая**, приоритет скорости, по умолчанию для преобразования текста в изображение |
| `gpt-image-2.5-sunburst` (снимок `-2026-09-08`) | Сен 2026 | `/v1/images/generations`, `/v1/images/edits` | Как выше                                                                       | **Текущая**, приоритет качества и точности редактирования                             |
| `gpt-image-2` (снимок `-2026-04-21`)            | Апр 2026 | `/v1/images/generations`, `/v1/images/edits` | Входные данные \$5.00 / выходные данные \$30.00 за M tokens                    | Текущая, предыдущее поколение, `quality` до `high`                                    |
| `gpt-image-1.5`                                 | Дек 2025 | `/v1/images/generations`                     | Входные данные \$5.00 / выходные данные \$10.00 за M tokens                    | Доступна; рекомендуется обновление до `gpt-image-2.5-flare` / `sunburst`              |
| `gpt-image-1`                                   | Апр 2025 | `/v1/images/generations`, `/v1/images/edits` | Входные данные \$2.50 / выходные данные \$8.00 за M tokens                     | Доступна; рекомендуется обновление до `gpt-image-2.5-flare` / `sunburst`              |
| `gpt-image-1-mini`                              | Апр 2025 | `/v1/images/generations`                     | Ниже, чем у `gpt-image-1`                                                      | Доступна                                                                              |

<Tip>
  **Миграция без изменений в коде**: замените `model` на `gpt-image-2` или `gpt-image-2-all`. Параметры (`size` / `quality` / `output_format`, …) в основном совместимы — структурные изменения в коде не требуются.
</Tip>

## Общие параметры (генерация)

Все устаревшие версии используют одинаковые параметры генерации:

| Параметр             | Описание                                                                                      |
| -------------------- | --------------------------------------------------------------------------------------------- |
| `model`              | `gpt-image-1.5` / `gpt-image-1` / `gpt-image-1-mini`                                          |
| `prompt`             | Описание изображения, до 32 000 символов (ограничение провайдера, подсчёт ведётся в символах) |
| `size`               | `1024x1024` / `1536x1024` / `1024x1536` / `auto`                                              |
| `quality`            | `low` / `medium` / `high` / `auto` (в серии 2.5 добавлены `xhigh` / `max`)                    |
| `output_format`      | `png` (по умолчанию) / `jpeg` / `webp`                                                        |
| `output_compression` | Только JPEG/WebP, 0–100%                                                                      |
| `background`         | `transparent` / `opaque` / `auto`                                                             |
| `n`                  | Количество изображений (1–10)                                                                 |

## Быстрый пример

```python theme={null}
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.apiyi.com/v1"
)

response = client.images.generate(
    model="gpt-image-1.5",  {/* or gpt-image-1 / gpt-image-1-mini */}
    prompt="A professional product photo on white background, soft studio lighting",
    size="1024x1024",
    quality="high"
)

print(response.data[0].url)
```

## Справочник по ценам за изображение

GPT-Image-1 / 1.5 поддерживают как тарификацию по token, так и тарификацию за изображение — система автоматически выбирает более выгодный вариант:

### GPT-Image-1.5

| Качество | 1024×1024 | 1024×1536 / 1536×1024 |
| -------- | --------- | --------------------- |
| Низкое   | \$0.009   | \$0.013               |
| Среднее  | \$0.034   | \$0.050               |
| Высокое  | \$0.133   | \$0.200               |

### GPT-Image-1

| Качество | 1024×1024 | 1024×1536 / 1536×1024 |
| -------- | --------- | --------------------- |
| Низкое   | \$0.005   | \$0.006               |
| Среднее  | \$0.011   | \$0.015               |
| Высокое  | \$0.036   | \$0.052               |

<Warning>
  Цифры для тарификации за изображение приведены только для справки. Фактическая стоимость определяется по тому режиму тарификации — по token или за изображение, — который система считает более выгодным.
</Warning>

## Редактирование изображений (только `gpt-image-1`)

`gpt-image-1` поддерживает редактирование на основе маски через эндпоинт `/v1/images/edits`:

```python theme={null}
response = client.images.edit(
    model="gpt-image-1",
    image=open("original.png", "rb"),
    mask=open("mask.png", "rb"),
    prompt="A modern glass skyscraper with reflective windows",
    size="1024x1024"
)
```

| Параметр | Описание                                                              |
| -------- | --------------------------------------------------------------------- |
| `image`  | Исходное изображение, PNG/WebP/JPG, \< 50MB каждое, до 16 изображений |
| `mask`   | Изображение маски — пиксели с alpha=0 будут перерисованы              |
| `prompt` | Описание того, что нужно сгенерировать в замаскированной области      |

<Note>
  Для новых рабочих процессов редактирования используйте [GPT-Image-2 Edit](/ru/api-capabilities/gpt-image-2/image-edit) (официальный) или [GPT-Image-2-All Edit](/ru/api-capabilities/gpt-image-2-all/image-edit) (обратный, поддерживает до 16 входных изображений для смешивания).
</Note>
