# Grok 4.6

> Grok 4.6 на APIYI: $2 за входные / $6 за выходные данные на 1 млн tokens, контекстное окно 500 000, доступен в 3 группах тарификации.

Использует основу 4.5 с 1,5T-параметрами и повышает индекс интеллекта Artificial Analysis с 56 до 61 только за счёт post-training — по той же базовой цене, что и 4.5.

| Вход | Кэшированный вход | Выход |

| \$2  | \$0.5             | \$6   |

<Info>В таблице указаны **базовые цены**. Акции на пополнение и групповые скидки **суммируются**; консоль отображает фактическое списание в реальном времени. См. [Тарификация](/ru/pricing) и [Акции на пополнение](/ru/faq/recharge-promotions).</Info>

## Многоуровневое ценообразование

Эта модель использует многоуровневую тарификацию в зависимости от размера token в каждом запросе (цена output = входная цена уровня × множитель output):

* 0 – 204,800 tokens: \$2/1M input
* 204,801 – 512,000 tokens: \$4/1M input

## Пример запроса

Пример ниже вызывает `grok-4.6` через OpenAI Chat Completions (`/v1/chat/completions`). Укажите base\_url на `https://api.apiyi.com/v1` — всё остальное соответствует официальному API.

```bash theme={null}
curl https://api.apiyi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $APIYI_API_KEY" \
  -d '{
    "model": "grok-4.6",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

<Tip>Получайте ключ из переменной окружения, никогда не встраивайте его напрямую в код. В production выпускайте отдельные token для каждого варианта использования, чтобы вы могли отзывать их и отдельно учитывать использование.</Tip>
