# CC Switch

> Единое настольное приложение для управления Claude Code и 4 другими AI CLI-инструментами — переключение провайдера в один клик, настройка модели и многое другое

## Обзор

CC Switch — desktop-приложение, созданное на Tauri 2 и объединяющее управление пятью AI CLI-инструментами: Claude Code, Codex CLI, Gemini CLI, OpenCode и OpenClaw. Больше не нужно вручную редактировать файлы конфигурации — переключайте API providers, models и keys через графический интерфейс.

## Основные возможности

### Управление провайдерами

* Более 50 встроенных пресетов, включая AWS Bedrock и NVIDIA NIM
* Переключение в один клик, сортировка перетаскиванием, импорт/экспорт
* Быстрый доступ из системного трея

### Управление MCP Server

* Единая конфигурация MCP Server для всех CLI-инструментов
* Двунаправленная синхронизация — изменения распространяются во все приложения

### Другие возможности

* **Управление промптами**: редактор Markdown + синхронизация между приложениями
* **Установка навыков**: установка навыков из репозиториев GitHub или ZIP-файлов
* **Браузер сессий**: просмотр и восстановление истории разговоров
* **Синхронизация с облаком**: поддержка Dropbox, OneDrive, iCloud и WebDAV
* **Deep Link**: протокол `ccswitch://` для импорта конфигурации в один клик

## Быстрый старт

### Шаг 1: Установите CC Switch

<Tabs>
  <Tab title="macOS">
    Установите через Homebrew:

    ```bash theme={null}
    brew install --cask cc-switch
    ```

    Или загрузите установщик DMG из GitHub Releases.
  </Tab>

  <Tab title="Windows">
    Загрузите установщик MSI или Portable ZIP из GitHub Releases.
  </Tab>

  <Tab title="Linux">
    Выберите способ установки для вашего дистрибутива:

    ```bash theme={null}
    # Debian/Ubuntu
    sudo dpkg -i cc-switch_*.deb

    # Fedora/RHEL
    sudo rpm -i cc-switch_*.rpm

    # Arch Linux
    paru -S cc-switch-bin
    ```

    Также доступны AppImage и Flatpak.
  </Tab>
</Tabs>

<Info>
  **Системные требования**: Windows 10+, macOS 10.15 (Catalina)+, Ubuntu 22.04+ / Debian 11+ / Fedora 34+
</Info>

### Шаг 2: Получите свой APIYI API-ключ

1. Перейдите на [страницу token в APIYI консоли](https://api.apiyi.com/token)
2. Нажмите, чтобы создать новый token
3. **Важно**: Выберите **【ClaudeCode】группу** для **скидки 88%**
4. Скопируйте сгенерированный ключ (начинается с `sk-`)

<Tip>
  **Сэкономьте**: Обязательно выбирайте **【ClaudeCode】группу** при создании token, чтобы пользоваться тарификацией со скидкой 88%.
</Tip>

### Шаг 3: Настройте APIYI в CC Switch

1. Откройте CC Switch
2. Перейдите на страницу управления **провайдером**, нажмите «Добавить» и выберите «Пользовательский шлюз»:

<img src="https://mintcdn.com/apiyillc/9frKyyBXrVY4n9Yi/images/cc-switch-provider-config.png?fit=max&auto=format&n=9frKyyBXrVY4n9Yi&q=85&s=bea7dc157f751d1a530f486664b15791" alt="Конфигурация провайдера CC Switch - добавление APIYI как унифицированного провайдера" width="1628" height="1522" data-path="images/cc-switch-provider-config.png" />

3. Заполните следующую информацию, как показано выше:
   * **Имя**: `APIYI`
   * **Адрес API**: `https://api.apiyi.com`
   * **API-ключ**: Вставьте ключ из предыдущего шага
   * **Включенные приложения**: Включите Claude Code (остальные — по необходимости)
4. Нажмите «Добавить», чтобы сохранить конфигурацию

### Шаг 4: Добавьте модели

Добавьте следующие модели в конфигурации вашего провайдера:

**Стандартные модели**:

| Название модели   | ID модели                   | Описание                                            |
| ----------------- | --------------------------- | --------------------------------------------------- |
| Claude Opus 4.6   | `claude-opus-4-6`           | Флагманская модель, лучше всего для сложных задач   |
| Claude Sonnet 4.6 | `claude-sonnet-4-6`         | Сильна в coding, лучшее соотношение цены и качества |
| Claude Haiku 4.5  | `claude-haiku-4-5-20251001` | Легкая и быстрая, для простых задач                 |

**Модели рассуждения** (с принудительным chain-of-thought):

| Название модели            | ID модели                            | Описание                                          |
| -------------------------- | ------------------------------------ | ------------------------------------------------- |
| Claude Opus 4.6 Thinking   | `claude-opus-4-6-thinking`           | Глубокое рассуждение, анализ сложной логики       |
| Claude Sonnet 4.6 Thinking | `claude-sonnet-4-6-thinking`         | coding с усиленным рассуждением, сбалансированная |
| Claude Haiku 4.5 Thinking  | `claude-haiku-4-5-20251001-thinking` | Легкое рассуждение, быстрое мышление              |

<Tip>
  **Советы по выбору модели**: Используйте `claude-sonnet-4-6` для повседневного coding, `claude-opus-4-6` для сложного проектирования архитектуры и `claude-haiku-4-5-20251001` для быстрых вопросов и ответов. Используйте варианты Thinking, когда требуется глубокое рассуждение.
</Tip>

### Шаг 5: Переключение в один клик

После настройки выберите APIYI как активного провайдера в CC Switch. Все связанные инструменты CLI (Claude Code, Codex CLI и т. д.) автоматически переключатся на конфигурацию APIYI.

## Руководство по использованию

### Управление несколькими инструментами CLI

CC Switch поддерживает одновременное управление этими 5 инструментами CLI для ИИ:

* **Claude Code** — официальный CLI-помощник Anthropic для программирования
* **Codex CLI** — инструмент командной строки OpenAI для программирования
* **Gemini CLI** — AI-помощник Google для командной строки
* **OpenCode** — open-source инструмент CLI для программирования
* **OpenClaw** — open-source локальный агент ИИ

Все инструменты используют общую конфигурацию Provider — переключите один раз, применится везде.

### Локальный прокси

CC Switch включает встроенный локальный сервер прокси со следующими возможностями:

* **Переключение на лету**: переключайте Provider без перезапуска
* **Автоматический failover**: автоматически переключается на резервный Provider при недоступности текущего
* **Circuit breaker**: останавливает запросы при повторяющихся сбоях, чтобы предотвратить расход ресурсов

### Резервное копирование конфигурации

* Система автоматического резервного копирования сохраняет 10 последних версий
* Импорт и экспорт полных конфигураций
* Синхронизация с облаком через Dropbox, OneDrive, iCloud, WebDAV

## Часто задаваемые вопросы

<AccordionGroup>
  <Accordion title="Какие операционные системы поддерживает CC Switch?">
    Windows 10+, macOS 10.15 (Catalina)+ и основные дистрибутивы Linux (Ubuntu 22.04+, Debian 11+, Fedora 34+, Arch Linux).
  </Accordion>

  <Accordion title="Как получить групповую скидку?">
    Некоторые группы (например, группа ClaudeCode) предлагают скидку при создании token в [консоли APIYI](https://api.apiyi.com/token) — проверьте консоль, чтобы узнать текущий тариф. Сочетайте это с бонусом за пополнение, чтобы получить еще более низкую итоговую стоимость.
  </Accordion>

  <Accordion title="Claude Code не может подключиться после настройки?">
    Проверьте:

    1. API Key указан верно (начинается с `sk-`)
    2. Base URL задан как `https://api.apiyi.com`
    3. На балансе APIYI достаточно средств
    4. CC Switch синхронизировал конфигурацию с Claude Code
  </Accordion>

  <Accordion title="В чем разница между стандартными моделями и моделями Thinking?">
    Модели Thinking (reasoning) принудительно включают режим chain-of-thought, выполняя глубокий анализ рассуждений перед ответом. Они идеально подходят для сложной логики, проектирования архитектуры и сценариев глубокого рассуждения. Стандартные модели отвечают быстрее и подходят для повседневного программирования и простых задач.
  </Accordion>

  <Accordion title="Как перейти с других способов настройки на CC Switch?">
    CC Switch поддерживает импорт и может автоматически обнаруживать существующие переменные среды и файлы конфигурации. После установки откройте приложение, и оно автоматически обнаружит установленные CLI-инструменты и их существующие конфигурации.
  </Accordion>

  <Accordion title="CC Switch бесплатен?">
    Сам CC Switch полностью бесплатен и с открытым исходным кодом (лицензия MIT). Плата взимается только за вызовы API — использование группы ClaudeCode через APIYI дает вам цену со скидкой 88%.
  </Accordion>
</AccordionGroup>
