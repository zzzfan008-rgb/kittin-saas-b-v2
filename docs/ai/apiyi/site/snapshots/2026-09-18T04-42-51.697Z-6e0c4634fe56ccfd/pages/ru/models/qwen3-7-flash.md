# Qwen3.7-Flash

## Пример запроса

В приведённом ниже примере вызывается `qwen3.7-flash` через Chat Completions OpenAI (`/v1/chat/completions`). Укажите `https://api.apiyi.com/v1` в качестве base\_url — всё остальное соответствует официальному API.

```bash theme={null}
curl https://api.apiyi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $APIYI_API_KEY" \
  -d '{
    "model": "qwen3.7-flash",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

<Tip>Считывайте ключ из переменной окружения, никогда не встраивайте его напрямую в код. В рабочей среде создавайте отдельные token для каждого сценария использования, чтобы их можно было отзывать и отдельно отслеживать использование.</Tip>
