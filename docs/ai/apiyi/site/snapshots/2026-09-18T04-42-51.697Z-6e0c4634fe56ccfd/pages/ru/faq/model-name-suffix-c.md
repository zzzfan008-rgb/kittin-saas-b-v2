# Что означает суффикс -c в названиях model?

> Объясняет значение названий model с суффиксом -c, таких как gemini-3-pro-image-preview-c, и различия в их тарификации

## Краткий ответ

<Info>
  **`-c` означает «вызов» (оплата за каждый вызов).**

  Модели с суффиксом `-c` (например, `gemini-3-pro-image-preview-c`) и без него (например, `gemini-3-pro-image-preview`) — это по сути **одна и та же модель** с идентичными возможностями. Единственное отличие — способ тарификации: версия `-c` предназначена специально для **оплаты за каждый вызов**.
</Info>

## Официальное объяснение

<img src="https://mintcdn.com/apiyillc/-8MuET9SQdeEzoC1/images/model-name-suffix-c-explain.png?fit=max&auto=format&n=-8MuET9SQdeEzoC1&q=85&s=892eb766d8a1d4f3ebd5a249d21b1d5a" alt="Объяснение суффикса -c в названии модели" width="1062" height="476" data-path="images/model-name-suffix-c-explain.png" />

Ключевые моменты:

* `-c` означает «call» — отдельное название модели для тарификации по каждому вызову
* По сути это **та же модель**, что и версия без суффикса
* Оба варианта — это официальный релей API, просто используются разные названия моделей, чтобы различать способы тарификации
* В будущем тарификация может различаться только через режимы тарификации token

## Почему суффикс -c?

APIYI внедряет тарификацию на основе token, и некоторые модели поддерживают как тарификацию на основе token, так и тарификацию за вызов. Система использует суффиксы в именах моделей, чтобы различать разные каналы тарификации:

| Имя модели                     | Способ тарификации | Описание                                  |
| ------------------------------ | ------------------ | ----------------------------------------- |
| `gemini-3-pro-image-preview`   | На основе token    | Списывается по объему использования token |
| `gemini-3-pro-image-preview-c` | За вызов           | Фиксированная цена за каждый вызов API    |

<Note>
  Оба названия вызывают **точно одну и ту же официальную модель** через официальный API-релей. Возможности модели и качество вывода идентичны.
</Note>

## Как выбрать?

<CardGroup cols={2}>
  <Card title="По token (без суффикса)" icon="chart-line">
    **Лучше всего для**:

    * Запросов с меньшим количеством входных/выходных token
    * Когда нужен точный контроль затрат
    * В основном задач понимания/анализа текста

    Используйте имя модели без `-c`
  </Card>

  <Card title="За вызов (суффикс -c)" icon="hand">
    **Лучше всего для**:

    * Генерации изображений и сценариев с фиксированным результатом
    * Прозрачной фиксированной стоимости за вызов
    * Когда не нужно рассчитывать расход token

    Используйте имя модели с `-c`
  </Card>
</CardGroup>

<Tip>
  **Рекомендуется**: При создании token выберите режим тарификации «**сначала token**». Система автоматически выберет для вас наиболее подходящий метод тарификации, и вам не придется вручную различать суффиксы имени модели. Подробности см. в [Режимы тарификации по token](/ru/faq/token-billing-modes).
</Tip>

## Планы на будущее

<Info>
  APIYI постоянно оптимизирует свою систему тарификации. В будущем тарификация может различаться **только через режимы тарификации token**, что устранит необходимость в суффиксах в названиях моделей. Пожалуйста, следите за объявлениями платформы, чтобы получать обновления.
</Info>

## Часто задаваемые вопросы

<AccordionGroup>
  <Accordion title="Модель с суффиксом -c — это та же самая, что и без суффикса?">
    **Да, это абсолютно та же модель.**

    Суффикс `-c` только указывает канал тарификации и не влияет на возможности модели. Оба имени в конечном итоге перенаправляются в тот же официальный API с одинаковым качеством вывода.
  </Accordion>

  <Accordion title="Какое имя модели мне следует использовать?">
    Это зависит от режима тарификации вашего token:

    * **Токен типа «Token-first»**: используйте имя без суффикса (например, `gemini-3-pro-image-preview`), система обработает это автоматически
    * **Токен с тарификацией по вызовам**: используйте имя с `-c` (например, `gemini-3-pro-image-preview-c`)
    * **Если не уверены**: рекомендуем использовать токен типа «Token-first» + имя модели без суффикса
  </Accordion>

  <Accordion title="У всех моделей есть версия -c?">
    Нет. Только у моделей, которые поддерживают как тарификацию по token, так и тарификацию по вызовам, есть версия с суффиксом `-c`. Чисто текстовые модели (такие как GPT-4o, Claude) обычно поддерживают только тарификацию по token и не имеют версии `-c`.
  </Accordion>

  <Accordion title="Суффикс -c будет существовать всегда?">
    APIYI настраивает свою систему тарификации и в будущем, возможно, больше не потребуется суффиксы в имени модели для различения способов тарификации, а управление полностью перейдет через режимы тарификации token. Мы рекомендуем использовать токены типа «Token-first», чтобы на вас не повлияли будущие изменения.
  </Accordion>
</AccordionGroup>
