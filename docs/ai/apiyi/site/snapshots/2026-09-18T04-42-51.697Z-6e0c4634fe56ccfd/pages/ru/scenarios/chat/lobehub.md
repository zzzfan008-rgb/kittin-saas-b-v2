# LobeHub

> Руководство по интеграции Open-source AI-чат-клиента с кастомными провайдерами и локальной базой знаний

LobeHub — это open-source, кроссплатформенный AI chat client (ранее Lobe Chat), который поддерживает несколько моделей, мультимодальный ввод, маркетплейс плагинов и локальную базу знаний. С APIYI вы можете использовать один API key в LobeHub для доступа к 400+ основным AI моделям — не нужно регистрироваться и оплачивать каждого провайдера отдельно.

## Быстрый старт

### 1. Получите ваш APIYI API key

См. [Руководство по управлению API Key](/ru/faq/token-management), чтобы получить ваш API key.

### 2. Установите LobeHub

LobeHub предлагает три способа использования:

* **Настольный**: официальный клиент для Windows, macOS и Linux — загрузите его с `lobechat.com`
* **Веб (официальный)**: просто перейдите на `lobechat.com`, зарегистрируйтесь и используйте без самостоятельного хостинга
* **Самостоятельное развертывание**: разверните через Docker / Vercel / локальный исходный код — отлично подходит для корпоративных задач или требований к конфиденциальности

<Tip>
  Для личного использования мы рекомендуем официальный веб- или настольный клиент. Если у вас есть требования к конфиденциальности данных или соблюдению нормативных требований, используйте самостоятельное развертывание с Docker (просто настройте APIYI через переменные окружения).
</Tip>

### 3. Создайте пользовательский провайдер

<img src="https://mintcdn.com/apiyillc/xf0Zzocq7Adycbe5/images/lobehub-create-provider.png?fit=max&auto=format&n=xf0Zzocq7Adycbe5&q=85&s=ddda3ebd3c4aa4e60aa6c9f87bd14ecb" alt="LobeHub — Создание пользовательского провайдера AI-сервиса" width="763" height="916" data-path="images/lobehub-create-provider.png" />

Перейдите на `Settings → Model Providers`, нажмите значок `+` в правом верхнем углу, чтобы добавить пользовательский провайдер, и заполните поля, как показано выше:

| Поле                    | Значение                   | Примечания                                                    |
| ----------------------- | -------------------------- | ------------------------------------------------------------- |
| **ID провайдера**       | `apiyi`                    | Уникальный идентификатор — после создания его нельзя изменить |
| **Название провайдера** | `apiyi`                    | Пользовательское отображаемое имя                             |
| **Описание провайдера** | `apiyi`                    | Пользовательское описание                                     |
| **Логотип провайдера**  | (оставьте пустым)          | Необязательно — URL пользовательского логотипа                |
| **Формат запроса**      | `OpenAI`                   | APIYI полностью совместим с OpenAI                            |
| **URL прокси**          | `https://api.apiyi.com/v1` | Базовый URL — **должен заканчиваться на `/v1`**               |
| **API Key**             | Ваш APIYI API key          | Получите его в консоли APIYI                                  |

Нажмите кнопку **Создать** в правом нижнем углу, чтобы сохранить.

<Info>
  **Советы по конфигурации**

  * `Proxy URL` ДОЛЖЕН заканчиваться на `/v1`, иначе запросы не будут маршрутизироваться
  * При вставке удаляйте все пробелы в начале и в конце вашего API key
  * Выберите `OpenAI` в качестве формата запроса, чтобы получить доступ ко всем более чем 400 моделям APIYI
  * Один ключ работает со всеми включенными моделями — платите только за то, что используете
</Info>

### 4. Проверьте подключение

<img src="https://mintcdn.com/apiyillc/xf0Zzocq7Adycbe5/images/lobehub-configured.png?fit=max&auto=format&n=xf0Zzocq7Adycbe5&q=85&s=b230b3aac1cd11cb9bd186d020ce8b73" alt="LobeHub — Вид настроенного провайдера" width="1473" height="913" data-path="images/lobehub-configured.png" />

После создания провайдера вы перейдете на его страницу с подробной информацией. Здесь вы можете:

1. **Подтвердить или обновить API Key и URL прокси**
2. **Включить расширенные параметры** (необязательно):
   * `Use Responses API spec` — включает новый формат запросов OpenAI (только для моделей OpenAI)
   * `Use client-side request mode` — браузер отправляет запросы напрямую, что может повысить скорость ответа
3. **Проверка подключения** — выберите модель в выпадающем списке и нажмите **Проверить**
4. **Получить список моделей** — нажмите кнопку **Получить список моделей**, чтобы загрузить все доступные модели из APIYI

После успешного получения `Model list` покажет все, что сейчас предлагает APIYI, сгруппированное по типам: Чат, Изображение, Видео, Embedding, ASR, TTS.

<Warning>
  Если проверка подключения не удалась, пройдите по этому списку:

  * URL прокси заканчивается на `/v1`?
  * API key все еще действителен? (проверьте в консоли APIYI)
  * Может ли ваша сеть получить доступ к `api.apiyi.com`?
  * Блокирует ли firewall или proxy трафик HTTPS?
</Warning>

### 5. Выберите модель и начните чат

В выпадающем списке моделей в интерфейсе чата выберите модель, например `claude-opus-5`, `gpt-5-6-terra` или `deepseek-v4-pro`, и можно начинать.

<Card title="Смотрите сегодняшние лучшие рекомендации по моделям" icon="star" href="/ru/api-capabilities/model-info">
  Просматривайте последние рекомендации по моделям, сравнения производительности и советы по использованию в различных сценариях — для написания текстов, программирования, быстрого отклика, генерации изображений, генерации видео и многого другого.
</Card>

<Info>
  **Почему здесь нет конкретного списка моделей?**

  Модели ИИ обновляются очень быстро. Чтобы рекомендации оставались точными, мы поддерживаем актуальный список моделей, данные о производительности и советы по использованию на [странице рекомендаций по моделям](/ru/api-capabilities/model-info).
</Info>

## Доступ ко всем 400+ моделям с одним провайдером

LobeHub поставляется со встроенными каналами для многих популярных провайдеров, каждому из которых нужен свой ключ. С APIYI вы создаете **один** собственный провайдер, который охватывает все модели:

| Канал                            | Модели                                                   | Ключевое преимущество                                         | API-эндпоинт               |
| -------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------- | -------------------------- |
| **Совместимый с OpenAI (apiyi)** | Все 400+ моделей (Claude, Gemini, GPT, DeepSeek и т. д.) | Один ключ открывает все возможности — самая простая настройка | `https://api.apiyi.com/v1` |

<Tip>
  **Один канал apiyi охватывает Claude, Gemini и все остальные модели**

  APIYI объединяет Claude, Gemini, GPT, DeepSeek и другие ведущие модели под протоколом, совместимым с OpenAI. Таким образом, один `apiyi` собственный провайдер в LobeHub дает вам доступ ко всем 400+ моделям в выпадающем списке — не нужно настраивать отдельные каналы для каждого поставщика.
</Tip>

## Подробный разбор возможностей LobeHub

### Маркетплейс плагинов

LobeHub поставляется с богатым маркетплейсом плагинов (`Settings → Plugins`). Рекомендуемые плагины:

* **Web Search** — дайте моделям доступ к интернету в реальном времени
* **Code Interpreter** — запускайте Python прямо в чате для анализа данных и визуализации
* **Chart Generation** — автоматически создавайте блок-схемы и майнд-карты
* **Image Generation** — генерируйте изображения с помощью моделей вроде `gpt-image-2` и `gemini-3-pro-image`

### Локальная база знаний (RAG)

LobeHub может построить локальное векторное хранилище из ваших файлов:

1. Перейдите на страницу `Knowledge Base` и создайте новую базу знаний
2. Загрузите файлы PDF, Markdown, Word, Excel или TXT
3. Система автоматически разбивает их на фрагменты и создает embeddings
4. В чате выберите базу знаний, и модель будет отвечать, опираясь на ваши файлы

<Warning>
  На этапе embedding вызывается embedding model (это учитывается в тарификации). Мы рекомендуем использовать `text-embedding-3-large` от APIYI или аналогичные embedding-модели.
</Warning>

### Мультимодальный чат

Загружайте изображения для понимания изображений, распознавания и OCR:

* Рекомендуемые vision-модели: `gemini-3-6-flash`, `claude-opus-5`, `gpt-5-6-terra`
* Просто перетащите изображение в поле ввода чата, и модель распознает его

### Маркетплейс агентов

LobeHub поставляется с богатым набором предустановленных агентов (перевод, написание, программирование, подготовка к собеседованию и т. д.). Вы также можете:

* Активировать в один клик любой агент, которым поделилось сообщество, из `Agent marketplace`
* Создать собственного агента — с настраиваемой персоной, prompt, приветственной репликой, базой знаний и плагинами

### Управление беседами

* Разветвляйте беседы, редактируйте сообщения, регенерируйте ответы
* Экспортируйте беседы в Markdown, PNG или JSON
* Глобальный поиск по истории сообщений

## Расширенная конфигурация

### Пользовательские параметры запроса

На странице сведений о провайдере вы можете настроить общие параметры:

```yaml theme={null}
Default parameters:
  Temperature: 0.7        # Creativity (reasoning models such as the GPT-5.6 series must use 1)
  Top P: 0.9              # Sampling (reasoning models must use 1)
  Max Tokens: 4096        # Maximum output length
  Context Length: 8192    # Context window
```

<Warning>
  Некоторые модели рассуждения (например, серия GPT-5.6) поддерживают только `Temperature = 1` и `Top P = 1`. Другие значения игнорируются или вызывают ошибки на стороне сервера.
</Warning>

### Сетевой прокси и самостоятельное размещение

Для использования прокси или самостоятельно размещенного LobeHub:

1. **Настольный клиент**: `Settings → Network` для настройки HTTP/HTTPS-прокси
2. **Самостоятельный хостинг (Docker)**: передайте конфигурацию APIYI через переменные окружения:
   ```bash theme={null}
   OPENAI_API_KEY=sk-your-apiyi-key
   OPENAI_PROXY_URL=https://api.apiyi.com/v1
   CUSTOM_MODELS=gpt-5-6-terra,claude-opus-5,deepseek-v4-pro
   ```
3. **Режим запросов на стороне клиента**: включает прямые запросы из браузера (только если браузер может обратиться к APIYI)

## Mobile

Десктопный клиент LobeHub работает на Windows / macOS / Linux. Для мобильных устройств используйте адаптивное веб-приложение на `lobechat.com` — отдельная установка не требуется.

## Устранение неполадок

### Сбой соединения / проверка подключения не проходит

| Симптом    | Что проверить                                                                  |
| ---------- | ------------------------------------------------------------------------------ |
| 401 / 403  | API key недействителен или баланс исчерпан — проверьте в консоли APIYI         |
| 404        | В URL прокси отсутствует суффикс `/v1`                                         |
| Timeout    | Проблема с сетью — проверьте прокси или firewall                               |
| CORS error | Отключите `Client-side request mode` или используйте прокси на стороне сервера |

### Список моделей пуст

* Нажмите **Получить список моделей**, чтобы выполнить повторную загрузку
* Подождите 1-2 секунды, затем обновите страницу
* Убедитесь, что API key активен в консоли APIYI

### Медленный ответ или прерывания потоковой передачи

* Переключитесь на более быструю модель (например, `gemini-3-5-flash-lite`, `claude-haiku-4-5`, `deepseek-v4-flash`)
* Отключите ненужные плагины
* Проверьте задержку сети
* Сократите длинный контекст (закройте устаревшие диалоги)

### Извлечение из базы знаний неточно

* Уменьшите размер chunk для более точного извлечения
* Переключитесь на более мощную embedding-модель в APIYI
* Добавьте больше релевантных документов, чтобы повысить полноту поиска

## Лучшие практики

### Стратегия выбора модели

Используйте подходящую модель для соответствующей задачи — подбирайте по сложности:

* **Ежедневный чат / простые вопросы и ответы**: `gemini-3-5-flash-lite`, `claude-haiku-4-5`, `deepseek-v4-flash`
* **Сложное рассуждение / анализ длинных документов**: `claude-opus-5`, `gpt-5-6-sol`, `deepseek-v4-pro`
* **Кодинг**: `claude-opus-5`, `gpt-5-6-sol`, `claude-sonnet-5`
* **Понимание изображений**: `gemini-3-6-flash`, `claude-opus-5`, `gpt-5-6-terra`
* **Генерация изображений**: `gpt-image-2`, `gemini-3-pro-image`

Полный список моделей и сравнение производительности см. на странице [Рекомендации по моделям](/ru/api-capabilities/model-info).

### Управление контекстом

* Периодически удаляйте устаревшие беседы
* Разбивайте сложные задачи на более короткие беседы
* Используйте функцию `branch conversation`, чтобы изучать альтернативные ответы

### Безопасность и конфиденциальность

* Не делитесь своим API key в публичном доступе
* Периодически меняйте ключи (сброс в один клик в консоли APIYI)
* Для конфиденциальных бесед разворачивайте LobeHub у себя — данные остаются локально

### Советы по self-hosting

* Используйте Docker + PostgreSQL в production, а не встроенную БД
* Поставьте Cloudflare перед системой как обратный прокси
* Управляйте secret-ами через переменные окружения для удобного развертывания на нескольких инстансах

## Сравнение с другими клиентами

Все три клиента подключаются к APIYI одинаково (протокол, совместимый с OpenAI). Они отличаются главным образом моделью развертывания и фокусом на функциях:

| Функция                         | LobeHub                                                                  | [Chatbox AI](/ru/scenarios/chat/chatbox)           | [Cherry Studio](/ru/scenarios/chat/cherry-studio) |
| ------------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------- | ------------------------------------------------- |
| **Развертывание**               | Настольное приложение + web + Docker / самостоятельный хостинг на Vercel | Настольное приложение + мобильное приложение + web | Настольное приложение + мобильное приложение      |
| **Локальная база знаний (RAG)** | Встроенное векторное хранилище                                           | Понимание документов для каждого диалога           | Встроенная база знаний                            |
| **Плагины / расширения**        | Магазин плагинов, богатая экосистема                                     | Встроены основные возможности                      | Преимущественно встроенные возможности            |
| **Протоколы каналов**           | Совместимый с OpenAI                                                     | Совместимый с OpenAI                               | OpenAI / Anthropic / Gemini                       |
| **Мобильные**                   | Адаптивный web                                                           | Нативные приложения                                | Нативные приложения                               |

<Tip>
  **Когда выбирать LobeHub?**

  * Вам нужна **постоянная локальная база знаний** или **экосистема плагинов** (веб-поиск, интерпретатор кода, графики и т. д.)
  * Вы хотите **частное развертывание** (Docker / Vercel) с полным контролем над данными
  * Вы хотите один **единый интерфейс** для Desktop + web

  Все три варианта — надежный выбор: выбирайте Chatbox AI, если для вас важны **нативные мобильные приложения и локальное хранение**; выбирайте Cherry Studio, если вам нужны **нативные протоколы Claude / Gemini** (включая кэширование промптов).
</Tip>

Нужна дополнительная помощь? См. документацию в `lobechat.com` или посетите [сайт APIYI](https://api.apiyi.com).
