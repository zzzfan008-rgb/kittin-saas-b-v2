# Как обеспечивается безопасность контента и соблюдение требований?

> Описание политики APIYI по обеспечению безопасности контента и соблюдению требований, включая механизм проверки контента и меры по обработке нарушений

## Система обеспечения безопасности контента

APIYI стремится предоставлять безопасные и соответствующие требованиям AI-сервисы, применяя многоуровневые меры безопасности для обеспечения соответствия контента.

## Механизм проверки контента

### Профессиональная система проверки

Мы интегрировали **профессиональные официальные API проверки контента** для обеспечения защиты всех запросов в реальном времени:

<Info>
  **Принцип работы проверки**

  * **Обнаружение в реальном времени**: каждый запрос API проходит проверку контента
  * **Интеллектуальная идентификация**: автоматически определяет потенциально нарушающий контент
  * **Проактивное перехватывание**: нарушающий контент не возвращается пользователям
  * **Политика нулевой терпимости**: строгие меры в отношении нарушающего контента
</Info>

### Область покрытия проверки

* **Проверка входящего контента**: проверяет весь текст и изображения, отправленные пользователями
* **Проверка исходящего контента**: обеспечивает соответствие сгенерированного AI-контента стандартам
* **Поддержка нескольких языков**: поддерживает проверку основных языков, включая китайский и английский
* **Мультимодальное обнаружение**: охватывает различные формы контента, включая текст и изображения

## Требования к соблюдению

### Обязанности пользователя

<Warning>
  **Соблюдение законодательства**

  Пользователи должны **соблюдать местные законы и нормативные акты** при использовании сервисов APIYI, включая, помимо прочего:

  * Национальные и местные правовые нормы
  * Отраслевые нормативные требования
  * Международные правовые нормы
  * Условия использования платформы
</Warning>

### Запрещенные типы контента

Следующие типы контента строго запрещены:

* **Незаконный контент**: Информация, связанная с незаконной деятельностью
* **Вредоносная информация**: Контент, который может причинить вред
* **Неприемлемый контент**: Информация, нарушающая общественные моральные нормы
* **Контент, нарушающий права**: Материалы, нарушающие права других лиц

## Меры реагирования на нарушения

### Последствия нарушений

Платформа APIYI оставляет за собой право принимать меры в случае нарушений:

<Card title="Механизм реагирования на нарушения" icon="gavel">
  **Незначительные нарушения**

  * Перехват контента и напоминание
  * Разъяснение правил использования и предупреждение

  **Повторные нарушения**

  * Ограничение использования аккаунта
  * Снижение уровня доступа к функциям

  **Серьезные нарушения**

  * Приостановка или прекращение аккаунта
  * Уплаченные сборы не подлежат возврату
  * Сотрудничество с компетентными органами в ходе расследования
</Card>

## Техническая надежность

### Технология проверки

* **AI Intelligent Review**: Сочетание технологий machine learning и deep learning
* **Manual Review**: Ручная вторичная проверка важного контента
* **Real-time Updates**: Непрерывная оптимизация и обновление правил проверки
* **Multiple Verification**: Кросс-валидация с использованием различных алгоритмов обнаружения

### Безопасность данных

* **Encrypted Transmission**: При передаче всех данных используется шифрование
* **Secure Storage**: Безопасное хранение и управление журналами проверки
* **Access Control**: Строгое управление правами доступа и контроль доступа
* **Regulatory Compliance**: Подлежит надзору и аудиту со стороны соответствующих органов
