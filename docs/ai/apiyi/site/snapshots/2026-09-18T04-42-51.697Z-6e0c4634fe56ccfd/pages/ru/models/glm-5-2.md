## Пример запроса

Ниже приведён пример вызова `glm-5.2` через OpenAI Chat Completions (`/v1/chat/completions`). Укажите base\_url на `https://api.apiyi.com/v1` — все остальное совпадает с официальным API.

```bash theme={null}
curl https://api.apiyi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $APIYI_API_KEY" \
  -d '{
    "model": "glm-5.2",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

<Tip>Читайте ключ из переменной среды, никогда не встраивайте его в код. В production выдавайте отдельные token для каждого сценария использования, чтобы вы могли отозвать их и атрибутировать использование по отдельности.</Tip>
