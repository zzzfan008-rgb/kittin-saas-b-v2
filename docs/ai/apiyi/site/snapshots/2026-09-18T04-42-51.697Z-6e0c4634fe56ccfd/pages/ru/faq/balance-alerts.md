# Как настроить оповещения о балансе?

> APIYI поддерживает несколько способов оповещения о балансе, включая email, групповые боты WeCom/DingTalk/Feishu и настраиваемый API напоминания о балансе.

## Краткий ответ

APIYI поддерживает **три способа оповещения о балансе**: уведомления по email (включены по умолчанию), push-уведомления в групповой bot через WeCom / DingTalk / Feishu и пользовательский API напоминания о балансе. Перейдите на страницу **Настройки уведомлений** в консоли, чтобы настроить пороги оповещения и каналы.

<Card title="Перейти к Настройки уведомлений" icon="settings" href="https://api.apiyi.com/account/notificationSettings">
  Путь в консоли: **Аккаунт → Настройки уведомлений**

  Здесь вы можете настроить пороги оповещения и включить или отключить каждый канал уведомлений.
</Card>

## Описание способов уведомления

<CardGroup cols={3}>
  <Card title="Уведомление по email" icon="mail">
    **Включено по умолчанию**

    Когда ваш баланс опускается ниже порогового значения, на зарегистрированный email аккаунта автоматически отправляется письмо с оповещением — дополнительная настройка не требуется.
  </Card>

  <Card title="Групповые боты" icon="bot">
    Поддерживает webhook-ботов WeCom / DingTalk / Feishu для отправки оповещений прямо в ваш командный чат в реальном времени.
  </Card>

  <Card title="API напоминания о балансе" icon="code">
    Поддерживает собственный **Balance Reminder API** для интеграции с вашими системами мониторинга или платформами оповещений.
  </Card>
</CardGroup>

## Шаги настройки

<Steps>
  <Step title="Войдите в панель управления APIYI">
    Перейдите на [api.apiyi.com](https://api.apiyi.com) и войдите в свою учетную запись.
  </Step>

  <Step title="Откройте настройки уведомлений">
    В левом меню перейдите в **Account → Notification Settings** или сразу откройте [страницу настроек уведомлений](https://api.apiyi.com/account/notificationSettings).
  </Step>

  <Step title="Задайте порог оповещения">
    Настройте уровень баланса, при котором срабатывает оповещение (например, оповещение при балансе менее \$10). Рекомендуем установить порог, который покрывает 3-7 дней обычного использования.
  </Step>

  <Step title="Включите каналы уведомлений">
    При необходимости включите email, webhook бота группы или API напоминания о балансе и укажите соответствующий адрес уведомления / webhook URL.
  </Step>

  <Step title="Проверьте оповещение">
    После настройки проверьте, что оповещение работает, с помощью кнопки тестирования или временно снизив порог.
  </Step>
</Steps>

## Рекомендации по каналам

<Tip>
  **Для команд включайте несколько каналов одновременно**

  * **Индивидуальные разработчики**: обычно достаточно электронной почты
  * **Небольшие команды**: электронная почта + групповый бот WeCom / DingTalk / Feishu
  * **Корпоративные пользователи**: электронная почта + групповой бот + API напоминания о балансе (интегрировано с внутренним мониторингом)
</Tip>

## Частые вопросы

<AccordionGroup>
  <Accordion title="Почему я не получил письмо с уведомлением?">
    Проверьте:

    1. Ваш зарегистрированный адрес электронной почты указан верно и может принимать письма
    2. Письмо с уведомлением не было помечено как спам (проверьте папку со спамом)
    3. В настройках уведомлений включено **Email notification**
    4. Ваш баланс действительно ниже настроенного порога
  </Accordion>

  <Accordion title="Как получить webhook URL бота для группы?">
    * **WeCom**: групповой чат → Group Bots → Add Bot → Copy Webhook URL
    * **DingTalk**: Group Settings → Smart Group Assistant → Add Bot → Custom Bot → Copy Webhook
    * **Feishu**: Group Settings → Group Bots → Add Bot → Custom Bot → Copy Webhook URL

    Вставьте webhook URL в соответствующее поле в настройках уведомлений.
  </Accordion>

  <Accordion title="Как работает API Balance Reminder?">
    API Balance Reminder позволяет настроить собственный callback URL для HTTP. Когда баланс опускается ниже порога, система отправляет на этот URL POST-запрос, что позволяет интегрировать ее с вашими собственными платформами мониторинга (Grafana, Prometheus, внутренние системы оповещения и т. д.).

    Подробности интеграции см. в документации API в центре документации или обратитесь в поддержку за помощью.
  </Accordion>

  <Accordion title="Как часто будут повторно отправляться уведомления после срабатывания?">
    В системе встроено антиспам-ограничение, чтобы избежать повторных уведомлений за короткий промежуток времени. После получения уведомления мы рекомендуем как можно скорее выполнить пополнение, чтобы предотвратить прерывание сервиса.
  </Accordion>

  <Accordion title="Можно ли задать несколько порогов уведомлений?">
    В настоящее время страница Notification Settings поддерживает только один порог. Для многоуровневых стратегий оповещения мы рекомендуем реализовать их в вашей собственной системе через API Balance Reminder.
  </Accordion>
</AccordionGroup>
