# Исторические версии Seedream

> Сравнение спецификаций Seedream 5.0 / 4.5 / 4.0, различия в стоимости и руководство по миграции. Все три версии по-прежнему доступны для вызова — выбирайте по потребностям, без несовместимых изменений.

<Note>
  На этой странице перечислены все версии Seedream, которые по-прежнему можно вызывать на APIYI. Три версии активны одновременно, с **полностью совместимыми параметрами** — переключайтесь, изменяя только поле `model`. Для последней версии и общего введения см. [Обзор Seedream](/ru/api-capabilities/seedream-image/overview).
</Note>

## Спецификации по версиям

### `seedream-5-0-pro-260628` (5.0 Pro)

* **Дата выпуска**: 2026-06-28 (UTC+8); доступна в APIYI с 2026-07-19
* **Цена APIYI**: **\$0.12 / request** (фиксированная цена за запрос, 1 image per request, ≈ ¥0.84 по прайсу). Официально модель использует два ценовых уровня по пикселям на выходе (≤2.36M / >2.36M) плюс плату за референсные изображения сверх первого; APIYI упрощает это до фиксированной цены за запрос с учетом платы за входные изображения
* **Уровни разрешения**: предустановки `1K` / `2K` (**без предустановок 3K/4K**) плюс точные пиксели `WxH`, всего до **4.19M** (макс. 2048×2048; при 16:9 самая длинная сторона достигает `2720x1530` ≈ 2.7K, подтверждено)
* **Формат вывода**: `png` / `jpeg`
* **Оптимизация prompt**: стандартный / быстрый
* **Особенности**:
  * Наилучшее качество изображений и следование инструкциям в семействе; интерактивное редактирование (указывайте области правок через координаты, рамки выделения, стрелки)
  * Официально многокадровое слияние поддерживает **до 10 референсных изображений**
* **Известные ограничения**:
  * **`sequential_image_generation` / `stream` не принимаются** — любое значение (включая `"disabled"`) возвращает 400; полностью опустите оба параметра
  * Медленная генерация: стабильно **\~2 минуты** на изображение (измерено 110-130s) — установите таймаут клиента ≥ 240s
  * Цена в 3.4× выше, чем у 5.0-lite; для повседневной работы используйте 5.0-lite

### `seedream-5-0-260128` (5.0-lite)

* **Дата выпуска**: 2026-01-28 (UTC+8)
* **Цена APIYI**: \$0.035 / image (≈ ¥0.245 по прайсу)
* **Уровни разрешения**: `2K` / `3K` (**без 4K**)
* **Формат вывода**: `png` / `jpeg` (единственная версия с выводом png)
* **Оптимизация prompt**: стандартный
* **Особенности**:
  * Лучший общий опыт; наиболее зрелая реализация многокадрового слияния / редактирования / пакетной последовательности
  * Единственная версия, поддерживающая вывод `png` (а значит, и прозрачные фоны)
  * Зрелая потоковая передача вывода (`stream: true`)
* **Известные ограничения**:
  * Разрешение ограничено 3K (\~3072×3072). Для ассетов 4K используйте 4.5 / 4.0
* **Официальная документация**: `docs.byteplus.com/en/docs/ModelArk/1824121`

### `seedream-4-5-251128`

* **Дата выпуска**: 2025-11-28 (UTC+8)
* **Цена APIYI**: \$0.04 / image (≈ ¥0.28 по прайсу)
* **Уровни разрешения**: `2K` / `4K`
* **Формат вывода**: `jpeg`
* **Оптимизация prompt**: стандартный
* **Особенности**:
  * Унифицированная архитектура генерации и редактирования с 1.2B параметров
  * **Прорыв в рендеринге текста**: мелкий текст остается четким — лучшее в классе для постеров, рекламы, скриншотов UI
  * Официально многокадровое слияние поддерживает до 10 референсных изображений
  * При редактировании сохраняются освещение, тон и естественные детали лица
* **Известные ограничения**:
  * Только вывод `jpeg` (без `png`, без прозрачности)
* **Новостная статья**: [Запуск Seedream 4.5](/en/news/seedream-4-5-launch)

### `seedream-4-0-250828`

* **Дата выпуска**: 2025-08-28 (UTC+8)
* **Цена APIYI**: \$0.03 / image (≈ ¥0.21 по прайсу)
* **Уровни разрешения**: `1K` / `2K` / `4K` (самое широкое покрытие)
* **Формат вывода**: `jpeg`
* **Оптимизация prompt**: стандартный / **быстрый**
* **Особенности**:
  * Проверенная в бою стабильная версия
  * Высокая визуальная согласованность, сбалансированная детализация 4K
  * **Единственная версия с поддержкой режима prompt fast** — более быстрая генерация для сценариев, чувствительных к стоимости
* **Известные ограничения**:
  * Рендеринг текста слабее, чем в 4.5
  * Только вывод `jpeg`

## Руководство по миграции

<Steps>
  <Step title="Оцените различия">
    Эти три версии **полностью совместимы на уровне параметров** — для переключения меняйте только поле `model`. Обязательно проверьте:

    * Поддерживается ли вашим уровнем `size` новая версия (в 5.0 нет 1K / 4K; в 4.5 нет 1K; в 4.0 есть все)
    * Зависите ли вы от `output_format: "png"` (только 5.0)
    * Используете ли вы `prompt_optimization: "fast"` (только 4.0)
  </Step>

  <Step title="Запускайте их параллельно">
    Запустите один и тот же набор prompt на старой и новой версиях, сравните качество и стоимость. Сначала проверьте на небольшом наборе (10-20 изображений), прежде чем масштабировать.
  </Step>

  <Step title="Внедряйте постепенно">
    Переводите трафик поэтапно (10% / 50% / 100%). На каждом этапе оценивайте качество, частоту сбоев и стоимость, прежде чем масштабировать дальше.
  </Step>

  <Step title="Сохраните резервный вариант">
    Сохраняйте конфигурации старой и новой `model` в продакшн-коде. Если новая версия ведет себя некорректно, мгновенно переключитесь обратно. У всех трех версий единая тарификация — одновременный запуск обеих не требует дополнительных затрат.
  </Step>
</Steps>

## Пример устаревшего вызова

```python theme={null}
{/* Switching versions only changes the model field; other params are compatible */}
from openai import OpenAI

client = OpenAI(api_key="sk-your-api-key", base_url="https://api.apiyi.com/v1")

resp = client.images.generate(
    model="seedream-4-0-250828",   # change this line to switch to 4.5 / 5.0
    prompt="A serene mountain landscape at golden hour, snow-capped peaks, ultra detailed, 4K",
    size="4K",                      # NOTE: 5.0 does not support 4K — use 2K or 3K
    response_format="url",
    extra_body={
        "watermark": False,
    }
)

print(resp.data[0].url)
```

## Сравнение стоимости

Оценка по типичному объему (**до учёта бонусов за пополнение**; с бонусами эффективная цена снижается вплоть до 80%):

| Версия                    | Цена за единицу | 100 изображений | 1,000 изображений | 10,000 изображений |
| ------------------------- | --------------- | --------------- | ----------------- | ------------------ |
| `seedream-5-0-pro-260628` | \$0.12 / запрос | \$12            | \$120             | \$1200             |
| `seedream-5-0-260128`     | \$0.035         | \$3.5           | \$35              | \$350              |
| `seedream-4-5-251128`     | \$0.04          | \$4             | \$40              | \$400              |
| `seedream-4-0-250828`     | \$0.03          | \$3             | \$30              | \$300              |

<Info>
  **Как выбрать**:

  * 4K assets + сильный текст → **4.5**
  * 4K assets + лучшая цена → **4.0**
  * Лучший универсальный вариант / вывод png / прозрачные фоны → **5.0**
  * Долгосрочное стабильное пакетное производство → **4.0** (проверено, самый дешевый, быстрый prompt mode)
  * Наивысшее качество / сложные инструкции для профессиональной работы → **5.0-pro** (\$0.12/запрос + \~2 мин на изображение — пропустите, если это вам не нужно)
</Info>
