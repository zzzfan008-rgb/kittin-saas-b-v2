## Пример запроса

Пример ниже вызывает `qwen3.8-flash` через OpenAI Chat Completions (`/v1/chat/completions`). Укажите `https://api.apiyi.com/v1` в качестве base\_url — всё остальное соответствует официальному API.

```bash theme={null}
curl https://api.apiyi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $APIYI_API_KEY" \
  -d '{
    "model": "qwen3.8-flash",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

<Tip>Считывайте ключ из переменной окружения, не задавайте его жёстко в коде. В рабочей среде выпускайте отдельные токены для каждого сценария использования, чтобы их можно было отзывать и отдельно учитывать использование.</Tip>
