# Как исправить ошибку несоответствия содержимого изображения MIME-типу?

> Если URL изображения заканчивается параметром x-oss-process (или аналогичным параметром обработки CDN), возникает эта ошибка. Удалите параметр или используйте прямую ссылку на исходный файл.

## Краткий ответ

Если URL изображения, переданный в API, заканчивается параметром обработки облачного хранилища, например `?x-oss-process=...`, API возвращает ошибку «содержимое изображения не соответствует MIME-типу».

Чтобы исправить это, удалите параметр обработки из URL и передайте в API исходную прямую ссылку либо скачайте изображение и повторно обработайте его на собственном сервере перед загрузкой.

## Как выглядит ошибка?

Ответ с ошибкой:

```json theme={null}
{
  "error": {
    "message": "decode image: image content does not match MIME type 'image/png'",
    "type": "invalid_request_error",
    "code": 429
  }
}
```

Типичный URL, вызывающий такую ошибку, выглядит следующим образом:

```text theme={null}
https://oss.fzputi.com/tools/aiCraft/...jpg?x-oss-process=image/resize,w_800
```

Суффикс `?x-oss-process=...` — это параметр обработки изображений, используемый Alibaba Cloud OSS и аналогичными службами объектного хранения. Известно, что эндпоинты генерации изображений в APIYI возвращают указанную выше ошибку, если URL содержит параметр такого типа.

## Известное имя параметра, вызывающее проблему

Сообщалось, что следующее имя параметра вызывает эту ошибку при наличии в URL изображения:

* `x-oss-process`

Если вы используете параметры обработки изображений от других поставщиков облачного хранилища (например, эквивалентные параметры в Tencent Cloud COS или Huawei Cloud OBS), выполните те же действия ниже, прежде чем передавать URL в API.

## Шаги по исправлению

<Steps>
  <Step title="Удалите параметр обработки из URL">
    Скопируйте исходную прямую ссылку на изображение (без параметра типа `?x-oss-process=`) и снова передайте её в API.

    Например, замените:

    ```text theme={null}
    https://oss.fzputi.com/abc.jpg?x-oss-process=image/resize,w_800
    ```

    на:

    ```text theme={null}
    https://oss.fzputi.com/abc.jpg
    ```
  </Step>

  <Step title="Если требуется изменить размер, сначала обработайте изображение на своём сервере">
    Если ваш рабочий процесс действительно зависит от сжатия или обрезки на стороне OSS, сначала скачайте обработанное изображение из вашего бакета в локальное хранилище, а затем загрузите его через локальный путь или новую прямую ссылку без параметров.
  </Step>
</Steps>

## Примечания

<Warning>
  Передавайте URL изображений в API как обычные прямые ссылки без завершающих параметров, иначе может возникнуть эта ошибка.
</Warning>

## Если это по-прежнему не работает

* Убедитесь, что URL можно открыть напрямую в браузере, а фактический формат изображения, отображаемый браузером (щелчок правой кнопкой мыши → просмотр кода), соответствует расширению URL (jpg / png / webp)
* Если вы используете параметр обработки изображений от другого поставщика облачного хранилища, обратитесь в службу технической поддержки, предоставив полный JSON ошибки и идентификатор запроса
