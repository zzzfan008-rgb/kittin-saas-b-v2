## Обзор

WorkBuddy — офисный продукт AI Agent от Tencent, построенный вокруг новой парадигмы: **укажите требование, дайте ему выполнить задачу, получите готовый результат**. В отличие от conversational AI, которое лишь предлагает варианты и отвечает текстом, WorkBuddy понимает инструкции на естественном языке, самостоятельно разбивает задачу на части, планирует шаги и выполняет операции. Он работает с multimodal-задачами — документами, таблицами, слайдами, анализом данных — и может читать авторизованную локальную папку для пакетной обработки, выдавая результаты, за которые вы действительно можете поставить финальное одобрение (еженедельные отчеты, протоколы встреч, презентации, панели данных).

WorkBuddy поставляется со встроенными mainstream-моделями — Hunyuan, GLM, MiniMax, Kimi, DeepSeek (предоставляется через Tencent Cloud's Token Plan) — а также позволяет подключить любую стороннюю large model в качестве базового движка через **Конфигурация модели**. Подключение APIYI дает вам:

| Возможность                                        | Подробности                                                                                                                                              |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🧩 Один ключ, все модели                           | Не нужно отдельно регистрироваться у каждого поставщика — один ключ APIYI дает вам GPT / Claude / Gemini / DeepSeek и остальную матрицу внутри WorkBuddy |
| 🔐 Ключ хранится локально                          | Ваша конфигурация (включая API key) сохраняется только в `workbuddy/models.json` на вашем компьютере и никогда не загружается в cloud                    |
| ⚡ Графическая настройка за один шаг                | Настройки → Модели → Custom: заполните endpoint, key и model name, затем сохраните. Не нужно редактировать config files                                  |
| 💰 Оплата по мере использования, на вашем аккаунте | Расходы по custom models оплачиваются напрямую в APIYI и не расходуют собственные кредиты WorkBuddy или квоту плана                                      |

> ℹ️ **Информация о продукте**: WorkBuddy создан Tencent. Сайт `www.workbuddy.cn`, официальная документация `www.workbuddy.cn/docs/workbuddy/Overview`.

## Установка

WorkBuddy в настоящее время предлагает десктопные клиенты для **Windows / macOS**. Скачайте установщик с сайта и дважды щёлкните его, чтобы установить — командная строка не нужна:

| Платформа           | Как получить                                                                                                             |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Главная сайта       | `www.workbuddy.cn` — нажмите кнопку загрузки, чтобы получить установщик для вашей платформы                              |
| Windows             | См. официальное руководство по установке Windows: `/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Win-Guide` |
| macOS               | См. официальное руководство по установке Mac: `/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Mac-Guide`     |
| Более старые версии | Официальная документация, «История загрузок»: `/docs/workbuddy/Download-History`                                         |

После установки откройте WorkBuddy, войдите в систему, и вы сможете отправить задачу одной фразой из панели **Новая задача** — либо пройдите официальные пошаговые руководства «Быстрый старт» / «Ваша первая задача», чтобы ознакомиться с основами.

## Подключение APIYI

Диалог настройки моделей WorkBuddy поддерживает только API с протоколом, совместимым с OpenAI (об этом указано вверху диалога). APIYI предоставляет стандартный API, совместимый с OpenAI, так что достаточно выбрать провайдер **Custom** — и вы сразу получите всю матрицу моделей целиком (GPT / Claude / Gemini / DeepSeek / Zhipu / Kimi и другие).

### Графическая настройка (единственный способ, рекомендуется)

В WorkBuddy откройте **Settings → Models**, нажмите **Add model** и заполните поля так:

| Поле                     | Что ввести                                                                                                                                                             |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Провайдер                | Выберите `Custom`                                                                                                                                                      |
| Эндпоинт                 | `https://api.apiyi.com/v1/chat/completions` — введите **полный путь** до `/chat/completions`. Не вводите только `https://api.apiyi.com` или `https://api.apiyi.com/v1` |
| API Key                  | Ваш ключ APIYI (`sk-...`)                                                                                                                                              |
| Имя модели               | ID модели, который вам нужен, например `claude-sonnet-5`, `gpt-5.4`, `deepseek-v3.2`, `kimi-k2.6`                                                                      |
| Дополнительные параметры | Отметьте вручную в соответствии с тем, что реально поддерживает выбранная вами модель — см. примечание ниже                                                            |

<img src="https://mintcdn.com/apiyillc/hVgOxBLyKM6-uzFJ/images/workbuddy-model-config-zh.png?fit=max&auto=format&n=hVgOxBLyKM6-uzFJ&q=85&s=d52fe72d995e805cc4a587d6aada814b" alt="WorkBuddy custom model configuration dialog (OpenAI-compatible protocol APIs only)" width="660" height="639" data-path="images/workbuddy-model-config-zh.png" />

> ℹ️ **О флагах возможностей в разделе "Дополнительные параметры"**: когда вы выбираете **стандартного провайдера**, например Token Plan Tencent Cloud, такие флаги, как вызов инструментов и ввод изображений, заполняются автоматически. Когда вы выбираете **Custom** для подключения APIYI, они **не** определяются автоматически — вам нужно отмечать их вручную в зависимости от того, что действительно поддерживает ваша модель:
>
> * Ориентируйтесь на **фактические возможности** указанного вами ID модели. Если не уверены, **отмечайте меньше, а не больше** — в примере на скриншоте у `claude-sonnet-5` включен только вызов инструментов
> * Добавляйте **ввод изображений** / **режим рассуждения** только после того, как убедитесь, что модель действительно поддерживает vision или расширенное рассуждение
> * Если отметить возможность, которой у модели нет (например, включить вызов инструментов у модели, которая его не поддерживает), это может привести к ошибкам запроса, поэтому отмечайте только то, что вам нужно

Разделы **Input** и **Output** задают длину контекстного окна и максимальное число tokens вывода. Оставьте их пустыми, чтобы использовать значения провайдера по умолчанию, или выберите пресет — 32K/64K/128K/256K для input, 8K/16K/32K/64K для output. Нажмите **Save**, вернитесь в вид чата, и модель появится в группе Custom в селекторе моделей, готовая к использованию.

> ⚠️ **Введите endpoint полностью как `https://api.apiyi.com/v1/chat/completions`** — полный путь, заканчивающийся на `/chat/completions`, как показано на скриншоте. Неполный адрес, такой как `https://api.apiyi.com` или `https://api.apiyi.com/v1`, приведет к сбою запросов.

**Дополнительный совет**: при создании token на `api.apiyi.com/token` **некоторые группы дают скидку** (например, группа ClaudeCode), и она суммируется с бонусами за пополнение. Консоль является источником актуальных тарифов.

> 💡 **Почему APIYI?**
>
> * **Один ключ, много поставщиков**: OpenAI / Anthropic / Google / DeepSeek / Zhipu / Kimi и остальная матрица — настройте один раз в WorkBuddy
> * **Ценовое преимущество**: обычно на 5%–20% ниже официальной тарификации, а по некоторым моделям доступны бонусы за пополнение
> * **Прямой доступ из материкового Китая**: получайте доступ к зарубежным моделям без proxy, поэтому настольному клиенту WorkBuddy не нужна дополнительная настройка сети
> * **Стандартный протокол, совместимый с OpenAI**: точно соответствует требованиям WorkBuddy к провайдеру **Custom**, без необходимости включать переключатель custom-протокола

> ℹ️ **Расходы и конфиденциальность**: все расходы, создаваемые custom-моделями (расход tokens и т. п.), оплачиваются напрямую через APIYI, поэтому следите за балансом APIYI и использованием. Ваш API key хранится только в `workbuddy/models.json` на вашем устройстве — WorkBuddy не загружает его в облако. Храните его в безопасности и удаляйте или очищайте конфигурацию в Settings, когда перестанете им пользоваться.

## Часто задаваемые вопросы

### После подключения APIYI мой API key будет загружен в облако WorkBuddy?

Нет. В официальной документации прямо указано, что параметры конфигурации модели (включая API key) хранятся локально в `workbuddy/models.json` и не загружаются в облако. Во время работы WorkBuddy выступает только как транспортное звено, пересылая ваш ввод в настроенный вами эндпоинт APIYI; результат возвращается напрямую от этой модели. Помимо того, что требуется для передачи, аудита безопасности, устранения неполадок и хранения в объеме, требуемом законом, WorkBuddy не читает и не хранит содержимое переписки.

### Как рассчитывается стоимость вызовов моделей через APIYI? Они расходуют кредиты WorkBuddy или квоту плана?

Нет, они не затрагивают собственные кредиты WorkBuddy или квоту плана. Все расходы по пользовательским моделям (расход token, абонентская плата и т. д.) вы оплачиваете и урегулируете напрямую с APIYI, поэтому следите за балансом и использованием APIYI, чтобы избежать неожиданных трат.

### Поддерживается ли нативный протокол Anthropic (`anthropic_messages`)?

Пока нет. Диалог пользовательской модели WorkBuddy поддерживает только API, совместимые с протоколом OpenAI (это явно указано в верхней части диалога). Поэтому при подключении APIYI используйте его совместимый с OpenAI эндпоинт `https://api.apiyi.com/v1/chat/completions` — нативный эндпоинт Anthropic пока не поддерживается.

### Когда нужен переключатель «custom protocol», и насколько полным должен быть эндпоинт?

Переключатель «custom protocol» нужен только тогда, когда подключаемый вами сервис модели находится за шлюзом или прокси-слоем, использующим нестандартный путь URL — при включении WorkBuddy пропускает проверку пути и отправляет запрос точно по введенному вами адресу. APIYI использует стандартный путь `/chat/completions`, поэтому оставьте переключатель **выключенным** (это значение по умолчанию). В любом случае вводите эндпоинт **полностью** в виде `https://api.apiyi.com/v1/chat/completions` (оканчивающегося на `/chat/completions`). Не вводите только базовый адрес (`https://api.apiyi.com` или `https://api.apiyi.com/v1`) и не дублируйте `/v1` — `.../v1/v1/chat/completions` вернет 404.

### Как отмечать tool calling / image input / режим рассуждения?

У стандартных провайдеров, таких как Tencent Cloud's Token Plan, эти флаги проставляются автоматически. При подключении APIYI в режиме **Custom** они не определяются автоматически, поэтому отмечайте их вручную в соответствии с тем, что реально поддерживает введенный вами ID модели. Если не уверены, **лучше отметить меньше, чем больше**. На скриншоте выше у `claude-sonnet-5` включен только tool calling; добавьте image input или режим рассуждения, как только убедитесь, что ваша модель это поддерживает. Отметка возможности, которой у модели нет, может привести к ошибкам запроса.

### Что указывать в поле "Имя модели"?

ID модели из документации APIYI — например, `claude-sonnet-5`, `gpt-5.4`, `deepseek-v3.2`, `gemini-3.1-pro-preview` или `kimi-k2.6`. Чтобы переключиться на другую модель, просто измените это поле в настройках и сохраните; перенастраивать эндпоинт или API key не нужно.
