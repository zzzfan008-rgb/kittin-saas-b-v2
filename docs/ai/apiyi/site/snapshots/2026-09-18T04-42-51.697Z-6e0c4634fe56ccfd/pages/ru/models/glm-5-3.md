## Пример запроса

В приведённом ниже примере выполняется вызов `glm-5.3` через Chat Completions OpenAI (`/v1/chat/completions`). Укажите `https://api.apiyi.com/v1` в качестве base\_url — всё остальное соответствует официальному API.

```bash theme={null}
curl https://api.apiyi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $APIYI_API_KEY" \
  -d '{
    "model": "glm-5.3",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

<Tip>Считывайте ключ из переменной окружения, никогда не встраивайте его в код напрямую. В рабочей среде используйте отдельные токены для каждого сценария, чтобы их можно было отзывать и отдельно отслеживать использование.</Tip>
