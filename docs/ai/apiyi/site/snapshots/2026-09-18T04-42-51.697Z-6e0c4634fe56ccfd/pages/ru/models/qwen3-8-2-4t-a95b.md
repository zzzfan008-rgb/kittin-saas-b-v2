# Qwen3.8-2.4T-A95B

## Пример запроса

В приведённом ниже примере выполняется вызов `qwen3.8-2.4t-a95b` через Chat Completions OpenAI (`/v1/chat/completions`). Укажите `https://api.apiyi.com/v1` в качестве base\_url — всё остальное соответствует официальному API.

```bash theme={null}
curl https://api.apiyi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $APIYI_API_KEY" \
  -d '{
    "model": "qwen3.8-2.4t-a95b",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

<Tip>Считывайте ключ из переменной окружения, никогда не встраивайте его в код. В рабочей среде создавайте отдельные tokens для каждого варианта использования, чтобы их можно было отзывать и отдельно учитывать использование.</Tip>
