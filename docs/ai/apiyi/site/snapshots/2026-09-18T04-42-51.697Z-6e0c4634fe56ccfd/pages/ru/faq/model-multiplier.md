# Что означает модельный 'множитель'?

> Узнайте значение, правила расчета и связь с официальной тарификацией модельных множителей на API.YI

## Краткий ответ

<Info>
  **Множители — это общепринятый в отрасли способ расчета стоимости.** Если вам не хочется разбираться с множителями, просто проверьте столбец **Цена** в списке моделей. Мы взимаем оплату в USD. Посмотреть все цены моделей: [Тарифы моделей](https://api.apiyi.com/modelPricing)
</Info>

## Стратегия тарификации

| Тип модели                               | Правило тарификации                        | Скидки                                                                 |
| ---------------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------- |
| **Текстовые / мультимодальные LLM**      | Как у официальной тарификации              | [Бонусы за пополнение](/ru/faq/recharge-promotions) + групповые скидки |
| **Модели генерации изображений / видео** | Оплата за каждый вызов, специальные тарифы | См. [Тарификация моделей](https://api.apiyi.com/modelPricing)          |

<Tip>
  Скидки для текстовых моделей бывают двух видов: **акции с бонусами за пополнение** (дополнительные credits при пополнении) и **групповые скидки** (например, отечественные модели в отдельной группе со скидкой 0.88x).
</Tip>

## Тарификация текстовой модели

Стоимость одного вызова = **Input Tokens × цена входа + Output Tokens × цена выхода**

Подробную информацию о тарификации см. в [Цены](/ru/pricing).

## Основные понятия

Два ключевых термина, которые нужно понять:

| Системный термин | Значение        |
| ---------------- | --------------- |
| **Prompt**       | Входные Tokens  |
| **Завершение**   | Выходные Tokens |

## Правила расчета коэффициентов тарифа

Коэффициенты — это относительные значения, используемые для определения фактических цен:

* **Коэффициент Prompt × 2** = Цена input (USD / миллион token)
* **Коэффициент completion** = Цена output ÷ Цена input (т.е. во сколько раз output стоит по сравнению с input)

## Пример расчета

Используя `claude-opus-4-6` в качестве примера:

| Item  | Multiplier                   | Calculation             | Final Price               |
| ----- | ---------------------------- | ----------------------- | ------------------------- |
| Вход  | Коэффициент prompt **2.5**   | 2.5 × 2 = 5             | **\$5 / million Tokens**  |
| Выход | Коэффициент completion **5** | 5 × 5 (цена входа) = 25 | **\$25 / million Tokens** |

При использовании этой формулы тарификация API.YI точно совпадает с официальной тарификацией.

## Тарификация моделей Image / Video

Модели Image и video используют **оплату за каждый вызов**, а для некоторых моделей действуют специальные скидочные тарифы. Смотрите страницу [Тарифы моделей](https://api.apiyi.com/modelPricing) в вашей консоли, чтобы узнать конкретные цены.

## Кратко

* Множители — это **стандартный для отрасли** метод расчета тарификации
* Вам не нужно разбираться в множителях, чтобы пользоваться сервисом — просто смотрите столбец **Цена**
* **Текстовые модели** соответствуют официальной тарификации; скидки доступны за счет бонусов пополнения и скидок для группы
* **Модели генерации изображений/видео** тарифицируются за вызов по специальным ставкам — см. [Тарификация моделей](https://api.apiyi.com/modelPricing)
