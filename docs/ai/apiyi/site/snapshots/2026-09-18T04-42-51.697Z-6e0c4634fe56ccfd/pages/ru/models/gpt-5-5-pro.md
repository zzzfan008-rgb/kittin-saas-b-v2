# GPT-5.5 Pro

> GPT-5.5 Pro на APIYI: $30 за входные данные / $180 за выходные данные на 1 млн tokens, контекстное окно 1 050 000, максимум выходных данных — 128 000, доступна в 2 группах тарификации.

Уровень с интенсивным рассуждением: дорогостоящий и доступен только в /v1/responses — не рекомендуется для задач вне узкоспециализированных нагрузок.

## Многоуровневая тарификация

Эта модель тарифицируется по размеру token каждого запроса (цена вывода = цена входа по уровню × коэффициент тарифа):

* 0 – 278,528 tokens: \$30/1M на вход
* Выше 278,528 tokens: \$60/1M на вход

## Пример запроса

Пример ниже вызывает `gpt-5.5-pro` через OpenAI Responses (`/v1/responses`). Укажите base\_url на `https://api.apiyi.com/v1` — все остальное соответствует официальному API.

```bash theme={null}
curl https://api.apiyi.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $APIYI_API_KEY" \
  -d '{
    "model": "gpt-5.5-pro",
    "input": "Hello"
  }'
```

<Tip>Считывайте key из переменной окружения, никогда не встраивайте его в код. В production используйте отдельные token для каждого варианта использования, чтобы можно было отдельно отзывать их и атрибутировать использование.</Tip>
