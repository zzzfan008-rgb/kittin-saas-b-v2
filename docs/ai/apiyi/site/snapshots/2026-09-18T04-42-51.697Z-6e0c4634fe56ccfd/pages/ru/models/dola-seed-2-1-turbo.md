# Seed 2.1 Turbo

> Seed 2.1 Turbo на APIYI: $0.5 вход / $2.5 выход за 1M tokens, 256,000 контекстное окно, доступен в 3 группах тарификации.

Промышленная текстовая модель для высокочастотных нагрузок: 15/15 подтверждено для обоих эндпоинтов, с переключателем рассуждения и двумя уровнями кэширования.

## Пример запроса

Пример ниже вызывает `dola-seed-2-1-turbo-260628` через OpenAI Chat Completions (`/v1/chat/completions`). Укажите base\_url на `https://api.apiyi.com/v1` — все остальное соответствует официальному API.

```bash theme={null}
curl https://api.apiyi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $APIYI_API_KEY" \
  -d '{
    "model": "dola-seed-2-1-turbo-260628",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

<Tip>Читайте ключ из переменной окружения, никогда не жестко вшивайте его в код. В production выпускайте отдельные tokens для каждого варианта использования, чтобы вы могли отзывать их и учитывать использование по отдельности.</Tip>
