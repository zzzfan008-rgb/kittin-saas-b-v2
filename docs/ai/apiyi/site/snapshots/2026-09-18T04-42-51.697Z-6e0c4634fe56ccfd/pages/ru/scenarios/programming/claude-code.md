# Claude Code

> Официальный командный помощник Claude для программирования, настроенный с APIYI для стабильного и эффективного опыта AI-программирования

<Warning>
  **По затратам, заранее**: для работы с длинным context window и глубокого agentic exploration, **использование API с оплатой по факту быстро сжигает credit, и обычно это оказывается менее выгодным по value, чем официальная подписка**.

  Coding agent заново читает context вашего проекта, обрабатывает вывод tools и на каждом ходе повторяет итерации — одна серьёзная задача легко уходит в сотни тысяч tokens. Это действительно случалось: **\$5 credit закончились до завершения одного deep-research запуска**. Это не ошибка; это нормальный расход для такого рода работы.

  * **Высокая нагрузка, и вы можете подключаться к official service напрямую**: купите официальную подписку Claude Pro / Max — фиксированная ежемесячная плата при такой интенсивности выгоднее.
  * **У вас есть блокировка со стороны сети, или вы просто хотите платить только за то, что используете**: вам больше подходит API — прямой доступ без proxy, без фиксированной ежемесячной платы, без необходимости поддерживать официальный аккаунт и с одним ключом для 400+ моделей.

  Ни один из вариантов не является безусловно лучшим. Выбирайте исходя из вашего фактического использования и сетевой ситуации. Мы говорим об этом заранее, чтобы счёт не стал для вас неожиданностью.
</Warning>

<Info>
  **Оплата по мере использования или официальный план Claude Max — что выбрать?**

  * **Claude Max (официальная подписка)**: фиксированная ежемесячная плата, которая ограничивает ваши расходы. **Лучшее решение для активных пользователей, которые только и делают, что пишут код и расходуют огромные объёмы** — при условии, что вы можете соблюдать официальные сетевые требования и готовы самостоятельно поддерживать аккаунт и нести риск блокировки.
  * **Настройка Claude в APIYI**: оплата по мере использования без риска блокировки. Качество обеспечивается двумя каналами — официальным доступом AWS Bedrock и прямым подключением по официальному ключу Anthropic — а бонусы за пополнение снижают фактическую стоимость. Пользователи, которые уже им пользовались, хорошо о нём отзываются и продолжают пополнять баланс. Для компаний это также решает вопросы прямого доступа и налогового соответствия (выставления счетов).
  * **API более гибкий**: помимо программирования, один и тот же ключ даёт доступ к 400+ моделям — куда больше выбора, чем у одного плана для программирования.
</Info>

## Группа токенов: ClaudeCode

При использовании APIYI с Claude Code обязательно выберите группу `ClaudeCode` при создании токена (в параметре «Group» в диалоге создания токена в консоли). Эта группа объединяет все модели, совместимые с нативным форматом Anthropic `/v1/messages`, в один канал, предназначенный для сценариев Claude Code.

<Tip>
  **Группа ClaudeCode получает скидку 5% по умолчанию** — никаких действий не требуется. Эта скидка суммируется с бонусными кампаниями пополнения (10%–20%), в результате чего эффективная стоимость оказывается примерно на 20% ниже официальной прямой тарификации.
</Tip>

<Note>
  **Где можно использовать эту группу?**

  * **Внутри Claude Code**: эта группа лучше всего подходит для Claude Code. **Некоторые китайские локальные модели можно вызывать внутри Claude Code только с токеном группы ClaudeCode** — токены из других групп будут отклоняться.
  * **Вне Claude Code**: токен группы ClaudeCode **тоже прекрасно работает** — он не ограничен только Claude Code. В этом случае это просто скидка: 5% по умолчанию (0.95x), которая суммируется с бонусными кампаниями пополнения (10%–20%).
</Note>

## Быстрый старт

<Note>
  **Совет по упрощенной конфигурации**: Если вы не хотите регистрировать официальную учетную запись Claude, рекомендуем ознакомиться с разделом [Advanced Configuration](#advanced-configuration) ниже, чтобы использовать файловую конфигурацию `~/.claude.json`, которая полностью обходит официальную верификацию.
</Note>

### 1. Установите Claude Code

Выполните следующую команду в терминале, чтобы установить глобально:

```bash theme={null}
npm install -g @anthropic-ai/claude-code
```

<Info>
  Требуется Node.js 18 или выше. Если он не установлен, перейдите на [nodejs.org](https://nodejs.org), чтобы скачать и установить его.
</Info>

### 2. Настройте ключ API

#### Получите ключ API

Обратитесь к [Руководству по управлению ключом API](/ru/faq/token-management), чтобы получить ваш ключ APIYI.

#### Задайте переменные окружения

Добавьте конфигурацию APIYI в системные переменные окружения.

<Tabs>
  <Tab title="macOS/Linux">
    Отредактируйте файл `~/.zshrc` или `~/.bashrc`:

    ```bash theme={null}
    # APIYI Configuration
    export ANTHROPIC_AUTH_TOKEN="sk-***"
    export ANTHROPIC_BASE_URL="https://api.apiyi.com"
    ```

    <Tip>
      **Совет для пользователей Mac**: Нажмите `⌘ + ⇧ + .` в вашем пользовательском каталоге, чтобы показать скрытые файлы, затем откройте файл `.zshrc` в текстовом редакторе.
    </Tip>
  </Tab>

  <Tab title="Windows">
    Отредактируйте конфигурацию с помощью PowerShell:

    ```powershell theme={null}
    # Edit configuration file
    notepad $PROFILE

    # Add the following content
    $env:ANTHROPIC_AUTH_TOKEN = "sk-***"
    $env:ANTHROPIC_BASE_URL = "https://api.apiyi.com"
    ```
  </Tab>
</Tabs>

### 3. Примените конфигурацию

<Tabs>
  <Tab title="macOS/Linux">
    ```bash theme={null}
    source ~/.zshrc
    # or
    source ~/.bashrc
    ```
  </Tab>

  <Tab title="Windows">
    Перезапустите PowerShell или выполните:

    ```powershell theme={null}
    . $PROFILE
    ```
  </Tab>
</Tabs>

### 4. Запустите Claude Code

Перейдите в каталог проекта и запустите:

```bash theme={null}
# Enter project directory
cd ~/Desktop/my-project

# Launch Claude Code
claude
```

## Дополнительная настройка

### Конфигурационные файлы (рекомендуется)

Чтобы обойти официальную проверку Claude, нужно настроить вместе два файла:

**Шаг 1**: Создайте `~/.claude.json` в домашнем каталоге, чтобы обойти официальную проверку:

```json theme={null}
{
  "hasCompletedOnboarding": true
}
```

**Шаг 2**: Настройте сервис APIYI в `~/.claude/settings.json`:

```json theme={null}
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "sk-your-APIYI-key",
    "ANTHROPIC_BASE_URL": "https://api.apiyi.com"
  }
}
```

<Tip>
  **Важное примечание**: `hasCompletedOnboarding: true` полностью обходят официальную проверку учетной записи Claude, что позволяет напрямую использовать сервис APIYI. Это означает, что вам не нужно:

  * Регистрировать учетную запись Claude (сложная регистрация, требуется зарубежный номер телефона)
  * Беспокоиться о блокировке официальной учетной записи Claude
  * Выполнять какие-либо дополнительные шаги авторизации
</Tip>

<Warning>
  **Напоминание о безопасности**: Конфигурационные файлы содержат конфиденциальную информацию, такую как API keys, пожалуйста, не делитесь ими с другими.
</Warning>

### Глобальная авторизация (не рекомендуется)

Если вы не настроите `hasCompletedOnboarding: true`, при первом использовании появится страница авторизации:

1. Нужно будет перейти на официальный сайт Claude для подтверждения
2. Требуется официальная учетная запись Claude (сложная регистрация и легко блокируется)
3. После успешной авторизации возврат в терминал

<Info>
  **Рекомендация**: Настоятельно рекомендуем использовать указанный выше способ с конфигурационными файлами, чтобы избежать различных ограничений официальных учетных записей Claude.
</Info>

## Руководство пользователя

### Основные команды

После запуска Claude Code отобразит текущую информацию о конфигурации:

```bash theme={null}
claude
# Displays API Key and API Base URL
# Confirm configuration is correct and select Yes to continue
```

### Workflow

1. **Запустите Ассистент**: Выполните `claude` в каталоге проекта
2. **Опишите требования**: Введите ваши потребности в программировании или вопросы
3. **Интерактивный диалог**: Claude понимает контекст и предлагает варианты кода
4. **Примените изменения**: После подтверждения Claude может напрямую изменять файлы
