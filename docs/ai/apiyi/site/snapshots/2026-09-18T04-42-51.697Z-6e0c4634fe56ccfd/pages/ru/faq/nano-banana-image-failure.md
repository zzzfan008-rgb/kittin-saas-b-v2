# Основные причины сбоев генерации изображений Nano Banana

> Анализ распространенных причин сбоев генерации изображений Nano Banana Pro/2, включая безопасность контента, удаление водяных знаков, известные объекты интеллектуальной собственности, несовершеннолетних и другие триггеры механизмов безопасности Google

## Краткий ответ

Серия Nano Banana (включая Nano Banana Pro и Nano Banana 2) использует модели Google Gemini в основе. Основная причина сбоев при генерации изображений — **срабатывание механизмов проверки безопасности контента Google**, которые блокируют запросы, не соответствующие требованиям, на этапе генерации. APIYI выступает как прозрачный прокси, точно передавая обратную связь Google.

## Типичные симптомы сбоя генерации

Когда генерация изображений завершается неудачей, API по-прежнему возвращает код состояния HTTP **200**, но ответ не содержит данных изображения — вместо этого он возвращает текстовое объяснение.

<Info>
  **Почему код состояния 200?** APIYI выступает как прозрачный прокси, добросовестно пересылая исходный ответ Google API. Во время блокировки по соображениям безопасности Google возвращает код состояния 200 с текстовым объяснением отказа, а не код HTTP-ошибки.
</Info>

### Распространенные сообщения об ошибке

Текст отказа Google API обычно содержит такие сообщения:

* `"I can't complete the modification of xxx"`
* `"I can't generate images that are sexually explicit."`
* `"I'm just a language model and can't help with that."`

<Warning>
  Примечание: фильтрация безопасности Google в некоторой степени случайна. **Один и тот же prompt иногда может успешно отработать, а иногда — завершиться ошибкой**, в зависимости от содержимого референсного изображения, комбинации prompt и других факторов.
</Warning>

## Рекомендации для разработчиков продуктов

Если вы создаете пользовательские продукты на базе Nano Banana API, мы рекомендуем реализовать корректную логику обработки ошибок, чтобы показывать пользователям понятные сообщения о сбоях.

<Tip>
  **Ключевые индикаторы для проверки**:

  1. **candidatesTokenCount = 0**: Google отклонил запрос на этапе проверки контента
  2. **finishReason не STOP**: заблокировано политикой безопасности во время генерации
  3. **Текст есть, но изображения нет**: API вернуло объяснение отказа вместо данных изображения
</Tip>
