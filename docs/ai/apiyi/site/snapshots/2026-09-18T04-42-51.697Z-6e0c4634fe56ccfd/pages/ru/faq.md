## 🔧 Устранение неполадок по симптомам

Найдите строку, соответствующую тому, что вы наблюдаете. Один симптом часто охватывает несколько тем, поэтому эта таблица заново связывает статьи по устранению неполадок на основе наблюдаемого поведения.

| Что вы наблюдаете                                                                    | Вероятная причина                                                                                                            | Где искать                                                                                                                                        |
| ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Недействительный API Key / 401                                                       | Base URL и KEY не совпадают или в KEY допущена опечатка                                                                      | [Недействительный API Key](/ru/faq/invalid-api-key) · [Настройка Base URL](/ru/faq/base-url-config)                                               |
| Сообщение об ошибке непонятно, неясно, с чего начать                                 | Последовательно изучите типы ошибок                                                                                          | [Устранение ошибок model API](/ru/faq/model-error-troubleshooting)                                                                                |
| Баланс ещё есть, но запросы не выполняются                                           | Механизм предварительного списания или слишком высокое значение max\_tokens                                                  | [Недостаточно баланса](/ru/faq/balance-insufficient) · [Предварительное списание](/ru/faq/pre-deduction-quota)                                    |
| Запрос завершается по тайм-ауту или обрывается во время потоковой передачи           | Тайм-аут клиента слишком короткий; модели с рассуждением работают медленно                                                   | [Предотвращение тайм-аутов API](/ru/faq/timeout-configuration)                                                                                    |
| В логе указаны успех и тарификация, но клиент ничего не получил                      | Длительность в логе заканчивается, когда шлюз завершает работу; проблема находится далее по цепочке или в сигнале завершения | [Лог завершён, но ответа нет](/ru/faq/log-duration-vs-client-wait)                                                                                |
| Сайт / API возвращает 502                                                            | Контейнер сервиса ненадолго автоматически перезапускается; восстановление занимает около 1 минуты                            | [Что делать при 502](/ru/faq/website-502-error)                                                                                                   |
| Скрипт периодически получает 502 с пустым телом, а в логах ничего нет                | Пустой 502 создаётся локальным прокси ПО (Clash / v2rayN)                                                                    | [Пустой 502, созданный прокси](/ru/faq/proxy-empty-502)                                                                                           |
| Python выдаёт SSLEOFError, но curl работает                                          | Post-quantum handshake OpenSSL 3.5+ обрывается промежуточными узлами                                                         | [Устранение SSLEOFError](/ru/faq/openssl-pq-handshake-eof)                                                                                        |
| Ошибки параллельных запросов 429                                                     | Достигнута квота параллельных запросов                                                                                       | [Лимиты параллельных запросов API](/ru/faq/api-concurrency)                                                                                       |
| Вывод обрывается на середине предложения                                             | max\_tokens не задан или слишком мал                                                                                         | [Что такое max\_tokens](/ru/faq/max-tokens)                                                                                                       |
| Конкретная модель не запускается                                                     | Заблокировано разрешение учётной записи или действует белый список моделей token                                             | [Почему я не могу использовать некоторые модели](/ru/faq/model-availability) · [Белый список моделей token](/ru/faq/token-model-whitelist)        |
| Генерация изображений не выполняется / возвращает пустой результат                   | Сработала защита Google от небезопасного контента                                                                            | [Сбои Nano Banana](/ru/faq/nano-banana-image-failure)                                                                                             |
| Gemini image API возвращает NO\_IMAGE                                                | Причина отличается от блокировок безопасности                                                                                | [Почему возникает NO\_IMAGE](/ru/faq/gemini-no-image)                                                                                             |
| Вывод сильно отличается от эталонного изображения                                    | Эталонные изображения необходимо загружать как base64                                                                        | [Изображение отличается от эталона](/ru/faq/image-result-differs-from-reference)                                                                  |
| Загрузка завершается ошибкой does not match MIME type                                | URL изображения содержит параметры обработки CDN                                                                             | [Несоответствие MIME type](/ru/faq/image-mime-type-mismatch-with-query)                                                                           |
| На изображении с белым фоном появляются чёрные пятна                                 | Известное поведение маршрута AI Studio                                                                                       | [Артефакты на белом фоне](/ru/faq/white-background-image-artifacts)                                                                               |
| Требуется опрашивать результаты изображения по ID задачи                             | Генерация изображений доступна только в синхронном режиме                                                                    | [Есть ли асинхронный image API](/ru/faq/image-async-api)                                                                                          |
| Счёт за изображение значительно выше ожидаемого                                      | Разрешение, качество, соотношение сторон и количество масштабируют выходные tokens                                           | [Почему выходные tokens GPT Image высоки](/ru/faq/gpt-image-output-token-calculation)                                                             |
| Seedance блокирует эталонное изображение лица                                        | Для реальных лиц требуется загрузка ресурса и подтверждение личности                                                         | [Почему ресурсы с лицами блокируются](/ru/faq/seedance2-face-asset-whitelist)                                                                     |
| Модель утверждает, что принадлежит другому поставщику / не может назвать свою версию | Самопознание модели ненадёжно                                                                                                | [Claude утверждает, что является Qwen](/ru/faq/claude-identity-confusion) · [Модели не знают свою версию](/ru/faq/model-version-identity)         |
| Веб-приложение умное, а API нет                                                      | Веб-приложение включает system prompt и tools; API предоставляет базовую модель                                              | [Веб-приложение и API](/ru/faq/webapp-vs-api-difference)                                                                                          |
| Неизвестные вызовы с вашим KEY                                                       | KEY мог быть скомпрометирован — отследите его и отключите                                                                    | [Расследование неожиданного использования KEY](/ru/faq/troubleshoot-key-usage) · [Безопасное управление ключами](/ru/faq/key-security-management) |
| Тарификация не сходится                                                              | Тарификация по использованию и по вызовам отображается по-разному                                                            | [Чтение тарификации в логах](/ru/faq/log-billing-explained) · [Коэффициент тарифа модели](/ru/faq/model-multiplier)                               |
| Загрузка изображений или видео происходит медленно                                   | Маршрутизация зарубежного CDN на отдельных серверах                                                                          | [Загрузка из CDN происходит медленно](/ru/faq/cdn-download-slow)                                                                                  |
| Нужен ли мне прокси?                                                                 | Прямое подключение работает; прокси не требуется                                                                             | [Нужен ли мне прокси](/ru/faq/network-proxy)                                                                                                      |
| При входе через GitHub указано «Account already bound»                               | Эта учётная запись GitHub привязана к другому email                                                                          | [Ошибка привязки GitHub](/ru/faq/github-bindng-bindng-error)                                                                                      |
| Вы забыли пароль                                                                     | Сбросьте его по email или обратитесь в поддержку                                                                             | [Забыли пароль](/ru/faq/forgot-password)                                                                                                          |
