# Есть ли интеграция одним кликом?

> Да, но не в виде кнопки. Вы передаёте документацию своему ИИ-помощнику по программированию, и он выполняет интеграцию за вас.

## Краткий ответ

**Да, но это не кнопка.**

Мы не предлагаем интеграцию в традиционном смысле — «нажать один раз, и всё будет настроено». Разные модели используют разные протоколы, параметры и способы аутентификации, поэтому такая кнопка могла бы охватить только базовый чат и не решила бы реальные задачи.

Вместо этого мы предлагаем более эффективный подход: **передайте документацию своему AI-помощнику для программирования и позвольте ему выполнить интеграцию**. Вам нужно только зарегистрировать аккаунт и скопировать ключ. Выбор модели, заполнение базового URL, написание кода и отладку можно полностью поручить AI.

## Четыре способа использования

<Steps>
  <Step title="Навык для всего сайта (рекомендуется)">
    Попросите своего агента выполнить `npx skills add https://docs.apiyi.com`, чтобы установить навык APIYI. Если это не сработает, попросите его напрямую прочитать `https://docs.apiyi.com/skill.md`.

    Этот файл предназначен для машин: в нём описаны эндпоинты, аутентификация, правила именования моделей, известные проблемы и контрольный список проверки. Прочитав его, агент получит всю необходимую справочную информацию.
  </Step>

  <Step title="Отправьте одну страницу AI">
    В правом верхнем углу каждой страницы документации есть кнопка **Копировать страницу**. Стрелка рядом с ней также предлагает варианты «Открыть в ChatGPT / Claude / Perplexity / Google AI Studio».

    Если у вас возникла проблема с конкретной моделью, откройте эту страницу, нажмите «Копировать страницу» и отправьте её вместе с сообщением об ошибке. Это самый быстрый способ устранить неполадку.
  </Step>

  <Step title="Подключитесь как сервер MCP">
    Добавьте `https://docs.apiyi.com/mcp` как сервер MCP, и ваш агент сможет при необходимости искать актуальное содержимое этого сайта без необходимости вручную передавать ему страницы.
  </Step>

  <Step title="Командная строка, установка не требуется">
    Если вы не хотите писать код, выполните `npx apiyi@latest check` в терминале (Node 18+). Команда проверяет ключ, тестирует ноду и выводит список моделей; затем `npx apiyi@latest chat "Hello" -m gpt-5.4-mini` отправляет первое сообщение. Таблица команд находится в [Наборе инструментов разработчика AI](/ru/developer-kit#cli).
  </Step>
</Steps>

<Info>
  **Почему это лучше**: кнопка в одно нажатие может охватить только фиксированный набор сценариев. AI анализирует фактический стек вашего проекта, пишет работающий код и по ходу обрабатывает тайм-ауты и повторные попытки — то, чего кнопка сделать не может.
</Info>

## Почему не одна кнопка?

Интеграция моделей различается по нескольким параметрам:

* **Разные протоколы**: OpenAI, Claude, Gemini и другие используют разные протоколы API
* **Разные параметры**: поля запросов и структуры ответов различаются у разных моделей
* **Разная аутентификация**: заголовки аутентификации и места их размещения не стандартизированы
* **Разные возможности**: вызов функций, кэширование промптов и веб-поиск реализованы по-разному в каждой модели

Принудительный сценарий в один клик обычно охватывал бы только базовый чат, чего недостаточно для реального использования.

<Note>
  **Регистрацию аккаунта вы по-прежнему выполняете самостоятельно.** API для самостоятельного создания аккаунта или ключа агентом не существует. Аккаунты и тарификация связаны с идентификацией и контролем рисков, поэтому этот шаг должен выполнить человек. Всё — от «у меня есть ключ» до «код работает» — можно передать AI.
</Note>
