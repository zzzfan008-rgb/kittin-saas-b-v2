# Gemini 3.8 Flash

> Gemini 3.8 Flash на APIYI: $0.75 за входные / $3.75 за выходные tokens на 1 млн tokens, доступна в 2 группах тарификации.

Следующая версия Flash по той же цене, что и 3.7, соответствует ей по каждому пункту в 150 измеренных случаях; официальные спецификации ещё не опубликованы. Уровни рассуждения сокращены до низкого, среднего и высокого — минимальный уровень упразднён.

## Пример запроса

В примере ниже выполняется вызов `gemini-3.8-flash` через OpenAI Chat Completions (`/v1/chat/completions`). Укажите в base\_url значение `https://api.apiyi.com/v1` — всё остальное соответствует официальному API.

```bash theme={null}
curl https://api.apiyi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $APIYI_API_KEY" \
  -d '{
    "model": "gemini-3.8-flash",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

<Tip>Считывайте ключ из переменной окружения и никогда не встраивайте его непосредственно в код. В рабочей среде выдавайте отдельные tokens для каждого сценария использования, чтобы их можно было отзывать и отдельно отслеживать использование.</Tip>
