# Переводчик Bob

> Руководство по интеграции профессионального инструмента перевода для macOS

Bob — отличное ПО для перевода на macOS, которое поддерживает перевод по выделению, перевод скриншотов и другие функции. Интегрировав APIYI, вы можете использовать модели ИИ, чтобы получать более точные и естественные результаты перевода.

## Быстрая настройка

### 1. Установите Bob

Скачайте и установите последнюю версию с [Официального сайта Bob](https://bobtranslate.com).

### 2. Настройте APIYI

1. Откройте настройки Bob (значок в строке меню > «Настройки»)
2. Перейдите на вкладку «Сервисы»
3. Добавьте сервис перевода OpenAI
4. Настройте параметры:
   * **API Key**: Ваш ключ APIYI
   * **API URL**: `https://api.apiyi.com`
   * **Model**: `gpt-3.5-turbo`

### 3. Проверьте настройку

Нажмите кнопку «Тест», чтобы проверить конфигурацию, и сохраните после появления сообщения об успешном результате.

## Способы использования

### Перевод выбранного текста

1. Выделите текст для перевода
2. Нажмите сочетание клавиш (по умолчанию `⌥ + D`)
3. Bob показывает результат перевода

### Перевод снимка экрана

1. Нажмите сочетание клавиш для снимка экрана (по умолчанию `⌥ + S`)
2. Выберите область для перевода
3. Bob распознает и переводит текст на изображении

### Перевод ввода

1. Откройте окно Bob (по умолчанию `⌥ + Space`)
2. Введите или вставьте текст для перевода
3. Выберите целевой язык
4. Просмотрите результат перевода

## Дополнительные настройки

### Пользовательские prompt

Шаблон prompt для оптимизации качества перевода:

```text theme={null}
You are a professional translation expert proficient in multiple languages. Please translate the following {source_lang} text to {target_lang}.

Requirements:
1. Maintain original tone and style
2. Use idiomatic expressions
3. For technical terms, mark original text in parentheses after translation
4. Be mindful of cultural differences, adjust expressions appropriately

Original text: {text}
```

### Настройка сочетаний клавиш

Настройте в Settings > General:

* **Перевод выделенного слова**: `⌥ + D`
* **Перевод скриншота**: `⌥ + S`
* **Перевод ввода**: `⌥ + Space`
* **Показать/скрыть**: `⌥ + B`

### Настройки поведения перевода

Рекомендуемая конфигурация:

* **Автоопределение языка**: Включено
* **Автокопирование после перевода**: По необходимости
* **Сохранять исходное форматирование**: Включено
* **История**: Включено

## Советы по использованию

### 1. Профессиональный перевод для конкретных предметных областей

Для конкретных предметных областей можно указать в prompt:

```text theme={null}
Please translate as a computer professional translator.
Preserve all technical terms in English, with Chinese explanations in parentheses.
```

### 2. Пакетный перевод

При переводе больших объемов текста:

1. Используйте режим перевода при вводе
2. Вставляйте текст частями
3. Используйте историю для просмотра всех переводов

### 3. Сравнительное чтение

При чтении материалов на иностранном языке:

1. Включите опцию «Показать оригинал»
2. Используйте перевод по выделенному слову для просмотра в реальном времени
3. Сравнивайте оригинал и перевод для обучения

### 4. Управление терминологией

Создайте собственную базу терминологии:

1. Добавляйте в закладки переводы распространенных терминов
2. Настраивайте переводы отдельных слов
3. Экспортируйте резервную копию базы терминологии

## Распространенные проблемы

### Низкая скорость перевода

**Анализ:**

* Проблемы с сетевым соединением
* Выбранная модель слишком большая
* Сервис API перегружен

**Решения:**

1. Проверьте сетевое соединение
2. Используйте быстрые модели, например gpt-3.5-turbo
3. Избегайте часов пик

### Неточный перевод

**Способы улучшения:**

1. Используйте более продвинутые модели (например, GPT-4)
2. Оптимизируйте prompt, предоставьте больше контекста
3. Укажите предметную область для профессионального контента

### Квота API исчерпана

**Действия:**

1. Проверьте баланс аккаунта APIYI
2. Разумно используйте разные модели, чтобы контролировать затраты
3. Установите дневные лимиты использования

## Расширенные возможности

### Интеграция схемы URL

Bob поддерживает интеграцию в другие приложения через URL Scheme:

```bash theme={null}
# Translate text directly
bob://translate?text=Hello&from=en&to=zh

# Open Bob window
bob://open
```

### Автоматизация AppleScript

```applescript theme={null}
tell application "Bob"
    translate "Hello World" from "en" to "zh"
end tell
```

### Функция экспорта

Регулярно экспортируйте записи переводов:

1. Откройте историю
2. Выберите диапазон времени
3. Экспортируйте в формате CSV или JSON

## Интеграция с другими инструментами

### Интеграция с Raycast

Быстро вызывайте Bob через расширение Raycast:

```javascript theme={null}
// Raycast script example
import { showToast, Toast } from "@raycast/api";
import { exec } from "child_process";

export default async function Command() {
  exec("open bob://translate", (error) => {
    if (error) {
      showToast(Toast.Style.Failure, "Failed to launch Bob");
    }
  });
}
```

### Рабочий процесс Alfred

Создайте workflow Alfred для быстрого перевода:

1. Создайте новый workflow
2. Добавьте триггер по ключевому слову
3. Подключите действие запуска скрипта
4. Вызовите URL Scheme Bob

### Расширение PopClip

Установите расширение Bob для PopClip, чтобы переводить сразу после выделения текста.

## Устранение неполадок

### Сервис недоступен

Проверьте:

1. API key указан верно
2. Подключение к сети работает нормально
3. Статус сервиса APIYI

### Конфликты сочетаний клавиш

Способы решения:

1. Проверьте наличие конфликтов сочетаний клавиш в System Preferences
2. Назначьте для Bob уникальные сочетания клавиш
3. Отключите сочетания клавиш конфликтующих приложений

### Проблемы с разрешениями

Убедитесь, что у Bob есть необходимые разрешения:

* Разрешение Accessibility
* Разрешение на запись экрана (для перевода скриншотов)
* Разрешение на ввод с клавиатуры
