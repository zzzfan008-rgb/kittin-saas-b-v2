# Qwen3.8-27B

> Qwen3.8-27B на APIYI: $0.44 за 1 млн tokens на ввод / $1.76 за 1 млн tokens на вывод, контекстное окно 262 144, доступна в 2 группах тарификации.

Плотная мультимодальная модель с 27B параметров по лицензии Apache-2.0, принимающая текст, изображения и видео; имея размер в одну девяностую от флагманской открытой модели того же поколения, она сохраняет возможности работы с изображениями, от которых отказывается более крупный открытый релиз.

## Пример запроса

В приведённом ниже примере выполняется вызов `qwen3.8-27b` через Chat Completions OpenAI (`/v1/chat/completions`). Укажите `https://api.apiyi.com/v1` в качестве base\_url — всё остальное соответствует официальному API.

```bash theme={null}
curl https://api.apiyi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $APIYI_API_KEY" \
  -d '{
    "model": "qwen3.8-27b",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

<Tip>Считывайте ключ из переменной окружения, никогда не прописывайте его в коде напрямую. В рабочей среде выпускайте отдельные токены для каждого сценария использования, чтобы их можно было отзывать и связывать использование с конкретным сценарием.</Tip>
