# APIYI - 엔터프라이즈 AI 모델 API 허브

> 2년 이상 운영해 온 전문적이고 안정적인 AI API 통합 서비스로, 월간 방문자 15만 명을 보유한 장기적으로 신뢰할 수 있는 서비스입니다

<Info>
  **중국어 사용자이십니까?** [중국어 버전으로 전환](/ko)
</Info>

**APIYI**는 엔터프라이즈급의 전문적이고 안정적인 AI 모델 API 허브입니다. 통합된 OpenAI API 표준과 호환되며 각 공급업체의 네이티브 API 형식(Claude, Gemini 등)도 지원하여 400개 이상의 인기 AI 모델을 제공합니다. 하나의 token으로 OpenAI, Claude, Gemini, DeepSeek, Qwen, Kimi, GLM, Minimax 및 모든 주요 대규모 언어 모델에 쉽게 액세스할 수 있습니다.

## 🏢 회사 배경

* 운영 주체: APIYI, LLC (미국)
* 공식 파트너: Google AI Studio, Microsoft Azure, Amazon AWS (정식 쿼터 출처, 안심하고 사용 가능)
* 서비스 보장:
  * 안정적: OpenAI, Claude, Google Gemini와 같은 주류 모델에 대해 높은 동시 실행 수와 안정적인 서비스를 제공합니다
  * 신뢰할 수 있음:
    * 많은 유명 애플리케이션이 운영 환경에서 안정적으로 통합되어 있습니다(사용 사례 섹션 참조).
    * 저명한 대학, 병원 및 기타 기관과 협력하며, 잘 알려진 기업에 서비스를 제공합니다.
    * 국내 법인은 기업 결제, 청구서 발행, 조달 목록 지원이 가능하여 걱정 없이 비용 정산할 수 있습니다.

## 🤖 AI가 대신 통합하도록 하는 세 가지 방법

문서를 읽거나 설정을 직접 입력할 필요가 없습니다. 현재 사용할 수 있는 AI를 선택하고, 해당 AI에 맞는 프롬프트를 복사하면 나머지는 AI가 처리합니다.

<Tabs>
  <Tab title="스킬 · 채팅 에이전트" icon="sparkles">
    **OpenClaw와 같은 채팅 에이전트에서 자연어로 APIYI를 호출합니다.** 에이전트에 프롬프트를 복사하면 스킬을 설치하고, 키를 자체 점검한 다음 설정 과정을 안내합니다.

    <Prompt description="OpenClaw, Claude Code, Cursor 또는 스킬을 지원하는 모든 에이전트에 복사" icon="bot" actions={["copy"]}>
      [https://docs.apiyi.com에서](https://docs.apiyi.com에서) APIYI 스킬을 설치합니다. 먼저 `npx skills add https://docs.apiyi.com`을 시도합니다.
      OpenClaw인 경우에는 대신 `git:apiyi-com/skills`을 설치하고, 그 외에는 [https://docs.apiyi.com/skill.md를](https://docs.apiyi.com/skill.md를) 읽습니다.
      그런 다음 키를 자체 점검합니다(스킬의 scripts/apiyi.py --check 또는 npx apiyi\@latest check).
      키가 없으면 [https://api.apiyi.com/token에서](https://api.apiyi.com/token에서) 키를 복사하여 APIYI\_API\_KEY에 입력하도록 안내합니다. 키를 코드에 직접 하드코딩하지 않습니다.
      점검 결과가 준비 완료로 표시되면 gpt-5.4-mini로 “Hello”를 전송하고 응답을 보여 줍니다.
    </Prompt>

    스킬 소스 `github.com/apiyi-com/skills` · 설치 경로와 키 설정은 [AI 개발 키트](/ko/developer-kit#skills)에서 확인할 수 있습니다.
  </Tab>

  <Tab title="CLI · 터미널" icon="terminal">
    **코드를 한 줄도 작성하지 않고 터미널에서 첫 번째 호출을 작동시킵니다.** `npx apiyi@latest check`은 설치가 필요 없습니다. 키를 확인하고, 노드 지연 시간을 측정하며, 모델을 나열하고, 메시지를 전송하고, 이미지를 생성합니다.

    <Prompt description="터미널 명령을 실행할 수 있는 에이전트에 복사하거나 직접 명령을 실행" icon="terminal" actions={["copy"]}>
      APIYI CLI를 설치하고 실행하도록 도와주세요: [https://github.com/apiyi-com/cli](https://github.com/apiyi-com/cli)
      요구 사항: Node 18 이상입니다. 설치할 필요 없이 `npx apiyi@latest check`를 실행합니다.
      API 키를 설정하도록 안내해 주세요(`npx apiyi@latest auth set-key` 또는 APIYI\_API\_KEY 환경 변수에 [https://api.apiyi.com/token에서](https://api.apiyi.com/token에서) 복사한 키를 입력).
      마지막으로 `npx apiyi@latest models --grep gpt-5`과 `npx apiyi@latest chat "Hello" -m gpt-5.4-mini`을 실행하고 출력을 붙여 넣어 주세요.
    </Prompt>

    소스 `github.com/apiyi-com/cli` · npm 패키지 `apiyi` · 전체 명령 표는 [AI 개발 키트](/ko/developer-kit#cli)에서 확인할 수 있습니다.
  </Tab>

  <Tab title="AI 개발 키트 · 코딩 에이전트" icon="code">
    **코드를 작성하기 전에 Cursor / Claude Code / Codex가 계약을 읽도록 합니다.** skill.md는 규칙집이고, llms.txt는 색인이며, model-registry.json은 모델의 단일 기준 소스입니다. 먼저 읽고 설명한 다음 수정합니다. 엔드포인트를 임의로 만들지 않습니다.

    <Prompt description="Cursor, Claude Code, Codex 또는 다른 코딩 에이전트에 복사" icon="code" actions={["copy"]}>
      먼저 [https://docs.apiyi.com/skill.md와](https://docs.apiyi.com/skill.md와) [https://docs.apiyi.com/llms.txt를](https://docs.apiyi.com/llms.txt를) 처음부터 끝까지 읽습니다.
      APIYI 통합 규칙을 반드시 준수합니다. 엔드포인트, 매개변수 이름, 열거형 값 또는 응답 형식을 임의로 만들지 않습니다.
      모델 ID의 단일 기준 소스로 [https://docs.apiyi.com/model-registry.json을](https://docs.apiyi.com/model-registry.json을) 사용합니다(점으로 버전이 표시되고 대소문자를 구분합니다. 예: gpt-5.4-mini).
      SDK에 따라 기본 URL을 선택합니다. OpenAI SDK는 [https://api.apiyi.com/v1을](https://api.apiyi.com/v1을) 사용하고, Anthropic 및 Google GenAI SDK는 [https://api.apiyi.com을](https://api.apiyi.com을) 사용합니다(Gemini는 api\_version도 v1beta로 설정).
      API 키는 APIYI\_API\_KEY 환경 변수에서만 읽습니다. 읽은 후 먼저 통합 흐름을 설명합니다. 아직 코드는 수정하지 않습니다.
    </Prompt>

    키트에 포함된 내용과 각 파일의 사용 방법: [AI 개발 키트](/ko/developer-kit)
  </Tab>
</Tabs>

## 🚀 왜 APIYI를 선택해야 할까요?

### 하나의 인터페이스, 다양한 모델

각 AI 서비스마다 별도의 계정을 신청하고 API 키를 관리할 필요가 없습니다. APIYI를 이용하시면 다음만으로 충분합니다:

* **하나의 계정**: 모든 AI 서비스 관리
* **하나의 API 키**: 모든 모델 이용
* **하나의 표준**: OpenAI API 형식과 호환

response = openai.ChatCompletion.create(

)
