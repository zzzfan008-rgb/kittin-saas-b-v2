# iCover AI Adds Wan3.0 with Multimodal Reference Inputs

> Following the Wan3.0 video model launch on APIYI, the iCover AI video testing tool now supports Wan3.0: reference images, videos, audio, documents and web links can all be used as inputs, by URL or local upload, with no code required.

**2026/10/11 11:59 (UTC+8)** · New Model · Alibaba

🚀 **The iCover AI video testing tool now supports Wan3.0, with multimodal reference uploads**

Following the launch of the [Wan3.0 video models](/en/api-capabilities/wan3/overview) on APIYI, [iCover AI](https://icover.ai/zh/wan-official), an APIYI product, has added them too, so you can test online without writing code. Reference inputs available for Wan3.0:

* Reference images: up to 9
* Reference video and reference audio
* Reference files: `pdf` / `docx` documents
* Reference web links: must be reachable from mainland China

Each input can be a public https URL or a local file upload, which the tool stores and turns into an accessible link automatically. Prompts support templates and one-click optimization.
