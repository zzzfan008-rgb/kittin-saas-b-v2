# Account security upgrade: 2FA is now available, please enable it

> APIYI completed a site system upgrade over the weekend, adding Two-Factor Authentication (2FA). Sensitive actions such as signing in or creating an API KEY may ask for a 2FA verification code. If you were signed out by the upgrade, sign in again with your email or account plus password; accounts created through GitHub one-click sign-up still sign in with GitHub. Enable 2FA from the 2FA section of Personal Center.

**2026/9/21 00:54 (UTC+8)** · Service Notice

🔐 **A site system upgrade this weekend added Two-Factor Authentication (2FA) — we strongly recommend enabling it**

Once enabled, sensitive actions such as signing in or creating an API KEY may ask for a 2FA verification code, which makes account takeover far harder.

How to enable it: click 【Personal Center】 in the top-right corner and scroll down to the 【2FA】 section, or go straight to [api.apiyi.com/account/profile](https://api.apiyi.com/account/profile). Any TOTP-compatible authenticator app works:

* Google Authenticator
* Microsoft Authenticator
* Any other TOTP-compatible authenticator

Some sessions were invalidated during the upgrade, so you may have been signed out. This is expected and affects neither API calls nor your account balance. If you signed up with an email or account name, sign in again with that plus your password; accounts created through GitHub one-click sign-up keep signing in with GitHub, no password needed.

If you need help, reach us through [WeCom support](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec) on the site homepage. Thank you for your understanding.
