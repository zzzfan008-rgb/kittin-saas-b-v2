# SD2Mini / SD2Fast Discount Ends, Back to 0.18x from October 8

> Volcengine's limited-time offer on Seedance 2.0 mini / fast ended on October 7. From 2026-10-08 12:00 (UTC+8), APIYI returns SD2Mini (was 0.10x) and SD2Fast (was 0.15x) to 0.18x, matching the SeeDance2 group. Both groups stay online; existing Tokens and code need no changes.

**2026/10/8 12:00 (UTC+8)** · Price Update · ByteDance

💸 **The `SD2Mini` / `SD2Fast` limited-time discount has ended — from 2026-10-08 12:00 (UTC+8) both are back at 0.18x, the same as the `SeeDance2` group**

Background: Volcengine's limited-time offer on Seedance 2.0 mini / fast ended on October 7, and APIYI has followed suit: `SD2Mini` (previously **0.10x**, `doubao-seedance-2-0-mini-260615` only) and `SD2Fast` (previously **0.15x**, `doubao-seedance-2-0-fast-260128` only) are both back at **0.18x**.

Both groups stay online, so existing Tokens keep working with no code changes. For new Tokens, just enable `SeeDance2` — one Token reaches all four models: 2.5, standard, fast, and mini. If the official side launches another offer, we will follow it. See the [SeeDance 2 overview](/en/api-capabilities/seedance2/overview) for group details.
