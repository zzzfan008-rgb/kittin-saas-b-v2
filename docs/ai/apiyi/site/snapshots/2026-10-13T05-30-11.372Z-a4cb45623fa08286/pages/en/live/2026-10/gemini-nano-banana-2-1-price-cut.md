# Nano Banana 2.1 per-request price cut to $0.045

**2026/10/13 00:17 (UTC+8)** · Price Update · Google

💸 **Nano Banana 2.1 (`gemini-nano-banana-2.1`) per-request price cut of 10%: \$0.05 → \$0.045**

With token-based billing, 1K / 2K images already cost only \$0.02–\$0.04 each, which made \$0.05 per request look expensive, so we lowered the per-request price too. 1K / 2K / 4K stay at the same price, and for 4K, per-request is now nearly 30% cheaper than token-based (\$0.06 or more).

* Per request: \$0.045, same for 1K / 2K / 4K, no change to how you call it
* Token-based: unchanged at \$0.66 input / \$13.2 output per 1M tokens

With the 10%–20% top-up bonus, the effective per-request cost is about \$0.038–\$0.041. See the [Nano Banana 2.1 overview](/en/api-capabilities/gemini-nano-banana-2.1/overview); the [Model Pricing](/en/models/index) tab is authoritative for current prices.
