# Seedream 歴代バージョン

> Seedream 5.0 Flash / 5.0 Pro / 5.0 / 4.5 / 4.0 の仕様比較、料金の違い、および移行ガイド。すべてのバージョンは引き続き呼び出し可能です — 用途に合わせて選択してください。

<Note>
  このページでは、APIYIで**引き続き呼び出し可能**なすべてのSeedreamバージョンを一覧表示しています。すべてのバージョンが同時に稼働しており、**パラメータは概ね互換性があります** — ほとんどの場合、`model`フィールドを変更するだけで切り替えが可能です（5.0 Flashおよび5.0 Proはシーケンシャル生成やストリーミングに対応していません。下記の互換性マトリクスを参照してください）。最新バージョンおよび全般的な概要については、[Seedream 概要](/ja/api-capabilities/seedream-image/overview)をご覧ください。
</Note>

## バージョン別仕様

### `seedream-5-0-flash-260915` (5.0 Flash)

* **リリース日**: 2026-09-15 (UTC+8)、APIYIでは2026-09-24より利用可能です
* **APIYI価格**: **\$0.018 / リクエスト**（リクエストごとの固定価格、1リクエストあたり1枚の画像）。BytePlusの公式価格と同じです。**参照画像は無料です**（テストでは参照画像1枚、3枚、10枚のいずれも\$0.018で課金されました）。また、パラメータエラーなどの失敗したリクエストは課金されません。チャージボーナスを含めると、実質価格は公式レートよりおおよそ**9%〜17%安くなります**
* **解像度ティア**: プリセット `1K` / `1.5K` / `2K`（**3K/4Kは非対応**。渡すと400が返されます）。`size` を省略した場合はデフォルトで2Kになります。プリセットを使用する場合、**モデルがコンテンツに基づいてアスペクト比を自動選択します**（テストでは2Kで1776×2368および1664×2496のポートレートが生成されました）。固定比率が必要な場合は、正確なピクセル数を指定してください
* **正確なピクセル範囲**: 総ピクセル数 921,600〜4,624,220（約0.92M〜4.62M）、長辺対短辺の比率は最大16:1まで。範囲外の値はエラーメッセージ内に有効範囲が示された400を返します（`2688x1712` および `4096x256` は動作します）
* **出力フォーマット**: `png` / `jpeg`
* **速度**: テキストからの画像生成で11〜20秒、参照画像を使用した編集で約16秒、10枚の参照画像では約28秒
* **コア機能**:
  * BytePlusにより高速・優れたレイアウト力・低コストとして位置づけられています。レイアウトタスクにおいて5.0 Proよりもフォントの多様性、構図、色の明るさに優れ、グレーや黄色の色かぶりが少なくなっています
  * **正確なテキストレンダリング**: テストでは3行の中国語ポスターや英語・日本語・韓国語のタイトルがすべて正しくレンダリングされました
  * **レイヤー分離（透過レイヤー）**: `layer_decomposition: true` は画像を背景ベースとアルファチャンネル付きレイヤー上の個別要素に分割し、再レイアウトや素材の再利用に役立ちます
  * **インタラクティブな編集**: 画像の他の部分を変更することなく、位置指定による編集（例：「右上に『NEW』バッジを追加」）が可能です
  * **最大10枚**の参照画像を用いた複数画像の融合（11枚目を渡すと400が返されます）
* **既知の制限事項**:
  * **`sequential_image_generation` / `stream` は非対応**: 5.0 Proと同様に、任意の値（`"disabled"` を含む）を渡すと400が返されるため、送信しないでください
  * `n` は警告なしで無視されます。1枚の画像のみが取得され、課金されます
  * **デフォルトで「AI generated」の透かしが追加されます**。商用利用の場合は明示的に `watermark: false` を渡してください
  * **透過にはプロンプトではなくレイヤー分離が必要**: prompt で透過背景を要求すると、アルファチャンネルのない png が返されます（市松模様が画像自体に描画されます）。透過素材を作成するには、1枚の参照画像とともに `layer_decomposition: true` を使用してください。塗りつぶされた背景ベースと複数の RGBA レイヤーが返されます（テストでは1Kで12枚の画像が約78秒で出力されました）。**レイヤー分離は出力画像ごとに課金されます**: 12枚の画像で \$0.216 かかります。2Kのレイヤーリクエストでは15分経過しても何も返されませんでしたが、**それでも \$0.216 が課金されたため**、必ず `1K` を使用してください。詳細は[画像編集](/ja/api-capabilities/seedream-image/image-edit)を参照してください
  * 写実的なポートレートや繊細な素材の質感表現には、BytePlusは現在も5.0 Proを推奨しています

### `seedream-5-0-pro-260628` (5.0 Pro)

* **リリース日**: 2026-06-28 (UTC+8)、APIYIでは2026-07-19より提供開始
* **APIYI価格**: **\$0.12 / リクエスト**（リクエストごとの固定価格、1リクエストあたり1画像、定価約¥0.84）。公式には、このモデルは2つの出力ピクセル価格ティア（≤2.36M / >2.36M）に加え、2枚目以降の参照画像に対する追加料金が発生しますが、APIYIでは入力画像料金を含めたリクエストごとの定額料金に簡略化しています
* **解像度ティア**: プリセット `1K` / `2K`（**3K/4Kプリセットなし**）、および合計最大**4.19M**までの正確なピクセル指定 `WxH`（最大2048×2048、16:9のアスペクト比では最長辺が `2720x1530` ≈ 2.7K に達することを検証済み）
* **出力フォーマット**: `png` / `jpeg`
* **プロンプト最適化**: standard / fast
* **主な特徴**:
  * シリーズ最高の画質と指示追従性を誇り、インタラクティブ編集（座標、選択ボックス、矢印による編集箇所の指定）に対応しています
  * マルチ画像フュージョンは公式に**最大10枚の参照画像**に対応しています
* **既知の制限事項**:
  * **`sequential_image_generation` / `stream` は受け付けられません** — 任意の値（`"disabled"` を含む）で400が返されるため、両方のパラメータを完全に省略してください
  * 生成が遅い：画像1枚あたり一貫して**約2分**（実測値110〜130秒）かかります — クライアントのタイムアウトを240秒以上に設定してください
  * 5.0-liteの3.4倍の単価です。日常的な作業には5.0-liteをご利用ください

  * `png` 出力をサポートする唯一のバージョンです（そのため透過背景にも対応しています）
  * 成熟したストリーミング出力（`stream: true`）
* **既知の制限事項**:
  * 解像度は最大3K（約3072×3072）に制限されています。4Kアセットには 4.5 / 4.0 をご利用ください

## 移行ガイダンス

<Steps>
  <Step title="相違点を確認する">
    各バージョンは**パラメータレベルでほぼ互換性があります** — ほとんどの場合、`model`フィールドを変更するだけで切り替えられます。以下の点を入念にご確認ください：

    * ご利用の`size`ティアが新しいバージョンでサポートされているかどうか（5.0 Flashおよび5.0 Proは最大2K程度まで対応、5.0には1K / 4Kがなく、4.5には1Kがなく、4.0にはすべて揃っています）
    * `sequential_image_generation`または`stream`を送信しているかどうか（5.0 Flash / 5.0 Proへ切り替える際は削除してください。削除しないと400エラーが返されます）
    * `output_format: "png"`に依存しているかどうか（5.0のみ）
    * `prompt_optimization: "fast"`を使用しているかどうか（4.0のみ）
  </Step>

  <Step title="並行して実行する">
    新旧両方のバージョンで同じpromptバッチを実行し、品質とコストを比較します。本格展開する前に、少量のバッチ（10〜20枚の画像）で検証してください。
  </Step>

  <Step title="段階的に展開する">
    トラフィックを段階的に切り替えます（10% / 50% / 100%）。各段階で品質、失敗率、コストを確認してから、さらに規模を拡大してください。
  </Step>

  <Step title="フォールバックを維持する">
    本番環境のコードには新旧両方の`model`設定を残しておきます。新しいバージョンで予期しない動作が発生した場合は、すぐに元へ戻すことができます。各バージョンは独自の単価で課金されるため、両方を実行しても追加費用は発生しません。
  </Step>
</Steps>

## レガシーな呼び出し例

```python theme={null}
{/* Switching versions only changes the model field; other params are compatible */}
from openai import OpenAI

client = OpenAI(api_key="sk-your-api-key", base_url="https://api.apiyi.com/v1")

resp = client.images.generate(
    model="seedream-4-0-250828",   # change this line to switch to 4.5 / 5.0
    prompt="A serene mountain landscape at golden hour, snow-capped peaks, ultra detailed, 4K",
    size="4K",                      # NOTE: 5.0 does not support 4K — use 2K or 3K
    response_format="url",
    extra_body={
        "watermark": False,
    }
)

print(resp.data[0].url)
```

## コスト比較

| - | - | - | - | - |
| `seedream-5-0-flash-260915` | \$0.018 / リクエスト | \$1.8 | \$18 | \$180 |
| `seedream-5-0-pro-260628` | \$0.12 / リクエスト | \$12 | \$120 | \$1200 |
| `seedream-5-0-260128` | \$0.035 | \$3.5 | \$35 | \$350 |

<Info>
  **選び方**:

  * 4Kアセット + 強力なテキスト描画 → **4.5**
  * 4Kアセット + 最安価格 → **4.0**
  * 大量生成 / ポスターレイアウト / スピードとコスト → **5.0 Flash**（\$0.018/リクエスト、1枚あたり約15〜20秒、最大約2K）
  * 総合力重視 / PNG出力 / 透過背景 → **5.0**
  * 長期運用の安定したバッチ生成 → **4.0**（実績豊富、最安、高速 prompt モード）
  * 最高品質 / プロ業務向けの複雑な指示 → **5.0-pro**（\$0.12/リクエスト + 1枚あたり約2分 — 必要でない限りスキップ推奨）
</Info>
