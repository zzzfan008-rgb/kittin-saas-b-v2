# Тарифы серии Nano Banana

> Полное сравнение цен на модели генерации изображений серии Nano Banana (Pro / 2.1 / 2 / 2 Lite / Gen 1), включая тарификацию за запрос, тарификацию по token, бонусы за пополнение и руководство по выбору token. Всего от 30.3% от официальных цен.

## Обзор

Серия Nano Banana включает пять моделей генерации изображений, доступных через APIYI по ценам значительно ниже официальных тарифов. На этой странице собрана информация о ценах на все модели Nano Banana, которая поможет вам выбрать оптимальный план тарификации.

<Info>
  При вызове API используемый вами **тип token** определяет метод тарификации. Nano Banana Pro, 2.1, 2 и Lite поддерживают два режима тарификации: **за запрос** и **на основе tokens**. Для каждого предусмотрено два уровня: стандартный стабильный уровень и корпоративный уровень высокой доступности.
</Info>

## Руководство по выбору типа token

<Info>
  При создании token параметр «Billing model» определяет способ тарификации. Выбирайте в зависимости от основного сценария использования:
</Info>

| Модель | Сценарий использования | Рекомендуемый тип token |
| - | - | - |
| Nano Banana Pro | Смешанное использование 1-4K | На основе token (приоритет) |
| Nano Banana Pro | Только 4K | За запрос |
| Nano Banana 2 | Смешанное использование 0.5K-4K | На основе token (приоритет) |
| Nano Banana 2 | Только 4K | За запрос |
| Nano Banana 2 Lite | Генерация объемом 1K | На основе token (приоритет) |

<Tip>
  **Простое правило**: если вы в основном генерируете изображения 4K, выбирайте **тарификацию за запрос** (одна и та же цена независимо от разрешения). При смешанном использовании разрешений **тарификация на основе token** позволяет больше экономить на более низких разрешениях.
</Tip>

## Изменение счёта — это не изменение цены

Два счёта за одну и ту же модель могут существенно различаться без какого-либо изменения цен: при **тарификации на основе token** стоимость отдельного запроса варьируется в зависимости от ваших параметров. Два основных измеренных фактора:

| Параметр | Влияние на счёт за один запрос | Применимо к |
| - | - | - |
| Выходное разрешение | от 1K до 4K: около **+90%** (\$0.033 → \$0.064, измерено на Nano Banana 2; для Pro при тарификации на основе token от 1-2K до 4K — около +47%) | Только тарификация на основе token; 2 Lite и первое поколение выводят 1K, поэтому к ним это неприменимо |
| `thinkingLevel` | от уровня по умолчанию до `high`: около **+54%** | Только Nano Banana 2 / 2 Lite; Pro рассуждает всегда, и это нельзя настроить |

Если запрос к одной и той же модели вчера стоил около \$0.033, а сегодня — около \$0.052, обычно это означает использование других параметров, а не изменение цен.

<Info>
  Замеры по уровням (tokens, стоимость, задержка) приведены в разделах [Генерация/редактирование изображений Nano Banana 2](/ru/api-capabilities/nano-banana-2-image/overview) и [Описание полей использования и вывода](/ru/api-capabilities/nano-banana-usage-metadata).
</Info>

**Выбирайте тарификацию за запрос, если вам нужна предсказуемая стоимость**: единая цена от 1K до 4K (Pro — \$0.09 за изображение, Nano Banana 2 — \$0.055) независимо от разрешения и количества tokens.
