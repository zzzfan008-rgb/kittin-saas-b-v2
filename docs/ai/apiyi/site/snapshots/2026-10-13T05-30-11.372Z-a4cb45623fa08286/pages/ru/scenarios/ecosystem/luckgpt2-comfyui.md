# Luck GPT-Image 2 — узлы ComfyUI

> Набор узлов ComfyUI от сообщества: три узла изображений, охватывающие официальный gpt-image-2 / gpt-image-2.5-flare / gpt-image-2.5-sunburst, а также обратные gpt-image-2-all / gpt-image-2-vip, и три узла управления промптами. С 2026-09-10 поддерживается GPT-Image 2.5 с шестью уровнями качества, 16 референсными изображениями, дорисовкой по маске и пользовательскими разрешениями.

## Обзор

`Comfyui-Luck-gpt2.0` — это набор пользовательских узлов ComfyUI, созданный участником сообщества luckdvr. Он напрямую вызывает модели изображений GPT APIYI внутри ComfyUI. В наборе сейчас доступны **три узла изображений** и **три узла управления промптами**:

* **`Comfyui-Luck gpt-image-2`** (официальный): в выпадающем списке моделей доступны `gpt-image-2` / `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst`, отправляет реальные `size` / `quality`, поддерживает заливку маски и до 16 эталонных изображений
* **`Comfyui-Luck gpt-2.0 all`** (обратный): вызывает `gpt-image-2-all`, тарификация за каждый вызов, высокая скорость, диалоговое редактирование
* **`Comfyui-Luck gpt-image-2-vip`** (обратный): вызывает `gpt-image-2-vip`, тарификация за каждый вызов, маршрут Adobe
* **Узлы управления промптами**: `GPT-Image-2 文生图提示词控制器` (контроллер промпта для преобразования текста в изображение) / `图生图提示词控制器` (контроллер промпта для преобразования изображения в изображение) / `文本停留编辑器` (редактор паузы текста). Они используют мультимодальную модель, чтобы преобразовать ваше краткое описание в структурированный промпт для изображения, и могут приостановить рабочий процесс для ручного редактирования

<Info>
  **Обновление от 2026-09-10: поддерживается GPT-Image 2.5.** В официальный узел добавлены `gpt-image-2.5-flare` (приоритет скорости) и `gpt-image-2.5-sunburst` (приоритет качества и точности редактирования), а `quality` расширен до шести уровней (новые `xhigh` / `max`). Названия узлов, идентификаторы, порядок виджетов и модель по умолчанию `gpt-image-2` не изменились, поэтому **существующие рабочие процессы не переключатся на другую модель или качество автоматически**. После обновления плагина выберите модель в раскрывающемся списке `model (模型)`. См. раздел «Использование GPT-Image 2.5 в узле» ниже.
</Info>

## Использование GPT-Image 2.5 в узле

Обновите плагин, полностью перезапустите ComfyUI, затем переключите раскрывающийся список `model (模型)` в `Comfyui-Luck gpt-image-2`. Все остальные виджеты остаются без изменений. Обе модели 2.5 поддерживают преобразование текста в изображение, редактирование изображений, 16 эталонных изображений и маску; узел выбирает эндпоинт генерации или редактирования на основе `mode` и наличия подключённых эталонных изображений.

| Модель | Значения `quality` | Позиционирование |
| - | - | - |
| `gpt-image-2` | `auto` / `low` / `medium` / `high` | Предыдущее поколение, значение по умолчанию для узла |
| `gpt-image-2.5-flare` (включая датированный снимок) | `auto` / `low` / `medium` / `high` / `xhigh` / `max` | В первую очередь скорость; выбор по умолчанию для преобразования текста в изображение |
| `gpt-image-2.5-sunburst` (включая датированный снимок) | `auto` / `low` / `medium` / `high` / `xhigh` / `max` | В первую очередь качество и точность редактирования; выбор для редактирования и объединения нескольких изображений |

<Warning>
  **Не переносите `quality` без изменений при переходе с `gpt-image-2` на 2.5.** Согласно измерениям APIYI выходных token при одинаковом размере, выполненным 2026-09-09, значение `high` в версии 2.5 соответствует старому `medium`, а старому `high` соответствует только значение `max` в версии 2.5. Это соответствие бюджета token, а не гарантия качества на уровне сопоставления пиксель к пикселю. Чтобы сопоставить бюджет `high` старой версии в 2.5, выберите `max`; при том же бюджете `high` / `xhigh` в версии 2.5 дают два более дешёвых промежуточных уровня.
</Warning>

Перед созданием рабочего процесса стоит учитывать следующие особенности поведения на уровне узла:

* **Без незаметного понижения уровня**: выбор `xhigh` / `max` в старой версии `gpt-image-2` или недействительной модели / настройки качества приводит к ошибке узла до отправки запроса. Узел никогда не заменяет уровень автоматически
* **Используйте `auto` экономно**: `auto` — это динамический уровень рассуждения, поэтому стоимость и задержка для одного и того же промпта меняются между уровнями. Чтобы контролировать расходы, выбирайте уровень явно
* **Фиксируйте датированные снимки в рабочей среде**: `gpt-image-2.5-flare-2026-09-08` / `gpt-image-2.5-sunburst-2026-09-08` в раскрывающемся списке фиксируют версию модели, поэтому изменение псевдонима upstream не повлияет на вас
* **Сохраняйте тайм-аут 600 секунд**: для `xhigh` / `max` версии 2.5, разрешений 2K / 4K или сложного редактирования оставьте значение по умолчанию или увеличьте его. Синхронный запрос всё ещё может тарифицироваться после истечения тайм-аута на стороне клиента, а автоматические повторы могут увеличить стоимость; установите `retry_times` в `1`, если повторы не нужны

## Параметры узла

### `Comfyui-Luck gpt-image-2` (официальный)

Метки виджетов на панели имеют китайский суффикс, например `api_key (API密钥)`; в таблицах ниже приведены только английские имена полей.

| Параметр | Тип | Обязательный | По умолчанию | Описание |
| - | - | - | - | - |
| `api_key` | string | Да | - | token APIYI. Рекомендуется использовать отдельный ключ с ограничением использования |
| `prompt` | string | Да | - | Инструкция по генерации или редактированию |
| `mode` | enum | Да | `AUTO` | `AUTO` / `text2img` / `img2img`; `AUTO` определяется на основе наличия подключённых референсных изображений |
| `model` | enum | Да | `gpt-image-2` | `gpt-image-2` / `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst` / `gpt-image-2.5-flare-2026-09-08` / `gpt-image-2.5-sunburst-2026-09-08` |
| `api_base` | enum | Да | `api.apiyi.com/v1` | Домен API, см. шаг 4 раздела «Установка» |
| `image_size` | enum | Да | `2K` | `auto (不传size)` / `1K` / `2K` / `4K` / `custom (自定义)` |
| `aspect_ratio` | enum | Да | `16:9` | 20 вариантов: AUTO, 1:4, 4:1, 1:8, 8:1, 1:1, 1:2, 2:1, 1:3, 3:1, 2:3, 3:2, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 9:21, 21:9 |
| `custom_size` | string | Нет | `1600x1200` | Используется только если `image_size` имеет значение `custom`, формат `WxH` |
| `quality` | enum | Да | `auto` | `auto` / `low` / `medium` / `high` / `xhigh` / `max`; последние два доступны только в версии 2.5 |
| `output_format` | enum | Да | `png` | `png` / `jpeg` / `webp` |
| `output_compression` | int | Да | 85 | 0–100, применяется только к jpeg / webp |
| `seed` | int | Да | 0 | Локальное управление ComfyUI (принудительно запускает повторное выполнение); **никогда не отправляется в API** |
| `timeout_seconds` | int | Да | 600 | Тайм-аут чтения, диапазон 60–1800; тайм-аут подключения фиксирован и составляет 30 с |
| `retry_times` | int | Да | 3 | Диапазон 1–10; `408` / `429` / `5xx` повторяются автоматически |
| `image_01` … `image_16` | ИЗОБРАЖЕНИЕ | Нет | - | Референсные изображения, не более 16 |
| `mask` | МАСКА | Нет | - | Маска для заливки, должна использоваться вместе с `image_01`; область, в которой значение маски ComfyUI равно 1, перерисовывается |

Для `custom_size` действуют четыре ограничения: ни один размер не должен превышать 3840 пикселей, ширина и высота должны быть кратны 16, соотношение длинной и короткой сторон должно быть не более 3:1, а общее количество пикселей должно находиться в диапазоне от 655,360 до 8,294,400. Соотношения `1:4` / `4:1` / `1:8` / `8:1` превышают официальный предел 3:1, поэтому узел округляет их до ближайшего допустимого размера границы; для `4K + 1:1` используется `2880x2880`, а не `3840x3840`, поскольку последний превышает ограничение на общее количество пикселей.

<Note>
  Узел не отправляет `background` / `moderation` / `response_format` / `input_fidelity`; для всех них используются значения API по умолчанию. Для прозрачного фона и аналогичных параметров вызывайте API напрямую; см. [часто задаваемые вопросы о прозрачном фоне](/ru/faq/image-transparent-background).
</Note>

### `Comfyui-Luck gpt-2.0 all` (обратный)

| Параметр | Тип | Обязательно | По умолчанию | Описание |
| - | - | - | - | - |
| `api_key` | string | Да | - | token APIYI |
| `prompt` | string | Да | - | Инструкция для диалоговой генерации / редактирования |
| `mode` | enum | Да | `AUTO` | `AUTO` / `text2img` / `img2img` |
| `model` | enum | Да | `gpt-image-2-all` | Один фиксированный вариант |
| `api_base` | enum | Да | `api.apiyi.com/v1` | Домен API |
| `endpoint` | enum | Да | `images_api` | `images_api` (`/v1/images/generations` или `/v1/images/edits`) / `chat_completions` (диалоговые или эталонные изображения по онлайн-URL) |
| `aspect_ratio` | enum | Да | `AUTO` | 22 варианта (добавляет `2:5` / `5:2` по сравнению с официальным узлом). **Добавляется к prompt только как текст**, а не используется для жёсткого управления размером |
| `response_format` | enum | Да | `url` | `url` / `b64_json`, отправляется только на эндпоинт `images_api` |
| `seed` | int | Да | 0 | Только локальное управление, никогда не отправляется |
| `timeout_seconds` | int | Да | 300 | Диапазон 30–1200 |
| `retry_times` | int | Да | 3 | Диапазон 1–10 |
| `image_01` … `image_14` | IMAGE | Нет | - | Эталонные изображения, до 14 |

`gpt-image-2-all` не принимает поля API `size` / `quality` / `n` / `aspect_ratio`, и узел никогда их не отправляет; 2K / 4K можно указать только в prompt, без гарантии количества пикселей. Выходные данные `url` обычно представляют собой временную ссылку CDN, действительную около суток, поэтому при необходимости длительного хранения разместите её на другом хостинге.

### `Comfyui-Luck gpt-image-2-vip` (обратный)

Те же виджеты, что и у `gpt-2.0 all`, плюс два элемента управления размером:

| Параметр | Тип | Обязательный | Значение по умолчанию | Описание |
| - | - | - | - | - |
| `model` | enum | Да | `gpt-image-2-vip` | Единственный фиксированный вариант |
| `image_size` | enum | Да | `2K Recommended` | `1K Fast` / `2K Recommended` / `4K Detail`; **в настоящее время это подсказка интерфейса, сохранённая для старых рабочих процессов; узел не отправляет `size`** |
| `aspect_ratio` | enum | Да | `16:9` | 10 вариантов: 1:1, 2:3, 3:2, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9; используется только как резервный префикс промпта |
| остальные | - | - | - | `api_key` / `prompt` / `mode` / `api_base` / `endpoint` / `response_format` / `seed` / `timeout_seconds` (300) / `retry_times` (3) / `image_01` … `image_14`, то же, что и в `gpt-2.0 all` |

<Note>
  Автор создал этот узел на основе уведомления APIYI от 2026-06-23 о том, что `size` был отключён, поэтому по умолчанию он не отправляет `size`. На стороне APIYI `size` для `gpt-image-2-vip` была восстановлена 2026-07-22 (30 распространённых размеров; см. [документацию по gpt-image-2-vip](/ru/api-capabilities/gpt-image-2-vip/overview)); плагин ещё не обновлён. Чтобы сегодня задавать реальные размеры выходных данных внутри ComfyUI, используйте официальный узел `Comfyui-Luck gpt-image-2`. Обратный `b64_json` содержит префикс `data:image/png;base64,`, который узел декодирует автоматически.
</Note>

| - | - | - |
| `GPT-Image-2 文生图提示词控制器` | `gemini-3.5-flash` | Преобразует текстовое описание в структурированный промпт для изображений, подходящий для линейки GPT-Image |
| `图生图提示词控制器` | `gemini-3.5-flash` | Обрабатывает до 5 референсных изображений (требуется `reference_image_01`, `02`–`05` — необязательные), а также необязательный `subject_image` и формирует промпт с ограничениями по стилю, композиции и макету |
| `文本停留编辑器` | - | Приостанавливает рабочий процесс на этом этапе; отредактируйте текст, затем нажмите `Continue` на узле, чтобы продолжить |

* Оба контроллера вызывают APIYI `POST /v1/chat/completions`; в выпадающем списке моделей доступны `gemini-3.5-flash` / `gpt-5.5` / `gpt-4o` / `gpt-4.1-mini` / `gemini-2.5-flash` / `gemini-2.5-pro`
* Контроллер преобразования изображения в изображение выполняет только анализ изображений и улучшение промпта. Для полноценного использования нескольких референсных изображений или их объединения подключите те же изображения также к последующему узлу изображений
* Редактор паузы выводит в `edited_text` одну строку для `prompt` узла изображений; `edited_texts` — это список, предназначенный для пакетных рабочих процессов с текстом. После паузы **нажмите `Continue` на узле**. Не нажимайте основную кнопку «Запуск» ещё раз, иначе ComfyUI повторно поставит рабочий процесс в очередь и заново выполнит предшествующее улучшение промпта

    * `example_workflow_gpt_image_2_5.json`: отдельный пример для 2.5, Flare: текст в изображение → редактирование Sunburst → предпросмотр, со значениями по умолчанию для `1K + 1:1`, `quality=high`, таймаутом 600 секунд и `retry_times=1`

    Ключи API в примерах не указаны; введите свой ключ для запуска. Удалите ключ перед тем, как делиться своим рабочим процессом.
  </Step>

## Примеры использования

### Пример 1: Flare 2.5 4K — высококачественная генерация изображений из текста

```
Node: Comfyui-Luck gpt-image-2
model: gpt-image-2.5-flare
prompt: "Cinematic portrait of a samurai in a misty bamboo forest, volumetric light, 85mm lens, photorealistic"
image_size: 4K
aspect_ratio: 2:3
quality: max
output_format: png
```

`max` — это уровень 2.5 с тем же бюджетом token, что и у старого `gpt-image-2` `high`; сначала попробуйте `high` или `xhigh`, если вам нужны более высокая скорость и меньшая стоимость.

### Пример 2: Рисование по маске Sunburst 2.5

```
Node: Comfyui-Luck gpt-image-2
model: gpt-image-2.5-sunburst
mode: img2img
image_01: original photo
mask: the area to replace
prompt: "replace the sky with dramatic sunset clouds, keep everything else intact"
image_size: 2K
quality: high
```

### Пример 3: Цепочка Flare: текст → редактирование Sunburst

Соответствует `example_workflow_gpt_image_2_5.json` в репозитории:

```
[Comfyui-Luck gpt-image-2 · gpt-image-2.5-flare]
  prompt: "product shot of a matte black ceramic mug on a walnut table, soft window light"
  image_size: 1K · aspect_ratio: 1:1 · quality: high
  image ─────────────────────────────┐
                                      ▼
[Comfyui-Luck gpt-image-2 · gpt-image-2.5-sunburst]
  mode: img2img · image_01: ← output of the node above
  prompt: "add a thin gold rim to the mug, keep lighting and background unchanged"
  quality: high
  image ──▶ PreviewImage
```

### Пример 4: Обратное диалоговое изображение

```
Node: Comfyui-Luck gpt-2.0 all
endpoint: images_api
aspect_ratio: 9:16
prompt: "A girl in hanfu standing under a cherry blossom tree, watercolor style, soft lighting"
response_format: url
timeout_seconds: 300
retry_times: 3
```

### Пример 5: Контроллер prompt → приостановка и редактирование → генерация

```
5 reference images
  ├─ into 图生图提示词控制器 reference_image_01 ~ reference_image_05
  └─ also into Comfyui-Luck gpt-image-2 image_01 ~ image_05

图生图提示词控制器 optimized_prompt
  └─ into 文本停留编辑器 text_list

文本停留编辑器 edited_text
  └─ into Comfyui-Luck gpt-image-2 prompt (model: gpt-image-2.5-sunburst)
```

Поставьте запуск в очередь на финальном `PreviewImage` / `SaveImage`. Когда поток остановится в редакторе паузы, измените текст и нажмите `Continue` на узле. Если одно из изображений представляет собой объект, который необходимо зафиксировать, также подключите его к `subject_image` контроллера и разместите на `image_01` узла изображения.

## Часто задаваемые вопросы

<AccordionGroup>
  <Accordion title="Какой из трех узлов для изображений выбрать?">
    * **`Comfyui-Luck gpt-image-2` (официальный)**: настоящие `size` / `quality`, нативная маска, до 16 референсов, тарификация за token. Выбирайте его, когда требуются точные размеры, локальное редактирование или шесть уровней качества 2.5; по умолчанию используйте `gpt-image-2.5-flare` для text-to-image и `gpt-image-2.5-sunburst` для редактирования
    * **`Comfyui-Luck gpt-2.0 all` (reverse)**: тарификация за вызов (\$0.025 за изображение), около 30–60 с, веб-маршрут ChatGPT. Выбирайте его для итеративного редактирования и качественного рендеринга текста, когда строгий контроль размеров не требуется
    * **`Comfyui-Luck gpt-image-2-vip` (reverse)**: тарификация за вызов (\$0.03 за изображение), около 90–150 с, маршрут Adobe. Второй reverse-маршрут, который стоит держать под рукой; в настоящее время плагин не отправляет `size`
    * Полное сравнение: [официальный против reverse](/ru/api-capabilities/gpt-image-2/vs-gpt-image-2-all)
  </Accordion>

  <Accordion title="Переключатся ли существующие рабочие процессы на 2.5 после обновления плагина?">
    Нет. Названия узлов, идентификаторы, порядок виджетов и модель по умолчанию `gpt-image-2` не изменились, поэтому старый рабочий процесс продолжит выполнять `gpt-image-2` с исходным качеством. Чтобы перейти на 2.5, вручную переключите выпадающий список `model (模型)` и выберите заново `quality`, сверяясь с таблицей выше.
  </Accordion>

  <Accordion title="Почему после переключения на 2.5 с тем же значением high результат дешевле и более размытый?">
    В версии 2.5 была изменена сетка уровней качества. По замерам APIYI для одинаковых размеров от 2026-09-09, 2.5 `high` выдает примерно четверть от объема tokens модели `gpt-image-2` `high`, что соответствует прежнему уровню `medium`; чтобы получить бюджет старого `high` на 2.5, выберите `max`. И наоборот, при том же бюджете в 2.5 добавлены `high` / `xhigh` в качестве двух более дешевых промежуточных уровней. Протестируйте свои prompt по одному разу на каждый уровень и сравните `usage.output_tokens` перед запуском в продакшн.
  </Accordion>

  <Accordion title="Поддерживает ли плагин gpt-image-2.5-all / gpt-image-2.5-vip?">
    В двух reverse-узлах в настоящее время доступны только `gpt-image-2-all` и `gpt-image-2-vip`. Веб-приложение ChatGPT, на котором работает `gpt-image-2-all`, было обновлено до Images 2.5, поэтому эта модель уже генерирует изображения 2.5, ведет себя так же и стоит столько же, сколько `gpt-image-2.5-all`; см. [документацию gpt-image-2.5-all](/ru/api-capabilities/gpt-image-2-all/overview). Модели `gpt-image-2.5-flare-vip` / `gpt-image-2.5-sunburst-vip` пока отсутствуют в выпадающем списке узла; при необходимости вызывайте API напрямую.
  </Accordion>

  <Accordion title="Узел не найден после установки?">
    1. Убедитесь, что папка находится по пути `ComfyUI/custom_nodes/Comfyui-Luck-gpt2.0`
    2. Команда `pip install -r requirements.txt` выполнена без ошибок
    3. Полностью перезапустите ComfyUI (простого обновления интерфейса в браузере недостаточно)
  </Accordion>

  <Accordion title="Частые тайм-ауты при 4K, xhigh / max или произвольных размерах?">
    * В официальном узле по умолчанию установлен тайм-аут чтения 600 секунд; сохраните или увеличьте его для 2.5 `xhigh` / `max` и 2K / 4K. Ошибка `408 Timeout` обычно означает, что истек тайм-аут задачи генерации на стороне провайдера, а не неверный параметр узла
    * Синхронный запрос может быть тарифицирован даже после истечения тайм-аута у клиента, а автоматические повторные попытки приводят к лишним расходам; установите `retry_times` на `1`, чтобы отключить повторы
    * Если сетевое соединение вашего сервера медленное, см. [Медленная загрузка изображений/видео через CDN](/ru/faq/cdn-download-slow)
    * Переключите `api_base` на `b.apiyi.com/v1`, если домен по умолчанию работает нестабильно
  </Accordion>

  <Accordion title="При загрузке старого рабочего процесса возникает ошибка Value 3 smaller than min of 30?">
    Порядок виджетов в старом рабочем процессе больше не соответствует узлу, поэтому `retry_times=3` было считано как `timeout_seconds=3`. Используйте актуальный `example_workflow.json` из репозитория либо удалите и добавьте узел заново.
  </Accordion>

  <Accordion title="После подключения редактора пауз gpt-image-2 выдает Value not in list?">
    Преобразование `prompt` во входной сокет оставляет старый рабочий процесс без одного плейсхолдера prompt, из-за чего виджеты после него сдвигаются на один шаг (например, `mode` считывает `gpt-image-2`, `api_base` считывает `2K`). Актуальный узел проходит валидацию и восстанавливает смещенные значения во время выполнения; если на панели они по-прежнему отображаются со сдвигом, перезагрузите текущий рабочий процесс или добавьте `Comfyui-Luck gpt-image-2` заново.
  </Accordion>

  <Accordion title="b64_json из reverse-узлов возвращается с префиксом?">
    Reverse `gpt-image-2-all` / `gpt-image-2-vip` возвращают `b64_json` с префиксом `data:image/png;base64,`, тогда как официальная линейка `gpt-image-2` — без него. Все три узла автоматически декодируют оба формата, поэтому подключайте вывод напрямую к `PreviewImage`. Подробности см. в [сравнении официального и reverse-вариантов](/ru/api-capabilities/gpt-image-2/vs-gpt-image-2-all).
  </Accordion>

  <Accordion title="Вызовы возвращают 401 / 403?">
    1. Проверьте валидность `api_key` и наличие ограничений по группе
    2. Убедитесь, что выбранная модель добавлена в белый список для token
    3. Вопросы по балансу: см. раздел [Баланса кажется достаточно, но вызовы завершаются ошибкой](/ru/faq/balance-insufficient)
  </Accordion>
</AccordionGroup>
