# Предыдущие версии Seedream

> Сравнение характеристик Seedream 5.0 Flash / 5.0 Pro / 5.0 / 4.5 / 4.0, различия в тарификации и руководство по миграции. Каждая версия остается доступной для вызова — выбирайте под свои задачи.

<Note>
  На этой странице перечислены все версии Seedream, **по-прежнему доступные для вызова** на APIYI. Все версии активны одновременно и обладают **во многом совместимыми параметрами** — в большинстве случаев для переключения достаточно изменить только поле `model` (5.0 Flash и 5.0 Pro не поддерживают последовательную генерацию или потоковую передачу; см. матрицу совместимости ниже). Информацию о последней версии и общее описание см. в [Обзор Seedream](/ru/api-capabilities/seedream-image/overview).
</Note>

## Спецификации по версиям

### `seedream-5-0-flash-260915` (5.0 Flash)

* **Дата релиза**: 2026-09-15 (UTC+8); доступно на APIYI с 2026-09-24
* **Цена на APIYI**: **\$0.018 / запрос** (фиксированная цена за запрос, 1 изображение на запрос), что соответствует официальным ценам BytePlus. **Референсные изображения бесплатны** (1, 3 и 10 референсных изображений в наших тестах тарифицировались по \$0.018 каждое), а неудачные запросы, например из-за ошибок в параметрах, не тарифицируются. С учетом бонусов за пополнение фактическая цена примерно на **9%–17% ниже** официального тарифа
* **Уровни разрешения**: пресеты `1K` / `1.5K` / `2K` (**без 3K/4K**; их передача возвращает 400). Если опустить `size`, по умолчанию используется 2K. При использовании пресетов **модель подбирает соотношение сторон на основе контента** (в наших тестах 2K выдавало портреты 1776×2368 и 1664×2496); передавайте точные пиксели, если вам нужно фиксированное соотношение
* **Точный диапазон пикселей**: от 921 600 до 4 624 220 пикселей суммарно (примерно 0,92M–4,62M), соотношение длинной стороны к короткой до 16:1; значения вне диапазона возвращают 400 с указанием допустимого диапазона в сообщении об ошибке (`2688x1712` и `4096x256` работают)
* **Форматы вывода**: `png` / `jpeg`
* **Скорость**: 11–20 с для text-to-image; около 16 с для редактирования с референсными изображениями, около 28 с с 10 референсными изображениями
* **Основные возможности**:
  * Позиционируется BytePlus как быстрое, оптимизированное под верстку и недорогое решение: лучшее разнообразие шрифтов, композиция и яркость цветов по сравнению с 5.0 Pro в задачах верстки, с меньшим серым или желтым оттенком
  * **Точный рендеринг текста**: плакат из трех строк на китайском языке и заголовок на английском / японском / корейском языках в наших тестах отрендерились корректно
  * **Разделение на слои (прозрачные слои)**: `layer_decomposition: true` разделяет изображение на фоновую основу и отдельные элементы на слоях с альфа-каналом, что полезно для изменения макета и повторного использования ассетов
  * **Интерактивное редактирование**: редактирование по положению (например, «добавить значок NEW в правый верхний угол») без изменения остальной части изображения
  * Объединение нескольких изображений с использованием **до 10** референсных изображений (11-е возвращает 400)
* **Известные ограничения**:
  * **Отсутствие `sequential_image_generation` / `stream`**: как и в случае с 5.0 Pro, любое значение (включая `"disabled"`) возвращает 400, поэтому не отправляйте их
  * `n` молча игнорируется; вы получаете и оплачиваете 1 изображение
  * **По умолчанию добавляет водяной знак «AI generated»**; для коммерческого использования явно передавайте `watermark: false`
  * **Для прозрачности требуется разделение на слои, а не указание в prompt**: запрос прозрачного фона в prompt возвращает png без альфа-канала (шахматная сетка врисована в изображение). Для прозрачных ассетов используйте `layer_decomposition: true` с одним референсным изображением; это возвращает заполненную фоновую основу плюс несколько RGBA-слоев (12 изображений примерно за 78 с при 1K в наших тестах). **Разделение на слои тарифицируется за каждое выходное изображение**: 12 изображений стоят \$0.216. Запрос разделения слоев в 2K ничего не вернул спустя 15 минут, **но все равно был тарифицирован на \$0.216**, поэтому всегда используйте `1K`. См. [Редактирование изображений](/ru/api-capabilities/seedream-image/image-edit)
  * Для фотореалистичных портретов и мелкой детализации материалов BytePlus по-прежнему рекомендует 5.0 Pro

### `seedream-5-0-pro-260628` (5.0 Pro)

* **Дата релиза**: 2026-06-28 (UTC+8); доступно на APIYI с 2026-07-19
* **Цена на APIYI**: **\$0.12 / запрос** (фиксированная цена за запрос, 1 изображение на запрос, ≈ ¥0.84 по прейскуранту). Официально модель использует два тарифных уровня по количеству выходных пикселей (≤2.36M / >2.36M) плюс плату за референсные изображения сверх первого; APIYI упрощает это до единой фиксированной цены за запрос со включенной стоимостью входных изображений
* **Уровни разрешения**: пресеты `1K` / `2K` (**без пресетов 3K/4K**) плюс точные пиксели `WxH` в сумме до **4.19M** (макс. 2048×2048; при 16:9 длинная сторона достигает `2720x1530` ≈ 2.7K, проверено)
* **Формат вывода**: `png` / `jpeg`
* **Оптимизация prompt**: стандартная / быстрая
* **Особенности**:
  * Лучшее в семействе качество изображений и следование инструкциям; интерактивное редактирование (указание областей редактирования с помощью координат, рамок выделения, стрелок)
  * Слияние нескольких изображений официально поддерживает **до 10 референсных изображений**
* **Известные ограничения**:
  * **`sequential_image_generation` / `stream` не принимаются** — любое значение (включая `"disabled"`) возвращает 400; полностью исключите оба параметра
  * Медленная генерация: стабильно **\~2 минуты** на изображение (110–130 с по результатам замеров) — установите таймаут клиента ≥ 240 с
  * Цена за единицу в 3,4 раза выше, чем у 5.0-lite; используйте 5.0-lite для повседневных задач

### `seedream-5-0-260128` (5.0-lite)

* **Дата релиза**: 2026-01-28 (UTC+8)
* **Цена APIYI**: \$0.035 / изображение (≈ ¥0.245 по прайс-листу)
* **Уровни разрешения**: `2K` / `3K` (**без 4K**)
* **Формат вывода**: `png` / `jpeg` (единственная версия с выводом png)
* **Оптимизация prompt**: стандартная
* **Ключевые особенности**:
  * Лучший опыт в целом; наиболее зрелая реализация объединения нескольких изображений / редактирования / пакетных последовательностей
  * Единственная версия с поддержкой вывода `png` (и, следовательно, прозрачного фона)
  * Зрелая потоковая передача вывода (`stream: true`)
* **Известные ограничения**:
  * Разрешение ограничено 3K (\~3072×3072). Для материалов в 4K используйте 4.5 / 4.0
* **Официальная документация**: `docs.byteplus.com/en/docs/ModelArk/1824121`

### `seedream-4-5-251128`

* **Дата релиза**: 2025-11-28 (UTC+8)
* **Цена APIYI**: \$0.04 / изображение (≈ ¥0.28 по прайс-листу)
* **Уровни разрешения**: `2K` / `4K`
* **Формат вывода**: `jpeg`
* **Оптимизация prompt**: стандартная
* **Ключевые особенности**:
  * Единая архитектура генерации и редактирования на 1,2 млрд параметров
  * **Прорыв в рендеринге текста**: мелкий текст остается четким — лучший в своем классе для постеров, рекламы и скриншотов интерфейса
  * Объединение нескольких изображений напрямую поддерживает до 10 референсных изображений
  * Редактирование сохраняет освещение, тон и естественную детализацию лиц
* **Известные ограничения**:
  * Вывод только в `jpeg` (без `png`, без прозрачности)
* **Новостная статья**: [Запуск Seedream 4.5](/en/news/seedream-4-5-launch)

### `seedream-4-0-250828`

* **Дата релиза**: 2025-08-28 (UTC+8)
* **Цена APIYI**: \$0.03 / изображение (≈ ¥0.21 по каталогу)
* **Уровни разрешения**: `1K` / `2K` / `4K` (наиболее широкий охват)
* **Формат вывода**: `jpeg`
* **Оптимизация prompt**: стандартная / **быстрая**
* **Ключевые особенности**:
  * Проверенная на практике стабильная версия
  * Высокая визуальная согласованность, сбалансированная детализация в 4K
  * **Единственная версия с поддержкой быстрого режима prompt** — более быстрая генерация для чувствительных к затратам сценариев
* **Известные ограничения**:
  * Рендеринг текста слабее, чем в 4.5
  * Только вывод `jpeg`

## Руководство по миграции

<Steps>
  <Step title="Оцените различия">
    Версии **во многом совместимы на уровне параметров** — в большинстве случаев для переключения достаточно изменить только поле `model`. Перепроверьте:

    * Поддерживается ли ваш уровень `size` новой версией (5.0 Flash и 5.0 Pro ограничены примерно 2K; в 5.0 нет 1K / 4K; в 4.5 нет 1K; в 4.0 есть все)
    * Отправляете ли вы `sequential_image_generation` или `stream` (удалите их при переходе на 5.0 Flash / 5.0 Pro, иначе вы получите ошибку 400)
    * Зависите ли вы от `output_format: "png"` (только в 5.0)
    * Используете ли вы `prompt_optimization: "fast"` (только в 4.0)
  </Step>

  <Step title="Запустите параллельное тестирование">
    Запустите один и тот же пакет prompt на старой и новой версиях, сравните качество и стоимость. Проверьте результат на небольшом пакете (10–20 изображений) перед масштабированием.
  </Step>

  <Step title="Внедряйте постепенно">
    Переключайте трафик поэтапно (10% / 50% / 100%). На каждом этапе отслеживайте качество, частоту сбоев и стоимость перед дальнейшим масштабированием.
  </Step>

  <Step title="Сохраняйте возможность отката">
    Сохраняйте конфигурации `model` для старой и новой версий в продакшен-коде. Если новая версия работает некорректно, мгновенно переключитесь обратно. Каждая версия тарифицируется по собственной цене за единицу — параллельный запуск не влечет дополнительных затрат.
  </Step>
</Steps>

## Пример устаревшего вызова

```python theme={null}
{/* Switching versions only changes the model field; other params are compatible */}
from openai import OpenAI

client = OpenAI(api_key="sk-your-api-key", base_url="https://api.apiyi.com/v1")

resp = client.images.generate(
    model="seedream-4-0-250828",   # change this line to switch to 4.5 / 5.0
    prompt="A serene mountain landscape at golden hour, snow-capped peaks, ultra detailed, 4K",
    size="4K",                      # NOTE: 5.0 does not support 4K — use 2K or 3K
    response_format="url",
    extra_body={
        "watermark": False,
    }
)

print(resp.data[0].url)
```

Оценка на основе типичного объема (**до учета бонусов за пополнение**; с бонусами эффективная цена снижается вплоть до 80%):

| `seedream-5-0-pro-260628` | \$0.12 / запрос | \$12 | \$120 | \$1200 |

<Info>
  **Как выбрать**:

  * 4K-материалы + качественный текст → **4.5**
  * 4K-материалы + лучшая цена → **4.0**
  * Большие объемы / макеты постеров / скорость и экономия → **5.0 Flash** (\$0.018/запрос, \~15–20 с на изображение, примерно до 2K)
  * Лучший универсальный вариант / вывод в png / прозрачный фон → **5.0**
  * Длительное стабильное пакетное производство → **4.0** (проверенная, самая доступная, быстрый режим prompt)
  * Максимальное качество / сложные инструкции для профессиональной работы → **5.0-pro** (\$0.12/запрос + \~2 мин на изображение — пропустите, если нет прямой необходимости)
</Info>
