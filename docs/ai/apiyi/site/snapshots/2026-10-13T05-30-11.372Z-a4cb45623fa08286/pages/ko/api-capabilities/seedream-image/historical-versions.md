# Seedream 역대 버전

> Seedream 5.0 Flash / 5.0 Pro / 5.0 / 4.5 / 4.0 사양 비교, 요금 차이 및 마이그레이션 가이드입니다. 모든 버전을 계속 호출할 수 있으니 필요에 따라 선택하십시오.

<Note>
  이 페이지에는 APIYI에서 **여전히 호출 가능한** 모든 Seedream 버전이 나열되어 있습니다. 모든 버전은 동시에 활성화되어 있으며 **대부분 호환되는 파라미터**를 제공합니다 — 대부분의 경우 `model` 필드만 변경하여 전환할 수 있습니다(5.0 Flash 및 5.0 Pro는 순차 생성 또는 스트리밍을 지원하지 않으므로 아래 호환성 매트릭스를 참조하십시오). 최신 버전 및 전반적인 소개는 [Seedream 개요](/ko/api-capabilities/seedream-image/overview)를 참조하십시오.
</Note>

## 버전별 사양

### `seedream-5-0-flash-260915` (5.0 Flash)

* **출시일**: 2026-09-15 (UTC+8), APIYI에서는 2026-09-24부터 제공됩니다
* **APIYI 가격**: **요청당 \$0.018** (요청당 고정 가격, 요청 1회당 이미지 1장)로 BytePlus 공식 가격과 동일합니다. **참조 이미지는 무료이며** (테스트 결과 참조 이미지 1장, 3장, 10장 모두 각각 \$0.018로 과금됨), 매개변수 오류 등 실패한 요청에는 과금되지 않습니다. 충전 보너스를 적용하면 실질 가격은 공식 요율보다 약 **9%\~17% 저렴합니다**
* **해상도 등급**: 프리셋 `1K` / `1.5K` / `2K` (**3K/4K 미지원**, 전달 시 400 반환). `size` 생략 시 기본값은 2K입니다. 프리셋을 사용할 경우 **모델이 콘텐츠에 맞춰 화면비를 자동으로 선택합니다** (테스트 결과 2K에서 1776×2368 및 1664×2496 인물 사진이 생성됨). 고정 비율이 필요한 경우 정확한 픽셀 값을 전달하십시오
* **정확한 픽셀 범위**: 총 921,600~~4,624,220픽셀 (약 0.92M~~4.62M), 긴 변과 짧은 변의 비율 최대 16:1, 범위를 벗어난 값은 오류 메시지에 유효 범위가 포함된 400을 반환합니다 (`2688x1712` 및 `4096x256` 지원)
* **출력 형식**: `png` / `jpeg`
* **속도**: 텍스트-이미지 생성 시 11\~20초, 참조 이미지를 사용한 편집 시 약 16초, 참조 이미지 10장 사용 시 약 28초 소요됩니다
* **핵심 기능**:
  * BytePlus에서 빠른 속도, 뛰어난 레이아웃 능력, 저렴한 비용을 강점으로 포지셔닝한 모델입니다. 레이아웃 작업 시 5.0 Pro보다 글꼴 다양성, 구도 및 색상 밝기가 우수하며, 회색이나 노란색 색조 왜곡이 적습니다
  * **정확한 텍스트 렌더링**: 테스트 결과 3줄로 구성된 중국어 포스터와 영어/일본어/한국어 제목이 모두 정확하게 렌더링되었습니다
  * **레이어 분리(투명 레이어)**: `layer_decomposition: true`는 이미지를 배경 베이스와 알파 채널 레이어의 개별 요소로 분리하여 레이아웃 재구성 및 에셋 재사용에 유용합니다
  * **대화형 편집**: 이미지의 나머지 부분은 그대로 유지한 채 특정 위치를 지정하여 편집할 수 있습니다(예: “우측 상단에 NEW 배지 추가”)
  * **최대 10장**의 참조 이미지를 활용한 다중 이미지 융합 지원(11번째 이미지는 400 반환)
* **알려진 제한 사항**:
  * **`sequential_image_generation` / `stream` 미지원**: 5.0 Pro와 마찬가지로 어떤 값(`"disabled"` 포함)을 전달해도 400을 반환하므로 전달하지 마십시오
  * `n`는 별도의 알림 없이 무시되며, 1장의 이미지만 생성 및 과금됩니다
  * **기본적으로 “AI generated” 워터마크가 추가됩니다**. 상업적 용도로 사용할 경우 명시적으로 `watermark: false`를 전달하십시오
  * **투명도 처리는 prompt가 아닌 레이어 분리가 필요합니다**: prompt에 투명 배경을 요청하면 알파 채널이 없는 png가 반환됩니다(체커보드 패턴이 이미지에 그려짐). 투명 에셋이 필요한 경우 참조 이미지 1장과 함께 `layer_decomposition: true`를 사용하십시오. 채워진 배경 베이스와 여러 개의 RGBA 레이어가 반환됩니다(테스트 결과 1K에서 약 78초 만에 12장의 이미지가 반환됨). **레이어 분리는 출력 이미지당 과금됩니다**: 12장의 이미지에 \$0.216가 과금됩니다. 2K 해상도로 레이어를 요청했을 때 15분 후에도 아무 결과가 반환되지 않았으나 **여전히 \$0.216가 과금되었으므로**, 항상 `1K`를 사용하십시오. 자세한 내용은 [이미지 편집](/ko/api-capabilities/seedream-image/image-edit)을 참고하십시오
  * 사실적인 인물 사진과 정교한 질감 디테일 작업에는 BytePlus에서 여전히 5.0 Pro 사용을 권장합니다

### `seedream-5-0-pro-260628` (5.0 Pro)

* **출시일**: 2026-06-28 (UTC+8); 2026-07-19부터 APIYI에서 이용 가능합니다
* **APIYI 가격**: **\$0.12 / 요청** (요청당 고정 가격, 요청당 이미지 1개, 정가 약 ¥0.84 상당). 공식적으로 해당 모델은 두 가지 출력 픽셀 가격 등급(≤2.36M / >2.36M) 및 첫 번째 이미지를 초과하는 참조 이미지에 대한 추가 요금을 적용하지만, APIYI에서는 입력 이미지 요금을 포함한 요청당 단일 고정 가격으로 단순화했습니다
* **해상도 등급**: 프리셋 `1K` / `2K` (**3K/4K 프리셋 미지원**) 및 최대 총 **4.19M** 픽셀의 정밀 픽셀 `WxH` (최대 2048×2048, 16:9 비율에서 가장 긴 변 기준 `2720x1530` ≈ 2.7K 지원 검증 완료)
* **출력 형식**: `png` / `jpeg`
* **프롬프트 최적화**: standard / fast
* **주요 특징**:
  * 해당 제품군 중 가장 뛰어난 화질 및 지시 준수 능력, 대화형 편집(좌표, 선택 상자, 화살표를 통한 편집 위치 지정)
  * 다중 이미지 융합 시 공식적으로 **최대 10개의 참조 이미지** 지원
* **알려진 제한 사항**:
  * **`sequential_image_generation` / `stream`는 지원되지 않습니다** — 어떤 값(`"disabled"` 포함)을 전달해도 400이 반환되므로 두 파라미터를 완전히 생략하십시오
  * 느린 생성 속도: 이미지당 일관되게 **약 2분** 소요(실측 110\~130초) — 클라이언트 타임아웃을 240초 이상으로 설정하십시오
  * 5.0-lite 단가의 3.4배이므로 일상적인 작업에는 5.0-lite를 사용하십시오

## 마이그레이션 안내

<Steps>
  <Step title="차이점 검토">
    각 버전은 **파라미터 수준에서 대체로 호환**되므로 대부분의 경우 `model` 필드만 변경하여 전환할 수 있습니다. 다음 사항을 재확인하십시오:

    * 새 버전에서 사용 중인 `size` 티어를 지원하는지 여부 (5.0 Flash 및 5.0 Pro는 최대 약 2K까지 지원하며, 5.0에는 1K / 4K가 없고, 4.5에는 1K가 없으며, 4.0은 모두 지원합니다)
    * `sequential_image_generation` 또는 `stream`을 전송하는지 여부 (5.0 Flash / 5.0 Pro로 전환할 때 이를 제거하지 않으면 400 오류가 발생합니다)
    * `output_format: "png"`에 의존하는지 여부 (5.0 전용)
    * `prompt_optimization: "fast"`를 사용하는지 여부 (4.0 전용)
  </Step>

  <Step title="병행 실행">
    이전 버전과 새 버전에서 동일한 prompt 배치를 실행하여 품질과 비용을 비교하십시오. 본격적으로 확장하기 전에 소규모 배치(10\~20개 이미지)로 먼저 검증하십시오.
  </Step>

  <Step title="점진적 배포">
    트래픽을 단계별(10% / 50% / 100%)로 전환하십시오. 각 단계에서 품질, 실패율, 비용을 관찰한 후 추가로 확장하십시오.
  </Step>

  <Step title="폴백 대책 유지">
    프로덕션 코드에 이전 버전과 새 버전의 `model` 설정을 모두 유지하십시오. 새 버전에 문제가 발생하면 즉시 이전 상태로 되돌릴 수 있습니다. 각 버전은 자체 단가로 과금되므로 두 버전을 동시에 운영하더라도 추가 비용이 발생하지 않습니다.
  </Step>
</Steps>

## 레거시 호출 예시

```python theme={null}
{/* Switching versions only changes the model field; other params are compatible */}
from openai import OpenAI

client = OpenAI(api_key="sk-your-api-key", base_url="https://api.apiyi.com/v1")

resp = client.images.generate(
    model="seedream-4-0-250828",   # change this line to switch to 4.5 / 5.0
    prompt="A serene mountain landscape at golden hour, snow-capped peaks, ultra detailed, 4K",
    size="4K",                      # NOTE: 5.0 does not support 4K — use 2K or 3K
    response_format="url",
    extra_body={
        "watermark": False,
    }
)

print(resp.data[0].url)
```
