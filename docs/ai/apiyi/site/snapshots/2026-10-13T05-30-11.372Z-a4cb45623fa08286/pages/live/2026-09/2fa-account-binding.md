# 账户安全升级：网站新增 2FA，建议尽快绑定

> API易于本周末完成网站系统升级，新增 2FA（双重身份验证）。网站登录、创建 API KEY 等重要操作可能要求输入 2FA 动态验证码。升级后若账号被退出，邮箱或账号加密码登录即可，原 GitHub 一键注册的客户仍走 GitHub 登录。绑定入口在个人中心页面下方的 2FA 区域。

**2026/9/21 00:54 (UTC+8)** · 服务通知

🔐 **本周末完成网站系统升级，新增 2FA（双重身份验证），建议尽快绑定启用**

绑定后，在网站登录、创建 API KEY 等重要操作场景中，系统可能会要求输入 2FA 动态验证码进行安全验证，账号被盗用的风险显著降低。

绑定入口：网站右上角【个人中心】→ 页面下方【2FA】区域，直达 [api.apiyi.com/account/profile](https://api.apiyi.com/account/profile)。验证器 App 用任意兼容 TOTP 的即可：

* Google Authenticator
* Microsoft Authenticator
* 其他兼容 TOTP 的身份验证器

升级过程中部分会话失效，账号可能被退出登录，这是升级的正常现象，不影响 API 调用与账户余额。邮箱或账号注册的客户用邮箱（或账号）加密码重新登录；原 GitHub 一键注册的客户仍然通过 GitHub 登录，不需要另设密码。

如需协助，请通过网站首页的[企业微信客服](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec)联系我们。感谢理解与配合。
