# GPT-6 Sol 与 Luna 已上线，价格比上一代减半

> OpenAI 9 月 22 日发布的 gpt-6-sol 与 gpt-6-luna 已在 API易 上线，default、svip、CodexResponses 分组可用。Sol 输入 2 美元、输出 10 美元，Luna 输入 0.10 美元、输出 0.50 美元每百万 tokens，约为 5.6 代一半且为长期价格，与 Claude Opus 5.5 同日降价。实测 Chat 与 Responses 双端点均可用，含函数调用。

**2026/9/23 14:51 (UTC+8)** · 新模型 · OpenAI

🚀 **`gpt-6-sol` 与 `gpt-6-luna` 已上线，价格比上一代减半**

OpenAI 9/22 补齐 GPT-6 系列的中档和轻量档，官方说明是长期价格、不是限时促销。同一天 Anthropic 也发布了降价的 Claude Opus 5.5，两家同日让利，开发者和用户直接受益。

两款定价（每百万 tokens，四项计费与官网一致）：

* `gpt-6-sol`：输入 \$2 / 输出 \$10 / 缓存读取 \$0.20，上一代 `gpt-5.6-sol` 为 \$4 / \$20
* `gpt-6-luna`：输入 \$0.10 / 输出 \$0.50 / 缓存读取 \$0.01，上一代 `gpt-5.6-luna` 为 \$0.20 / \$1.20

`default` / `svip` / `CodexResponses` 分组可用。我们上线当天实测，`/v1/chat/completions` 与 `/v1/responses` 双端点全部通过，Chat 端点也能带函数工具，从 5.6 迁移只需改模型名。
