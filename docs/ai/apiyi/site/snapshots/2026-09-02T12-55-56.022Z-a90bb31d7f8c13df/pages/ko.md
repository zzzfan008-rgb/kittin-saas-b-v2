# APIYI에 오신 것을 환영합니다

**APIYI**는 엔터프라이즈급의 전문적이고 안정적인 AI 모델 API 허브입니다. 통합된 OpenAI API 표준과 호환되며, 각 벤더의 네이티브 API 형식(Claude, Gemini 등)도 지원하여 400개 이상의 인기 AI 모델을 포괄합니다. 하나의 token으로 OpenAI, Claude, Gemini, DeepSeek, Qwen, Kimi, GLM, Minimax 및 모든 주류 대규모 언어 모델에 손쉽게 접근할 수 있습니다.

## 🏢 회사 배경

* 운영 주체: APIYI, LLC (미국)
* 공식 파트너: Google AI Studio, Microsoft Azure, Amazon AWS (정식 쿼터 출처, 안심하고 사용 가능)
* 서비스 보장:
  * 안정적: OpenAI, Claude, Google Gemini와 같은 주류 모델에 대해 높은 동시 실행 수와 안정적인 서비스를 제공합니다
  * 신뢰할 수 있음:
    * 많은 유명 애플리케이션이 운영 환경에서 안정적으로 통합되어 있습니다(사용 사례 섹션 참조).
    * 저명한 대학, 병원 및 기타 기관과 협력하며, 잘 알려진 기업에 서비스를 제공합니다.
    * 국내 법인은 기업 결제, 청구서 발행, 조달 목록 지원이 가능하여 걱정 없이 비용 정산할 수 있습니다.

## 🚀 APIYI를 선택해야 하는 이유?

### 하나의 인터페이스, 여러 모델

각 AI 서비스마다 별도 계정을 신청하고 API 키를 관리할 필요가 없습니다. APIYI를 사용하면 다음만 필요합니다:

* **하나의 계정**: 모든 AI 서비스를 관리합니다
* **하나의 API 키**: 모든 모델에 액세스합니다
* **하나의 표준**: OpenAI API 형식과 호환됩니다

### 🔧 간단하고 쉬움

모델 전환은 하나의 매개변수만 바꾸면 될 정도로 간단합니다:

```python theme={null}
# Using GPT-4
response = openai.ChatCompletion.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Hello!"}]
)

# Switch to Claude 3
response = openai.ChatCompletion.create(
    model="claude-3-opus-20240229",  # Just change the model name
    messages=[{"role": "user", "content": "Hello!"}]
)
```
