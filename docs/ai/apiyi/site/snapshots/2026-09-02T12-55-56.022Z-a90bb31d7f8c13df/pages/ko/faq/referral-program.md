# 에이전트 파트너십은 어떻게 신청하나요? 친구를 초대하면 리베이트를 받을 수 있나요?

> APIYI는 내장된 추천 리베이트 프로그램을 제공합니다 — 친구를 초대하고 지속적인 5% 크레딧 리베이트를 받으세요. 별도의 에이전트 신청은 필요하지 않습니다.

## 간단 답변

APIYI에는 별도의 「에이전트 파트너십」 신청 채널이 없습니다. 대신 모든 사용자는 내장된 **추천 리베이트** 프로그램을 이용할 수 있습니다. 계정 센터에서 초대 링크 / 초대 코드를 받아 두면, 성공적으로 초대한 친구마다 **지속적인 5% 크레딧 리베이트**를 받게 됩니다.

<Info>
  리베이트는 **플랫폼 내 크레딧**(API 사용 잔액)으로 지급됩니다. **출금할 수는 없으며** — 본인의 API 호출에만 사용할 수 있습니다.
</Info>

## 초대 링크와 초대 코드는 어디에서 찾을 수 있습니까?

<Steps>
  <Step title="계정 센터를 엽니다">
    로그인한 후 [계정 센터 / 프로필](https://api.apiyi.com/account/profile) 페이지로 바로 이동합니다
  </Step>

  <Step title="Locate the &#x22;推广信息 / Referral Info&#x22; section">
    페이지에서 **초대 정보 (Referral Info)** 카드로 스크롤하면 **Invite Code**와 **Invite Link** 버튼이 표시됩니다
  </Step>

  <Step title="초대 링크 / 초대 코드를 복사합니다">
    클릭하여 복사한 다음 친구들과 공유합니다
  </Step>
</Steps>

## 리베이트는 어떻게 지급되고 사용됩니까?

초대받은 사용자가 **충전을 완료할 때마다**, 귀하의 몫이 **Reward (奖励金) 잔액**에 적립됩니다. 그런 다음 **보상을 기본 API 잔액으로 수동 이체**할 수 있으며, 이후 일반 API 호출에 사용할 수 있습니다.

<Info>
  **리베이트 내역을 추적**: **Logs** 페이지에서 \*\*Type = 奖励金划转 (Reward Transfer)\*\*로 필터링하면 각 리베이트 항목과 그 출처 및 금액을 확인할 수 있습니다.
</Info>

  <Card title="리베이트 비율" icon="percent">

    초대한 친구들의 모든 충전과 사용에 대해 지속적인 리베이트를 받습니다
  </Card>

  <Card title="지속 지급" icon="infinity">
    **장기적으로 유효**

    추천 관계가 성립되어 있는 한, 리베이트는 **지속적**입니다 — 일회성 지급이 아닙니다
  </Card>

  <Card title="리베이트 형식" icon="wallet">
    **플랫폼 내 크레딧**

    리베이트는 API 사용 잔액으로 직접 적립되며 — 현금으로 인출할 수는 없습니다
  </Card>

  <Card title="사용 범위" icon="check">
    **모든 모델**

    리베이트 크레딧은 플랫폼의 모든 모델을 호출하는 데 사용할 수 있습니다
  </Card>
</CardGroup>

<Warning>
  **과거 요율 변경**: \*\*2026년 5월 15일 (UTC+8)\*\*부터 추천 리베이트 비율이 \*\*10%\*\*에서 \*\*5%\*\*로 조정되었습니다. 기존 추천 관계에는 영향이 없으며 현재 비율로 정산됩니다.
</Warning>

## 가입 시 초대 링크가 추천 관계를 잃어버리면 어떻게 하나요?

일부 브라우저, 시크릿/인코그니토 모드 또는 리디렉션 흐름에서는 초대 링크의 쿠키/파라미터가 유실될 수 있어 추천 관계가 자동으로 설정되지 않을 수 있습니다. 이 경우 친구가 수동으로 연결할 수 있습니다:

<Steps>
  <Step title="등록 페이지를 여십시오">
    친구가 APIYI 가입 페이지를 방문하도록 하십시오
  </Step>

  <Step title="Fill in the &#x22;Invite Code&#x22; field">
    등록 양식에서 **초대 코드** 필드에 개인 초대 코드를 입력하십시오
  </Step>

  <Step title="등록 완료">
    양식을 제출하십시오 — 추천 관계가 정상적으로 설정됩니다
  </Step>
</Steps>

<Tip>
  **권장 사항**: 초대 링크를 공유할 때는 **초대 코드도 함께 보내** 예비 수단으로 제공하십시오. 링크 파라미터가 유실되더라도 관계를 계속 연결할 수 있습니다. 초대 코드 없이 등록이 완료되면 추천 관계는 **사후에 추가할 수 없습니다**.
</Tip>

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="리베이트 크레딧을 현금으로 출금할 수 있습니까?">
    **아니요.** 리베이트는 **플랫폼 내 API 사용 크레딧**으로 지급되며, 본인 용도로만 사용할 수 있습니다. 은행 계좌, WeChat 또는 Alipay로 출금할 수는 없습니다.
  </Accordion>

  <Accordion title="리베이트는 일회성입니까, 아니면 계속 적용됩니까?">
    **계속 적용됩니다.** 초대 관계가 유지되는 한, 초대받은 사용자의 모든 충전과 사용은 현재 요율 기준으로 계속해서 귀하의 계정에 5% 리베이트를 생성합니다.
  </Accordion>

  <Accordion title="더 일찍 가입한 친구들은 10%로 정산되나요, 5%로 정산되나요?">
    정산은 항상 **현재 규칙**을 따릅니다. **2026년 5월 15일 (UTC+8)** 이후에 적립된 리베이트는 5%로 계산됩니다. 해당 날짜 이전에 이미 지급된 리베이트는 소급 조정되지 않습니다.
  </Accordion>

  <Accordion title="기업 사용자는 더 높은 리베이트율을 받을 수 있습니까?">
    **아니요.** 기업 사용자와 개인 사용자는 모두 일괄적으로 \*\*5%\*\*로 정산되며, 차등 요율이나 맞춤 요율은 제공되지 않습니다.
  </Accordion>

  <Accordion title="리베이트를 챙기기 위해 제 부계정을 초대할 수 있습니까?">
    **자기 초대는 엄격히 금지됩니다.** 플랫폼은 **IP, 기기 지문, 결제 정보**를 포함한 여러 신호를 통해 의심 계정을 식별합니다. 적발될 경우:

    * 플랫폼은 **초대 관계를 일방적으로 취소할 권리**를 보유합니다
    * 이미 지급된 의심 리베이트는 **회수되거나 동결될 수 있습니다**
    * 중대한 경우 계정 리스크 관리 조치가 적용될 수 있습니다

    초대 리베이트 프로그램은 실제 신규 사용자 유치를 보상하기 위해 설계되었습니다. 어떠한 형태의 악용도 시도하지 마십시오.
  </Accordion>

  <Accordion title="내가 초대한 사용자와 리베이트 내역은 어떻게 확인합니까?">
    [계정 센터](https://api.apiyi.com/account/profile)를 열어 초대한 사용자 데이터를 확인하십시오. 거래별 리베이트 항목은 **로그** 페이지로 이동한 뒤 \*\*유형 = 奖励金划转 (Reward Transfer)\*\*로 필터링하십시오.
  </Accordion>
</AccordionGroup>
