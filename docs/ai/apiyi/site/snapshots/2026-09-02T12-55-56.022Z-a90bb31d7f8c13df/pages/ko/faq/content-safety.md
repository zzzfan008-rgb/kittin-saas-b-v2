# 콘텐츠 안전과 규정 준수는 어떻게 보장됩니까?

> APIYI 콘텐츠 안전 및 규정 준수 정책 설명으로, 콘텐츠 검토 메커니즘과 위반 처리 조치를 포함합니다

## 콘텐츠 안전 보장 시스템

APIYI는 안전하고 규정을 준수하는 AI 서비스를 제공하기 위해 최선을 다하며, 콘텐츠 준수를 보장하기 위해 다층 보안 조치를 채택하고 있습니다.

## 콘텐츠 검토 메커니즘

### 전문 검토 시스템

우리는 모든 요청에 대해 실시간 보호를 제공하기 위해 **전문 공식 콘텐츠 검토 API**를 통합했습니다:

<Info>
  **검토 작동 원리**

  * **실시간 감지**: 모든 API 요청은 콘텐츠 검토를 거칩니다
  * **지능형 식별**: 잠재적으로 위반 가능성이 있는 콘텐츠를 자동으로 식별합니다
  * **사전 차단**: 위반 콘텐츠는 사용자에게 반환되지 않습니다
  * **무관용 정책**: 위반 콘텐츠에 대해 엄격한 조치를 적용합니다
</Info>

### 검토 범위

* **입력 콘텐츠 검토**: 사용자가 제출한 모든 텍스트와 이미지를 확인합니다
* **출력 콘텐츠 검토**: AI가 생성한 콘텐츠가 기준을 준수하는지 보장합니다
* **다국어 지원**: 중국어와 영어를 포함한 주요 언어의 검토를 지원합니다
* **멀티모달 감지**: 텍스트와 이미지를 포함한 다양한 콘텐츠 형식을 포괄합니다

## 준수 요구사항

### 사용자 책임

<Warning>
  **법적 준수**

  사용자는 APIYI 서비스를 사용할 때 다음을 포함하되 이에 국한되지 않는 **현지 법률 및 규정을 준수해야 합니다**.

  * 국가 및 지방의 법적 규정
  * 업계 규제 요구사항
  * 국제 법적 규범
  * 플랫폼 이용 약관
</Warning>

### 금지 콘텐츠 유형

다음 유형의 콘텐츠는 엄격히 금지됩니다.

* **불법 콘텐츠**: 불법 행위와 관련된 정보
* **유해 정보**: 피해를 초래할 수 있는 콘텐츠
* **부적절한 콘텐츠**: 사회적 도덕 기준을 위반하는 정보
* **침해 콘텐츠**: 타인의 권리를 침해하는 자료

### 위반 결과

APIYI 플랫폼은 위반에 대해 조치를 취할 권리를 보유합니다:

<Card title="위반 처리 메커니즘" icon="gavel">
  **경미한 위반**

  * 콘텐츠 차단 및 안내
  * 사용 안내 및 경고

  **반복 위반**

  * 계정 사용 제한
  * 기능 권한 하향 조정

  **중대한 위반**

  * 조사와 관련하여 관련 당국과 협조합니다
</Card>

## 정책 문서

### 서비스 약관

사용자는 서비스 약관을 주의 깊게 읽어야 합니다:

* **이용 정책**: 플랫폼 이용 기준을 자세히 설명합니다
* **개인정보 처리방침**: 데이터 처리 및 개인정보 보호 조치를 설명합니다
* **면책 조항**: 플랫폼과 사용자 책임의 경계를 명확히 정의합니다

### 권장 모범 사례

<Tip>
  **안전한 사용 제안**

  1. **콘텐츠 자체 점검**: 전송 전에 콘텐츠의 정책 준수 여부를 자체 점검합니다
  2. **규칙 이해**: 플랫폼 이용 정책과 제한 사항을 숙지합니다
  3. **합리적 사용**: 적법하고 합법적인 사용 목적을 보장합니다
  4. **적시 업데이트**: 정책 업데이트와 조정을 따라갑니다
</Tip>

## 기술적 보장

### 검토 기술

* **AI 지능형 검토**: 머신러닝과 딥러닝 기술을 결합합니다
* **수동 검토**: 중요한 콘텐츠에 대해 수동으로 2차 검토를 진행합니다
* **실시간 업데이트**: 검토 규칙을 지속적으로 최적화하고 업데이트합니다
* **다중 검증**: 다양한 탐지 알고리즘을 사용한 교차 검증을 수행합니다

### 데이터 보안

* **암호화 전송**: 모든 데이터 전송은 암호화 보호를 사용합니다
* **안전한 저장**: 검토 로그를 안전하게 저장하고 관리합니다
* **접근 제어**: 엄격한 권한 관리와 접근 제어를 적용합니다
* **규제 준수**: 관련 기관의 감독과 감사를 받습니다
