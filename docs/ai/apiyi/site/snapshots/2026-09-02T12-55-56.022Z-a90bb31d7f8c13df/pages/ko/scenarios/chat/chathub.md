# ChatHub

> 여러 모델의 답변을 나란히 비교하는 브라우저 확장 AI 클라이언트이며, APIYI를 통해 400개 이상의 모델에 통합적으로 접근할 수 있습니다

ChatHub는 크롬 / Edge 브라우저 확장 프로그램으로, 하나의 대화에서 여러 AI 모델에 같은 질문을 하고 답변을 나란히 표시하여 현재 작업에 가장 잘 맞는 모델을 빠르게 판단할 수 있게 해줍니다. APIYI를 사용하면 ChatHub는 OpenAI, Claude, Gemini, DeepSeek, Qwen을 포함한 400개 이상의 주류 모델에 대한 접근을 통합할 수 있습니다.

## 핵심 기능: 나란히 모델 비교

ChatHub의 다른 클라이언트와의 가장 큰 차별점은 **다중 모델 병렬 Q\&A**입니다:

* 한 탭에서 같은 질문을 2\~6개 모델에 전송합니다
* 답변을 **나란히** 또는 **표** 레이아웃으로 확인합니다
* 어떤 조합이든 가능합니다: GPT-5.5 + Claude Opus 4.7 + Gemini 3 Pro + DeepSeek V4를 함께 사용합니다
* 비교 보기에서는 Markdown 렌더링, 코드 하이라이트, 이미지 미리보기를 지원합니다

<Tip>
  **가장 적합한 시나리오**

  * 코드 작성 / 버그 수정: GPT-5.5와 Claude Opus 4.7 패치를 한 번에 확인합니다
  * 장문 작성: Claude Sonnet과 Qwen3.7의 중국어 표현을 비교합니다
  * 번역 / 요약: 동일한 문단을 GPT-5.5, Gemini 3 Flash, DeepSeek V4에 입력합니다
  * 모델 선택: 동일한 prompt로 여러 모델을 스트레스 테스트하여 기본 모델을 고릅니다
</Tip>

## 설치

ChatHub을 설치하려면 `https://chathub.gg/zh-CN/download`를 방문하세요.

## 빠른 설정 (OpenAI 호환 모드)

이것은 가장 범용적인 설정이며 APIYI의 400개 이상의 모든 모델을 지원합니다.

### 1단계: API 키 가져오기

APIYI 키를 가져오려면 [API key 생성 및 관리](/ko/faq/token-management)를 참고합니다.

### 2단계: ChatHub 설정 열기

1. 브라우저 오른쪽 위에 있는 ChatHub 아이콘을 클릭합니다
2. 팝업에서 오른쪽 위의 **설정**(톱니바퀴) 아이콘을 클릭합니다
3. **사용자 지정 공급자** 탭으로 이동합니다

### 3단계: APIYI 공급자 추가

<img src="https://mintcdn.com/apiyillc/1n99GeVSDKf0eLgj/images/chathub-add-apiyi-provider-zh.png?fit=max&auto=format&n=1n99GeVSDKf0eLgj&q=85&s=ac7db1a0937fc11a8012b39741f15b91" alt="ChatHub APIYI 공급자 추가 구성 예시" width="688" height="691" data-path="images/chathub-add-apiyi-provider-zh.png" />

위 스크린샷을 참고하여 공급자 추가 대화상자를 다음과 같이 입력합니다.

* **이름**: `apiyi` (목록에서 이 공급자를 구분하는 데 도움이 되는 아무 이름이나 입력합니다)
* **API 호스트**: 드롭다운에서 `OpenAI`를 선택하고, 아래 URL 필드에 `https://api.apiyi.com/v1`를 입력합니다
* **API 키**: APIYI 키를 붙여넣습니다
* **모델**: 자주 사용하는 모델, 예를 들어 `deepseek-v4-pro`

선택적 고급 옵션:

* **이미지 입력**: 모델이 비전을 지원하는 경우 활성화합니다(예: `gpt-5-chat-latest`, `gemini-3-pro-preview`, `claude-sonnet-4-5`)
* **함수 호출**: 모델이 도구/함수 호출을 지원하는 경우 활성화합니다
* **고급 설정**: 기본적으로 접혀 있습니다. 펼쳐서 요청 헤더, 타임아웃 등을 사용자 지정할 수 있습니다

완료되면 오른쪽 아래의 **확인**을 클릭하여 저장합니다.

<Info>
  **구성 참고 사항**

  * API Host URL 필드에는 `/v1` 접미사가 포함되어야 합니다
  * "모델"이 기본값입니다. 채팅 중 언제든지 모델을 전환할 수 있습니다
  * 브라우저를 다시 시작할 필요가 없습니다. 설정은 즉시 적용됩니다
  * 다른 공급자를 추가하려면 이 단계를 반복합니다
</Info>

### 4단계: 모델 선택

저장한 후 ChatHub 메인 인터페이스로 돌아갑니다. 방금 추가한 모델이 드롭다운에 표시되며, 자유롭게 전환할 수 있습니다.

## 세 가지 사용 모드

| 모드           | 실행 조건                                   | 사용 시점                        |
| ------------ | --------------------------------------- | ---------------------------- |
| **단일 모델 채팅** | 일반 ChatGPT처럼 하나의 모델과 대화합니다              | 일상적인 Q\&A, 하나의 모델이 특히 잘하는 작업 |
| **다중 모델 비교** | 입력 상자 오른쪽에서 2\~6개의 모델을 선택합니다            | 선택 테스트, 가장 좋은 답변 찾기          |
| **웹 어시스턴트**  | 아무 페이지에서나 텍스트를 선택하여 ChatHub 도구 모음을 띄웁니다 | 논문을 번역/요약하거나 이메일을 다듬을 때      |

<Tip>
  **비교 모드 팁**

  * 비교 모드에서는 각 모델의 답변이 **서로 독립적**입니다. 왼쪽 메인 패널에는 여전히 기본 모델이 표시됩니다
  * 모든 답변을 내보내고 싶으신가요? 대화창 오른쪽 위의 **Export** 버튼을 클릭하시면 됩니다 — Markdown / JSON / PNG를 모두 지원합니다
  * 비교할 때는 스타일이 뚜렷이 다른 모델을 선택하십시오. 예: "GPT-5.5 + Claude Opus 4.7 + DeepSeek V4" — 차이점이 훨씬 쉽게 드러납니다
</Tip>

## 고급: 가장 강력한 비교 설정

ChatHub의 핵심 기능은 “여러 벤더를 한 번에 실행”하는 것입니다. APIYI를 통해 어떤 벤더의 모델이든 하나의 비교 세션에서 조합할 수 있습니다.

| 작업                | 권장 조합                                            | 이유                        |
| ----------------- | ------------------------------------------------ | ------------------------- |

| **장문 / 창작 글쓰기**   | Claude Sonnet 4.5 + Qwen3.7-Max + GPT-5.5        | 중국어 표현력 + 서구식 스토리텔링       |

## 핵심 기능

### 키보드 단축키

| 단축키                        | 동작                            |
| -------------------------- | ----------------------------- |
| `Ctrl/Cmd + Shift + Y`     | 어떤 웹 페이지에서든 ChatHub 사이드바를 엽니다 |
| `Ctrl/Cmd + B`             | 사이드바 표시 여부를 전환합니다             |
| `Ctrl/Cmd + Enter`         | 메시지를 전송합니다(단일 모델 모드)          |
| `Ctrl/Cmd + Shift + Enter` | 선택한 모든 모델에 전송합니다(비교 모드)       |

### 웹 어시스턴트

웹 페이지에서 아무 텍스트나 선택하면 ChatHub이 다음 작업을 할 수 있는 툴바를 표시합니다.

* 선택한 텍스트를 번역합니다
* 선택한 문단을 요약합니다
* 다시 작성 / 다듬기
* 코드를 설명합니다

### 대화 관리

* 각자 독립적인 컨텍스트를 가진 여러 대화
* 대화 기록의 로컬 저장(클라우드 의존 없음)
* Markdown 렌더링 및 코드 하이라이팅
* 한 번의 클릭으로 Markdown / PDF로 내보내기

### prompt 라이브러리

내장된 prompt 템플릿 마켓플레이스가 있으며, 재사용 가능한 자신만의 prompt를 저장하고 변수를 사용할 수도 있습니다.

## 고급 설정

### 매개변수 조정

```yaml theme={null}
Chat parameters:
  - Temperature: 0.7        # Creativity control (reasoning models like GPT-5 only support 1)
  - Max Tokens: 4096        # Maximum output length
  - Top P: 0.9              # Nucleus sampling threshold
  - Frequency Penalty: 0    # Repetition penalty
  - Presence Penalty: 0     # New-topic tendency
```

### 스트리밍 출력

더 부드러운 사용 경험을 위해 ChatHub에서는 스트리밍이 기본으로 켜져 있습니다.

### 프록시 설정

프록시를 통해 접근해야 한다면:

1. Settings > Advanced로 이동합니다.
2. HTTP/HTTPS 프록시를 구성합니다.
3. 필요하면 프록시 인증을 설정합니다.

## 문제 해결

### 연결 실패

* API Base URL을 확인합니다: `https://api.apiyi.com/v1`
* API key가 유효한지 확인합니다
* 네트워크 연결을 확인합니다

### 모델이 표시되지 않음

* 모델 목록이 자동 새로고침될 때까지 기다립니다
* “모델 새로고침” 버튼을 수동으로 클릭합니다
* API key 권한을 확인합니다

### 비교 모드에서 응답이 하나만 표시됨

* 입력 상자 오른쪽에서 여러 모델을 선택했는지 확인합니다
* 모든 모델이 구성된 provider에서 제공되는지 확인합니다

### 응답이 느림

* 더 빠른 모델을 사용해 봅니다
* 네트워크 지연 시간을 확인합니다
* 컨텍스트를 줄입니다

## 모범 사례

### 성능 최적화

1. **모델을 현명하게 선택하십시오**
   * 모델 크기를 작업 복잡도에 맞추십시오
   * 최신 선택 팁은 [모델 추천](/ko/api-capabilities/model-info)을 참고하십시오

2. **비교 전략**
   * 서로 유사한 두 모델(GPT 두 개)을 비교해도 얻을 수 있는 정보는 매우 적습니다
   * **서로 다른 강점**을 가진 모델을 선택하십시오: 코딩용 하나, 글쓰기용 하나, 추론용 하나, 번역용 하나
   * 한 번에 4개 이상의 모델을 비교하지 마십시오. token 사용량은 선형적으로 증가합니다

3. **리소스 관리**
   * API 사용량을 모니터링하십시오
   * 지출 알림을 설정하십시오
   * 확장을 정기적으로 업데이트하십시오

### 보안 팁

* API 키를 절대 공유하지 마십시오
* 키를 주기적으로 교체하십시오
* 강력한 비밀번호로 브라우저를 보호하십시오
* 민감한 정보는 신중하게 처리하십시오

### 팀 협업

ChatHub는 주로 개인용이지만, 다음을 통해 팀도 지원할 수 있습니다:

* 공유 프롬프트 템플릿
* 내보낸 대화 기록
* 표준화된 API 구성

### ChatHub를 선택하는 이유

1. **선택 도구**: 여러 모델을 한 번에 비교할 수 있다는 점은 대체할 수 없습니다
2. **다중 공급업체 조합**: OpenAI / Claude / Gemini / 국내 모델을 자유롭게 조합할 수 있습니다
3. **웹 네이티브**: 브라우저 확장 프로그램이므로 어떤 페이지에서든 호출할 수 있습니다
4. **개인정보 우선**: 대화는 로컬에 저장되며, 확장 프로그램은 사용자의 데이터를 수집하지 않습니다
5. **활발한 개발**: 지속적으로 유지보수되고 있습니다
