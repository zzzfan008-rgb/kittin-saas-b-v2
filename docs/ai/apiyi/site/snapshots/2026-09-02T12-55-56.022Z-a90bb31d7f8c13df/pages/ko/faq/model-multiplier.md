# 모델 'Multiplier'는 무엇을 의미합니까?

> API.YI의 모델 배수의 의미, 계산 규칙, 그리고 공식 가격과의 관계를 이해합니다.

## 빠른 답변

<Info>
  **배수는 가격을 계산하는 업계 표준 방식입니다.** 배수를 다루고 싶지 않다면 모델 목록의 **Price** 열만 확인하시면 됩니다. 요금은 USD로 청구됩니다. 모든 모델 가격 보기: [모델 가격](https://api.apiyi.com/modelPricing)
</Info>

## 과금 전략

| 모델 유형               | 과금 규칙         | 할인                                             |
| ------------------- | ------------- | ---------------------------------------------- |
| **텍스트 / 멀티모달 LLMs** | 공식 과금과 동일     | [충전 보너스](/ko/faq/recharge-promotions) + 그룹 할인  |
| **이미지 / 동영상 모델**    | 호출당 과금, 특별 요율 | [모델 과금](https://api.apiyi.com/modelPricing) 참조 |

<Tip>
  텍스트 모델 할인은 두 가지 형태로 제공됩니다: **충전 보너스 프로모션**(충전 시 추가 크레딧 제공)과 **그룹 할인**(예: 국내 모델을 별도 그룹으로 두고 0.88배 할인을 적용).
</Tip>

## 텍스트 모델 과금

호출당 비용 = **입력 token × 입력 가격 + 출력 token × 출력 가격**

자세한 과금 정보는 [요금](/ko/pricing)을 참조하십시오.

## 기본 개념

이해해야 할 핵심 용어는 다음과 같습니다.

| 시스템 용어         | 의미       |
| -------------- | -------- |
| **Prompt**     | 입력 token |
| **Completion** | 출력 token |

## 배수 계산 규칙

배수는 실제 가격을 산출하는 데 사용하는 상대값입니다.

* **Prompt 배수 × 2** = 입력 가격 (USD / 백만 Tokens)
* **Completion 배수** = 출력 가격 ÷ 입력 가격 (즉, 출력이 입력에 비해 몇 배의 비용이 드는지)

## 예시 계산

`claude-opus-4-6`을 예시로 들면:

| 항목     | 요율 배수                  | 계산                    | 최종 가격               |
| ------ | ---------------------- | --------------------- | ------------------- |
| Input  | Prompt 요율 배수 **2.5**   | 2.5 × 2 = 5           | **\$5 / 백만 token**  |
| Output | Completion 요율 배수 **5** | 5 × 5 (input 가격) = 25 | **\$25 / 백만 token** |

이 공식을 사용하면 API.YI 요금은 공식 요금과 정확히 일치합니다.

## 이미지 / 동영상 모델 과금

이미지 및 동영상 모델은 **호출당 과금**을 사용하며, 일부 모델에는 특별 할인 요율이 적용됩니다. 대시보드의 [모델 요금](https://api.apiyi.com/modelPricing) 페이지에서 구체적인 가격을 확인하세요.

## 요약

* 배수는 **업계 표준** 가격 계산 방식입니다
* 서비스를 사용하는 데 배수를 이해할 필요는 없습니다 — **가격** 열만 확인하시면 됩니다
* **텍스트 모델**은 공식 가격과 일치하며, 충전 보너스와 그룹 할인을 통해 할인됩니다
* **이미지/동영상 모델**은 특수 요율로 호출당 과금됩니다 — [모델 가격](https://api.apiyi.com/modelPricing)을 참조하십시오
