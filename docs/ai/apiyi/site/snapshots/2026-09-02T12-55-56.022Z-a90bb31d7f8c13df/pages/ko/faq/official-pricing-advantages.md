# 공식 요율과 동일합니다 — 왜 APIYI에서 구매해야 합니까?

> 텍스트 모델은 공식 요율과 동일한 가격이지만, 최대 20%의 충전 보너스(대략 17% 할인)가 그룹 할인과 함께 적용되며, 공식 직접 라우팅, 캐시 과금 지원, 해외 계정 불필요까지 제공합니다

## 간단한 답변

**텍스트(멀티모달 포함) 모델의 단가는 실제로 공식 요금과 동일합니다**, 하지만 실제 비용은 더 낮습니다. 충전 보너스는 최대 20%까지 제공되어(정가의 약 83%를 지불하는 것과 같으며, 즉 17% 할인입니다), 특정 모델 그룹의 5% 할인 같은 그룹 기반 할인과도 중복 적용되어 결합 비용이 공식 가격의 약 79% 수준까지 내려갑니다. 게다가 공식 릴레이, 캐시 과금 지원, 모든 모델에 하나의 키로 사용, 해외 계정이나 신용카드가 필요 없다는 점은 직접 연결해서는 한꺼번에 얻을 수 없는 장점입니다.

## 절감 효과는 어디서 나오나

<Card title="💰 같은 가격 ≠ 같은 비용" icon="calculator">
  APIYI는 단가를 가지고 장난치지 않습니다 — 텍스트 모델은 공식 정가로 과금되므로, billing은 투명하고 왜곡 없이 유지됩니다. 실제 절감 효과는 **충전 보너스**와 **그룹 할인**에서 나오며, 이 둘은 서로 중복 적용됩니다.
</Card>

### 1. 단계별 충전 보너스 (최대 20％)

\$100 이상을 한 번 충전하면 10%-20%의 단계별 보너스를 받을 수 있습니다:

| 단일 충전 금액               | 보너스     | 실질 할인율       |
| ---------------------- | ------- | ------------ |
| \$100 ≤ X \< \$500     | 10%     | 약 9% 할인      |
| \$500 ≤ X \< \$1,000   | 12%     | 약 11% 할인     |
| \$1,000 ≤ X \< \$3,000 | 15%     | 약 13% 할인     |
| X ≥ \$3,000            | **20%** | **약 17% 할인** |

20% 보너스를 예로 들면, \$3,000을 충전하면 \$3,600 크레딧을 받게 되며 — 실질적으로 공식 가격의 1/1.2 ≈ 83.3%를 지불하는 셈이므로, 즉 약 17% 할인입니다.

  첫 충전 보너스, 단계별 보너스율, 그리고 크레딧 반영 일정
</Card>

### 2. 그룹 할인 (중복 적용 가능)

일부 모델 그룹에는 추가 할인이 적용됩니다 — 예를 들어, 일부 전용 그룹은 **5% 할인**을 제공하며 — 이 할인은 충전 보너스와 **중복 적용**됩니다:

* 20% 충전 보너스 → 실질 비용은 공식 가격의 약 83.3%
* 여기에 5% 할인 그룹을 추가로 적용 → 83.3% × 0.95 ≈ **공식 가격의 약 79%**

## 텍스트 모델의 과금 방식

텍스트 모델은 token 사용량 기준으로 과금됩니다:

```text theme={null}
Cost per request = input tokens × input price + output tokens × output price
```

입력/출력 단가는 각 모델마다 공식 요율과 동일합니다. [모델 가격 개요](/ko/pricing)를 참고하십시오.

<Note>
  **이미지 및 동영상 모델**은 사용 횟수 기준으로 과금됩니다(token당 과금되지 않음). 콘솔의 “모델 가격” 페이지에서 정확한 가격을 확인하십시오. 충전 보너스도 이 모델들에 적용됩니다.
</Note>

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="왜 단가를 공식 요금보다 낮게 그냥 설정하지 않습니까?">
    공식 단가와 맞추는 것은 **공식 직접 라우팅과 투명한 과금**의 보증입니다. 공식 비용보다 낮은 가격은 보통 품질이 떨어지는 릴레이나 역공학된 채널을 의미합니다. APIYI는 대신 그 절감분을 충전 보너스로 돌려드립니다. 요금은 공개되어 있고 모든 고객에게 동일하며, 실제 비용은 직접 이용할 때보다 여전히 더 낮아집니다.
  </Accordion>

  <Accordion title="보너스 크레딧은 원금과 다른 점이 있습니까?">
    사용상 차이는 없습니다. 보너스 크레딧은 원금처럼 텍스트, 이미지, 동영상 및 그 밖의 모든 모델에 걸쳐 **사이트 전체에서 사용 가능**하며, 원금과 동일한 유효 기간 규칙을 따릅니다(결제일로부터 365일, 새로운 충전이 있으면 초기화됨). 유일한 차이는 보너스 크레딧은 환불되지 않는다는 점입니다. [잔액 유효 기간](/ko/faq/recharge-promotions)을 참조하십시오.
  </Accordion>

  <Accordion title="이미지 및 동영상 모델은 어떻게 과금됩니까?">
    이미지 및 동영상 모델은 token 기준이 아니라 **사용당 과금**됩니다(생성 1회당 고정 요금). 정확한 요금은 콘솔에 로그인한 뒤 “모델 가격” 페이지에서 확인하십시오. 충전 보너스는 이 비용도 줄여줍니다.
  </Accordion>

  <Accordion title="충전 보너스와 그룹 할인은 어떻게 중복 적용됩니까?">
    서로 독립적으로 적용되며 중복됩니다.

    * **20% 충전 보너스**: \$3,000 충전 시 \$3,600 수령 — 약 17% 할인
    * **5% 할인 그룹**: 해당 그룹의 호출은 95%로 과금됨
    * **합산**: 83.3% × 0.95 ≈ 79%, 즉 전체적으로 공식 가격의 약 79%
  </Accordion>
</AccordionGroup>
