# どのチャージ特典がありますか？

> APIYIのチャージ特典について学びます。初回ボーナス、段階的ボーナス、エンタープライズサービス、請求書発行サービスを含みます

## チャージ特典の概要

APIYIでは、AIサービスをより手頃な価格でご利用いただけるよう、さまざまなチャージ特典をご用意しています。

<Card title="💰 特典のハイライト" icon="star">
  * 🎁 **初回ボーナス**: 初回のチャージで \$1-2 のボーナスを獲得できます
  * 📊 **段階的ボーナス**: チャージ額が高いほど、ボーナスも高くなります (10%-20%)
  * ⏰ **365日有効**: チャージした残高は支払日から1年間有効で、新たなチャージを行うとリセットされます
  * 🌐 **全対応**: プラットフォーム上のすべてのモデルで有効です
  * 🏢 **請求書対応**: オンライン決済と法人振込の両方で請求書発行に対応しています
</Card>

## 段階別チャージボーナス

チャージ額が大きいほど、ボーナス率も高くなります。高額チャージボーナスは、特別な申請なしでプラットフォームにより自動的に付与されます。

<Info>
  **ポリシー更新**: 新しいチャージボーナス施策は2025年12月18日より有効です
</Info>

### ボーナス率表

| チャージ額（1回の取引）           | ボーナス率   | 実際の付与倍率  | チャージ例                     |
| ---------------------- | ------- | -------- | ------------------------- |
| \$100 ≤ X \< \$500     | **10%** | 1.1× 残高  | チャージ \$100 → 付与 \$110     |
| \$500 ≤ X \< \$1,000   | **12%** | 1.12× 残高 | チャージ \$560 → 付与 \$600     |
| \$1,000 ≤ X \< \$3,000 | **15%** | 1.15× 残高 | チャージ \$1,000 → 付与 \$1,150 |
| X ≥ \$3,000            | **20%** | 1.2× 残高  | チャージ \$3,000 → 付与 \$3,600 |

<Note>
  **重要**: ボーナス率は**累計合計**ではなく、**単回のチャージ額**に基づきます
</Note>

### ボーナスの付与

<Info>
  **自動付与**: \$100以上のチャージに対する段階的ボーナスは、プラットフォームによって自動的に認識され、付与されます — 手動申請は不要です。ボーナスは、当社の経理チームが「システム自動化＋人手レビュー」ワークフローを用いて、毎日23:00 - 01:00 (UTC+8) の間に付与します。**翌日確認するだけでOKです — ボーナスは届きますので、フォローアップは不要です。**
</Info>

### 計算例

<Tabs>

    **ボーナス額**: \$200 × 10% = \$20

    **実際の付与額**: \$200 + \$20 = **\$220** (1.1×)
  </Tab>

  <Tab title="例2: チャージ $700">

    **実際の付与額**: \$700 + \$84 = **\$784** (約 1.12×)
  </Tab>

  <Tab title="例3: チャージ $1,500">
    **チャージ額**: \$1,500

    **区分範囲**: \$1,000 ≤ X \< \$3,000

    **ボーナス率**: 15%

    **ボーナス額**: \$1,500 × 15% = \$225

    **実際の付与額**: \$1,500 + \$225 = **\$1,725** (1.15×)
  </Tab>

    **実際の付与額**: \$5,000 + \$1,000 = **\$6,000** (1.2×)
  </Tab>
</Tabs>

### 残高の有効期間（2026-08-02 から有効）

アカウント残高は支払い日から **365日** 有効です。ルールは次のとおりです。

| 項目                    | ルール                                               |
| --------------------- | ------------------------------------------------- |
| **有効期間**              | チャージしたクレジットは支払い日から365日有効です                        |
| **新規チャージ**            | **利用可能な残高全体** の有効期間が再び1年にリセットされます                 |
| **ボーナス／プロモーションクレジット** | チャージしたクレジットと同じルールです。365日有効で、新規チャージにより同様にリセットされます  |
| **既存の残高**             | 過去のチャージ日にはさかのぼらず、適用開始日（2026-08-02）から365日として計算されます |
| **有効期限切れ時**           | 期限切れの残高は自動的に失効します。返金、復元、変換はありません                  |
| **有効期限の確認**           | 現在の残高の有効期限はコンソールに表示されます                           |

<Warning>
  **実際の利用量に合わせてチャージしてください**: 定期的にチャージして消費している限り、新しいチャージのたびに残高全体が1年にリセットされるため、実運用では影響はありません。ただし、1年以内にクレジットを使い切る見込みがない場合は、より高いボーナス階層に到達するためだけに過剰にチャージしないでください。期限切れの残高は返金も復元もされません。

  公式の文言は [利用規約](https://cf-index.apiyi.com/terms) と [返金ポリシー](https://cf-index.apiyi.com/refund) に記載されています。
</Warning>

## 請求書サービス

APIYIは法人ユーザー向けに、財務精算のニーズに対応するための正式な請求書（VAT普通請求書およびVAT特別請求書）の発行をサポートしています。

### 請求書の申請方法

<Steps>
  <Step title="チャージを完了">
    オンライン決済または法人振込でチャージを完了します
  </Step>

  <Step title="オンラインで請求書情報を提出">
    **APIYIダッシュボード** → **トップナビゲーション** → **請求書を提出** にログインします

    請求書情報を入力します（最低限必要な情報：会社名と納税者番号）

    **オンライン請求書フォーム**: `https://xinqikeji.feishu.cn/share/base/form/shrcns8TS3alZTN2Av1JfkOvmqh`
  </Step>

  <Step title="発行を待つ">
    請求書は3〜5営業日以内に発行され、ご提供いただいたメールアドレスに送信されます
  </Step>
</Steps>

<Info>
  **対応する請求書の種類**:

  * VAT普通請求書（小規模納税者向け）
  * VAT特別請求書（一般納税者向け、税控除対象）
</Info>

<Note>
  **請求書処理時間**: 請求書は通常、依頼を受領してから3〜5営業日以内に発行されます。月末や四半期末などの繁忙期には、多少遅れる場合があります。
</Note>

## よくある質問

<AccordionGroup>
  <Accordion title="初回ボーナスは段階ボーナスと併用できますか？">
    **はい、併用できます！**

    例: 初回に \$700 をチャージ

    * 初回ボーナス: \$1（教育ユーザーは \$2）
    * 段階ボーナス: \$700 × 12% = \$84
    * 合計クレジット: \$700 + \$1 + \$84 = **\$785**（通常ユーザー）

    初回ボーナスを受け取るには、[Enterprise WeChat でお問い合わせください](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec)！
  </Accordion>

  <Accordion title="チャージはいつ反映されますか？">
    **反映時間**:

    * **オンライン決済**: 即時（元本はすぐに反映されます）
    * **段階ボーナス**: 当社の財務チームにより毎日 23:00 - 01:00 (UTC+8) に反映（システム自動処理 + 人手確認）— 翌日に表示
    * **初回ボーナス**: [Enterprise WeChat でお問い合わせ](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec)後に手動で追加、通常は 1 営業日以内

    **法人振込**: 受領後 1 営業日以内に処理
  </Accordion>

  <Accordion title="最低チャージ額はありますか？">
    **最低金額の制限はありません**が、推奨は以下の通りです:

    * 頻繁なチャージを避けるため、最低 \$10 以上のチャージ
    * 段階ボーナスの特典を受けるには \$100 以上のチャージ
    * ボーナス率を上げるために一度に大きくチャージする場合は、365日間の有効期間とのバランスを考慮してください
  </Accordion>

  <Accordion title="チャージした残高は失効しますか？">
    **はい。** 2026年8月2日より、アカウント残高には **365日間の有効期間** が適用されます:

    * チャージされたクレジットは、支払い日から1年間有効です
    * **新たなチャージが行われるたびに、利用可能残高全体の有効期間が1年にリセット** されるため、通常のチャージと利用のサイクルには影響しません
    * ボーナスおよびプロモーションクレジットも同じルールに従います
    * 既存残高は 2026-08-02 から365日として計算されます
    * 期限切れ残高は自動的に失効します — 返金、復元、変換はありません

    現在の残高の有効期限はコンソールに表示されます。詳細な規約は [利用規約](https://cf-index.apiyi.com/terms) と [返金ポリシー](https://cf-index.apiyi.com/refund) をご覧ください。
  </Accordion>

  <Accordion title="チャージした残高は返金できますか？">
    プラットフォームの方針に基づきます:

    * **未使用のチャージ残高**: 特別な状況では返金可能
    * **ボーナス残高**: 返金不可
    * **使用済み残高**: 返金不可

    返金が必要な場合はカスタマーサービスにご連絡ください。
  </Accordion>

  <Accordion title="\$600 チャージしたのに、段階計算ではなく 12% のボーナスしか付かないのはなぜですか？">
    **ボーナス率は累積区分ではなく、チャージ総額の階層に基づいて計算されます。**

    **正しい計算**:

    * \$600 のチャージは \$500 ≤ X \< \$1,000 の階層に該当
    * ボーナス率: 12%
    * ボーナス額: \$600 × 12% = \$72
    * 実際の反映額: \$672

    **分割計算ではありません**（誤り）:
    ❌ 最初の \$500 × 12% + 次の \$100 × 10%
  </Accordion>

  <Accordion title="請求書はどのように申請しますか？">
    **請求書情報をオンラインで送信**:

    1. APIYI ダッシュボードにログイン
    2. 上部ナビゲーションの「請求書を送信」をクリック
    3. 請求書情報を入力（最低必須項目: 会社名と税番号）
    4. 送信後、3〜5 営業日お待ちください

    **オンライン請求書フォーム**: `https://xinqikeji.feishu.cn/share/base/form/shrcns8TS3alZTN2Av1JfkOvmqh`
  </Accordion>
</AccordionGroup>
