# APIYIのエンタープライズサービスは信頼できますか？ モデルは本物ですか？

> 私たちは、純粋で透明性のある公式リレープロキシです。ルーティング変更も、ダウングレードも、モデルの差し替えもありません。このページでは、稼働率やトラフィックデータから料金ロジックやデータセキュリティに至るまで、私たちを信頼できる検証可能な理由をご紹介します。

## 簡単な回答

**はい — そして、私たちの言葉をそのまま信じるのではなく、ご自身で確かめていただくことを歓迎します。**

APIYI は **純粋で透明性の高い公式リレープロキシ** です。リクエストは追跡可能な公式チャネルのみを通ります（たとえば、Claude はデフォルトで AWS Bedrock の公式アクセス経由でルーティングされます）。私たちは **より安いモデルへ迂回ルーティングせず、ダウングレードせず、モデルを入れ替えず、お客様のデータを保持しません**。私たちは低価格プラットフォームではありません。低価格の真の代償は、たいてい目に見えない「希釈」です。以下に、私たちを信頼できる **客観的に検証可能な** 理由をいくつか示します。まずは少額の残高から始めて、少しずつ信頼を積み重ねることもできます。

<Info>
  **この懸念は十分理解しています。**

  「ゲートウェイが私のリクエストをこっそり安いモデルに迂回ルーティングするのでは？」——ベンダー選定を真剣に行うすべての企業が抱く疑問です。口約束ではなく、私たちは **検証可能な証拠** と **ご自身でテストできる方法** を提供したいと考えています。
</Info>

## なぜ「より安いモデルにこっそり差し替える」ことをしないのか

根本的な理由はシンプルです。**私たちのビジネスモデルは、品質を薄めて利益を出すものではないからです。**

<Warning>
  **「希釈」は、低価格プラットフォームだけがやる必要のあることです**

  逆解析によるアクセス、共有アカウント、モデルの格下げ、高価なモデルを安価なものにこっそり差し替えること——こうした手法はどれも価格を下げることはできますが、使ってみるとチャネルの中に何が混ざっているのか分かりません。出力品質は不安定になり、サービスはいつでも遮断され得ますし、会話データが再販されても気づかないかもしれません。

  **価格が低いほど、たいてい透明性も低くなります。** 低価格プラットフォームには、見えない隠れコストがほぼ確実にあります。
</Warning>

<Info>
  **APIYI は別の道を取ります。純粋な公式リレーです。多少高くても、クリーンな方を選びます**

  Claude を例にすると、デフォルトでは **AWS Bedrock の公式アクセス** を経由し、バックアップとして **Anthropic の公式キーによる直接接続** を使います。どちらのチャネルも純粋な公式リレーで、追跡可能、従量課金、かつデータを保持しません。オールインコストは **公式価格の約 85%**（チャージ特典込みでおおむね 79%〜86% の範囲）です。

  私たちの節約は、**高いキャッシュヒット率**（Claude のネイティブ形式における Prompt Cache）とチャージ特典によるもので、**モデルの格下げや差し替えではありません**。詳しくは [Claude API Basics](/ja/api-capabilities/claude) をご覧ください。
</Info>

### 1. 稼働状況とトラフィック水準

APIYI は**2年以上オンライン**です。急ごしらえの新規サイトではなく、長期のリピート顧客に支えられたプラットフォームです。第三者のトラフィック監視では `api.apiyi.com`、**月間約14.5万訪問と、登録から2年以上のドメイン**が確認できます:

  データは第三者のトラフィック監視ツールによるもので、参考情報にすぎません。詐欺や「水増し」のような手口を使うプラットフォームなら、2年間にわたる安定したトラフィックと継続的な顧客定着を維持するのは難しいはずです。
</Note>

### 2. ドキュメントセンターの専門性

まさに今ご覧いただいているドキュメントそのものが、プラットフォームが「丁寧に整備されている」かどうかの直接的な証拠です。何百もの API ガイド、モデルノート、FAQ が継続的に更新され、価格、課金ルール、チャネルの詳細もすべて公開されています。**手っ取り早く稼ぎたいだけのプラットフォームなら、ここまで説明する手間はかけません。**

### 3. 価格面では、私たちは低価格プラットフォームではありません

料金を一言で言うと、**純粋な公式リレーの AWS Claude を定価の約85%で提供し、品質は安定、高いキャッシュヒット率でコストを抑えています。**

私たちは高いこと自体が目的ではありません。価格は「安定して信頼できる」と「手頃」の境目に置き、**出所不明の安売り品には手を出しません**。あるプラットフォームの価格が極端に安いなら、十分に警戒してください。その差は、見えない形で回収されている可能性が非常に高いです。

詳しくは[Claude API 基礎](/ja/api-capabilities/claude)をご覧ください。

### 4. データセキュリティ: 何も保持しない透明プロキシ

APIYI は**透明プロキシ**です。私たちの役割は、リクエストを上流の公式チャネルへ安全かつ効率的に転送することであり、**会話内容は保持しません**。これはプライバシーの保証であると同時に、根本的には、リクエストに「細工」をする動機がない理由でもあります。

詳しくは[APIYI はどのようにデータセキュリティを保護しますか？](/ja/faq/data-security)をご覧ください。

### 5. 信頼は一歩ずつ築くものです

最初から大きな金額をお願いすることはありません。**信頼は検証の上に築くべきです:**

<Tip>
  **推奨するオンボーディングの進め方**

  1. 少額の\*\*\$10の残高\*\*をチャージし、実際の業務シナリオで試してください;
  2. 公式出力と比較し、呼び出しログを確認して、品質と課金が期待どおりか確かめてください;
  3. 確認できたら、長期的なパートナーシップに向けて段階的に拡大してください。

  こうすることで、投資の各ステップがすでに検証済みの結果に基づき、リスクを適切に管理できます。
</Tip>

## 「モデルの真正性」を自分で確認する方法

約束をうのみにするのではなく、**実際に自分で確かめる**ことができます:

<Steps>
  <Step title="少額残高での並行テスト">
    **\$10残高**を使って実際のタスクを実行し、公式チャネルの出力と比較します。品質が一貫していて安定しているかを確認してください。
  </Step>

  <Step title="呼び出しログを確認する">
    コンソールで、各呼び出しのモデル、token消費量、課金詳細を確認します。透明性が高く、追跡可能な会計です。[呼び出しログを確認するには？](/ja/faq/call-logs) を参照してください。
  </Step>

  <Step title="キャッシュと課金を確認する">
    Claude の **Anthropic native format**（`/v1/messages`）を使用すると、キャッシュ課金が発生する場合があり、長いコンテキストウィンドウ / 同じ system prompt を繰り返し使うシナリオでは請求額が目に見えて下がります。これは公式リレーチャネルだけが提供する機能です。[Claude API 基本](/ja/api-capabilities/claude) を参照してください。
  </Step>
</Steps>

<Note>
  月間消費量が多い企業のお客様は、SLA保証とクレジット補償の条件について当社にご相談いただくこともでき、責任範囲を契約書に明記できます。[APIYI は SLA を提供していますか？](/ja/faq/sla-guarantee) を参照してください。
</Note>
