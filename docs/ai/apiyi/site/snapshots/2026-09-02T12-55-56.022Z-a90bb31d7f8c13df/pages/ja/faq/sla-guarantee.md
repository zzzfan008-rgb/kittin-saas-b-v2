# APIYI は SLA 保証を提供していますか?

> APIYI は実用的な SLA 保証を提供しています。大量の画像生成を利用するお客様には異常課金の補償を行い、当社側の問題による損失にはクレジットの再発行を行い、エンタープライズ契約には補償上限付きの SLA 条項を用意しています。

## クイックアンサー

**はい、ご要望に応じて利用可能です。**

客観的に見ても、今日のAI業界で99.99%のSLAを約束できるプロバイダーはありません（OpenAIやClaude自身でさえ同様です）。APIYIは守れない約束はしません。その代わり、実際に機能する**保証**を提供しています。具体的には、大量の画像生成をご利用のお客様向けの異常課金補償、当社側の問題による損失に対するクレジット再発行、そして法人契約で設定できる補償上限付きのSLA条項です。

## 正直な前提

<Info>
  **なぜ単に99.99%を約束しないのですか？**

  AI は急速に進化しており、上流のモデルは頻繁に更新され、レート制限がかかり、ポリシーも調整されます。**OpenAI と Claude 自身でさえ、99.99% の SLA を達成することはできません。** これは業界全体における客観的な事実です。

  達成できない数値を提示する代わりに、問題が発生した際にお客様が損失を被らないよう、**明確で実行可能な**保証メカニズムを提供することを優先しています。
</Info>

### 1. 高ボリューム画像顧客向けの異常課金補償

**Nano Banana Pro / 2** や **GPT-Image-2** のような画像モデルを高ボリュームで利用する顧客（**月間利用額が \$10,000 以上**）には、**明らかに異常な課金**に対する補償を提供します。

**たとえば**: 画像リクエストが**異常にタイムアウト**（たとえば300秒を超過）したにもかかわらず、生成された画像として**請求**される場合、そのような明らかに異常な課金については、ログを確認したうえで補償します。そのため、高ボリューム顧客が無駄に支払う必要はありません。

<Note>
  **これはあくまで例示シナリオであり、生成時間の保証ではありません。**

  私たちは\*\*「300秒以内に画像が生成されなければ補償する」とは約束できません\*\*。AI 画像生成は上流の変動の影響を受けるため、生成速度について厳密な約束はできません。この保証は、**生成速度**ではなく、**明らかに異常な課金による損失**を対象としています。正確な範囲についてはサポートまでお問い合わせください。
</Note>

### 2. 当社起因の損失に対するクレジット再発行

損失が**明らかに当社起因**である場合、私たちは積極的に補償します。典型的なケースは次のとおりです。

* **バックエンドサーバーの異常**により顧客のクレジットが失われた場合
* **画像モデルの異常タイムアウト**が発生したにもかかわらずデータが返却され、請求された場合

**当社の約束**: 当社側の明確な問題が顧客に影響を与えた場合、**ログを一律にエクスポートし、影響範囲を確認したうえで、クレジットを再発行**し、ユーザーが無駄に損をしないようにします。

<Warning>
  **帰属の原則**: この再発行は、**当社に明確に帰属する問題**（たとえば、プラットフォームのバックエンド異常）に適用されます。**当社の制御外**の要因、たとえば上流の公式コンテンツモデレーションによるブロックや上流のレート制限は、それぞれの説明に従って処理されます（たとえば、上流の一部のモデレーションブロックは、そもそも請求されません）。
</Warning>

### 3. エンタープライズ契約に明記されるSLA

エンタープライズ顧客については、具体的なSLA 条項を**契約で明確に定めることができます**。内容には次が含まれます。

* 適用範囲と可用性指標
* 障害対応および解決までの時間
* **補償上限**などの条項

このように、SLA の保証と責任範囲は契約締結時に明確化されます。**これは顧客とAPIYIの双方にとって明確な保護策です**。

  <Accordion title="なぜ 99.99% の SLA を保証できないのですか？">
    上流の AI モデルは頻繁に更新され、レート制限され、調整されます。**OpenAI や Claude 自身でさえ 99.99% を達成できません**。これは客観的な事実です。私たちは守れない約束はしません。その代わり、明確で実行可能な補償メカニズムでお客様の利益を守ります。
  </Accordion>

  <Accordion title="大量利用の画像顧客向けの異常課金補償には、どうすれば参加できますか？">
    この保証は、**Nano Banana Pro / 2 や GPT-Image-2 などの画像モデルを大量に利用するお客様**向けです。**月額利用額が \$10,000 以上**の方が参加でき、明らかな異常課金（たとえば、リクエストがタイムアウトしたのに生成された画像として課金されるケース）を対象とします。**これは「300 秒以内に画像を保証、できなければ当社が支払う」という約束ではありません**。異常課金による損失に対する補償です。有効化と設定のためにサポートまでご連絡ください。
  </Accordion>

  <Accordion title="お客様側の問題による損失は、どのように補償されますか？">
    当社に明確な原因がある損失（例：バックエンドサーバーの異常、データを返した画像モデルの異常タイムアウト）については、**ログを一括でエクスポートし、影響範囲を検証したうえで、クレジットを再発行**します。お客様が無駄に損失を被ることのないようにします。
  </Accordion>

  <Accordion title="企業は契約に SLA を明記できますか？">

  </Accordion>
</AccordionGroup>
