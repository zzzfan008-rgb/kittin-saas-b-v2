# ChatHub

> 複数のモデルの回答を並べて比較できるブラウザー拡張の AI クライアントです。APIYI を通じて 400 以上のモデルへ統一的にアクセスできます。

ChatHubは、Chrome / Edge のブラウザー拡張機能で、1つの会話の中で複数のAIモデルに同じ質問を投げかけ、その回答を並べて表示できます。これにより、現在のタスクに最も適したモデルをすばやく判断できます。APIYI を使うと、ChatHub は OpenAI、Claude、Gemini、DeepSeek、Qwen を含む 400以上の主要モデルへのアクセスを一元化できます。

## コア機能: モデルの並列比較

ChatHubが他のクライアントと比べて最大の差別化ポイントは、**マルチモデル並列Q\&A**です:

* 同じ質問を1つのタブで2〜6個のモデルに送信できます
* 回答を**横並び**または**表**レイアウトで表示できます
* 任意の組み合わせに対応: GPT-5.5 + Claude Opus 4.7 + Gemini 3 Pro + DeepSeek V4 を一緒に使えます
* 比較ビューはMarkdownレンダリング、コードハイライト、画像プレビューをサポートします

<Tip>
  **最適な用途**

  * コード作成 / バグ修正: GPT-5.5 と Claude Opus 4.7 のパッチを一度に確認
  * 長文執筆: Claude Sonnet と Qwen3.7 の中国語表現を比較
  * 翻訳 / 要約: 同じ段落を GPT-5.5、Gemini 3 Flash、DeepSeek V4 に入力
  * モデル選定: 同じ prompt で複数モデルを負荷テストし、デフォルトを選ぶ
</Tip>

## インストール

`https://chathub.gg/zh-CN/download` にアクセスして ChatHub をインストールしてください。

## クイックセットアップ（OpenAI互換モード）

これは最も汎用的なセットアップで、APIYI の 400 以上のすべてのモデルをサポートします。

### ステップ 1: API キーを取得する

APIYI キーを取得するには、[API key creation and management](/ja/faq/token-management) を参照してください。

### ステップ 2: ChatHub の設定を開く

1. ブラウザ右上の ChatHub アイコンをクリックします
2. ポップアップで、右上の **設定**（歯車）アイコンをクリックします
3. **カスタムプロバイダー** タブに移動します

### ステップ 3: APIYI プロバイダーを追加する

<img src="https://mintcdn.com/apiyillc/1n99GeVSDKf0eLgj/images/chathub-add-apiyi-provider-zh.png?fit=max&auto=format&n=1n99GeVSDKf0eLgj&q=85&s=ac7db1a0937fc11a8012b39741f15b91" alt="ChatHub の APIYI プロバイダー追加設定例" width="688" height="691" data-path="images/chathub-add-apiyi-provider-zh.png" />

上のスクリーンショットに従って、プロバイダー追加ダイアログを次のように入力してください。

* **名前**: `apiyi`（一覧でこのプロバイダーを見分けやすくする任意の名前）
* **API Host**: ドロップダウンから `OpenAI` を選び、下の URL フィールドに `https://api.apiyi.com/v1` を入力します
* **API Key**: APIYI キーを貼り付けます
* **Model**: よく使うモデル。例: `deepseek-v4-pro`

任意の詳細オプション:

* **画像入力**: モデルがビジョンをサポートしている場合に有効にします（例: `gpt-5-chat-latest`, `gemini-3-pro-preview`, `claude-sonnet-4-5`）
* **Function calling**: モデルが tool/function 呼び出しをサポートしている場合に有効にします
* **詳細設定**: 初期状態では折りたたまれています — 展開して request headers やタイムアウトなどをカスタマイズします

完了したら、右下の **確認** をクリックして保存します。

<Info>
  **設定の注意事項**

  * API Host URL フィールドには `/v1` のサフィックスを含める必要があります
  * 「Model」がデフォルトです。チャット中はいつでもモデルを切り替えられます
  * ブラウザの再起動は不要です — 設定はすぐに反映されます
  * 別のプロバイダーを追加するには、この手順を繰り返してください
</Info>

### ステップ 4: モデルを選択する

保存したら、ChatHub のメイン画面に戻ります。追加したモデルがドロップダウンに表示されるので、自由に切り替えられます。

## 3つの使用モード

| モード           | トリガー                                    | 使う場面                  |
| ------------- | --------------------------------------- | --------------------- |
| **単一モデルチャット** | 通常の ChatGPT のように1つのモデルと会話します            | 日々のQ\&A、1つのモデルが得意なタスク |
| **複数モデル比較**   | 入力ボックスの右側で2〜6個のモデルにチェックを入れます            | 選定テスト、最適な回答の発見        |
| **Webアシスタント** | 任意のページでテキストを選択すると ChatHub のツールバーが表示されます | 論文の翻訳/要約、メールの推敲       |

<Tip>
  **比較モードのヒント**

  * 比較モードでは各モデルの返信は**独立**しており、左側のメインパネルには引き続き既定モデルが表示されます
  * みんなの返信をエクスポートしたいですか？ 会話の右上にある **Export** ボタンをクリックしてください — Markdown / JSON / PNG のすべてに対応しています
  * 比較には**文体の異なる**モデルを選ぶとよいです。たとえば「GPT-5.5 + Claude Opus 4.7 + DeepSeek V4」などです。違いがはるかに見つけやすくなります
</Tip>

## 上級編: 最強の比較構成

ChatHubの強みは、「複数のベンダーを同時に実行できる」ことです。APIYIを使えば、どのベンダーのモデルでも1つの比較セッションで組み合わせられます。

### おすすめの比較構成

| タスク                    | おすすめの組み合わせ                                       | 理由                              |
| ---------------------- | ------------------------------------------------ | ------------------------------- |
| **コード生成 / バグ修正**       | GPT-5.5 + Claude Opus 4.7 + DeepSeek V4          | 最上位のコーディング性能 + コスト効率のよい国内向けの選択肢 |
| **長文 / クリエイティブライティング** | Claude Sonnet 4.5 + Qwen3.7-Max + GPT-5.5        | 中国語表現 + 欧米的なストーリーテリング           |
| **翻訳 / 多言語**           | GPT-5.5 + Gemini 3 Flash + DeepSeek V4           | 3つのベンダーで相互検証                    |
| **推論 / 数学**            | GPT-5.5 (xhigh) + Claude Opus 4.7 + Gemini 3 Pro | トップクラスの推論構成3つ                   |

## 主な機能

### キーボードショートカット

| ショートカット                    | 操作                         |
| -------------------------- | -------------------------- |
| `Ctrl/Cmd + Shift + Y`     | 任意のWebページでChatHubのサイドバーを開く |
| `Ctrl/Cmd + B`             | サイドバーの表示/非表示を切り替える         |
| `Ctrl/Cmd + Enter`         | メッセージを送信（単一モデルモード）         |
| `Ctrl/Cmd + Shift + Enter` | 選択したすべてのモデルに送信（比較モード）      |

### Webアシスタント

Webページ上の任意のテキストを選択すると、ChatHubが次の操作を行えるツールバーを表示します:

* 選択したテキストを翻訳する
* 選択した段落を要約する
* 書き換え / 文章を整える
* コードを説明する

### 会話管理

* それぞれ独自のコンテキストを持つ、複数の独立した会話
* 会話履歴のローカル保存（クラウド依存なし）
* Markdownレンダリングとコードハイライト
* ワンクリックでMarkdown / PDFへエクスポート

### Promptライブラリ

組み込みのpromptテンプレートマーケットプレイスがあり、自分用の再利用可能なpromptを保存して、変数を使用することもできます。

## 詳細設定

### パラメータ調整

```yaml theme={null}
Chat parameters:
  - Temperature: 0.7        # Creativity control (reasoning models like GPT-5 only support 1)
  - Max Tokens: 4096        # Maximum output length
  - Top P: 0.9              # Nucleus sampling threshold
  - Frequency Penalty: 0    # Repetition penalty
  - Presence Penalty: 0     # New-topic tendency
```

### ストリーミング出力

ChatHub では、よりスムーズに使えるように、ストリーミングが既定で有効です。

### プロキシ設定

プロキシ経由でアクセスする必要がある場合:

1. 設定 > 詳細設定 に移動します
2. HTTP/HTTPS プロキシを設定します
3. 必要に応じてプロキシ認証を設定します

## トラブルシューティング

### 接続に失敗しました

* API Base URL を確認してください: `https://api.apiyi.com/v1`
* API key が有効であることを確認してください
* ネットワーク接続を確認してください

### モデルが表示されない

* モデル一覧が自動更新されるまでお待ちください
* "モデルを更新" ボタンを手動でクリックしてください
* API key の権限を確認してください

### 比較モードで応答が 1 つしか表示されない

* 入力ボックス右側で複数のモデルにチェックを入れたことを確認してください
* 各モデルが設定済みのプロバイダーから提供されていることを確認してください

### 応答が遅い

* より高速なモデルを試してください
* ネットワークの遅延を確認してください
* コンテキストを短くしてください

## ベストプラクティス

### パフォーマンス最適化

1. **モデルは賢く選ぶ**
   * モデルのサイズをタスクの複雑さに合わせます
   * 最新の選定ヒントは[モデルのおすすめ](/ja/api-capabilities/model-info)をご覧ください

2. **比較戦略**
   * 似たような2つのモデル（2つのGPT）を比較しても、得られる情報はごくわずかです
   * **異なる強み**を持つモデルを選びます。たとえば、コーディング用、ライティング用、推論用、翻訳用です
   * 一度に4つを超えるモデルを比較しないでください。token使用量は線形に増加します

3. **リソース管理**
   * API使用量を監視します
   * 支出アラートを設定します
   * 拡張機能を定期的に更新します

### セキュリティのヒント

* APIキーを絶対に共有しないでください
* キーは定期的にローテーションします
* 強力なパスワードでブラウザを保護します
* 機密情報は慎重に取り扱います

### チームでのコラボレーション

ChatHubは主に個人向けですが、次の方法でチームも支援できます:

* 共有プロンプトテンプレート
* エクスポートした会話記録
* 標準化されたAPI設定

## 比較

### 他のクライアントとの比較

| 機能             | ChatHub   | 単一モデルクライアント | その他の拡張機能 |
| -------------- | --------- | ----------- | -------- |
| **複数モデルの並列比較** | ✅ 中核機能    | ❌           | 一部       |
| **ブラウザのサイドバー** | ✅         | ❌           | 一部       |
| **Web アシスタント** | ✅         | ❌           | 一部       |
| **カスタム API**   | ✅         | ✅           | ✅        |
| **デバイス間同期**    | ✅（ブラウザ同期） | ❌           | 実装依存     |
| **ローカル会話履歴**   | ✅         | 実装依存        | 実装依存     |

### ChatHub を選ぶ理由

1. **選択ツール**: 複数のモデルを一度に比較できるのは代替不可能です
2. **マルチベンダー混在**: OpenAI / Claude / Gemini / 国内モデルを自由に組み合わせられます
3. **Web ネイティブ**: ブラウザ拡張機能として、どのページでも呼び出せます
4. **プライバシー優先**: 会話はローカルに保存され、拡張機能はあなたのデータを収集しません
5. **活発な開発**: 継続的にメンテナンスされています
