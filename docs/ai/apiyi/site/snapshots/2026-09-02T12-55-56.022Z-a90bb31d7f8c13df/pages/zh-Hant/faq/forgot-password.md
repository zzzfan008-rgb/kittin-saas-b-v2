# 忘記密碼了怎麼辦？

> 忘記 API易 賬號密碼的找回方法，包括郵箱重置、客服協助找回等多種方案

## 簡短回答

如果您是郵箱註冊的使用者，可以在登入頁面通過「重置密碼」功能找回；如果沒有繫結郵箱，可以聯絡客服通過使用者名稱、充值記錄或 API Key 協助找回。

## 方案一：郵箱重置密碼

如果您是通過**郵箱註冊**的使用者，可以自助找回密碼：

<Steps>
  <Step title="開啟登入頁面">
    進入 API易 登入頁面，輸入您的郵箱地址。
  </Step>

  <Step title="觸發重置入口">
    輸入郵箱後，隨意輸入一個密碼並點選登入。登入失敗後，頁面會出現**紅色的「重置密碼」連結**。
  </Step>

  <Step title="點選重置密碼">
    點選紅色的「重置密碼」文字，系統會跳轉到密碼找回頁面，通過您繫結的郵箱傳送重置連結。
  </Step>

  <Step title="完成重置">
    前往郵箱查收重置郵件，點選連結設定新密碼即可。
  </Step>
</Steps>

<Info>
  如果沒有收到重置郵件，請檢查垃圾郵件資料夾，或稍等幾分鐘後重試。
</Info>

## 方案二：聯絡客服找回

如果您**沒有繫結郵箱**，或者忘記了註冊郵箱，可以聯絡客服協助找回。請提供以下任意一項資訊用於驗證身份：

<CardGroup cols={3}>
  <Card title="使用者名稱" icon="user">
    提供您記得的 API易 使用者名稱
  </Card>

  <Card title="充值記錄" icon="receipt">
    提供支付寶或微信的充值賬單截圖
  </Card>

  <Card title="API Key" icon="key">
    提供您使用過的 API Key
  </Card>
</CardGroup>

<Warning>
  請至少提供以上一項資訊，客服核實後會協助您找回賬號。
</Warning>

## 方案三：找回後繫結郵箱

成功登入後，**強烈建議**您在使用者中心繫結郵箱：

<Steps>
  <Step title="進入使用者中心">
    登入後，進入「使用者中心」頁面。
  </Step>

  <Step title="繫結郵箱">
    找到郵箱繫結選項，填寫您的常用郵箱並完成驗證。
  </Step>

  <Step title="設定密碼">
    繫結郵箱後，設定一個安全的密碼。後續即可使用郵箱 + 密碼登入。
  </Step>
</Steps>

<Tip>
  繫結郵箱後，您可以隨時通過郵箱自助找回密碼、修改密碼，無需再聯絡客服。
</Tip>

## 常見問題

<AccordionGroup>
  <Accordion title="重置密碼的紅色連結在哪裡？">
    在登入頁面輸入郵箱和一個錯誤的密碼，點選登入後，頁面會顯示登入失敗提示，同時出現紅色的「重置密碼」可點選文字。
  </Accordion>

  <Accordion title="我是第三方登入（GitHub/微信）的使用者怎麼辦？">
    第三方登入的使用者請直接使用對應平臺登入。如果第三方登入也遇到問題，請參考 [GitHub 登入問題](/zh-Hant/faq/github-bindng-bindng-error) 或聯絡客服。
  </Accordion>

  <Accordion title="為什麼建議繫結郵箱？">
    繫結郵箱後，您可以：

    * 通過郵箱自助重置密碼
    * 使用郵箱 + 密碼作為備用登入方式
    * 接收重要的賬戶通知
  </Accordion>
</AccordionGroup>
