# Nano Banana 系列價格總覽

> Nano Banana 系列圖片模型（Pro / 2 / 2 Lite / 第一代）完整價格對比，包括按次計費、按量計費、充值優惠及令牌選擇建議。最低可達官方 30.3% 的價格。

## 概述

Nano Banana 系列包含四款圖片生成模型，均支援通過 API易 以遠低於官方的價格呼叫。本頁彙總所有 Nano Banana 模型的定價資訊，幫助你快速選擇最適合的計費方案。

<Info>
  在 API 呼叫時，所使用的\*\*「令牌型別」\*\*決定計費方式。Nano Banana Pro、2、Lite 都有兩種計費方式：**按次計費**、**按量計費**。且僅有兩個分組：預設穩定分組、企業高可用分組。
</Info>

## Nano Banana 2 Lite 定價

模型名：`gemini-3.1-flash-lite-image`

最快最省的一檔，專注 1K 畫布、約 4 秒出圖。**推薦按量優先**：實測單價更低且可預期。

### 按量計費（推薦）

| 計費項  | API易            | 谷歌官方            | 相對官方       |
| ---- | --------------- | --------------- | ---------- |
| 輸入價格 | \$0.10/M tokens | \$0.25/M tokens | **官網 4 折** |
| 輸出價格 | \$12/M tokens   | \$30/M tokens   | **官網 4 折** |

按量計費預估單張價格：

| 解析度 | API易預估        | 谷歌官方      |
| --- | ------------- | --------- |
| 1K  | **\~\$0.018** | \~\$0.034 |

<Info>
  **實測可預期**：1K 出圖按量（按 tokens）**實測平均約 \$0.018/次**（常見區間約 \$0.016–\$0.019，輸出 token 決定單價），比按次固定價 \$0.025/次更省。可疊加充值活動進一步降本。
</Info>

### 按次計費

| 計費項  | API易      | 谷歌官方        | 說明               |
| ---- | --------- | ----------- | ---------------- |
| 單張價格 | \$0.025/次 | 約 \$0.034/張 | 固定單價，後續可能下調、暫時不動 |

<Tip>
  **計費模式怎麼選**：Lite **首選「按量優先」**（Pay-as-you-go Priority）——實測約 \$0.018/次、比按次 \$0.025 更省且可預期，同一把令牌還相容 Nano Banana Pro / 2 的按次計費，一把跑全系列。按次 \$0.025/次為固定單價，後續可能下調、暫時不動。
</Tip>

## 令牌型別選擇建議

<Info>
  選擇令牌型別時，令牌的「Billing model」設定決定了計費方式。請根據你的主要使用場景選擇：
</Info>

| 模型                 | 使用場景         | 推薦令牌型別 |
| ------------------ | ------------ | ------ |
| Nano Banana Pro    | 1-4K 混合使用    | 按量優先   |
| Nano Banana Pro    | 只跑 4K        | 按次計費   |
| Nano Banana 2      | 0.5K-4K 混合使用 | 按量優先   |
| Nano Banana 2      | 只用 4K        | 按次計費   |
| Nano Banana 2 Lite | 1K 走量出圖      | 按量優先   |

<Tip>
  **簡單原則**：如果你主要生成 4K 圖片，選**按次計費**更划算（不區分解析度統一價格）；如果解析度混合使用，選**按量計費**可以在低解析度時節省更多。
</Tip>
