# 令牌需要設定可用模型嗎？

> 詳細說明API易令牌的可用模型設定機制、使用建議和常見場景

## 一般情況：不需要設定

<Info>
  **推薦做法**：建立令牌時，**不需要設定可用模型**，這樣可以使用整個站點的所有模型。
</Info>

可用模型採用**白名單機制**：

* **不設定**：該令牌可以呼叫站點上所有 400+ 模型
* **設定後**：該令牌只能呼叫指定的模型，無法使用其他模型

如果您的業務場景多樣化，設定可用模型會限制令牌的使用範圍，反而影響靈活性。

## 為什麼不建議設定？

### 1. 限制呼叫範圍

假設您設定了可用模型為 `gpt-4o`、`claude-3-5-sonnet-20241022`，那麼：

* ✅ 可以呼叫：`gpt-4o`、`claude-3-5-sonnet-20241022`
* ❌ 無法呼叫：`gemini-2.5-pro`、`deepseek-v3`、其他 400+ 模型

這會嚴重限制您的業務靈活性。

### 2. 模型別名問題

<Warning>
  **模型別名陷阱**：部分模型有別名，設定可用模型時容易出錯。

  **案例**：

  * **別名**：`nano-banana-pro`（友好的簡稱）
  * **正式名稱**：`gemini-3-pro-image-preview`（官方 API 名稱）

  如果您設定可用模型為 `nano-banana-pro`，但程式碼中呼叫 `gemini-3-pro-image-preview`，會返回錯誤：

  ```
  {
    "error": {
      "message": "Model not allowed for this API key",
      "type": "invalid_request_error"
    }
  }
  ```
</Warning>

### 3. 業務場景變化

隨著業務發展，您可能需要測試或切換不同模型：

* 從 GPT-4 切換到 Claude 3.5
* 測試國產模型 DeepSeek、Qwen
* 嘗試新發布的 Gemini 2.5

如果提前設定了可用模型，每次需要修改白名單，非常麻煩。

## 什麼情況下需要設定？

雖然不推薦，但以下場景可以考慮設定可用模型：

### 場景 1：共享令牌給他人

<Card title="團隊協作/朋友共享" icon="users">
  如果您將令牌 KEY 共享給同事或朋友，並希望他們**只能使用特定模型**（如 `gpt-3.5-turbo`），避免高價模型消耗您的餘額，這種情況可以設定可用模型。

  **示例**：

  * 您的餘額有限，只想讓同事使用 `gpt-3.5-turbo`、`gpt-4o-mini`
  * 設定可用模型後，即使同事嘗試呼叫 `o3`，也會被拒絕
</Card>

### 場景 2：預算控制

<Card title="嚴格成本管理" icon="dollar-sign">
  如果您為某個專案設定了嚴格的預算，只允許使用低成本模型，可以通過可用模型白名單限制：

  **示例**：

  * 專案預算有限，只允許使用 `deepseek-v3`（\$0.07/百萬 tokens）
  * 禁止使用 `o3`（\$20/百萬 tokens）避免超支
</Card>

### 場景 3：安全合規

<Card title="企業安全策略" icon="shield">
  部分企業有嚴格的 AI 模型使用規範，只允許使用經過審批的模型。

  **示例**：

  * 公司只允許使用 OpenAI 官方模型
  * 設定可用模型為 `gpt-4o`、`gpt-4.1`，禁止使用其他廠商模型
</Card>

## 如何設定可用模型？

如果您確實需要設定可用模型，步驟如下：

1. 登入 [API易令牌管理頁面](https://api.apiyi.com/token)
2. 點選"新增 KEY"或編輯現有令牌
3. 在"可用模型"欄位中選擇允許的模型
4. 儲存配置

<Tip>
  **使用正式名稱**：設定可用模型時，建議使用模型的**官方正式名稱**（如 `gemini-3-pro-image-preview`），而非別名（如 `nano-banana-pro`），避免呼叫失敗。

  您可以在 [模型列表頁面](/zh-Hant/api-capabilities/model-info) 檢視所有模型的正式名稱。
</Tip>

## 總結

| 設定方式        | 優點                                            | 缺點                                       | 適用場景               |
| ----------- | --------------------------------------------- | ---------------------------------------- | ------------------ |
| **不設定可用模型** | ✅ 可使用所有 400+ 模型<br />✅ 無需擔心別名問題<br />✅ 業務靈活性高 | ❌ 無法限制他人使用高價模型                           | 個人使用、開發測試、生產環境（推薦） |
| **設定可用模型**  | ✅ 嚴格控制模型使用範圍<br />✅ 防止高價模型消耗餘額                | ❌ 限制靈活性<br />❌ 可能遇到別名問題<br />❌ 需要手動維護白名單 | 共享令牌、預算控制、安全合規     |

<Info>
  **推薦做法**：除非有明確的控制需求，否則**不設定可用模型**，享受所有模型的訪問權限。
</Info>
