# 如何申請代理合作？可以邀請好友返佣嗎？

> API易 預設提供邀請返佣機制，邀請好友註冊後可持續獲得 5% 額度返利，無需單獨申請代理合作。

## 簡短回答

API易 **沒有單獨的"代理合作"申請通道**，預設面向所有使用者開放**邀請返佣**機制：在「賬號中心」獲取專屬邀請連結 / 邀請碼，邀請好友註冊後即可**持續獲得 5% 的額度返利**。

<Info>
  返利以**站內額度**形式發放（即贈送給你的 API 呼叫餘額），**不支援提現**，僅可用於自己消費 API。
</Info>

## 在哪裡找到我的邀請連結和邀請碼？

<Steps>
  <Step title="進入「賬號中心」">
    登入後直接訪問 [賬號中心 / 個人中心](https://api.apiyi.com/account/profile)
  </Step>

  <Step title="找到「推廣資訊」欄目">
    在頁面下方的「**推廣資訊**」區域，即可看到你的**邀請碼**和**邀請連結**按鈕
  </Step>

  <Step title="複製邀請連結 / 邀請碼">
    點選複製後即可分享給朋友
  </Step>
</Steps>

## 返利如何到賬並使用？

每當被邀請的下游使用者**完成一次充值**，對應比例的返利會進入你的**獎勵金**賬戶。你可以**手動將獎勵金劃轉到自己的餘額**，劃轉後即可正常用於 API 呼叫消費。

<Info>
  **查詢返利明細**：在後臺「日誌」中篩選**型別 = 獎勵金劃轉**，即可檢視每一筆返利的來源與金額。
</Info>

## 如果朋友註冊時邀請連結丟失了關係怎麼辦？

部分瀏覽器、隱私模式或重定向場景下，邀請連結的 cookie/引數可能丟失，導致邀請關係沒建立。這種情況可以讓朋友手動繫結：

<Steps>
  <Step title="讓朋友開啟註冊頁面">
    訪問 API易 註冊頁面
  </Step>

  <Step title="在登錄檔單中填寫「邀請碼」">
    在註冊頁面的「邀請碼」欄位，輸入你的專屬邀請碼
  </Step>

  <Step title="完成註冊">
    提交註冊後，邀請關係即可成功建立
  </Step>
</Steps>

<Tip>
  **建議**：分享邀請連結時，**同時把邀請碼也發給對方**作為備用，避免因連結跳轉丟失關係。一旦註冊完成且未填邀請碼，邀請關係將無法補建。
</Tip>

## 常見問題

<AccordionGroup>
  <Accordion title="返利的額度可以提現嗎？">
    **不可以**。返利以**站內 API 呼叫額度**形式發放，僅供自己使用，不支援提現到銀行卡 / 微信 / 支付寶。
  </Accordion>

  <Accordion title="返利是一次性的還是持續的？">
    **持續性**返利。只要邀請關係成立，被邀請人的每一次充值或消費，都會按當前比例（5%）持續返利到你賬戶。
  </Accordion>

  <Accordion title="之前註冊的朋友是按 10% 還是 5% 結算？">
    按**當前規則**結算，即 2026 年 5 月 15 日 (UTC+8) 之後的返利按 5% 計算；該日期之前已發放的返利不追溯調整。
  </Accordion>

  <Accordion title="企業使用者可以申請更高比例的返利嗎？">
    **不可以**。無論是企業使用者還是個人使用者，邀請返利統一按 **5%** 執行，平臺不提供差異化或定製費率。
  </Accordion>

  <Accordion title="可以用大號邀請自己的小號刷返利嗎？">
    **嚴禁**自邀請刷返利。平臺會通過 **IP、裝置指紋、支付資訊**等多維度關聯識別可疑賬號，一經發現：

    * 平臺**保留單方面取消邀請關聯關係**的權利
    * 已發放的可疑返利**有權追回 / 凍結**
    * 嚴重者可能觸發賬號風控處理

    邀請返利旨在獎勵真實拉新，請勿嘗試任何形式的作弊。
  </Accordion>

  <Accordion title="如何檢視我邀請的好友和返利明細？">
    登入後進入 [賬號中心](https://api.apiyi.com/account/profile) 檢視邀請資料；返利的逐筆進賬可在「日誌」中篩選**型別 = 獎勵金劃轉**檢視。
  </Accordion>
</AccordionGroup>
