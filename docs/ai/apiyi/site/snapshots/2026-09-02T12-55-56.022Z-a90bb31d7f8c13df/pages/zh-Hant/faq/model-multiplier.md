# 系統裡模型的【倍率】是什麼？

> 瞭解 API易 模型倍率的含義、計算規則和與官方定價的對應關係

## 快速答案

<Info>
  **倍率是行業通用的價格計算方式。** 如果您不關心倍率，只需檢視模型列表中的【價格】列即可。本站美金充值、美金計費。檢視全部模型價格：[模型定價](https://api.apiyi.com/modelPricing)
</Info>

## 定價策略

| 模型型別          | 定價規則     | 折扣方式                                             |
| ------------- | -------- | ------------------------------------------------ |
| **文本/多模態大模型** | 與官方定價一致  | [充值加贈](/zh-Hant/faq/recharge-promotions) + 分組折扣  |
| **圖片/影片模型**   | 按次收費，有特價 | 具體價格見 [模型定價](https://api.apiyi.com/modelPricing) |

<Tip>
  文本模型的折扣體現在兩方面：**充值加贈活動**（充值時額外贈送額度）和**分組折扣**（如國產模型單獨分組享 0.88x 折扣）。
</Tip>

## 文本模型計費方式

一次呼叫的費用 = **輸入 Tokens × 輸入單價 + 輸出 Tokens × 輸出單價**

詳細計費說明請參考 [計費說明](/zh-Hant/pricing)。

## 基本概念

首先明確兩個術語對應關係：

| 系統術語               | 含義        |
| ------------------ | --------- |
| **提示（Prompt）**     | 輸入 Tokens |
| **補全（Completion）** | 輸出 Tokens |

## 倍率計算規則

倍率是一個相對值，用於推算具體價格：

* **提示倍率 × 2** = 輸入價格（美金 / 百萬 Tokens）
* **補全倍率** = 輸出價格 ÷ 輸入價格（即輸出是輸入的幾倍）

## 計算示例

以 `claude-opus-4-6` 為例：

| 專案 | 倍率           | 計算過程            | 最終價格                 |
| -- | ------------ | --------------- | -------------------- |
| 輸入 | 提示倍率 **2.5** | 2.5 × 2 = 5     | **\$5 / 百萬 Tokens**  |
| 輸出 | 補全倍率 **5**   | 5 × 5（輸入價格）= 25 | **\$25 / 百萬 Tokens** |

按照此公式計算，API易 的價格與官網定價完全一致。

## 圖片/影片模型計費

圖片和影片模型採用**按次收費**，部分模型有特價優惠，具體價格請在後臺 [模型定價](https://api.apiyi.com/modelPricing) 欄目中查詢。

## 總結

* 倍率是**內部及行業通用**的價格計算方式
* 不需要理解倍率也能正常使用，直接看\*\*【價格】列\*\*即可
* **文本模型**與官方定價一致，折扣通過充值加贈和分組折扣體現
* **圖片/影片模型**按次收費，有特價，詳見 [模型定價](https://api.apiyi.com/modelPricing)
