**2026/7/21 16:00 (UTC+8)** · New Model · Alibaba

🚀 **HappyHorse video series officially on sale: flagship upgraded to 1.1**

Alibaba's video generation series **HappyHorse** is now officially on sale at APIYI, with its docs section live at the same time. The flagship capabilities are upgraded to **1.1**, with four models available: Text-to-Video `happyhorse-1.1-t2v`, Image-to-Video `happyhorse-1.1-i2v`, Reference-to-Video `happyhorse-1.1-r2v` (**up to 9 reference images** for strong subject consistency), and Video Edit `happyhorse-1.0-video-edit` (up to 5 reference images).

Zero-cost onboarding: it shares the **`Wan&HappyHorse` group** (the former `Wan` group, renamed) and the same DashScope passthrough endpoint with the Wan series — existing Wan code works by **changing only the `model` field**, and one token calls both series.

Pricing is built into the APIYI system with no manual configuration: the group discount rate is **0.14x**, so the default price = 0.14 × 7 (fixed exchange rate) = 0.98 — **98% of the official price**; stacking [recharge bonuses](/en/faq/recharge-promotions) brings it down to **\~81% of official**. 720P / 1080P billed per second; failed tasks are not billed.
