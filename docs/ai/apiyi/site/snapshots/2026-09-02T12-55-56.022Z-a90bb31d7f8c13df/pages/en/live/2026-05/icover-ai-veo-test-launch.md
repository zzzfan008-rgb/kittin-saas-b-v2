💡 **Highlights**:

* **Out of the box**: just configure a **default-group APIYI API key** (no enterprise-group switching required)
* **Built-in prompt templates**: one-click apply for common scenarios
* **One-click prompt optimization**: auto-rewrites prompts to better fit VEO's visual-description style
* **Visual parameter controls**: resolution (720p / 1080p / 4K), aspect ratio (16:9 / 9:16 etc.), duration (4 / 6 / 8s), negative prompts, seed — all in the UI

🎯 **Who's it for**: product / design / ops folks who want to validate VEO 3.1 official-proxy quality quickly; developers writing VEO integration code who want to dial in prompts and parameters in a UI first.
