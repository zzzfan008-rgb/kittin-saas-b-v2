# Model catalog sync: the full pricing table now lives in the docs center

> The model catalog has been synced and reorganized. The full pricing table now lives at docs.apiyi.com/models, listing input, output and cache prices plus the callable endpoints and available groups for every model; api.apiyi.com/modelPricing in the console keeps a simplified view without endpoints or cache billing notes.

**2026/8/2 22:36 (UTC+8)** · Docs Update

📊 **New model pricing table is live — input, output and cache prices, callable endpoints and groups all on one page**

This sync moves the full pricing table to [Model Pricing](/en/models) in the docs center. Alongside the usual input and output rates, each model now also shows its **cache price**, the **endpoints it can be called on** (`/v1/chat/completions`, `/v1/responses`, `/v1/images/generations`, and so on) and the **groups it is available in** — the two questions we were asked most often: which endpoint does this model take, and which group can call it.

Both entry points remain available, pick whichever fits:

* Docs center [Model Pricing](/en/models): full version, with endpoints, groups and cache billing details
* Console `api.apiyi.com/modelPricing`: simplified version, without endpoints or cache billing notes

The docs center page is the reference for pricing; if anything shown elsewhere disagrees with it, let us know and we will reconcile it.
