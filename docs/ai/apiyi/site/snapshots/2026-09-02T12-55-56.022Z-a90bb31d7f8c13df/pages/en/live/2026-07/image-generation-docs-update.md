# Two New AI Image-Generation Guides in the Docs

> Two new experience-sharing docs: 'How to Get Satisfying Images' uses a real case to explain the web-vs-API pipeline gap, sampling variance, and four practical strategies; 'Image Compression & Output Resolution' clarifies that output resolution is set by size parameters and reasonable input compression doesn't hurt sharpness.

**2026/7/6 11:30 (UTC+8)** · Docs Update

📚 **Two new AI image-generation experience guides in the docs · how to get satisfying images**

Both are distilled from real customer cases plus our own testing, filed under the NanoBanana Best Practices collection to help developers raise their success rate:

* [How to Get Satisfying Images](/en/api-capabilities/image-generation-success-tips): a real "wrong color" editing case explaining the pipeline gap between the web-app agent and a single API call, where single-call variance comes from, and four strategies — better prompts, retries, switching models, and isolating issues with a test tool.
* [Image Compression & Output Resolution](/en/api-capabilities/image-compression-resolution): output resolution is set by size parameters (writing "4K" in the prompt does nothing), reasonable input compression doesn't hurt output sharpness, with a recommended compression table and EXIF/format/color-space best practices.

Take a look — and keep the feedback from real-world usage coming; we keep improving the docs.
