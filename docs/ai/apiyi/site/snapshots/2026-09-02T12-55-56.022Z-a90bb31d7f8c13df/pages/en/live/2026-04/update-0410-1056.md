🍌 Nano Banana token setup best practice: set billing mode to "Token Priority" (compatible with Nano Banana 2 token-based + Nano Banana Pro per-call), default channel `Default` (1x), fallback channel `NanoBananaEnterprise` (2.5x, \~50% off official). Traffic only falls back to Enterprise when Default fails — ensuring zero downtime. Acceptable for personal use; for B2C products with fixed pricing, please evaluate cost impact.
