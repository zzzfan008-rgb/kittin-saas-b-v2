🚀 **Seedance 2.0 Asset Library is open: real-person and virtual-avatar authorization both supported at the API level**

Need a portrait allowlist API for SD2? It's here — with the icover.ai Asset Library open API (an APIYI product), ingest images to get `asset://` asset IDs, then generate character-consistent videos through the APIYI gateway: the same character stays consistent across episodes and shots, ideal for animated drama and short-drama series. Virtual avatars ingest fully automatically with no review; real people appear on camera via the in-person face-verification authorization flow. A companion web UI covers zero-code use, and the REST API covers batch integration.
