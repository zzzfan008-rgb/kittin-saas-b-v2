# AI Image Master adds one-click prompt optimizer + quantity selector

> AI Image Master (imagen.apiyi.com) keeps iterating: a one-click prompt optimizer (powered by gemini-3.1-flash-lite — light, cheap, fast) and a quantity selector on the home generator (concurrent single-image runs). Try it and send feedback.

**2026/5/11 00:10 (UTC+8)** · Service Notice

🛠️ **AI Image Master upgrade: one-click prompt optimizer + quantity selector on the home page** — `imagen.apiyi.com` playground keeps iterating: a new **one-click prompt optimizer** rewrites the current prompt for you (powered by `gemini-3.1-flash-lite` by default — lightweight, cheap, fast, and a sane cost profile for a one-tap utility). The **home generator** also picks up a **quantity selector** — under the hood it concurrently runs multiple single-image generations, lighter than the batch page and handy when you just want a few candidates side by side.

🎯 **Positioning**: AI Image Master is APIYI's **API demo / testing tool** for customers — it exists to showcase API capabilities and help enterprise users onboard and trial faster. It is **not** a consumer-facing product. More feedback welcome — we keep iterating.

📖 Try it: `imagen.apiyi.com`
