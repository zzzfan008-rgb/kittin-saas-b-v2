## 充值阶梯加赠

充值金额越大，加赠比例越高。大额充值的加赠会由平台方自动添加，无需特别申请。

<Info>
  **政策更新时间**：2025 年 12 月 18 日起执行新的充值加赠政策
</Info>

### 加赠比例表

| 充值金额（单次充值）             | 加赠比例    | 实际到账倍数   | 充值示例                    |
| ---------------------- | ------- | -------- | ----------------------- |
| \$100 ≤ X \< \$500     | **10%** | 1.1 倍余额  | 充值 \$100 → 到账 \$110     |
| \$500 ≤ X \< \$1,000   | **12%** | 1.12 倍余额 | 充值 \$500 → 到账 \$560     |
| \$1,000 ≤ X \< \$3,000 | **15%** | 1.15 倍余额 | 充值 \$1,000 → 到账 \$1,150 |
| X ≥ \$3,000            | **20%** | 1.2 倍余额  | 充值 \$3,000 → 到账 \$3,600 |

<Note>
  **重要说明**：加赠比例按**单次充值金额**计算，而非累计充值金额
</Note>

### 加赠发放说明

<Info>
  **自动发放**：充值 \$100 及以上的阶梯加赠，平台方会自动识别并添加，无需您主动申请。每天 23:00 - 次日 01:00（UTC+8）由财务人员统一加赠，采用「系统自动化 + 人工复核」流程，**次日查看即可，到账无需催促**。
</Info>

### 额度有效期（2026-08-02 起执行）

账户余额自充值之日起 **365 天**内有效，规则如下：

| 项目            | 规则                                   |
| ------------- | ------------------------------------ |
| **有效期**       | 充值余额自充值之日起 365 天内有效                  |
| **再次充值**      | 重置**全部可用余额**的有效期，重新恢复为满一年            |
| **赠送 / 促销额度** | 与充值余额规则一致，同为 365 天，同样被新充值重置          |
| **存量余额**      | 统一自生效日（2026-08-02）起算 365 天，不按历史充值日倒推 |
| **到期处理**      | 到期余额自动失效，不退款、不恢复、不兑换                 |
| **到期日查询**     | 可在控制台查看当前余额的到期日                      |

<Warning>
  **充值金额请按实际用量规划**：只要保持正常的充值使用节奏，再次充值就会把全部余额的有效期重置为满一年，实际上不会受影响；但如果预计一年内用不完，请不要为了拿更高加赠比例而超额充值。到期余额不予退款或恢复。

  完整条款以 [用户协议](https://cf-index.apiyi.com/terms) 与 [退款政策](https://cf-index.apiyi.com/refund) 为准。
</Warning>

API易 支持为企业用户开具正规发票（增值税普通发票和增值税专用发票），满足您的财务报销需求。

### 如何申请发票

<Steps>
  <Step title="完成充值">
    通过在线充值或对公转账完成充值
  </Step>

  <Step title="在线提交开票资料">
    登录 **API易 网站后台** → **顶部导航** → **提交开票**

    填写开票资料（最少需要：开票主体和税号）

    **在线开票表单**：`https://xinqikeji.feishu.cn/share/base/form/shrcns8TS3alZTN2Av1JfkOvmqh`
  </Step>

  <Step title="等待开具">
    我们会在 3-5 个工作日内开具发票并发送至您提供的邮箱
  </Step>
</Steps>

<Info>
  **支持的发票类型**：

  * 增值税普通发票（适用于小规模纳税人）
  * 增值税专用发票（适用于一般纳税人，可抵扣税款）
</Info>

<Note>
  **开票周期**：发票通常在收到申请后 3-5 个工作日内开具。月底、季度末等财务高峰期可能略有延迟。

## 常见问题

<AccordionGroup>
  <Accordion title="首充加赠可以和阶梯加赠叠加吗？">
    **可以叠加！**

    例如：首次充值 \$700

    * 首充加赠：\$1（或教育用户 \$2）
    * 阶梯加赠：\$700 × 12% = \$84
    * 总到账：\$700 + \$1 + \$84 = **\$785**（普通用户）

    记得[联系企业微信客服](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec)申请首充加赠哦！
  </Accordion>

  <Accordion title="充值后多久到账？">
    **到账时间**：

    * **在线支付**：即时到账（充值本金立即到账）
    * **阶梯加赠**：每天 23:00 - 次日 01:00（UTC+8）由财务统一加赠（系统自动化 + 人工复核），次日查看即到账
    * **首充加赠**：[联系企业微信客服](https://work.weixin.qq.com/kfid/kfc9adfd5810ece25ec)后人工添加，通常 1 个工作日内

    **对公转账**：到账后 1 个工作日内处理
  </Accordion>

  <Accordion title="充值金额有最低限制吗？">
    **没有最低限制**，但建议：

    * 最低充值 \$10 以上，避免频繁充值
    * 充值 \$100 以上可享受阶梯加赠优惠
    * 一次性充值更多金额可享受更高加赠比例，同时请结合 365 天有效期评估用量
  </Accordion>

  <Accordion title="充值额度会过期吗？">
    **会**。自 2026 年 8 月 2 日起，账户余额有 **365 天有效期**：

    * 充值余额自充值之日起一年内有效
    * **再次充值会把全部可用余额的有效期重置为满一年**，因此保持正常充值使用节奏不会受影响
    * 赠送与促销额度适用同一规则
    * 存量余额统一自 2026-08-02 起算 365 天
    * 到期余额自动失效，不退款、不恢复、不兑换

    当前余额的到期日可在控制台查询。完整条款见 [用户协议](https://cf-index.apiyi.com/terms) 与 [退款政策](https://cf-index.apiyi.com/refund)。
  </Accordion>

  <Accordion title="充值额度可以退款吗？">
    根据平台政策：

    * **未使用的充值额度**：特殊情况可申请退款
    * **加赠额度**：不支持退款
    * **已使用额度**：不支持退款

    如需退款请联系客服说明情况。
  </Accordion>

  <Accordion title="我充值了 \$600，为什么只加赠了 12% 而不是分段计算？">
    **加赠比例是按充值总额区间计算的，不是分段累加。**

    **正确计算**：

    * 充值 \$600 属于 \$500 ≤ X \< \$1,000 区间
    * 加赠比例 12%
    * 加赠金额：\$600 × 12% = \$72
    * 实际到账：\$672

    **不是分段计算**（错误方式）：
    ❌ 前 \$500 × 12% + 后 \$100 × 10%
  </Accordion>

  <Accordion title="如何申请开具发票？">
    **在线提交开票资料**：

    1. 登录 API易 网站后台
    2. 点击顶部导航「提交开票」
    3. 填写开票资料（最少需要：开票主体和税号）
    4. 提交后等待 3-5 个工作日

    **在线开票表单**：`https://xinqikeji.feishu.cn/share/base/form/shrcns8TS3alZTN2Av1JfkOvmqh`
  </Accordion>
</AccordionGroup>
