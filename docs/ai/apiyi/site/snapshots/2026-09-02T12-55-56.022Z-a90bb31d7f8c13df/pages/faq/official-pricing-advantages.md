# 价格和官网一样，为什么选择 API易？

> 文本模型与官方同价，但充值加赠最高 20%（相当于约 83 折），可叠加分组折扣，再加上官方直连、缓存计费、免海外账号等优势，综合成本和体验优于直连官方

## 简短回答

文本（含多模态）模型的**单价确实与官网一致**，但实际成本更低：充值加赠最高 20%（相当于约 83 折，即 17% off），还可叠加部分模型分组的 95 折（5% off）优惠，叠加后综合成本可低至官网的 79 折左右。此外，官方直连转发、缓存计费支持、一个 Key 调用全部模型、免海外账号和信用卡等，都是直连官方无法同时获得的优势。

## 优惠从哪里来

### 1. 充值阶梯加赠（最高 20％）

单次充值 \$100 起即可享受 10%-20% 的阶梯加赠：

| 单次充值金额                 | 加赠比例    | 等效折扣                |
| ---------------------- | ------- | ------------------- |
| \$100 ≤ X \< \$500     | 10%     | 约 91 折（9% off）      |
| \$500 ≤ X \< \$1,000   | 12%     | 约 89 折（11% off）     |
| \$1,000 ≤ X \< \$3,000 | 15%     | 约 87 折（13% off）     |
| X ≥ \$3,000            | **20%** | **约 83 折（17% off）** |

以 20% 加赠为例：充值 \$3,000 到账 \$3,600，相当于按官网价格的 1/1.2 ≈ 83.3% 付费，即约 17% 的折扣。

<Card title="查看充值加赠详情" icon="gift" href="/faq/recharge-promotions">
  首充加赠、阶梯加赠比例、发放时间等完整说明
</Card>

### 2. 分组折扣（可叠加）

部分模型分组另有折扣，例如某些专属分组享 **95 折（5% off）**，与充值加赠**可以叠加**：

* 充值加赠 20% → 实际成本约为官网的 83.3%
* 再叠加分组 95 折 → 83.3% × 0.95 ≈ **官网的 79 折左右**

## 文本模型如何计费

文本模型按 token 用量计费，公式如下：

```text theme={null}
单次请求费用 = 输入 tokens × 输入单价 + 输出 tokens × 输出单价
```

各模型的输入/输出单价与官网一致，详见[模型价格总览](/pricing)。

<Note>
  **图像和视频模型**按次计费（而非按 token），具体价格请在网站后台的「模型价格」页面查询。充值加赠同样适用于这些模型。
</Note>

## 常见问题

<AccordionGroup>
  <Accordion title="为什么不直接把单价定得比官网低？">
    单价与官网一致是**官方直连、计费透明**的保证——低于官方成本的单价往往意味着中转降质或逆向通道。API易 选择把优惠放在充值加赠上：比例公开、对所有客户一视同仁，实际成本依然低于直连官方。
  </Accordion>

  <Accordion title="加赠额度和充值本金有区别吗？">
    使用上没有区别：加赠额度与本金一样**全站通用**，适用于文本、图像、视频等所有模型，有效期规则也与本金一致（自充值之日起 365 天，再次充值重置）。唯一区别是加赠部分不支持退款。详见 [额度有效期说明](/faq/recharge-promotions)。
  </Accordion>

  <Accordion title="图像、视频模型怎么计费？">
    图像和视频模型**按次计费**（每次生成收取固定费用），而非按 token 计费。具体价格请登录网站后台，在「模型价格」页面查询。充值加赠同样可以摊薄这部分成本。
  </Accordion>

  <Accordion title="充值加赠和分组折扣怎么叠加计算？">
    两者独立生效、可以叠加：

    * **充值加赠 20%**：充 \$3,000 到账 \$3,600，等效约 83 折
    * **分组 95 折**：该分组下的调用按 95% 计费
    * **叠加后**：83.3% × 0.95 ≈ 79%，即综合约为官网价格的 79 折
  </Accordion>
</AccordionGroup>
