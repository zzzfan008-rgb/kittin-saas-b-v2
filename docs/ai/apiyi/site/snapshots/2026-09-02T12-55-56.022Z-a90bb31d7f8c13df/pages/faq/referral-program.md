# 如何申请代理合作？可以邀请好友返佣吗？

> API易 默认提供邀请返佣机制，邀请好友注册后可持续获得 5% 额度返利，无需单独申请代理合作。

## 简短回答

API易 **没有单独的"代理合作"申请通道**，默认面向所有用户开放**邀请返佣**机制：在「账号中心」获取专属邀请链接 / 邀请码，邀请好友注册后即可**持续获得 5% 的额度返利**。

<Info>
  返利以**站内额度**形式发放（即赠送给你的 API 调用余额），**不支持提现**，仅可用于自己消费 API。
</Info>

## 在哪里找到我的邀请链接和邀请码？

<Steps>
  <Step title="进入「账号中心」">
    登录后直接访问 [账号中心 / 个人中心](https://api.apiyi.com/account/profile)
  </Step>

  <Step title="找到「推广信息」栏目">
    在页面下方的「**推广信息**」区域，即可看到你的**邀请码**和**邀请链接**按钮
  </Step>

  <Step title="复制邀请链接 / 邀请码">
    点击复制后即可分享给朋友
  </Step>
</Steps>

## 返利如何到账并使用？

每当被邀请的下游用户**完成一次充值**，对应比例的返利会进入你的**奖励金**账户。你可以**手动将奖励金划转到自己的余额**，划转后即可正常用于 API 调用消费。

<Info>
  **查询返利明细**：在后台「日志」中筛选**类型 = 奖励金划转**，即可查看每一笔返利的来源与金额。
</Info>

</Warning>

## 如果朋友注册时邀请链接丢失了关系怎么办？

部分浏览器、隐私模式或重定向场景下，邀请链接的 cookie/参数可能丢失，导致邀请关系没建立。这种情况可以让朋友手动绑定：

<Steps>
  <Step title="让朋友打开注册页面">
    访问 API易 注册页面
  </Step>

  <Step title="在注册表单中填写「邀请码」">
    在注册页面的「邀请码」字段，输入你的专属邀请码
  </Step>

  <Step title="完成注册">
    提交注册后，邀请关系即可成功建立
  </Step>
</Steps>

<Tip>
  **建议**：分享邀请链接时，**同时把邀请码也发给对方**作为备用，避免因链接跳转丢失关系。一旦注册完成且未填邀请码，邀请关系将无法补建。
</Tip>

## 常见问题

<AccordionGroup>
  <Accordion title="返利的额度可以提现吗？">
    **不可以**。返利以**站内 API 调用额度**形式发放，仅供自己使用，不支持提现到银行卡 / 微信 / 支付宝。
  </Accordion>

  <Accordion title="返利是一次性的还是持续的？">
    **持续性**返利。只要邀请关系成立，被邀请人的每一次充值或消费，都会按当前比例（5%）持续返利到你账户。
  </Accordion>

  <Accordion title="之前注册的朋友是按 10% 还是 5% 结算？">
    按**当前规则**结算，即 2026 年 5 月 15 日 (UTC+8) 之后的返利按 5% 计算；该日期之前已发放的返利不追溯调整。
  </Accordion>

  <Accordion title="企业用户可以申请更高比例的返利吗？">
    **不可以**。无论是企业用户还是个人用户，邀请返利统一按 **5%** 执行，平台不提供差异化或定制费率。
  </Accordion>

  <Accordion title="可以用大号邀请自己的小号刷返利吗？">
    **严禁**自邀请刷返利。平台会通过 **IP、设备指纹、支付信息**等多维度关联识别可疑账号，一经发现：

    * 平台**保留单方面取消邀请关联关系**的权利
    * 已发放的可疑返利**有权追回 / 冻结**
    * 严重者可能触发账号风控处理

    邀请返利旨在奖励真实拉新，请勿尝试任何形式的作弊。
  </Accordion>

  <Accordion title="如何查看我邀请的好友和返利明细？">
    登录后进入 [账号中心](https://api.apiyi.com/account/profile) 查看邀请数据；返利的逐笔进账可在「日志」中筛选**类型 = 奖励金划转**查看。
  </Accordion>
</AccordionGroup>
