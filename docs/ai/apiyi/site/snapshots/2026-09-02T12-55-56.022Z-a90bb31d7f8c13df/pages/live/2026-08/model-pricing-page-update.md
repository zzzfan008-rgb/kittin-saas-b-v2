# 模型广场调整同步：完整版模型价格表移至文档中心

> 模型广场做了一次同步调整，完整版移到文档中心 docs.apiyi.com/models，每个模型标注输入、输出、缓存三档价格以及可调用端点与可用分组；控制台 api.apiyi.com/modelPricing 保留简化版，不含端点与缓存计费说明。

**2026/8/2 22:36 (UTC+8)** · 文档更新

📊 **模型价格表新版上线，输入 / 输出 / 缓存价格、可用端点与分组一页看全**

这次同步调整把完整版的模型价格表放到了文档中心的 [模型价格](/models)。除了常见的输入与输出单价，页面还标注了**缓存价格**、每个模型**可调用的端点**（如 `/v1/chat/completions`、`/v1/responses`、`/v1/images/generations`）以及**可用分组**，用来解决此前最常被问到的两类问题：这个模型该走哪个端点、哪个分组能用它。

两个入口都可继续使用，按需自选：

* 文档中心 [模型价格](/models)：完整版，含端点、分组与缓存计费口径
* 控制台 `api.apiyi.com/modelPricing`：简化版，不含端点与缓存计费说明

价格以文档中心页面为准，如与其它位置的展示不一致，欢迎反馈我们核对。
