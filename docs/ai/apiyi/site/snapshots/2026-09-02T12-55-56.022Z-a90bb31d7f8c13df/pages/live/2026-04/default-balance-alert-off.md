# 默认 $30 余额告警邮件已停用，可在后台自行开启

> 平台默认的 $30 余额告警邮件已关闭，部分用户反馈打扰。如需开启请在后台「个人中心 → 通知设置」配置，支持邮箱、企业微信、飞书三种通道；技术团队也欢迎接入余额查询 API 实现自控查询。

**2026/4/28 15:59 (UTC+8)** · 服务通知

📣 **默认 \$30 余额告警邮件已停用** —— 此前默认对所有账户发送的 \$30 余额告警邮件已关闭，避免打扰。如需开启请在后台「个人中心 → 通知设置」自行配置，支持邮箱、企业微信、飞书三种通道；技术团队也欢迎接入 `余额查询 API` 实现自控查询。

📖 后台通知设置：[https://api.apiyi.com/account/notificationSettings](https://api.apiyi.com/account/notificationSettings)
