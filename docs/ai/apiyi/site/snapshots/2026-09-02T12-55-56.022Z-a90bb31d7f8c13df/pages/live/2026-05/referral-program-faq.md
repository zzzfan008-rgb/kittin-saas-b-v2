# 邀请返佣 5% 政策 + 奖励金划转流程 FAQ 上线

> API易 没有单独的代理合作通道，默认面向所有用户开放邀请返佣：5/15 起从 10% 调整为 5%，企业与个人统一 5%。奖励金需手动划转到余额方可消费，日志可筛选「奖励金划转」查询。严禁大号邀小号刷返利，平台保留取消邀请关联与追回返利的权利。

**2026/5/18 21:06 (UTC+8)** · 文档更新

🎉 **邀请返佣 5% 政策 + 奖励金划转流程 FAQ 上线** —— 新增 [/faq/referral-program](/faq/referral-program)：在 [账号中心](https://api.apiyi.com/account/profile) 「推广信息」获取邀请码 / 邀请链接，邀请好友注册后**持续 5% 额度返利**（5/15 起由 10% 调整为 5%，**企业与个人统一 5%**）。奖励金需手动**划转**到余额方可消费，日志筛选「**奖励金划转**」即可查看每一笔进账。

⚠️ **反作弊提示**：严禁大号邀请自己的小号刷返利，平台通过 **IP / 设备指纹 / 支付信息**等多维度识别可疑账号，**保留取消邀请关联关系、追回 / 冻结返利**乃至账号风控处理的权利。
