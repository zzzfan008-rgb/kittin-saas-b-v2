# DeepSeek 官网启用峰谷计费，本站同步为峰值档定价

> DeepSeek 官方自北京时间 8 月 17 日 00:00 (UTC+8) 起改为峰/谷两档计费，本站 deepseek-v4-flash 与 deepseek-v4-pro 同步调整为峰值档并固定不浮动。主因是官方并发不足时需用价格更高的 BytePlus 与阿里云官转保供，这部分不盈利；充值活动加赠仍可叠加。

**2026/8/15 08:55 (UTC+8)** · 价格变动 · DeepSeek

💸 **DeepSeek 官方启用峰谷计费，本站 DeepSeek 同步调整为峰值档定价，生效时间与官方一致**

官方公告的生效时间是 `16:00 UTC on August 16, 2026`，即**北京时间 8 月 17 日 00:00 (UTC+8)**。调整后 API 分峰、谷两档，谷时为峰时的一半；峰时为 01:00–04:00 与 06:00–10:00 UTC，对应北京时间 09:00–12:00 与 14:00–18:00 (UTC+8)，其余时段为谷时。原文见 `api-docs.deepseek.com/quick_start/pricing`。

本站 `deepseek-v4-flash` 与 `deepseek-v4-pro` 同步跟随，**固定按峰值档计费，不随时段浮动**。调整后每 1M tokens（缓存命中输入 / 缓存未命中输入 / 输出）：

* `deepseek-v4-flash`：\$0.014 / \$0.44 / \$1.32
* `deepseek-v4-pro`：\$0.044 / \$1.32 / \$3.96

为什么固定在峰值档：系统不支持按时段浮动计价是一方面，但主要原因在供给结构 —— 我们优先走官方渠道，官方并发不足时会用 BytePlus 与阿里云官转顶上，而这两家的 DeepSeek 价格一直明显高于官网。统一按峰值档定价是为了在两条链路上都能保供，这部分我们不赚钱。

即便按原价，充值活动的加赠依旧可以叠加，实际到手成本仍低于名义价。

调价细节、峰谷时段换算与第三方平台的三种定价对策，见 [深度解读](/news/deepseek-price-increase-2026-08)。
