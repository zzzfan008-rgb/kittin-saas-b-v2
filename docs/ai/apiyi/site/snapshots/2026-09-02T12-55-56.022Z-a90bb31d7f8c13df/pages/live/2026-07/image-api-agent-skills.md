# 图片 API Agent 技能文档上线

> 文档中心新增 GPT-Image-2 系列与 Nano Banana Pro 两套开箱即用的 Agent Skill，放进 Codex、Claude Code 等任意编码 Agent，一句话即可调用 API易 图片 API 完成文生图与改图。

**2026/7/6 14:25 (UTC+8)** · 文档更新 · OpenAI / Google

📚 **图片 API 的 Agent 技能（Skills）文档已上线**

为方便在 Codex、Claude Code、OpenClaw 等各类编码 Agent 中接入 API易 平台的图片 API，文档中心新增了两套开箱即用的 Agent Skill——每套只有两个文件，放进 Agent 后一句话即可出图。

两套技能页（按需自选）：

* [GPT-Image-2 系列 Agent 技能](/api-capabilities/gpt-image-2/skills)：一个脚本覆盖 `gpt-image-2`（官转）与 `gpt-image-2-all` / `gpt-image-2-vip`（官逆）三条通道，`--model` 一键切换，支持文生图、多图融合与局部重绘
* [Nano Banana Pro Agent 技能](/api-capabilities/nano-banana-image/skills)：封装 `gemini-3-pro-image`（Nano Banana Pro），零依赖脚本，支持文生图与图片编辑

后续会陆续为更多图像模型补充同款技能页，欢迎试用反馈。
