# 控制台短暂白屏已修复，仍白屏请清一次网站数据

> 今日中午 (UTC+8) 控制台出现短暂页面白屏，服务端已第一时间修复，API 调用全程不受影响，账号与余额数据无任何影响。故障期间打开过控制台的用户因浏览器保留了旧页面数据，修复后仍可能白屏且普通刷新无效，清一次本站网站数据即可恢复。

**2026/8/13 13:51 (UTC+8)** · 服务通知

⚠️ **控制台今日中午短暂白屏，服务端已修复；仍白屏请清一次网站数据**

服务端问题已在第一时间修复，**API 调用全程不受影响，账号与余额数据无任何影响**。但浏览器会在本地保留一份旧的页面数据，故障期间打开过控制台的用户在修复后仍可能看到白屏，且普通刷新无效——清除一次本站的网站数据即可恢复，之后无需再做任何操作（清除后需重新登录一次）。

先做个快速自检：用无痕 / 隐私模式打开 `api.apiyi.com`，能正常显示就说明只是本地旧数据，按下面对应方式清一次即可。

**电脑 Chrome / Edge**（最快，约 10 秒）

1. 打开 `api.apiyi.com`（白屏没关系）
2. 点击地址栏左侧的图标（🔒 或「调节」图标）
3. 选择「网站设置」→ 点「清除数据」（部分版本显示为「Cookie 和网站数据」→「管理网站数据」→ 删除）
4. 回到页面刷新，重新登录即可

**电脑 Safari（Mac）**

1. 菜单栏 Safari →「设置」→「隐私」→「管理网站数据」
2. 搜索 apiyi，选中后点「移除」
3. 刷新页面，重新登录

**手机浏览器**

浏览器设置 → 隐私 / 清除浏览数据 → 勾选「Cookie 和网站数据」（时间范围选最近 1 小时即可）→ 清除后重新打开页面。在微信内打开的，退出该网页重新进入即可；若仍白屏，则：微信「我」→ 设置 → 通用 → 存储空间 → 清理缓存。

给您带来不便深表歉意，如按上述步骤仍无法恢复，请随时联系我们。
