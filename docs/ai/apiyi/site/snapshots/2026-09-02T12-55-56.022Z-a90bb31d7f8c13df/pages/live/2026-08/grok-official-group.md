# 新增 GrokOfficial 官转分组 · 默认 8 折

> 新增 Grok 官方直转分组 GrokOfficial，倍率 0.8x，即默认分组售价的 8 折。模型能力与调用方式和默认分组一致，单独拆出分组只是为了做优惠和促销，折扣可与充值加赠叠加；grok-4.5 等模型在该分组下同样支持 Codex 场景使用。

**2026/8/2 13:26 (UTC+8)** · 新模型 · xAI

🚀 **新增 `GrokOfficial` 官转分组 · 倍率 0.8x，即默认分组的 8 折**

Grok 官方直转线路，模型能力与调用方式和默认分组完全一致。单独拆出这个分组只是为了做优惠和促销，倍率 **0.8x**（默认分组售价的 8 折），折扣可与充值加赠叠加。

`grok-4.5` 等模型在该分组下同样支持 Codex 场景使用。创建令牌时选择 `GrokOfficial` 分组，或在已有 Grok 令牌上增加该分组即可，代码无需改动。

接入见 [Grok 模型概览](/api-capabilities/grok/overview)，Codex 配置见 [Codex CLI 使用指南](/scenarios/programming/codex-cli)。
