# 官逆 gpt-image-2-all 报错 500 通常是内容违规（不计费）

> 官逆 gpt-image-2-all 返回 500 Internal Server Error、message 为「未接收到上游响应内容」时，通常是提示词或参考图触及上游内容策略（如知名人物、版权角色），重试无效，调用不计费，需引导用户调整提示词。

**2026/4/27 15:28 (UTC+8)** · 模型状态 · OpenAI

⚠️ **官逆 `gpt-image-2-all` 报错 500 通常是内容违规** —— 当返回 `500 Internal Server Error` 且 message 为 `未接收到上游响应内容` 时，多为提示词或参考图触及上游内容策略（如名人、版权角色等，例如「湖人球星詹姆斯」会直接出图失败）。这种调用不计费，重试也无效，需引导用户调整提示词后再试。
