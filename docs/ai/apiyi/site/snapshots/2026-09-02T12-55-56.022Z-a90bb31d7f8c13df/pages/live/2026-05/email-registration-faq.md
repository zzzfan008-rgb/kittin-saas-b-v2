# 注册邮箱支持列表 FAQ 上线

> API易 明确公告支持注册的邮箱后缀：Gmail / Outlook / Hotmail / Foxmail 与国内外高校邮箱（.edu / .edu.cn）均可正常注册；QQ / 126 / 163 暂不支持；企业自有域名邮箱默认未开通，可联系客服人工加入白名单。

**2026/5/18 21:05 (UTC+8)** · 文档更新

📧 **注册邮箱支持列表 FAQ 上线** —— 新增 [/faq/email-registration](/faq/email-registration)：明确公告 API易 支持注册的邮箱后缀：**Gmail / Outlook / Hotmail / Foxmail** + **国内外高校邮箱**（`.edu` / `.edu.cn`）均可正常注册；**暂不支持 QQ / 126 / 163** 等后缀（送达率较低，影响验证码与账户通知）。**企业自有域名邮箱默认未开通**，可通过客服微信联系我们**人工加入白名单**后正常注册。
