# Stripe 充值门槛调整：单笔最低 $50

> 受 Stripe 手续费与结算结构影响，Stripe 通道的单笔最低充值金额调整为 $50，未达该金额时 Stripe 不可选。其他支付方式不受影响，最低充值金额仍为 $5。

**2026/7/28 16:44 (UTC+8)** · 服务通知

🗂️ **Stripe 通道单笔最低充值金额调整为 \$50，其他支付方式不变**

调整原因：Stripe 的手续费与结算结构对小额支付并不友好，单笔金额越小，手续费占比越高。即日起，仅当充值金额达到 **\$50 及以上**时，Stripe 通道才可选。

各支付方式的最低充值金额：

* Stripe（外币信用卡）：单笔 \$50 起
* 其他支付方式：单笔 \$5 起，保持不变

给部分用户带来不便，我们深表歉意，感谢理解与一如既往的支持。—— API易 团队
