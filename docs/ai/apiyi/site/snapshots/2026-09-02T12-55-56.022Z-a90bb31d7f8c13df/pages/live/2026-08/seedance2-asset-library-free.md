🎁 **Seedance 2.0 素材库在 API易 免费使用，不另收年费**

Seedance 2.0 做「人物一致性」视频绕不开私域素材库：含写实人脸的参考图不能直接传，必须先入库拿到 `asset://` 素材 ID 再引用。这项能力在**官方侧对非框架签约客户是单独收费**的，需要十万元量级的年费采购（官网也提供购买入口），通常还伴随企业资质与商务流程。

在 API易，素材库**随 Seedance 2.0 接口免费使用**：一把勾选了 `SeeDance2` 分组的令牌即可，虚拟人像入库、真人认证（本人活体核身）与真人素材上传全部包含在内，网页零代码操作与 REST API 批量接入两种用法数据互通。

我们重视长期用户，这项成本已经包含在接口价格里，面向正常调用 SD2 接口的客户，正常业务量内不额外计费。
