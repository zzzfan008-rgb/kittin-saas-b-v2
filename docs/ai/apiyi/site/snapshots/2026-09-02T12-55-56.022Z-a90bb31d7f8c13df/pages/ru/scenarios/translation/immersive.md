# Immersive Translate

> Руководство по интеграции расширения для двуязычного чтения в браузере

Immersive Translate — отличное расширение для перевода в браузере, которое поддерживает двуязычное чтение веб-страниц. Благодаря интеграции с APIYI вы можете использовать мощные AI-модели, чтобы получать более точные и естественные результаты перевода.

## Краткая установка

### Поддерживаемые браузеры

* Chrome / Edge / Brave
* Firefox
* Safari

### Шаги установки

1. Откройте магазин расширений вашего браузера
2. Найдите «Immersive Translate»
3. Нажмите кнопку установки и добавьте расширение в браузер

Или перейдите на [официальный сайт](https://immersive-translate.owenyoung.com/), чтобы получить ссылки для установки.

## Настройка APIYI

### 1. Откройте настройки

Нажмите значок расширения на панели инструментов браузера и выберите «Настройки».

### 2. Настройте службу перевода

1. Выберите «Службы перевода» в левом меню
2. Найдите службу «OpenAI»
3. Нажмите «Управление» или «Настройки»
4. Выберите «Пользовательский ключ API»

### 3. Заполните конфигурацию

* **APIKEY**: Введите ваш ключ APIYI
* **Пользовательский адрес интерфейса API**: `https://api.apiyi.com/v1/chat/completions`
* **Пользовательская модель**: `gpt-3.5-turbo` (необязательно)

## Основные функции

### Перевод веб-страниц

#### Автоматический перевод

1. Откройте веб-страницу на иностранном языке
2. Расширение автоматически определяет язык
3. Нажмите кнопку перевода, чтобы начать

#### Ручной перевод

1. Нажмите значок расширения на панели инструментов
2. Выберите «Перевести эту страницу»
3. Дождитесь завершения перевода

### Режимы перевода

#### Двуязычное чтение (рекомендуется)

* Сохраняет исходный формат
* Перевод отображается под оригиналом
* Удобно для сравнительного изучения

#### Только перевод

* Полностью заменяет исходный текст
* Подходит для быстрого чтения
* Можно в любой момент вернуть двуязычный режим

### Перевод выделенного слова

1. Выделите текст для перевода
2. Нажмите появившуюся кнопку перевода
3. Просмотрите перевод во всплывающем окне

## Рекомендации по выбору модели

### Выбор по типу контента

| Тип контента              | Рекомендуемая модель | Причина                             |
| ------------------------- | -------------------- | ----------------------------------- |
| Новостные статьи          | gpt-3.5-turbo        | Быстро, точно                       |
| Техническая документация  | gpt-4                | Точная терминология                 |
| Научные статьи            | claude-3-opus        | Хорошее понимание                   |
| Литературные произведения | claude-3-sonnet      | Хороший литературный стиль          |
| Ежедневные веб-страницы   | gpt-3.5-turbo        | Высокое соотношение цены и качества |

### Баланс производительности и качества

```javascript theme={null}
// Smart model selection example
const selectModel = (textLength, contentType) => {
  if (textLength < 500) {
    return 'gpt-3.5-turbo'; // Use fast model for short text
  } else if (contentType === 'technical') {
    return 'gpt-4'; // Use accurate model for technical content
  } else if (contentType === 'creative') {
    return 'claude-3-sonnet'; // Use literary model for creative content
  } else {
    return 'gpt-3.5-turbo'; // Default to economical model
  }
};
```

## Оптимизация производительности

### Настройки кэша

* Включите кэш перевода
* Установите длительность кэша: 24 часа
* Регулярно очищайте кэш

### Пакетный перевод

* Настройте размер пакета: 5-10 абзацев
* Установите разумную параллельность: 2-3
* Оптимизируйте обработку длинного текста

### Условия срабатывания

* Минимальная длина перевода: 10 символов
* Игнорируйте определенные элементы: навигационные меню, рекламу
* Отложенный перевод: 200ms

## Распространенные проблемы

### Перевод не выполнен

**Возможные причины:**

* Недействительный ключ API
* Проблемы с сетевым подключением
* Особая структура страницы

**Решения:**

1. Проверьте ключ API
2. Проверьте сетевое подключение
3. Попробуйте обновить страницу
4. Проверьте ошибки в консоли браузера

### Низкая скорость перевода

**Методы оптимизации:**

1. Используйте более быстрые модели
2. Уменьшите объем текста за один перевод
3. Включите функцию кэша
4. Проверьте задержку сети

### Путаница в формате

**Способы обработки:**

1. Попробуйте другие режимы перевода
2. Настройте параметры отображения перевода
3. Настройте правила для конкретных сайтов
4. Сообщите о проблеме разработчикам

## Руководство по устранению неполадок

### Расширение не загружается

1. Проверьте совместимость версии браузера
2. Отключите конфликтующие расширения
3. Очистите кэш браузера
4. Переустановите расширение

### Результаты перевода не отображаются

1. Проверьте, поддерживает ли веб-страница перевод
2. Убедитесь, что сервис перевода настроен правильно
3. Проверьте, не блокирует ли его блокировщик рекламы
4. Попробуйте другие сервисы перевода

### Высокое потребление памяти

1. Регулярно очищайте кэш перевода
2. Уменьшите количество страниц, переводимых одновременно
3. Настройте параметры пакетного перевода
4. Закройте ненужные вкладки
