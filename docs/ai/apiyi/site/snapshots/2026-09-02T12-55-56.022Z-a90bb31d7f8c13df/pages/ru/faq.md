## 🔧 Устранение неполадок по симптомам

Найдите строку, которая соответствует тому, что вы на самом деле видите. Один и тот же симптом часто затрагивает несколько тем, поэтому эта таблица заново группирует статьи по устранению неполадок по наблюдаемому поведению.

| Что вы видите                                                                   | Вероятная причина                                                                                                         | Где смотреть                                                                                                                                      |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| API Key недействителен / 401                                                    | Базовый URL и KEY не совпадают, либо KEY введён с ошибкой                                                                 | [Недействительный API Key](/ru/faq/invalid-api-key) · [Настройка Base URL](/ru/faq/base-url-config)                                               |
| Баланс ещё есть, но запросы не выполняются                                      | Механизм предварительного списания, либо слишком большое значение max\_tokens                                             | [Недостаточный баланс](/ru/faq/balance-insufficient) · [Предварительное списание](/ru/faq/pre-deduction-quota)                                    |
| Запрос завершается по тайм-ауту или обрывается в середине stream                | Слишком короткий тайм-аут клиента; модели с reasoning работают медленно                                                   | [Как избежать тайм-аутов API](/ru/faq/timeout-configuration)                                                                                      |
| В журнале видно успех и тарификацию, но до клиента ничего не дошло              | Время в журнале останавливается, когда шлюз завершает работу; проблема возникает ниже по цепочке или в сигнале завершения | [Журнал завершился, но ответа нет](/ru/faq/log-duration-vs-client-wait)                                                                           |
| Сайт / API возвращает 502                                                       | Контейнер сервиса ненадолго автоматически перезапускается; восстановление занимает около 1 минуты                         | [Что делать при 502](/ru/faq/website-502-error)                                                                                                   |
| Ошибки 429 из-за concurrency                                                    | Квота параллельных запросов исчерпана                                                                                     | [Лимиты параллельных запросов API](/ru/faq/api-concurrency)                                                                                       |
| Вывод обрывается в середине предложения                                         | max\_tokens не задан или слишком мал                                                                                      | [Что такое max\_tokens](/ru/faq/max-tokens)                                                                                                       |
| Конкретная модель не запускается                                                | Блокировка прав аккаунта или whitelist модели token                                                                       | [Почему я не могу использовать некоторые модели](/ru/faq/model-availability) · [Whitelist моделей token](/ru/faq/token-model-whitelist)           |
| Генерация изображений не выполняется / возвращает пустой результат              | Сработала система контроля безопасности контента Google                                                                   | [Сбои Nano Banana](/ru/faq/nano-banana-image-failure)                                                                                             |
| Вывод сильно отличается от эталонного изображения                               | Эталонные изображения нужно загружать в формате base64                                                                    | [Изображение отличается от эталона](/ru/faq/image-result-differs-from-reference)                                                                  |
| На изображении с белым фоном видны чёрные точки                                 | Известное поведение на маршруте AI Studio                                                                                 | [Артефакты на белом фоне](/ru/faq/white-background-image-artifacts)                                                                               |
| Хотите опрашивать результаты изображения по task ID                             | Генерация изображений доступна только синхронно                                                                           | [Есть ли async API для изображений](/ru/faq/image-async-api)                                                                                      |
| Модель утверждает, что она от другого поставщика / не может назвать свою версию | Самопознание модели ненадёжно                                                                                             | [Claude утверждает, что он Qwen](/ru/faq/claude-identity-confusion) · [Модели не знают свою версию](/ru/faq/model-version-identity)               |
| Веб-приложение умное, а API — нет                                               | В веб-приложении есть системные prompt и инструменты; API — это «голая» модель                                            | [Веб-приложение против API](/ru/faq/webapp-vs-api-difference)                                                                                     |
| На вашем KEY замечены незнакомые вызовы                                         | KEY мог быть скомпрометирован — отследите его и отключите                                                                 | [Разобраться с неожиданным использованием KEY](/ru/faq/troubleshoot-key-usage) · [Безопасное управление ключами](/ru/faq/key-security-management) |
| Тарификация не сходится                                                         | Тарификация по использованию и по вызовам читается по-разному                                                             | [Как читать тарификацию в журналах](/ru/faq/log-billing-explained) · [Коэффициент тарифа модели](/ru/faq/model-multiplier)                        |
| Загрузка изображений или видео медленная                                        | На некоторых серверах используется зарубежная маршрутизация CDN                                                           | [Загрузки через CDN медленные](/ru/faq/cdn-download-slow)                                                                                         |
| Нужен ли мне proxy?                                                             | Прямое подключение работает; proxy не требуется                                                                           | [Нужен ли мне proxy](/ru/faq/network-proxy)                                                                                                       |
| В GitHub login указано «Account already bound»                                  | Этот аккаунт GitHub привязан к другому email                                                                              | [Ошибка привязки GitHub](/ru/faq/github-bindng-bindng-error)                                                                                      |
| Вы забыли пароль                                                                | Сбросьте его по email или обратитесь в support за помощью                                                                 | [Забыли пароль](/ru/faq/forgot-password)                                                                                                          |
