# OpenClaw

> Локальный ИИ-ассистент с открытым исходным кодом, поддерживающий Telegram/WhatsApp/Discord и другие сервисы, с интеграцией APIYI для автономного выполнения задач

## Обзор

OpenClaw — это локальный AI-ассистент с открытым исходным кодом, созданный разработчиком Peter Steinberger в ноябре 2025 года. Он работает на вашем собственном компьютере и взаимодействует через различные chat-платформы, такие как Telegram, WhatsApp, Discord и другие, позволяя выполнять операции с файлами, команды в terminal, управлять браузером и решать другие задачи автоматизации.
