# Нужен ли мне прокси для использования API?

> Узнайте о способах сетевого доступа APIYI и о том, требуется ли прокси или VPN

## Краткий ответ

**Прокси не нужен. Доступно прямое подключение.**

APIYI поддерживает прямой доступ из материкового Китая без необходимости использовать прокси или VPN.

## Инструкции по сетевому доступу

### Пользователи в материковом Китае

<Info>
  **Прямое подключение без прокси**

  * ✅ Настройка прокси или VPN не требуется
  * ✅ Прямой доступ к `api.apiyi.com`
  * ✅ Выделенная линия корпоративного уровня для подключения из Китая
  * ✅ Низкая задержка, высокая стабильность

* 🌐 Прямая международная маршрутизация

## Часто задаваемые вопросы

### Почему я могу подключаться напрямую из Китая?

Мы используем соответствующие требованиям выделенные линии корпоративного уровня для подключения к Китаю, обеспечивая стабильный и быстрый доступ для пользователей в материковом Китае.

### В чем разница между HTTPS и HTTP?

* **HTTPS** (Рекомендуется): Зашифрованная передача, высокая безопасность данных
* **HTTP** (Альтернативный вариант): Передача в открытом виде, используйте только временно при возникновении проблем с HTTPS

### Как проверить, что сетевое подключение в норме?

Вы можете протестировать с помощью следующих команд:

```bash theme={null}
# Test API connection
curl -I https://api.apiyi.com

# Test DNS resolution
ping api.apiyi.com
```

Если вы получаете нормальные ответы, сетевое подключение в порядке.
