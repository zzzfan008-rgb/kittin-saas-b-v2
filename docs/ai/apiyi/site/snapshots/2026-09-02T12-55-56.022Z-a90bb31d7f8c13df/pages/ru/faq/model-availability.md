# Почему я не могу использовать некоторые модели?

> Пояснение по правам доступа к моделям APIYI, узнайте, как открыть доступ ко всем моделям и почему модели могут быть недоступны

## Группы пользователей и права доступа к моделям

### Автоматическое повышение для пользователей с пополнением

После пополнения платформа периодически переводит пользователей с пополнением в группы **VIP** или **SVIP**, что открывает доступ ко всем моделям.

<Info>
  **Автоматическое изменение группы**

  * Пользователи с пополнением автоматически назначаются в группы VIP/SVIP
  * Пользователи VIP/SVIP могут использовать все доступные модели на платформе
  * Изменение группы обычно завершается автоматически после пополнения
</Info>

## Конкретные причины недоступности моделей

### 1. Ограничения для моделей с высокой стоимостью

Большинство моделей можно использовать нормально, но для нескольких моделей с высокой стоимостью действуют ограничения для группы `default`:

* **Пример**: `claude-opus-4-20250514` и другие недавно выпущенные модели высокого класса
* **Причина**: Из-за высокой стоимости они пока не открыты для группы по умолчанию
* **Решение**: Пополните баланс, чтобы повысить группу до VIP/SVIP и получить доступ

<Warning>
  **Модели с высокой стоимостью**

  Некоторые последние или модели высокого класса доступны только платным пользователям из-за более высокой стоимости. Пополните баланс, чтобы получить полный доступ к моделям.
</Warning>

### 2. Модели, снятые с платформы

Некоторые модели недоступны, потому что официальные платформы прекратили их поддержку:

* **Пример**: `gpt-4.5-preview`
* **Причина**: Платформа OpenAI прекратила поддержку этой модели
* **Результат**: Мы также соответствующим образом прекратили ее поддержку и больше не можем предоставлять услугу

<Info>
  **Пояснение к снятию модели**

  Когда исходные провайдеры AI-сервисов (например, OpenAI, Anthropic и т. д.) прекращают поддержку модели, мы также синхронно прекращаем поддержку этой модели. Это обеспечивает стабильность и согласованность сервиса.
</Info>

## Описание групп пользователей

### Группа по умолчанию

* **Права**: Базовый доступ к model
* **Ограничения**: Некоторые модели с высокой ценой недоступны
* **Применимо**: Бесплатные пользователи и недавно зарегистрированные пользователи

### Группы VIP/SVIP

* **Права**: Доступ ко всем доступным model
* **Преимущества**: Включая новейшие и высококлассные модели
* **Как получить**: Автоматическая или ручная корректировка после пополнения

## Проверка доступности модели

### Подтвердите текущую группу

1. Войдите в консоль, чтобы просмотреть информацию об аккаунте
2. Подтвердите текущий уровень группы пользователя
3. Просмотрите доступный список моделей

### Проверьте вызовы модели

1. Используйте тестовую функцию в документации API
2. Попробуйте выполнить вызов конкретной модели
3. Просмотрите возвращенную информацию об ошибке

## Общие решения

1. **Пополнение и обновление**: наиболее прямое решение, открывает все модели
2. **Обратиться в службу поддержки**: для случаев, когда после пополнения группа не была скорректирована
3. **Выбрать альтернативную модель**: используйте другие доступные модели с аналогичными функциями
4. **Подождать обновлений**: следите за объявлениями платформы о запуске новых моделей
