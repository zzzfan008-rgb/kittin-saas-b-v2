# Сравнение VEO 3.1 Official и Reverse Channel

> Сравнение VEO 3.1 Official (эта серия) и существующего VEO 3.1 (обратный канал) по всем параметрам — тарификация, возможности, дерево принятия решений и рекомендации по каждому сценарию.

<Info>
  APIYI одновременно предоставляет два канала Veo 3.1. Эта страница поможет вам **выбрать по сценарию**: официальное качество + можно принять асинхронный опрос → **Официальный** (эта серия); чувствительно к стоимости + нужен синхронный поток или кадр-в-видео → **Обратный** ([VEO 3.1](/en/api-capabilities/veo/overview)). Оба канала можно **использовать параллельно под одной учетной записью** без конфликтов.
</Info>

| Параметр                          | **Официальный** (эта серия)                                                                             | **Реверсный** ([существующий VEO 3.1](/en/api-capabilities/veo/overview))                 |

| **Режим тарификации**             | Оплата за запрос (не зависит от длительности / разрешения)                                              | Оплата за запрос (не зависит от длительности / разрешения)                                |
| **Цена**                          | \$0.3 (быстрый) / \$1.2 (стандартный)                                                                   | \$0.15 (быстрый) / \$0.25 (стандартный) — **на 50–75% дешевле**                           |

| **Группа**                        | `Default`                                                                                               | `Default`                                                                                 |
| **Модель тарификации**            | Оплата за запрос ✅ / Priority с оплатой по мере использования ✅ (чистая оплата по мере использования ❌) | Оплата за запрос ✅ / Priority с оплатой по мере использования ✅                           |

## Дерево решений из трех шагов

<Steps>
  <Step title="В1: Нужна ли вам возможность преобразования кадра в видео?">
    * **Да** → Используйте **[VEO 3.1 (Реверс)](/en/api-capabilities/veo/overview)** `-fl` серии (например, `veo-3.1-landscape-fast-fl`); Официальный **пока не предоставляет** frame-to-video
    * **Нет** → Перейдите к В2
  </Step>

  <Step title="В2: Нужна ли вашему frontend полоса прогресса синхронизации с потоковой передачей?">
    * **Да** (пользовательский UI не может оставаться пустым) → Используйте **[VEO 3.1 (Реверс)](/en/api-capabilities/veo/overview)** `/v1/chat/completions` эндпоинт потоковой передачи
    * **Для backend-задач** (потребитель очереди, пакетная обработка) → Перейдите к В3
  </Step>

  <Step title="В3: Что в приоритете: бюджет или качество?">
    * **Сначала бюджет** (\$0.15 против \$0.3 — разница важна) → Используйте **[VEO 3.1 (Реверс)](/en/api-capabilities/veo/overview)**, цена на 50% ниже
    * **Сначала качество / стабильность** (финальная поставка, 4K, строгое следование инструкциям) → Используйте **Официальный** (эта серия) с `veo-3.1-generate-preview`
    * **Итерации / предпросмотр** → Используйте **Официальный** `veo-3.1-fast-generate-preview` (\$0.3) или **Реверс** `-fast` (\$0.15)
  </Step>
</Steps>

## Рекомендации по сценариям

| Бизнес-сценарий                                               | Рекомендуемый канал | Рекомендуемая модель                                           | Почему                                                               |
| ------------------------------------------------------------- | ------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------- |
| Пакетное производство матрицы коротких видео (100+/день)      | **Реверс**          | `veo-3.1-landscape-fast`                                       | Цена за единицу \$0.15, управляемая стоимость пакета                 |
| Финальная передача рекламы клиенту                            | **Официальный**     | `veo-3.1-generate-preview`                                     | Стабильное официальное качество + опционально 4K                     |
| Живой показ на фронтенде (нужна анимация загрузки)            | **Реверс**          | `veo-3.1-landscape-fast` + синхронизация streaming             | Видимый прогресс, без тревожного пустого ожидания                    |
| Статичный постер + frame-to-video → динамический клип         | **Реверс**          | `veo-3.1-landscape-fast-fl`                                    | Поддержка frame-to-video                                             |
| Кинематографичные клипы 4K (ключевой ассет)                   | **Официальный**     | `veo-3.1-generate-preview` + `resolution=4k`                   | Только Официальный поддерживает 4K                                   |
| Онбординг зарубежной команды (существующий Key без изменений) | **Официальный**     | `veo-3.1-fast-generate-preview`                                | Группа по умолчанию + оплата за каждый запрос, без лишних сложностей |
| Исследование стиля с одинаковым prompt и несколькими seed     | **Официальный**     | `veo-3.1-fast-generate-preview`                                | Опционально 4–6 сек, низкая стоимость итераций                       |
| Рабочий процесс итераций + финальной передачи                 | Смешанный           | Быстрые итерации на Реверс → финал по стандарту на Официальный | Дешевые итерации, стабильная передача                                |

## Могу ли я использовать оба канала вместе?

**Безусловно**. Два канала маршрутизируются независимо:

* В рамках одного аккаунта **один Token** (в группе по умолчанию) может одновременно вызывать оба канала; тарификация ведется за каждый вызов
* Переключайте поле `model` в вашем бизнес-коде по мере необходимости:
  * Чтобы использовать официальный канал → `veo-3.1-fast-generate-preview` / `veo-3.1-generate-preview`
  * Чтобы использовать обратный канал → `veo-3.1-fast` / `veo-3.1-landscape` / `veo-3.1-fl` и т. д.

<Tip>
  **Рекомендуемая схема**: направляйте «критически важную доставку» в официальный канал, а «итерации / пакетные предпросмотры / синхронизацию UI» — в обратный канал. Единая учетная запись, прозрачная тарификация, взаимодополняющие возможности.
</Tip>
