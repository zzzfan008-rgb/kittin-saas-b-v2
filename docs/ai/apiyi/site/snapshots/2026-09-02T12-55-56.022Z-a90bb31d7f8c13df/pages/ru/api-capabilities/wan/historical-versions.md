# Исторические версии Wan (Wan2.6)

> Примечания и руководство по миграции для серии Wan2.6 (включая wan2.6-r2v-flash): она использует тот же эндпоинт и схему, что и Wan2.7, поэтому для вызова достаточно просто изменить имя модели.

Эта страница предназначена для **пользователей, которые сейчас используют Wan2.6**, и объясняет различия между версиями, а также путь миграции на Wan2.7. Новым пользователям следует начать с [Обзора Wan](/ru/api-capabilities/wan/overview).

## Обзор версий

| Версия     | Статус                 | Эндпоинт / протокол                              | Рекомендуется для                                                                                            |
| ---------- | ---------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| **Wan2.7** | ✅ Рекомендуется сейчас | `/wan/api/v1/...video-synthesis`                 | Первый выбор для новых интеграций, наиболее полный набор функций (audio drive, референс нескольких объектов) |
| **Wan2.6** | 🟡 Обслуживание        | То же, что у Wan2.7 (меняется только имя модели) | Существующий код для Wan2.6 или нужен низколатентный уровень `r2v-flash`                                     |

<Info>
  Wan2.6 и Wan2.7 **используют один и тот же сквозной эндпоинт DashScope и одну и ту же структуру запроса**. Чтобы выполнить миграцию, **просто измените поле `model` с `wan2.6-*` на `wan2.7-*`** и оставьте остальную часть тела без изменений. Точные даты запуска и актуальная доступность указаны в списке моделей в [консоли APIYI](https://api.apiyi.com/token).
</Info>

## Модели Wan2.6

| Идентификатор модели | Возможность                                   | Примечания                                                                                                                                                                       |
| -------------------- | --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `wan2.6-t2v`         | Текст в видео                                 | Соответствует `wan2.7-t2v`                                                                                                                                                       |
| `wan2.6-i2v`         | Изображение в видео                           | Соответствует `wan2.7-i2v`                                                                                                                                                       |
| `wan2.6-r2v`         | Референс в видео                              | Соответствует `wan2.7-r2v`                                                                                                                                                       |
| `wan2.6-r2v-flash`   | Референс в видео (уровень с низкой задержкой) | Быстрый уровень, доступный только в Wan2.6: более быстрая генерация, более низкая цена за единицу, идеально подходит для итераций, отладки и пакетных предварительных просмотров |

<Tip>
  `wan2.6-r2v-flash` — это облегченный быстрый уровень в серии Wan2.6, без аналога в 2.7. Используйте его на этапе разработки, чтобы быстро проверять prompt и результаты по референсному изображению, а затем переключитесь на `wan2.7-r2v` для финального рендера после завершения настройки.
</Tip>

## Советы по миграции

<Steps>
  <Step title="Оцените различия">
    Wan2.7 сильнее в ссылках на несколько объектов, голосовых ссылках (`reference_voice`) и аудиодрайве. Если вы используете только базовые t2v / i2v / r2v, стоимость миграции практически нулевая.
  </Step>

  <Step title="Проведите сравнение на одинаковых условиях">
    Используя один и тот же набор prompt и медиаактивов, отправьте задачи `wan2.6-*` и `wan2.7-*` отдельно, сравните качество и согласованность, а затем решите, стоит ли переходить.
  </Step>

  <Step title="Переходите постепенно">
    Просто измените поле `model`. Эндпоинт, заголовки, структура `input` / `parameters`, а также поток опроса и загрузки идентичны, без breaking change.
  </Step>
</Steps>

## Пример устаревшего вызова

```python theme={null}
import requests

# Calling Wan2.6: the only difference from Wan2.7 is the model name
body = {
    "model": "wan2.6-r2v-flash",   # change to wan2.7-r2v to upgrade to 2.7
    "input": {
        "prompt": "The reference image: a girl walking slowly through a garden, cinematic lighting",
        "media": [{"type": "reference_image", "url": "https://your-cdn.com/girl.png"}],
    },
    "parameters": {"resolution": "720P", "duration": 5, "prompt_extend": True},
}
resp = requests.post(
    "https://api.apiyi.com/wan/api/v1/services/aigc/video-generation/video-synthesis",
    json=body,
    headers={"Authorization": "Bearer sk-your-api-key", "Content-Type": "application/json",
             "X-DashScope-Async": "enable"},
    timeout=30,
)
print(resp.json()["output"]["task_id"])
```

## Различия в тарификации

<Note>
  Настройка тарификации и группы для Wan2.6 и Wan2.7 скоро появится и будет добавлена на эту страницу. Как общее правило: быстрые тарифы, такие как `r2v-flash`, имеют более низкую цену за единицу, тогда как более высокое разрешение / большая длительность стоят дороже. Актуальные цены являются определяющими на странице тарификации [консоли APIYI](https://api.apiyi.com/token).
</Note>
