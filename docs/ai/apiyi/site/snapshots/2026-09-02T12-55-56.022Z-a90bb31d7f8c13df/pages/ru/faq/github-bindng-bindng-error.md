# Вход через GitHub показывает «Учетная запись уже привязана»?

> Исправьте ошибку «Эта учетная запись GitHub уже привязана» при входе в APIYI через GitHub

## Быстрый ответ

Сначала войдите в `github.com` в **том же браузере**, затем используйте вход в один клик через GitHub на сайте APIYI. **Обязательно используйте браузер Chrome**.

## Симптом

При попытке войти в APIYI с помощью своей учетной записи GitHub вы видите сообщение об ошибке:

> Эта учетная запись GitHub уже привязана

Это не позволяет вам войти в систему обычным образом.

## Шаги решения

<Steps>
  <Step title="Откройте браузер Chrome">
    Убедитесь, что для этого процесса вы используете **браузер Chrome**. Не используйте другие браузеры (например, Safari, Firefox и т. д.), чтобы процесс входа работал корректно.
  </Step>

  <Step title="Войдите в GitHub">
    Откройте `github.com` в Chrome и убедитесь, что вы вошли в нужную учетную запись GitHub.

    Если ранее вы были вошли в другую учетную запись GitHub, сначала выйдите, а затем войдите в учетную запись, привязанную к APIYI.
  </Step>

  <Step title="Войдите в APIYI">
    В **том же браузере Chrome** откройте веб-сайт APIYI и нажмите кнопку «GitHub One-Click Login», чтобы завершить вход.

    <Warning>
      Вы должны выполнить оба шага в одном и том же браузере. Не используйте разные браузеры для каждого шага.
    </Warning>
  </Step>
</Steps>

## Часто задаваемые вопросы

<AccordionGroup>
  <Accordion title="Почему мне нужно использовать браузер Chrome?">
    У Chrome лучшая совместимость с потоком входа GitHub OAuth. В других браузерах могут возникать проблемы с Cookie или синхронизацией сеанса, из-за которых вход не удается.
  </Accordion>

  <Accordion title="Я использую Chrome, но это все равно не работает. Что мне делать?">
    Попробуйте следующее:

    * Очистите кэш и cookie Chrome
    * Убедитесь, что Chrome не находится в режиме инкогнито
    * Проверьте, не блокируют ли какие-либо расширения браузера сторонние cookie
    * Выйдите из GitHub, войдите снова и еще раз попробуйте вход APIYI в один клик
  </Accordion>

  <Accordion title="Как изменить привязанный аккаунт GitHub?">
    Если вам нужно изменить привязанный аккаунт GitHub, обратитесь в службу поддержки за помощью.
  </Accordion>
</AccordionGroup>
