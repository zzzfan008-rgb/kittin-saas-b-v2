# Аннотатор изображений - узел ComfyUI

> Интерактивный узел для аннотаций, созданный сообществом: рисуйте точки/рамки/многоугольники прямо на изображениях, чтобы отмечать области редактирования — отличное ускорение для написания prompt при использовании с Nano Banana.

## Обзор

`comfyui-image-annotator` — это **интерактивный узел ComfyUI для аннотации изображений**, внесенный участником сообщества luckdvr. Его ключевая ценность: **снижение порога для написания prompt**. Вместо того чтобы пытаться описать «замените красную кнопку в левом верхнем углу», вы просто **обводите, щелкаете или выделяете рамкой** область, которую хотите изменить, и позволяете модели точно увидеть, где нужно редактировать. Он предназначен для размещения **перед** узлом Nano Banana Pro в трехэтапном пайплайне: «изображение → аннотация → API».

<Tip>
  **Рекомендуемый workflow: Изображение → Аннотатор → узел API**

  ```
  LoadImage  ─►  ImageAnnotator  ─►  Luck Nano Banana Pro  ─►  SaveImage
                 (mark the area to edit)      (edit per annotation + prompt)
  ```

  Лучше всего подходит для **пользователей, которым сложно писать prompt на английском или точно описывать «что и где редактировать»**. Пусть мышь отвечает за *где*, а короткий prompt в одну строку — за *что*.
</Tip>

## Поддерживаемые модели APIYI

Этот узел сам по себе **не вызывает никакой API** — он только добавляет аннотации. Аннотированное изображение можно передать любой модели APIYI, которая принимает изображение на вход. Лучшие сочетания:

| Model                      | Model ID                     | Назначение                                                    | Документация API                                        |
| -------------------------- | ---------------------------- | ------------------------------------------------------------- | ------------------------------------------------------- |
| Nano Banana Pro            | `gemini-3-pro-image-preview` | Редактирование / смешивание изображений с привязкой к области | [View](/ru/api-capabilities/nano-banana-image/overview) |
| Семейство Gemini / Qwen-VL | различные                    | Понимание изображений, VQA, опирающаяся на аннотации          | [View](/ru/api-capabilities/gemini/native)              |

## Сведения об узле

### Вход

| Parameter | Type  | Required | Description                   |
| --------- | ----- | -------- | ----------------------------- |
| `image`   | IMAGE | Yes      | Изображение для аннотирования |

### Выходы

| Output             | Type   | Description                                                                                       |
| ------------------ | ------ | ------------------------------------------------------------------------------------------------- |
| `annotated_image`  | IMAGE  | Изображение с отрисованными метками аннотаций (передавайте напрямую в последующий API-узел)       |
| `annotations_json` | STRING | Строка JSON, описывающая позиции/типы аннотаций (для узлов, которым нужен структурированный ввод) |

## Установка

<Steps>
  <Step title="Шаг 1: Склонируйте в custom_nodes">
    ```bash theme={null}
    cd ComfyUI/custom_nodes
    git clone https://github.com/luckdvr/comfyui-image-annotator.git
    ```
  </Step>

  <Step title="Шаг 2: Перезапустите ComfyUI">
    Никаких дополнительных зависимостей — используется встроенное окружение ComfyUI. После перезапуска найдите `ImageAnnotator` в палитре узлов.
  </Step>

  <Step title="Шаг 3: Подключите узлы в трехэтапном рабочем процессе">
    Подключите узлы по порядку:

    ```
    LoadImage → ImageAnnotator → Luck Nano Banana Pro → SaveImage
    ```

    Обведите область для редактирования на `ImageAnnotator` холсте, затем в downstream API-узле введите простой prompt (например, «замените отмеченную область на красный спортивный автомобиль») и запустите.
  </Step>
</Steps>

## Примеры использования

### Пример 1: Локальная замена (для начинающих)

<Steps>
  <Step title="Загрузите исходное изображение">
    `LoadImage` — загрузите фото вашей гостиной
  </Step>

  <Step title="Разметьте целевую область">
    `ImageAnnotator` — нарисуйте прямоугольник вокруг пустого места рядом с диваном
  </Step>

  <Step title="Напишите prompt в одну строку">
    `Luck Nano Banana Pro` — prompt: "Поставьте зеленое комнатное растение в отмеченную область"
  </Step>

  <Step title="Запустите и сохраните">
    Модель добавляет растение точно в выделенную вами область и оставляет остальное без изменений
  </Step>
</Steps>

### Пример 2: Точные правки в нескольких областях

Используйте **polygon** для обводки одежды + **point** для расположения шляпы + **rectangle** для фона, затем укажите prompt:

```
Change the clothing in polygon 1 to a black suit, add a hat at point 1,
replace the background in rectangle 1 with a sunset beach
```

Модель выполнит отдельные правки в каждой области.

### Пример 3: Визуальные вопросы и ответы / понимание

С Gemini / Qwen-VL: попросите модель объяснить «что за объект находится внутри прямоугольника и какова его роль в сцене». Разметка дает модели точные визуальные ориентиры.

## Частые вопросы

<AccordionGroup>
  <Accordion title="Почему это отлично подходит тем, кому трудно с prompt?">
    Традиционное редактирование изображений требует описывать *и* где, *и* как — это непросто для тех, для кого английский не родной, и для новичков в AI.

    С этим узлом **информация о расположении поступает от мыши**, поэтому prompt нужно описывать только *что* изменить. Описания, которые раньше занимали 3-5 предложений, превращаются в одну короткую фразу.
  </Accordion>

  <Accordion title="Метки аннотации влияют на качество генерации?">
    Да — **в хорошем смысле**. Большинство multimodal-моделей (Nano Banana, Gemini, Qwen-VL) распознают символы аннотаций на изображении как «обозначенные пользователем целевые области» и точнее следуют инструкциям.

    Если вас беспокоит визуальное перекрытие, уменьшите толщину линии и используйте полупрозрачную заливку в настройках узла.
  </Accordion>

  <Accordion title="Узел не найден после установки?">
    1. Подтвердите каталог: `ComfyUI/custom_nodes/comfyui-image-annotator`
    2. Полностью перезапустите ComfyUI (обновления интерфейса недостаточно)
    3. Проверьте консоль ComfyUI на наличие ошибок
  </Accordion>

  <Accordion title="Можно ли выводить только JSON без рендеринга?">
    Да — просто подключите только выход `annotations_json` дальше по цепочке. Полезно, когда нужно передать координаты в пользовательский скрипт для постобработки.
  </Accordion>

  <Accordion title="Лучшие практики при использовании вместе с Luck Nano Banana Pro?">
    Рекомендуемая схема: `LoadImage → ImageAnnotator → Luck Nano Banana Pro`

    * Подключите `ImageAnnotator.annotated_image` к `Luck Nano Banana Pro.image_01`
    * Используйте prompt на естественном языке, описывающий «что делать с отмеченной областью»
    * Если первый результат неточен, используйте `retry_times` или режимы seed в Luck Nano Banana Pro, чтобы запустить заново
  </Accordion>
</AccordionGroup>
