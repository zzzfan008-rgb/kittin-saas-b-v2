# Как посмотреть мои записи вызовов?

> Руководство по просмотру журнала вызовов APIYI: узнайте, как просматривать записи вызовов API и детали тарификации

## Доступ к журналам вызовов

Перейдите на страницу «Журналы» в верхней навигации: [https://api.apiyi.com/log](https://api.apiyi.com/log)

В разделе журналов вы можете просматривать:

* **Запись об успешном выполнении каждого вызова**
* **Журналы ошибок API-вызовов**
* **Подробные пояснения по тарификации**

## Содержимое записи лога

### Записи успешных вызовов

Каждый успешный запрос API записывает следующую информацию:

* **Время запроса**: временная метка вызова с точностью до секунды
* **Используемая модель**: модель ИИ, использованная для этого вызова
* **Количество token**: статистика по количеству входных и выходных token
* **Сумма тарификации**: конкретная стоимость этого вызова
* **Статус вызова**: статус выполнения запроса

### Логи ошибок

Неудачные вызовы API записывают:

* **Тип ошибки**: конкретная классификация ошибки
* **Сообщение об ошибке**: подробное описание ошибки
* **Время возникновения**: временная метка возникновения ошибки
* **Связанные параметры**: информация о параметрах запроса, вызвавших ошибку

## Политика конфиденциальности и данных

<Info>
  **Защита конфиденциальности данных**

  В целях защиты конфиденциальности и с учетом затрат на хранение данных наша система журналирования:

  * **Не записывает подробное содержимое входных и выходных данных**
  * **Сохраняет только базовую информацию о количестве token**
  * **Хранит только необходимые данные журнала, требуемые для тарификации**
  * **Обеспечивает безопасность конфиденциальности данных пользователей**
</Info>

## Советы по просмотру журналов

### Функции фильтрации

* **Фильтр по диапазону времени**: Просмотр записей вызовов за определенный период времени
* **Фильтр по модели**: Просмотр использования конкретных моделей AI
* **Фильтр по статусу**: Различение успешных и неудачных записей вызовов

### Анализ тарификации

* **Стоимость одного вызова**: Конкретная стоимость каждого вызова API
* **Эффективность использования token**: Анализ соотношения входных и выходных token
* **Сравнение стоимости моделей**: Статистика стоимости использования для разных моделей

## Частые вопросы

### Почему я не вижу конкретное содержимое беседы?

Чтобы защитить конфиденциальность пользователей и снизить расходы на хранение, мы записываем только базовую информацию, связанную с тарификацией, а не конкретное содержимое ввода-вывода.

### Как долго хранятся журналы?

**Текущий месяц плюс два предыдущих календарных месяца**; более старые полные месяцы очищаются 5-го числа каждого месяца. Полные правила и рекомендации по экспорту: [политика хранения и очистки журналов](/ru/faq/log-retention-policy).

### Как экспортировать записи вызовов?

При необходимости отфильтруйте данные на странице журналов, затем используйте **асинхронный экспорт**. Задача выполняется в фоновом режиме, и вы скачаете файл после завершения — это подходит для сверки и архивов аудита.

Обратите внимание, что кнопки Export и Сводка по тарификации используют разные часовые пояса, а часовой пояс аккаунта должен оставаться по умолчанию UTC+0 — см. [Что мне следует знать о настройках часового пояса журналов и экспорте данных?](/ru/faq/log-timezone-and-export).
