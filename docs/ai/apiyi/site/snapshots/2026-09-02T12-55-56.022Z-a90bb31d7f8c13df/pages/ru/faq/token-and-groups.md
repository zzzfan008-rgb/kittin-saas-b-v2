# Tokens & Группы

> Узнайте, что делает APIYI token (ключ API), как его создать и редактировать, а также как работают группы — включая группы по умолчанию и резервные группы.

## Что такое token (API KEY)

token — это **ключ API**, который вы используете для вызова APIYI, начиная с `sk-`. Это учетные данные для подтверждения вашей личности и прав доступа. Его основные функции включают:

<CardGroup cols={2}>
  <Card title="Аутентификация" icon="shield">
    Каждый вызов API должен содержать token для проверки вашей личности и учетной записи.
  </Card>

  <Card title="Управление квотой и разрешениями" icon="sliders-horizontal">
    Назначайте отдельную квоту, дату истечения, разрешенные модели и группы для каждого token.
  </Card>

  <Card title="Статистика использования" icon="chart-line">
    Отслеживайте расходы каждого token, оставшуюся квоту и журналы вызовов независимо.
  </Card>

  <Card title="Гибкое распределение" icon="users">
    Создавайте отдельные tokens для разных проектов или участников команды.
  </Card>
</CardGroup>

<Info>
  После регистрации система автоматически создает **token по умолчанию**, который готов к использованию сразу. Вы также можете создавать дополнительные tokens по мере необходимости.
</Info>

## Как создать token

<Steps>
  <Step title="Откройте страницу Token">
    Откройте страницу «Token» в верхней навигации: [https://api.apiyi.com/token](https://api.apiyi.com/token)
  </Step>

  <Step title="Нажмите «New»">
    Нажмите кнопку «New» в правом верхнем углу, чтобы открыть диалог создания token.
  </Step>

  <Step title="Заполните сведения о token">
    Укажите имя token, квоту (необязательно, без ограничений), срок действия (необязательно, без срока истечения), режим тарификации и группу (см. ниже).
  </Step>

  <Step title="Сохраните и скопируйте ключ">
    После сохранения нажмите значок копирования справа от token, чтобы скопировать полный `sk-` ключ.
  </Step>
</Steps>

<Tip>
  При создании token вам **не нужно задавать разрешенные модели**. Применяется механизм белого списка: оставьте его пустым, и token сможет использовать все 400+ моделей; задайте его, и token будет ограничен этими моделями. См. [Белый список моделей token](/ru/faq/token-model-whitelist).
</Tip>

## Редактирование token и просмотр примеров кода

Нажмите **меню управления (значок гаечного ключа)** в столбце «Действия», чтобы развернуть все операции:

<img className="hidden dark:block" src="https://mintcdn.com/apiyillc/OMY6ItCc2mC1yzgA/images/apiyi-token-simple-code.png?fit=max&auto=format&n=OMY6ItCc2mC1yzgA&q=85&s=067d8d551cd1d8aaebb833932e6632a5" alt="Меню управления token и пример запроса" width="1496" height="902" data-path="images/apiyi-token-simple-code.png" />

| Действие                                     | Описание                                                                                                              |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Отключить token**                          | Временно отключить token; вызовы будут отклоняться                                                                    |
| **Редактировать token**                      | Изменить имя, квоту, срок действия, режим тарификации, группу и т. д.                                                 |
| **Пример запроса**                           | **Просмотр примеров кода** — готовый к запуску код вызова на нескольких языках (curl, Python и т. д.) для этого token |
| **Журнал token**                             | Просмотреть записи вызовов этого token                                                                                |
| **Поделиться token / Настройка в один клик** | Быстро поделиться token или интегрировать его со сторонними инструментами                                             |

<Note>
  «Пример запроса» — это точка входа для **примера кода**. Он генерирует готовый к запуску код вызова с уже подставленным текущим token, поэтому вам не нужно вручную собирать KEY и эндпоинт — идеально для быстрого тестирования и интеграции.
</Note>

## Будет ли совместное использование одного token несколькими людьми приводить к лимиту запросов?

Частый вопрос от клиентов: **«Если один token используют несколько человек, будет ли действовать лимит запросов?»**

Ответ: **сам token не имеет лимита запросов**. Лимит запросов определяется **аккаунтом** — независимо от того, сколько у вас token или сколько людей ими пользуются. Один token, которым пользуются 10 человек, работает точно так же, как 10 token, которые использует по одному человеку.

<CardGroup cols={2}>
  <Card title="RPM (запросов в минуту)" icon="gauge">
    В общем, один аккаунт с нагрузкой до **100 RPM** — это вполне нормально: этого хватает для подавляющего большинства команд и приложений.
  </Card>

  <Card title="TPM (tokens в минуту)" icon="infinity">
    **TPM не применяется**, поэтому вам не нужно беспокоиться о длинных context window или большом объеме token при высокой параллельности, которые могут вызвать лимиты.
  </Card>
</CardGroup>

<Tip>
  Совместное использование token не влияет на лимиты запросов, но с точки зрения **управления** мы по-прежнему рекомендуем отдельные token для каждого участника или проекта: у каждого будет своя квота, журналы вызовов и статистика расходов.
</Tip>

## Что такое группа

**Группа — это «ресурсный канал», который вы можете выбрать для token.** Разные группы соответствуют разным upstream-ресурсам, доступным диапазонам моделей и коэффициентам тарифа и **доступны для выбора пользователями**.

Иными словами: одна и та же модель может обслуживаться через несколько upstream-каналов, а группа позволяет вам выбрать, какой канал использовать. **Для разных моделей могут требоваться разные группы**, поэтому правильный выбор группы гарантирует, что вызов сработает и вы получите соответствующую скидку.

<Info>
  В подавляющем большинстве случаев вам достаточно **группы по умолчанию (Default)** — она покрывает все модели, включая текстовые модели, серию NanoBanana, Veo 3.1 и большинство остальных.
</Info>

## Группа по умолчанию и резервные группы

Один token может иметь до **3 групп**: **1 группу по умолчанию + 2 резервные группы**.

<CardGroup cols={2}>
  <Card title="Группа по умолчанию (основная)" icon="circle-check">
    Группа, которую token использует первой; подходит для большинства моделей. У каждого token должна быть 1 группа по умолчанию.
  </Card>

  <Card title="Резервные группы (резерв)" icon="life-buoy">
    Резервные каналы, которые автоматически активируются, когда группа по умолчанию не может обработать запрос. До 2, что повышает успешность вызовов.
  </Card>
</CardGroup>

<img className="block dark:hidden" src="https://mintcdn.com/apiyillc/UCijFWltmtlBUyvg/images/nano-banana-token-fallback-setup.png?fit=max&auto=format&n=UCijFWltmtlBUyvg&q=85&s=60e569c034776ae83d9866fcfac343c0" alt="Выбор группы и резервной группы" width="1276" height="1176" data-path="images/nano-banana-token-fallback-setup.png" />

<img className="hidden dark:block" src="https://mintcdn.com/apiyillc/UCijFWltmtlBUyvg/images/nano-banana-token-fallback-setup.png?fit=max&auto=format&n=UCijFWltmtlBUyvg&q=85&s=60e569c034776ae83d9866fcfac343c0" alt="Выбор группы и резервной группы" width="1276" height="1176" data-path="images/nano-banana-token-fallback-setup.png" />

В диалоге создания/редактирования token:

* **Выбрать группу**: назначает группу по умолчанию (основную), `Default` по умолчанию
* **Резервная группа**: добавьте 1–2 резервные группы, которые подхватывают обработку, когда основная недоступна

<Tip>
  **Группа влияет на коэффициент тарифа token и доступные модели.** Выбирайте исходя из моделей, которые вы реально используете. Если не уверены, оставьте значение по умолчанию `Default`.
</Tip>

## Разным моделям нужны разные группы

Группа по умолчанию подходит для большинства моделей, но некоторым моделям (особенно **видео-моделям**) требуется выделенная группа:

| Модель / сценарий                                                 | Группа для выбора   |
| ----------------------------------------------------------------- | ------------------- |
| Текст, мультимодальные, NanoBanana, Veo 3.1 и большинство моделей | **По умолчанию**    |
| Официальное видео Sora 2                                          | **Sora2Official**   |
| Видео-серия Alibaba Wan & HappyHorse                              | **Wan\&HappyHorse** |

<Warning>
  При вызове официальных Sora 2, Wan\&HappyHorse и других моделей с выделенной группой модель будет недоступна, если у token нет соответствующей группы. Рассмотрите возможность добавить часто используемую выделенную группу как резервный вариант или создайте отдельный token для этих моделей.
</Warning>
