# Есть ли интеграция в один клик?

> Да — но это не кнопка. Вы передаёте документацию вашему AI coding agent, и он выполняет интеграцию за вас.

## Краткий ответ

**Да, но это не кнопка.**

Мы не предлагаем традиционную интеграцию в формате «нажал один раз — и всё настроено». Разные модели используют разные протоколы, параметры и методы аутентификации, поэтому такая кнопка могла бы покрыть только базовый чат — но не реальные сценарии.

Вместо этого есть лучший путь: **передайте документацию вашему ИИ-агенту для написания кода и позвольте ему выполнить интеграцию**. Вам нужно только зарегистрировать аккаунт и скопировать ключ. Выбор модели, правильное указание base URL, написание кода и его отладку можно полностью поручить ИИ.

## Три способа сделать это

<Steps>
  <Step title="Установите skill для всего сайта (рекомендуется)">
    Попросите вашего агента выполнить `npx skills add https://docs.apiyi.com`, чтобы установить skill APIYI. Если эта команда не сработает, укажите ему `https://docs.apiyi.com/skill.md` и дайте ему прочитать файл напрямую.

    Этот файл написан специально для машин: эндпоинты, аутентификация, правило именования model, известные подводные камни и чеклист проверки. Его чтение дает агенту все, что ему нужно.
  </Step>

  <Step title="Отправьте одну страницу в AI">
    На каждой странице документации есть кнопка **Скопировать страницу** в **правом верхнем углу**. Стрелка рядом с ней также предлагает **Открыть в ChatGPT / Claude / Perplexity / Google AI Studio**.

    Когда у вас возникает проблема с конкретной model, откройте эту страницу, нажмите **Скопировать страницу** и отправьте ее в AI вместе с вашей ошибкой. Это самый быстрый доступный путь отладки.
  </Step>

  <Step title="Подключите его как MCP server">
    Добавьте `https://docs.apiyi.com/mcp` как MCP server, и ваш агент сможет по запросу искать текущее содержимое этого сайта вместо того, чтобы вы каждый раз вставляли документацию.
  </Step>
</Steps>

<Info>
  **Почему это лучше кнопки**: кнопка в один клик может покрывать только фиксированный набор сценариев. AI может прочитать реальный стек вашего проекта, написать код, который будет в нем работать, и справиться с тем, с чем кнопка никогда бы не справилась — настройка тайм-аута, логика повторных попыток, обработка ошибок.
</Info>

## Почему не кнопка в один клик?

Интеграция моделей отличается по нескольким параметрам:

* **Разные протоколы**: OpenAI, Claude, Gemini и другие используют разные API-протоколы
* **Разные параметры**: Поля запроса и структуры ответа различаются у разных моделей
* **Разная аутентификация**: Заголовки авторизации и их расположение не стандартизированы
* **Разные возможности**: Возможности вроде Function Calling, кэширования промптов и веб-поиска реализованы по-разному у каждой модели

Принудительное построение сценария в один клик обычно охватывает только базовый чат, чего недостаточно для реального применения.

<Note>
  **Вы всё равно регистрируете аккаунт сами.** Нет такого API, который позволил бы агенту самостоятельно создать аккаунт или выпустить key — аккаунты и тарификация связаны с идентификацией и контролем рисков, для чего нужен человек. Но всё — от «у меня есть key» до «код работает» — можно передать AI.
</Note>
