# Chatbox AI

> Руководство по интеграции кроссплатформенного AI-клиентского приложения

Chatbox AI — это мощное кроссплатформенное AI-приложение-клиент, которое поддерживает несколько крупных языковых моделей и API. Через APIYI вы можете получить доступ к различным популярным AI-моделям в Chatbox, сохраняя при этом защиту конфиденциальности за счет локального хранения.

## Быстрый старт

### Загрузка и установка

Chatbox AI поддерживает установку на нескольких платформах:

* **Desktop**: Windows, macOS, Linux
* **Mobile**: iOS, Android
* **Web**: прямой доступ через браузер

Посетите [Официальный сайт Chatbox AI](https://chatboxai.app/en), чтобы загрузить версию, подходящую для вашей платформы.

### Настройка APIYI

#### Шаг 1: Откройте настройки

1. Запустите приложение Chatbox AI
2. Нажмите значок настроек (⚙️) в левом нижнем углу
3. Откройте интерфейс «Конфигурация модели»

#### Шаг 2: Добавьте пользовательского провайдера

<img src="https://mintcdn.com/apiyillc/OMY6ItCc2mC1yzgA/images/chatbox-setting.png?fit=max&auto=format&n=OMY6ItCc2mC1yzgA&q=85&s=dd787d3ef7889fbe04f9d2c3143b5cc5" alt="Интерфейс настроек Chatbox AI - пример конфигурации APIYI" width="2708" height="1536" data-path="images/chatbox-setting.png" />

Следуя интерфейсу настройки, показанному выше, выполните следующие шаги:

1. Нажмите кнопку **+ Add** в разделе «Поставщик модели»

2. Заполните информацию о провайдере:
   * **Name**: APIYI (имя можно изменить)
   * **API Mode**: выберите **OpenAI API Compatible**
   * **API Key**: введите ваш ключ APIYI
   * **API Host**: `https://api.apiyi.com/v1`
   * **API Path**: `/chat/completions` (значение по умолчанию)

3. **Дополнительная настройка** (необязательно):
   * Включите опцию «Improve Network Compatibility» (как показано на изображении)
   * Можно настроить отдельные эндпоинты генерации изображений

<Info>
  **Ключевые моменты настройки**

  * Поле API Host соответствует Base URL и должно включать суффикс `/v1`
  * Поле API Path указывает конкретный путь эндпоинта
  * API Key можно получить в [консоли APIYI](https://api.apiyi.com)
  * После настройки нажмите кнопку **+ New** в правом нижнем углу, чтобы добавить модель
</Info>

#### Шаг 3: Выберите модель

После завершения настройки вы сможете выбрать модель в интерфейсе чата.

## Основные возможности

### Синхронизация между платформами

Основные преимущества Chatbox AI:

* **Локальное хранение**: данные полностью хранятся локально, что защищает конфиденциальность
* **Кроссплатформенный доступ**: переключайтесь между разными устройствами
* **Офлайн-функциональность**: некоторые функции поддерживают офлайн-использование

### Управление беседами

**Интеллектуальные функции беседы**:

* Сохранение контекста многоходовой беседы
* Поиск и управление историей бесед
* Экспорт бесед (Markdown, PDF)
* Библиотека prompt и ссылки на сообщения

### Обработка документов

**Возможности понимания документов**:

* Загрузка документов PDF, TXT, DOCX
* Понимание и анализ изображений
* Рендеринг LaTeX и Markdown
* Подсветка кода и предпросмотр

### Генерация изображений

**Создание изображений с помощью AI**:

* Поддерживает генерацию изображений моделями серии DALL-E
* Настраиваемые выделенные эндпоинты генерации изображений
* Поддерживает различные размеры и стили изображений
* Функция пакетной генерации изображений

**Настройка генерации изображений**:

1. Добавьте выделенного провайдера генерации изображений в настройках
2. Используйте стандартный эндпоинт `/images/generations`
3. Прямо опишите требования к изображению в чате
4. Система автоматически вызывает API генерации изображений

### Дополнительные настройки

**Настройка параметров**:

```yaml theme={null}
Conversation Parameter Settings:
  - Temperature: 0.7        # Creativity control (reasoning models GPT-5 only use 1)
  - Max Tokens: 4096       # Maximum output length
  - Top P: 0.9            # Sampling parameter (reasoning models gpt-5 only use 1)
  - Context Length: 8192   # Context length
```

## Советы по использованию

### Оптимизация prompt

В Chatbox AI есть встроенная библиотека prompt, а также вы можете создавать пользовательские prompt:

```markdown theme={null}
# Programming Assistant
You are an experienced software engineer, please help me:
- Write high-quality code
- Explain complex concepts
- Provide best practice recommendations

# Output Format
Please format code using code blocks and provide detailed comments.
```

### Защита конфиденциальности

Chatbox AI придерживается философии «privacy by design»:

* Данные хранятся локально, не загружаются в cloud
* Поддерживает self-hosted API endpoint
* Может использоваться полностью offline (с локальными моделями)

## Расширенная конфигурация

### Пользовательские API-эндпоинты

Помимо базовой функции чата, вы также можете настроить выделенные эндпоинты для генерации изображений:

#### Конфигурация эндпоинта Chat Completion

```yaml theme={null}
Basic Chat Configuration:
  Provider Name: APIYI
  API Mode: OpenAI API Compatible
  API Key: sk-your-apiyi-key
  API Host: https://api.apiyi.com/v1
  API Path: /chat/completions
```

#### Конфигурация эндпоинта генерации изображений

**Способ 1: используйте выделенный Image API**

```yaml theme={null}
Image Generation Configuration:
  Provider Name: APIYI-Image
  API Mode: OpenAI API Compatible
  API Key: sk-your-apiyi-key
  API Host: https://api.apiyi.com/v1
  API Path: /images/generations  # Standard image generation endpoint
  Applicable Models: gpt-image-1, flux-kontext-pro
```

**Способ 2: используйте эндпоинт Responses**

```yaml theme={null}
Responses Configuration:
  Provider Name: APIYI-Responses
  API Mode: OpenAI API Compatible
  API Key: sk-your-apiyi-key
  API Host: https://api.apiyi.com
  API Path: /v1/responses  # General response endpoint
```

<Tip>
  **Рекомендации по выбору эндпоинта**

  * Обычные разговоры: используйте эндпоинт `/chat/completions`
  * Модели генерации изображений, полученные обратной разработкой, такие как sora\_image: используйте эндпоинт `/chat/completions`
  * Генерация изображений: отдавайте приоритет стандартному эндпоинту `/images/generations`
  * Особые потребности: можно использовать эндпоинт `gpt-image-1` или `/v1/responses`
  * В Chatbox поле «API Path» соответствует конкретному пути эндпоинта
</Tip>

### Настройки сетевого прокси

Если вам нужно использовать прокси для доступа:

1. Перейдите в Settings > Network Configuration
2. Настройте HTTP/HTTPS-прокси
3. Укажите аутентификацию прокси (при необходимости)

### Настройки сочетаний клавиш

Распространенные сочетания:

* `Ctrl/Cmd + N`: Новый разговор
* `Ctrl/Cmd + T`: Переключить модель
* `Ctrl/Cmd + /`: Показать палитру команд
* `Ctrl/Cmd + K`: Быстрый поиск

## Мобильная конфигурация

### Конфигурация для iOS/Android

Мобильная конфигурация такая же, как и на компьютере:

1. Скачайте мобильное приложение Chatbox AI
2. Перейдите в Settings > Model Configuration
3. Добавьте пользовательского провайдера APIYI
4. Настройте тот же API Base URL и ключ

### Функции для мобильных устройств

* **Голосовой ввод**: поддерживает преобразование речи в текст
* **Интеграция с камерой**: делайте фотографии напрямую для анализа изображений
* **Офлайн-кэш**: история переписки доступна офлайн
* **Push-уведомления**: оповещения о важных сообщениях

## Устранение неполадок

### Распространенные проблемы

**Сбой подключения**

* Проверьте API Base URL: `https://api.apiyi.com/v1`
* Убедитесь, что API key действителен
* Подтвердите, что сетевое подключение работает нормально

**Модели не отображаются**

* Подождите, пока список моделей обновится автоматически
* Вручную нажмите кнопку «Обновить модели»
* Проверьте права доступа API key

**Медленный ответ**

* Попробуйте переключиться на более быструю модель
* Проверьте задержку сети
* Уменьшите длину контекста

### Отладка журналов

Включите режим отладки:

1. Settings > Advanced Options
2. Включите «Debug Mode»
3. Просмотрите подробную информацию журнала

### Резервное копирование данных

Регулярно выполняйте резервное копирование данных переписки:

1. Settings > Data Management
2. Экспортируйте историю переписки
3. Создайте резервную копию конфигурационных файлов
