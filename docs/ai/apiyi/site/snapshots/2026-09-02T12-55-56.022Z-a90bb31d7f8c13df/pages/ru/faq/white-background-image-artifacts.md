# Почему на изображении с белым фоном появляются чёрные пятна, грязные разводы или размытые цветные блоки?

> Изображения с белым фоном из API Google Aistudio часто содержат артефакты. Измените prompt на светлый оттенок или перейдите на канал Vertex, чтобы исправить это.

## Краткий ответ

Это известная проблема Google Aistudio API. При высокой вычислительной нагрузке большие участки чисто белого цвета в сгенерированных изображениях обычно отображаются с черными точками, грязными пятнами или размытыми цветными блоками. Это неоднократно наблюдалось с апреля 2026 года. Два способа исправления:

* **Вариант 1 (сначала попробуйте это)**: измените prompt с «white background» на светлый оттенок (светло-серый, бежевый, нежно-голубой) — изменение конфигурации не требуется.
* **Вариант 2**: обратитесь в поддержку, чтобы включить группу `VertexGemini`, затем создайте token, привязанный к этой группе. Канал Vertex обеспечивает чистый белый фон без загрязнений.

## Подробное объяснение

При высокой нагрузке в конвейере изображений Aistudio возникают проблемы с сжатием и восстановлением **больших однотонных областей**, особенно чисто белых. Обычно встречаются три артефакта:

* **Черные точки / грязные пятна**: локальные темные точки или неровные пятна на изображении
* **Размытые цветовые блоки**: вместо чисто белого вы получаете туманную серовато-белую или желтоватую область
* **Смещение цвета**: белый фон уходит в теплый (бежевый) или холодный (серовато-синий) оттенок по сравнению с prompt

Это **не проблема возможностей модели** — это дефект отрисовки в конвейере Aistudio на однотонных фонах. На все Gemini image модели, такие как Nano Banana Pro и Nano Banana 2, это влияет при маршрутизации через Aistudio.

## Шаги по устранению

### Вариант 1: Обходной путь на уровне prompt (рекомендуется сначала)

Замените «white background / pure white background / #FFFFFF» в prompt на светлый оттенок:

* **Светло-серый**: `light gray background` / `#F5F5F5`
* **Бежевый**: `beige background` / `#F5F0E5`
* **Нежно-голубой**: `light blue background` / `#E8F0F8`
* **Прозрачный**: `transparent background` (если модель поддерживает вывод alpha)

<Info>
  На практике переход от чисто белого к светло-серому или бежевому почти полностью устраняет черные пятна и грязные области. Цвета объекта не затрагиваются — меняется только оттенок фона.
</Info>

### Вариант 2: Перейдите на канал Vertex

Если в вашем сценарии строго нужен чисто белый фон (например, снимки товаров для интернет-магазина), маршрутизация через Vertex устраняет первопричину.

#### Справка по группе VertexGemini

| Поле                      | Подробности                                                                                                        |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Идентификатор**         | `VertexGemini`                                                                                                     |
| **Описание**              | Модели Vertex Gemini: Nano Banana Pro / серия 2. Выделенная мощность для генерации изображений через канал Vertex. |
| **Поддерживаемые модели** | Nano Banana Pro, Nano Banana 2                                                                                     |
| **Преимущества**          | Устраняет проблему размытого чисто-белого фона                                                                     |
| **Недостатки**            | Ограниченные параллельные запросы (\~100 RPM); только по приглашению; немного медленнее, чем Aistudio              |

#### Как использовать

<Steps>
  <Step title="Запросите доступ у поддержки">
    Обратитесь в поддержку / ops APIYI, чтобы включить группу `VertexGemini`. Сейчас доступ только по приглашению.
  </Step>

  <Step title="Создайте отдельный token">
    Войдите в консоль APIYI → `Token management` → `Create token` → выберите группу **`VertexGemini`** → сохраните ключ.
  </Step>

  <Step title="Переключите вызов">
    Используйте новый token для вызова Nano Banana Pro / Nano Banana 2. Базовый URL остается прежним (`https://api.apiyi.com/v1`).
  </Step>
</Steps>

<Warning>
  У группы `VertexGemini` ограниченные параллельные запросы (\~100 RPM), поэтому ее не рекомендуется использовать для production-нагрузок с высоким потоком. Оставьте Aistudio основным каналом и переключайтесь на Vertex только для проверки чисто-белого фона.
</Warning>

## Часто задаваемые вопросы

<AccordionGroup>
  <Accordion title="Почему изменение цвета фона устраняет проблему?">
    Проблема рендеринга Aistudio возникает из-за сжатия больших однородных областей одного цвета. Переход на светло-серый или бежевый фон добавляет фону некоторую текстуру, что позволяет избежать условия «сжать большую однородную область», которое и вызывает артефакты.
  </Accordion>

  <Accordion title="Всегда ли Vertex дает более высокое качество, чем Aistudio?">
    Не обязательно. Vertex стабильнее на чисто-белых / однотонных фонах, но в других сценах (сложная композиция, портреты) оба варианта сопоставимы — и Vertex работает медленнее. Переключайтесь только если вы убедились, что проблему вызывает чисто белый фон.
  </Accordion>

  <Accordion title="Как запросить группу VertexGemini?">
    Доступ только по приглашению — обратитесь в поддержку APIYI или к вашему менеджеру по аккаунту. Для большинства пользователей Вариант 1 (смена фона на более светлый оттенок) достаточно.
  </Accordion>

  <Accordion title="Меняется ли при переходе на Vertex URL запроса?">
    Нет. Базовый URL остается `https://api.apiyi.com/v1`. Меняется только группа token; бэкенд APIYI автоматически направляет трафик группы Vertex на платформу Vertex.
  </Accordion>
</AccordionGroup>
