# ChatHub

> AI-клиент в виде расширения для браузера, который сравнивает ответы нескольких моделей рядом; единый доступ к более чем 400 моделям через APIYI

ChatHub — это расширение браузера Chrome / Edge, которое позволяет вам задать один и тот же вопрос нескольким моделям AI в одной беседе и отображает их ответы рядом, чтобы вы могли быстро определить, какая модель лучше всего подходит для текущей задачи. С APIYI ChatHub может объединить доступ к более чем 400 основным моделям, включая OpenAI, Claude, Gemini, DeepSeek и Qwen.

## Основная возможность: сравнение моделей бок о бок

Главное отличие ChatHub от других клиентов — это **параллельные Q\&A для нескольких моделей**:

* Отправляйте один и тот же вопрос 2–6 моделям в одной вкладке
* Просматривайте их ответы в макете **бок о бок** или **таблица**
* Подходит любая комбинация: GPT-5.5 + Claude Opus 4.7 + Gemini 3 Pro + DeepSeek V4 вместе
* Режим сравнения поддерживает рендеринг Markdown, подсветку кода и предпросмотр изображений

<Tip>
  **Лучшие сценарии использования**

  * Написание кода / исправление багов: сразу сравнивайте патчи GPT-5.5 и Claude Opus 4.7
  * Длинные тексты: сравнивайте формулировки Claude Sonnet и Qwen3.7 на китайском
  * Перевод / краткое изложение: отправьте один и тот же абзац в GPT-5.5, Gemini 3 Flash и DeepSeek V4
  * Выбор модели: проводите стресс-тест нескольких моделей с одним и тем же prompt, чтобы выбрать модель по умолчанию
</Tip>

## Установка

Посетите `https://chathub.gg/zh-CN/download`, чтобы установить ChatHub.

## Быстрая настройка (режим, совместимый с OpenAI)

Это самый универсальный способ настройки, и он поддерживает все 400+ моделей в APIYI.

### Шаг 1: Получите API-ключ

См. [Создание и управление API-ключом](/ru/faq/token-management), чтобы получить свой ключ APIYI.

### Шаг 2: Откройте настройки ChatHub

1. Нажмите на значок ChatHub в правом верхнем углу браузера
2. Во всплывающем окне нажмите значок **Настройки** (шестеренка) в правом верхнем углу
3. Перейдите на вкладку **Пользовательские провайдеры**

### Шаг 3: Добавьте провайдер APIYI

<img src="https://mintcdn.com/apiyillc/1n99GeVSDKf0eLgj/images/chathub-add-apiyi-provider-zh.png?fit=max&auto=format&n=1n99GeVSDKf0eLgj&q=85&s=ac7db1a0937fc11a8012b39741f15b91" alt="ChatHub пример настройки добавления провайдера APIYI" width="688" height="691" data-path="images/chathub-add-apiyi-provider-zh.png" />

Следуя скриншоту выше, заполните диалог добавления провайдера следующим образом:

* **Имя**: `apiyi` (что угодно, что поможет вам отличать этот провайдер в списке)
* **API Host**: выберите `OpenAI` из выпадающего списка и укажите `https://api.apiyi.com/v1` в поле URL ниже
* **API Key**: вставьте свой ключ APIYI
* **Model**: модель, которую вы часто используете, например `deepseek-v4-pro`

Дополнительные параметры:

* **Image input**: включите, если модель поддерживает vision (например, `gpt-5-chat-latest`, `gemini-3-pro-preview`, `claude-sonnet-4-5`)
* **Function calling**: включите, если модель поддерживает вызовы tool/function
* **Advanced settings**: по умолчанию свернуто — разверните, чтобы настроить заголовки запросов, тайм-ауты и т. д.

Когда закончите, нажмите **Подтвердить** в правом нижнем углу, чтобы сохранить.

<Info>
  **Примечания к настройке**

  * Поле URL API Host должно включать суффикс `/v1`
  * «Model» используется по умолчанию; вы можете в любой момент переключать модели во время чата
  * Перезапуск браузера не требуется — настройки вступают в силу сразу
  * Чтобы добавить еще одного провайдера, повторите этот шаг
</Info>

### Шаг 4: Выберите модель

После сохранения вернитесь в основной интерфейс ChatHub. Добавленные вами модели появятся в выпадающем списке — свободно переключайтесь между ними.

## Три режима использования

| Режим                            | Триггер                                                                     | Когда использовать                                                         |
| -------------------------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| **Чат с одной моделью**          | Общайтесь с одной моделью как в обычном ChatGPT                             | Ежедневные вопросы и ответы, задачи, в которых одна модель особенно хороша |
| **Сравнение нескольких моделей** | Отметьте 2–6 моделей справа от поля ввода                                   | Тесты выбора, поиск лучшего ответа                                         |
| **Веб-помощник**                 | Выделите текст на любой странице, чтобы открыть панель инструментов ChatHub | Перевести/суммировать статью, улучшить письмо                              |

<Tip>
  **Советы для режима сравнения**

  * В режиме сравнения ответ каждой модели **независим**; левая основная панель по-прежнему показывает вашу модель по умолчанию
  * Хотите экспортировать ответы всех? Нажмите кнопку **Экспорт** в правом верхнем углу диалога — поддерживаются Markdown / JSON / PNG
  * Выбирайте для сравнения **стилистически разные** модели, например «GPT-5.5 + Claude Opus 4.7 + DeepSeek V4» — так различия гораздо легче заметить
</Tip>

## Продвинутое: самая сильная схема сравнения

Ключевая особенность ChatHub — «запускать несколько вендоров одновременно». Через APIYI вы можете смешивать модели любого вендора в одной сессии сравнения.

### Рекомендуемые комбинации для сравнения

| Задача                                  | Рекомендуемая смесь                              | Почему                                                        |
| --------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------- |
| **Генерация кода / исправление ошибок** | GPT-5.5 + Claude Opus 4.7 + DeepSeek V4          | Лучшая кодовая экспертиза + экономичный отечественный вариант |
| **Длинные тексты / креативное письмо**  | Claude Sonnet 4.5 + Qwen3.7-Max + GPT-5.5        | Китайская выразительность + западное повествование            |
| **Перевод / мультиязычность**           | GPT-5.5 + Gemini 3 Flash + DeepSeek V4           | Три вендора взаимно проверяют результаты                      |
| **Рассуждение / математика**            | GPT-5.5 (xhigh) + Claude Opus 4.7 + Gemini 3 Pro | Три лучших конфигурации для рассуждения                       |

## Основные возможности

### Сочетания клавиш

| Сочетание                  | Действие                                             |
| -------------------------- | ---------------------------------------------------- |
| `Ctrl/Cmd + Shift + Y`     | Открыть боковую панель ChatHub на любой веб-странице |
| `Ctrl/Cmd + B`             | Переключить видимость боковой панели                 |
| `Ctrl/Cmd + Enter`         | Отправить сообщение (режим одного модели)            |
| `Ctrl/Cmd + Shift + Enter` | Отправить всем выбранным моделям (режим сравнения)   |

### Веб-помощник

Выберите любой текст на веб-странице, и ChatHub отобразит панель инструментов, которая может:

* Переводить выбранный текст
* Суммировать выбранный абзац
* Переписывать / улучшать стиль
* Объяснять код

### Управление беседами

* Несколько независимых бесед со своими контекстами
* Локальное хранение истории бесед (без зависимости от облака)
* Отрисовка Markdown и подсветка кода
* Экспорт в Markdown / PDF в один клик

### Библиотека prompt

Встроенная площадка шаблонов prompt; вы также можете сохранять собственные повторно используемые prompt и использовать переменные.

## Дополнительные настройки

### Настройка параметров

```yaml theme={null}
Chat parameters:
  - Temperature: 0.7        # Creativity control (reasoning models like GPT-5 only support 1)
  - Max Tokens: 4096        # Maximum output length
  - Top P: 0.9              # Nucleus sampling threshold
  - Frequency Penalty: 0    # Repetition penalty
  - Presence Penalty: 0     # New-topic tendency
```

### Потоковая передача вывода

Потоковая передача включена по умолчанию в ChatHub для более плавной работы.

### Настройки прокси

Если вам нужно подключение через прокси:

1. Перейдите в Настройки > Дополнительно
2. Настройте HTTP/HTTPS-прокси
3. При необходимости задайте аутентификацию прокси

## Устранение неполадок

### Подключение не удалось

* Проверьте базовый URL API: `https://api.apiyi.com/v1`
* Убедитесь, что API key действителен
* Проверьте подключение к сети

### Модели не отображаются

* Подождите, пока список моделей обновится автоматически
* Нажмите кнопку «Обновить модели» вручную
* Проверьте разрешения API key

### Режим сравнения показывает только один ответ

* Убедитесь, что вы выбрали несколько моделей справа от поля ввода
* Проверьте, что каждая модель поступает от настроенного провайдера

### Медленный ответ

* Попробуйте более быструю модель
* Проверьте задержку сети
* Сократите контекст

## Лучшие практики

### Оптимизация производительности

1. **Выбирайте модели с умом**
   * Подбирайте размер модели под сложность задачи
   * См. [Рекомендации по моделям](/ru/api-capabilities/model-info) для последних советов по выбору

2. **Стратегия сравнения**
   * Сравнение двух похожих моделей (двух GPTs) мало что вам скажет
   * Выбирайте модели с **разными сильными сторонами**: одну для кодинга, одну для письма, одну для рассуждения, одну для перевода
   * Не сравнивайте одновременно более 4 моделей — расход token растет линейно

3. **Управление ресурсами**
   * Отслеживайте использование API
   * Настройте оповещения о расходах
   * Регулярно обновляйте расширение

### Советы по безопасности

* Никогда не делитесь API-ключами
* Периодически меняйте ключи
* Защитите браузер надежным паролем
* Осторожно обращайтесь с конфиденциальной информацией

### Командная работа

Хотя ChatHub в первую очередь предназначен для отдельных пользователей, вы все равно можете поддерживать команды с помощью:

* Общих шаблонов prompt
* Экспортированных записей разговоров
* Стандартизированной конфигурации API

### Почему выбирают ChatHub

1. **Инструмент выбора**: сравнивать несколько моделей одновременно незаменимо
2. **Смешение разных вендоров**: свободно комбинируйте OpenAI / Claude / Gemini / отечественные модели
3. **Нативность для веба**: как расширение браузера, оно доступно на любой странице
4. **Приватность прежде всего**: беседы хранятся локально; расширение не собирает ваши данные
5. **Активная разработка**: постоянно поддерживается
