<Info>
  **Ключевые особенности моделей видео**:

  * **Серия Seedance 2.5 / 2.0 (ByteDance)**: `doubao-seedance-2-5-260628` (2.5 — до 30 с, 30 референсных изображений, вывод в формате mov) / `doubao-seedance-2-0-260128` (standard) / `-fast-260128` (fast) / `-mini-260615` (mini) — цены и скорости различаются (mini \< fast \< standard \< 2.5, при этом 2.5 примерно в 1,5 раза дороже standard); mini и fast поддерживают разрешение не выше 720p. **Все четыре модели работают в группе `SeeDance2`** (0.18x), поэтому один token покрывает их все. Режим тарификации token должен быть «сначала использование» или «на основе использования». `SD2Mini` (0.10x) и `SD2Fast` (0.15x) — группы со скидкой на ограниченный срок — **скидка 44,4% для mini, 16,7% для fast действует до 2026-09-07 23:59 (UTC+8)**; после этого коэффициент возвращается к 0.18x, а группы остаются доступными
  * **VEO 3.1 Official**: прямое перенаправление на официальный эндпоинт Google AI Studio, ведущая в отрасли синхронизация аудио и видео, поддержка реальных людей, доступ через группу по умолчанию + token с тарификацией за вызов/на основе использования; рекомендуемая альтернатива на время приостановки Veo 3.1 Reverse
  * **Veo 3.1 Reverse**: **приостановлена** из-за контроля рисков Google, сроки восстановления пока неизвестны; тем временем используйте VEO 3.1 Official
  * **Sora 2 Official**: прекращена, в настоящее время недоступна
  * **Wan2.7 / Wan2.6 (Alibaba Wanxiang)**: цена по умолчанию составляет примерно 98% от официальной, обе серии используют общую группу `Wan&HappyHorse` с HappyHorse, один token для всех; Wan2.6 и Wan2.7 используют один и тот же эндпоинт и схему — для миграции достаточно изменить название `model`
  * **HappyHorse 1.1 (Alibaba)**: превосходно обеспечивает согласованность объекта по нескольким референсам, использует общие с Wan группу `Wan&HappyHorse` и эндпоинт

## 💰 Информация о тарификации

* **Оплата по факту использования**: Взимается на основе фактического использования, без минимального платежа
* **Срок действия баланса**: Действует 365 дней с даты пополнения, автоматически сбрасывается при следующем пополнении (см. [Акции на пополнение](/ru/faq/recharge-promotions))
* Посетите [Страницу тарификации консоли APIYI](https://www.apiyi.com/account/pricing), чтобы узнать актуальную тарификацию для всех моделей
