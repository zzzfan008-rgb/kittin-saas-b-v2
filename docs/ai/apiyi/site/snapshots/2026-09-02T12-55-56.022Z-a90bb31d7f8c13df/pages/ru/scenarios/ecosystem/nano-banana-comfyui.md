# Узлы ComfyUI для Nano Banana

> Узлы сообщества с открытым исходным кодом для ComfyUI для вызова моделей генерации изображений Nano Banana Pro и Nano Banana 2 через APIYI, с поддержкой text-to-image, image-to-image и многораундового чата.

## Обзор

ComfyUI-Nano-Banana-apiyi — это созданная сообществом коллекция custom nodes для ComfyUI, специально разработанная для пользователей APIYI. Она позволяет вызывать самые мощные модели Google для генерации изображений — Nano Banana Pro и Nano Banana 2 — напрямую в рабочих процессах ComfyUI, **без необходимости в аккаунте Google Cloud**. Для начала создания вам нужен только APIYI API key.

| **Nano Banana 2 Multi-Turn Chat** | Flash  | Диалоговое редактирование + экстремальные соотношения сторон          | Быстрая итерация             |

## Начало работы: установка и настройка

<Steps>
  <Step title="Шаг 1: Проверьте необходимые требования">
    Убедитесь, что у вас установлено следующее:

    * **ComfyUI** (последняя версия) — если не установлено, см.: `github.com/comfyanonymous/ComfyUI`
    * **Python 3.12+**
    * **Git**

    <Warning>
      Версия Python должна быть 3.12 или выше. Более низкие версии могут привести к сбоям при установке зависимостей.
    </Warning>
  </Step>

  <Step title="Шаг 2: Скачайте код узла">
    Откройте терминал, перейдите в каталог custom nodes в ComfyUI и клонируйте репозиторий:

    ```bash theme={null}
    cd ComfyUI/custom_nodes
    git clone https://github.com/pdmaker/ComfyUI-Nano-Banana-apiyi.git
    ```
  </Step>

  <Step title="Шаг 3: Установите зависимости">
    Перейдите в каталог плагина и установите необходимые зависимости:

    ```bash theme={null}
    cd ComfyUI-Nano-Banana-apiyi
    pip3 install -r requirements.txt
    ```

    Для поддержки узла Nano Banana 2 также установите:

    ```bash theme={null}
    pip3 install google-genai --upgrade
    ```
  </Step>

  <Step title="Шаг 4: Получите свой APIYI-ключ">
    1. Перейдите в [APIYI Console](https://api.apiyi.com), чтобы зарегистрироваться или войти
    2. Перейдите в раздел Token
    3. Сгенерируйте новый API-ключ
    4. Скопируйте ключ (начинается с `sk-`)

    <Info>
      Новые пользователи получают бесплатные пробные кредиты, которых достаточно, чтобы попробовать генерацию изображений Nano Banana.
    </Info>
  </Step>

  <Step title="Шаг 5: Настройте переменные окружения">
    В каталоге плагина скопируйте шаблонный файл и заполните свои учетные данные:

    ```bash theme={null}
    cp .env.api.template .env
    ```

    Отредактируйте файл `.env`, указав ваш ключ APIYI и Base URL:

    ```bash theme={null}
    GOOGLE_API_KEY=sk-your-apiyi-key
    CUSTOM_BASE_URL=https://api.apiyi.com
    ```

    <Tip>
      **Ключевая настройка**: `CUSTOM_BASE_URL` должен быть установлен в `https://api.apiyi.com`, чтобы все запросы шли через APIYI — учетная запись Google Cloud не нужна. Код автоматически добавляет правильный путь версии API.
    </Tip>
  </Step>

  <Step title="Шаг 6: Перезапустите ComfyUI и проверьте">
    После перезапуска ComfyUI найдите `Nano Banana` в списке узлов. Вы должны увидеть 4 новых узла:

    * Nano Banana AIO
    * Nano Banana Multi-Turn Chat
    * Nano Banana 2 AIO
    * Nano Banana 2 Multi-Turn Chat

    Если вы видите эти узлы, установка выполнена успешно!
  </Step>
</Steps>

## Практическое руководство: от текста к изображению

### Сценарий 1: Из текста в изображение (базовый)

Самое простое использование — введите текстовое описание и сгенерируйте изображение.

<Steps>
  <Step title="Добавьте узел">
    Щелкните правой кнопкой мыши по холсту ComfyUI, найдите и добавьте узел **Nano Banana AIO** (или Nano Banana 2 AIO).
  </Step>

  <Step title="Введите prompt">
    Введите желаемое описание изображения в поле `prompt`, например:

    ```
    An orange tabby cat sitting on a windowsill, Tokyo nightscape outside, cyberpunk style, neon lights, high detail, cinematic quality
    ```
  </Step>

  <Step title="Настройте параметры">
    * **image\_count**: Количество изображений для генерации (1-10)
    * **aspect\_ratio**: Выберите соотношение сторон, например, `16:9` (обои для рабочего стола в альбомной ориентации) или `9:16` (обои для телефона)
    * **image\_size**: Разрешение — рекомендуем `2K` или `4K`
    * **temperature**: Уровень креативности, 0.0 — наиболее консервативно, 2.0 — наиболее креативно
  </Step>

  <Step title="Запустите рабочий процесс">
    Нажмите кнопку ComfyUI **Queue Prompt** и подождите несколько секунд, чтобы увидеть сгенерированное изображение.
  </Step>
</Steps>

### Сценарий 2: Редактирование и слияние изображений

Используйте референсные изображения для управления генерацией — отлично подходит для переноса стиля, слияния элементов и многого другого.

1. Подключите ваши референсные изображения к входам `image_1` и `image_6` узла **Nano Banana AIO**
2. Опишите желаемый эффект в `prompt`, например: «Преобразуйте это фото в стиль акварельной живописи»
3. Модель объединяет референсные изображения и текстовое описание для генерации новых изображений

<Tip>
  **Nano Banana 2 AIO Exclusive**: Поддерживает до 14 референсных изображений (10 объектов + 4 референса для согласованности персонажа), идеально подходит для творческих проектов, где требуется единообразный внешний вид персонажа.
</Tip>

### Сценарий 3: Многоходовое диалоговое редактирование

Самая уникальная функция — пошагово дорабатывайте изображения, как в чате.

1. Добавьте узел **Nano Banana Multi-Turn Chat**
2. Раунд 1: Введите первоначальное описание, создайте базовое изображение
3. Раунд 2: Введите изменение, например: «Измените фон на пляж»
4. Раунд 3: Продолжайте уточнять, например: «Добавьте освещение на закате»
5. Каждый раунд опирается на память беседы

Переключите `reset_chat`, чтобы очистить историю беседы и начать заново.

## Справочник параметров узла

### Nano Banana AIO / Nano Banana 2 AIO

| Параметр                  | Тип     | Обязательно | Описание                                        |
| ------------------------- | ------- | ----------- | ----------------------------------------------- |
| `prompt`                  | string  | Да          | Текст описания изображения                      |
| `image_count`             | integer | Нет         | Количество изображений (1-10), по умолчанию 1   |
| `aspect_ratio`            | enum    | Нет         | Соотношение сторон (11 вариантов / у NB2 их 14) |
| `image_size`              | enum    | Нет         | Разрешение: 512px (только NB2), 1K, 2K, 4K      |
| `temperature`             | float   | Нет         | Креативность 0.0-2.0                            |
| `use_search`              | boolean | Нет         | Включить grounding через поиск Google           |
| `image_1` \~ `image_6/14` | image   | Нет         | Входные изображения-референсы                   |

### Поддерживаемые соотношения сторон

| Стандартные (общие для обоих узлов) | Эксклюзивно для Nano Banana 2            |
| ----------------------------------- | ---------------------------------------- |
| 1:1, 2:3, 3:2, 3:4, 4:3             | 1:4 (сверхвысокий вертикальный формат)   |
| 4:5, 5:4, 9:16, 16:9                | 4:1 (сверхширокий горизонтальный формат) |
| 21:9, Auto (автовыбор AI)           | 1:8, 8:1 (экстремальные соотношения)     |

## Часто задаваемые вопросы

<AccordionGroup>
  <Accordion title="Не удается найти узлы после установки?">
    Проверьте следующее:

    1. Папка плагина находится в каталоге `ComfyUI/custom_nodes/`
    2. Вы выполнили `pip3 install -r requirements.txt`
    3. Для узлов Nano Banana 2 также выполните `pip install google-genai --upgrade`
    4. Вы **перезапустили** ComfyUI (не просто обновили браузер — нужно перезапустить backend)
  </Accordion>

  <Accordion title="Ошибка: недействительный API Key?">
    Пожалуйста, проверьте:

    1. `GOOGLE_API_KEY` в файле `.env` — это ваш ключ APIYI (начинается с `sk-`)
    2. `CUSTOM_BASE_URL` установлено в `https://api.apiyi.com`
    3. На вашем аккаунте APIYI достаточно баланса (проверьте в консоли)
  </Accordion>

  <Accordion title="Медленная генерация или тайм-аут?">
    * Разрешение 4K требует больше времени — для проверки сначала попробуйте 1K
    * Несколько изображений (image\_count больше 1) увеличивают время обработки
    * Если тайм-ауты случаются часто, попробуйте более низкое разрешение или меньшее количество изображений
  </Accordion>

  <Accordion title="Nano Banana Pro или Nano Banana 2 — что выбрать?">
    * **Nano Banana Pro** (`gemini-3-pro-image-preview`): Более высокое качество, идеально для премиальных работ
    * **Nano Banana 2** (`gemini-3.1-flash-image-preview`): Быстрее, дешевле (от \$0.025 за изображение), больше референсных изображений и экстремальные соотношения сторон
    * Для ежедневной работы рекомендуется Nano Banana 2; для максимального качества выбирайте Pro
  </Accordion>

  <Accordion title="Как получить APIYI API key?">
    Перейдите в [APIYI Console](https://api.apiyi.com/token), зарегистрируйте аккаунт и создайте новый ключ в разделе Token. Новые пользователи получают бесплатные пробные кредиты.
  </Accordion>

  <Accordion title="Сбой генерации изображений из-за проверки безопасности контента?">
    У моделей Nano Banana встроены проверки безопасности контента. Некоторые описания могут вызывать ограничения. Рекомендации:

    1. Скорректируйте prompt, чтобы избежать чувствительного контента
    2. См. [Устранение неполадок при сбое генерации изображений Nano Banana](/ru/faq/nano-banana-image-failure) для дополнительной помощи
  </Accordion>
</AccordionGroup>
