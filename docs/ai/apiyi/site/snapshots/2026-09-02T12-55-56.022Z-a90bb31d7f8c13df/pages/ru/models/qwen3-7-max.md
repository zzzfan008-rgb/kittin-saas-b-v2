## Пример запроса

Пример ниже вызывает `qwen3.7-max` через OpenAI Chat Completions (`/v1/chat/completions`). Укажите base\_url на `https://api.apiyi.com/v1` — все остальное совпадает с официальным API.

```bash theme={null}
curl https://api.apiyi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $APIYI_API_KEY" \
  -d '{
    "model": "qwen3.7-max",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

<Tip>Берите ключ из переменной окружения, никогда не задавайте его жестко в коде. В production выдавайте отдельные token для каждого сценария использования, чтобы вы могли отдельно отзывать их и учитывать использование.</Tip>
