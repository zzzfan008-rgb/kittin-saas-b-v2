Pay-as-you-go означает, что вы платите только за услуги, которыми фактически пользуетесь, без ежемесячной или ежегодной предоплаты.

### Приоритет режимов тарификации

APIYI поддерживает два режима тарификации. Когда модель поддерживает оба:

<Warning>
  **Тарификация за вызов имеет приоритет над тарификацией по token**

  Если модель поддерживает и тарификацию за вызов, и тарификацию по token, система по умолчанию использует тарификацию за вызов.
</Warning>

#### Влияние настроек Token (API Key)

Ваш метод тарификации также зависит от конфигурации token:

<CardGroup cols={2}>
  <Card title="Тарификация только по token" icon="sliders-horizontal">
    Если для token установлена «тарификация только по token», то даже если модель поддерживает тарификацию за вызов, будет использоваться тарификация по token
  </Card>

  <Card title="Настройка по умолчанию" icon="circle-check">
    По умолчанию tokens поддерживают все режимы тарификации, система автоматически выбирает (приоритет тарификации за вызов)
  </Card>
</CardGroup>

### Что такое Tokens?

Tokens — это базовые единицы, которые AI models используют для обработки текста. Понимание tokens помогает вам оценивать и контролировать затраты.

<Info>
  **Справка по расчету token**

  * Китайский: 1 символ ≈ 1-2 tokens
  * Английский: 1 слово ≈ 1-2 tokens
  * 1000 tokens ≈ 750 английских слов ≈ 500 китайских иероглифов
</Info>

#### Пример расчета token

```
Input text: "Hello, please help me write a Python function"
Token count: About 12-15 tokens

Output text: "def hello_world():\n    print('Hello, World!')"
Token count: About 15-20 tokens

Total consumption: Input + Output ≈ 30-35 tokens
```

### Промпты и завершения

В каждом API-вызове затраты состоят из двух частей:

<Steps>
  <Step title="Prompt - входные Tokens">
    Весь контент, который вы отправляете модели, включая:

    * Системные промпты
    * Вопросы пользователя
    * Контекстную информацию
    * Историю беседы (если есть)
  </Step>

  <Step title="Completion - выходные Tokens">
    Контент, сгенерированный моделью, включая:

    * Текстовые ответы
    * Генерацию кода
    * Структурированные данные
  </Step>
</Steps>

<Warning>
  У разных моделей могут быть разные цены на входные и выходные Tokens. Обычно выходные Tokens стоят дороже входных Tokens.
</Warning>

### Метод оценки стоимости

<Steps>
  <Step title="Тестирование на небольшой выборке">
    Проверьте на небольшом количестве примеров (5-10)
  </Step>

  <Step title="Просмотр журналов потребления">
    Проверьте подробное потребление token для каждого вызова в консоли APIYI
  </Step>

  <Step title="Расчет среднего значения">
    Рассчитайте среднее количество token на один вызов
  </Step>

  <Step title="Оценка общей стоимости">
    Среднее число token × Ожидаемое число вызовов × Цена за единицу модели
  </Step>
</Steps>

<Card title="Практические рекомендации" icon="lightbulb">

  3. Выбирайте подходящую модель в зависимости от сложности задачи

После успешного онлайн-пополнения или корпоративного перевода счета-фактуры выставляются на основании фактически оплаченной суммы (все цены включают налог). Вам нужно предоставить подробные данные для счета-фактуры: название компании или университета, ИНН и т. д.

<Steps>

    [Подать заявку на счет-фактуру →](https://xinqikeji.feishu.cn/share/base/form/shrcns8TS3alZTN2Av1JfkOvmqh)
  </Step>

  <Step title="Тип счета-фактуры">
