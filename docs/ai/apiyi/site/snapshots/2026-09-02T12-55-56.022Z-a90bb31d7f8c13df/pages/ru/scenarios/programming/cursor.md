# Cursor

> Руководство по интеграции редактора кода на базе AI

Cursor — это редактор кода на основе ИИ. Интегрировав APIYI, вы можете получить мощную ИИ-помощь при написании кода.

## Быстрая настройка

### 1. Откройте настройки

Нажмите на значок шестерёнки ⚙️ в правом верхнем углу, выберите пункт **Models**

### 2. Настройте API

* **Ключ API OpenAI**: Введите ваш ключ APIYI (можно использовать токен по умолчанию напрямую)
* **Переопределить базовый URL OpenAI**: Отметьте и введите `https://api.apiyi.com/v1`
* Нажмите **Verify**, чтобы проверить конфигурацию

### 3. Настройка модели

<Warning>
  **Важное примечание**: Cursor в настоящее время **не поддерживает режим Agent**, доступен только режим Chat. Вы можете сгенерировать код с помощью AI в чате, а затем вручную применить его к реальному коду.

  Если вы новичок и сильно полагаетесь на режим Agent для Vibe Coding, рекомендуем:

  * Приобрести официальную подписку Cursor, чтобы использовать их нативный сервис
  * Или использовать альтернативы: плагины **RooCode** или **Cline** для VS Code (поддерживают режим Agent)
</Warning>

#### Рекомендуемая конфигурация моделей

С учетом текущей производительности новейших моделей и соотношения цены и качества рекомендуем следующее:

**Основные модели для программирования**:

* `claude-sonnet-4-20250514` - Claude 4 Sonnet, лучшее программирование
* `gpt-4.1` - Высокая скорость, сильные общие возможности
* `deepseek-v3` - Отлично подходит для программирования на китайском, высокое соотношение цены и качества

**Модели для оптимизации затрат**:

* `gpt-4.1-mini` - Легковесная, но способная
* `claude-3-haiku` - Самая дешевая в серии Claude
* `gemini-2.5-flash` - Быстрореагирующая модель Google

**Модели с усиленным рассуждением**:

* `o4-mini` - Первый выбор среди моделей рассуждения для задач программирования
* `o3` - Сложные задачи рассуждения и алгоритмические проблемы

## Пояснение режима использования

### Рабочий процесс в режиме чата

Поскольку Cursor не поддерживает режим Agent, рекомендуем следующий рабочий процесс:

1. **Диалог для генерации кода**
   * Используйте `Ctrl/Cmd + L`, чтобы открыть чат
   * Опишите свои требования, попросите AI сгенерировать код
   * Просматривайте сгенерированные фрагменты кода

2. **Ручное применение кода**
   * Скопируйте код из окна чата
   * Вставьте его в целевой файл
   * Или используйте кнопку «Apply» (если доступна)

3. **Итерации и оптимизация**
   * Продолжайте беседу, чтобы запросить изменения
   * Повторяйте процесс применения

### Сравнение альтернатив

| Инструмент             | Режим Agent | Преимущества                                                      | Недостатки                               |
| ---------------------- | ----------- | ----------------------------------------------------------------- | ---------------------------------------- |
| **Cursor**             | ❌           | Элегантный интерфейс, хороший опыт автодополнения                 | Нет режима Agent                         |
| **Cline (VS Code)**    | ✅           | Полная функциональность Agent, может автоматически изменять файлы | Требуется VS Code                        |
| **RooCode (VS Code)**  | ✅           | Режим Agent, поддерживает многофайловое редактирование            | Более новый, функциональность улучшается |
| **Continue (VS Code)** | ✅           | Open source, высокая настраиваемость                              | Более сложная конфигурация               |

## Основные возможности

### Умное автодополнение кода

* **Tab Completion**: Нажмите Tab, чтобы принять предложения ИИ
* **Multi-line Completion**: Поддерживает генерацию кода на уровне функции
* **Context Aware**: Предлагает варианты на основе структуры проекта

### Разговор с ИИ

* **Ctrl/Cmd + K**: Открыть палитру команд
* **Ctrl/Cmd + L**: Беседа в боковой панели
* **Code Explanation**: Выберите код и задайте вопрос ИИ

### Редактирование кода

* **Generate Code**: Опишите требования, ИИ автоматически сгенерирует код
* **Refactoring Suggestions**: Получите рекомендации по оптимизации
* **Error Fixing**: ИИ помогает находить и исправлять ошибки

## Горячие клавиши

| Сочетание      | Функция                  |
| -------------- | ------------------------ |
| `Ctrl/Cmd + K` | панель команд AI         |
| `Ctrl/Cmd + L` | диалог с AI              |
| `Tab`          | принять предложение кода |
| `Esc`          | отменить предложение     |

## Советы по использованию

### 1. Предоставляйте понятный контекст

```javascript theme={null}
// @context: React component for user authentication
// @requirements: Need to support OAuth2 login
// @constraints: Compatible with NextJS 13+

// AI will generate more accurate code based on this information
```

### 2. Оптимизируйте prompt

```
// Bad prompt
"Fix this function"

// Good prompt
"Fix floating point precision issue in calculateTotal function, ensure amount calculation accurate to 2 decimal places"
```

### 3. Полностью используйте режим Chat

Хотя режима Agent нет, вы можете:

* Попросить AI сгенерировать полный содержимое файла
* Попросить AI предоставить подробные инструкции по изменению
* Использовать AI для code review и предложений по рефакторингу

## Устранение неполадок

### Истекло время ожидания соединения

1. Проверьте сетевое подключение
2. Подтвердите адрес API: `https://api.apiyi.com/v1`
3. Проверьте действительность API key

### Модель не отвечает

1. Проверьте баланс аккаунта
2. Попробуйте переключить модели
3. Перезапустите Cursor

### Низкое качество предложений кода

1. Предоставьте больше контекста по проекту
2. Используйте более точные prompt
3. Попробуйте другие модели

## Лучшие практики

### Конфигурация на уровне проекта

Создайте `.cursor-settings.json` в корне проекта:

```json theme={null}
{
  "model": "gpt-4.1",
  "temperature": 0.7,
  "contextFiles": ["README.md", "package.json"],
  "rules": [
    "Use TypeScript strict mode",
    "Follow ESLint standards",
    "Add appropriate comments"
  ]
}
```

### Стандарты кода

Четко указывайте стандарты кода в prompt:

* Используйте TypeScript
* Соблюдайте стандарты Airbnb
* Добавляйте JSDoc-комментарии
* Используйте функциональный стиль

### Осведомленность о безопасности

* Не включайте конфиденциальную информацию в код
* Проверяйте сгенерированный AI код
* Проверяйте безопасность сторонних зависимостей
