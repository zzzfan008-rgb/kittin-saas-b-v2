# Cherry Studio

> Руководство по интеграции мощного клиента для общения с ИИ с типами каналов OpenAI, Anthropic и Gemini

Cherry Studio — мощный клиент для общения с AI, который поддерживает несколько больших языковых моделей. Через APIYI вы можете использовать в Cherry Studio различные популярные AI-модели и выбирать разные типы каналов для лучшего опыта и оптимизации затрат.

## Быстрая интеграция (формат, совместимый с OpenAI)

Это наиболее универсальный способ интеграции, поддерживающий все 400+ моделей на APIYI.

### 1. Получите API Key

Пожалуйста, обратитесь к [руководству по управлению API-ключом](/ru/faq/token-management), чтобы получить ваш API-ключ.

### 2. Шаги конфигурации

<img src="https://mintcdn.com/apiyillc/OMY6ItCc2mC1yzgA/images/cherry-studio-config.png?fit=max&auto=format&n=OMY6ItCc2mC1yzgA&q=85&s=697ce7c87d0a7ddadbc2a4ae4eeca322" alt="Интерфейс конфигурации Cherry Studio, совместимый с OpenAI" width="2400" height="1668" data-path="images/cherry-studio-config.png" />

Следуя изображению выше, выполните следующие шаги конфигурации:

1. Откройте приложение Cherry Studio
2. Нажмите на значок настроек слева, чтобы перейти на страницу настроек
3. Выберите опцию «Model Service»
4. Создайте пользовательский канал \[APIYI] в списке провайдеров модели
5. Заполните информацию конфигурации:
   * **Адрес API**: `https://api.apiyi.com`
   * **API-ключ**: Введите ваш API-ключ APIYI ([как получить](/ru/faq/token-management))
6. Нажмите кнопку «➕ Добавить» внизу, чтобы сохранить конфигурацию

<Info>
  **Ключевые моменты конфигурации**

  * Адрес API должен быть: `https://api.apiyi.com`
  * Для настройки API-ключа см. [руководство по управлению API-ключом](/ru/faq/token-management)
  * Рекомендуется сначала проверить соединение, чтобы убедиться в правильности конфигурации
</Info>

## Сравнение трёх типов каналов

Cherry Studio поддерживает несколько типов каналов, все доступны через APIYI. Выберите лучший способ для вашего сценария:

| Возможность               | Совместимый с OpenAI                           | Формат Anthropic                        | Формат Gemini                                        |
| ------------------------- | ---------------------------------------------- | --------------------------------------- | ---------------------------------------------------- |
| **Адрес API**             | Все используют `https://api.apiyi.com`         |                                         |                                                      |
| **Поддерживаемые модели** | Все 400+ моделей                               | Только модели Claude                    | Только модели Gemini                                 |
| **Ключевое преимущество** | Универсальная совместимость                    | Экономия на стоимости кэша              | Нативные функции + генерация изображений             |
| **Тарификация кэша**      | Н/Д                                            | Кэшированные token примерно 10% от цены | Н/Д                                                  |
| **Особенности**           | Самая широкая поддержка моделей                | Оптимизация затрат для чатов            | Преобразование текста в изображение, выполнение кода |
| **Лучше всего для**       | Общего использования, многомодельных сценариев | Интенсивного использования Claude       | Особенностей, специфичных для Gemini                 |

<Tip>
  **Как выбрать?**

  * Если вы используете несколько моделей, выберите **Формат, совместимый с OpenAI** (рекомендуемый вариант по умолчанию)
  * Если вы в основном используете Claude с частыми разговорами (в течение 5 минут), выберите **Формат Anthropic**, чтобы сэкономить
  * Если вам нужны преобразование текста в изображение Gemini или другие нативные функции, выберите **Формат Gemini**
</Tip>

## Тип канала Anthropic

Нативный формат Anthropic поддерживает **[кэширование промптов](/ru/api-capabilities/claude-prompt-caching)**. При непрерывных беседах в течение 5 минут кэшированные входные tokens стоят лишь около 10% от обычной цены, что значительно снижает затраты на использование.

### Шаги настройки

<img src="https://mintcdn.com/apiyillc/7TkKa5JmqO5PH0BI/images/cherry-studio-anthropic-provider.png?fit=max&auto=format&n=7TkKa5JmqO5PH0BI&q=85&s=2f3eeb3f3536cbe6cb0ec1f2bd2478f8" alt="Диалог добавления провайдера Anthropic в Cherry Studio" width="1570" height="1020" data-path="images/cherry-studio-anthropic-provider.png" />

1. Откройте настройки Cherry Studio → Служба моделей
2. Нажмите кнопку «➕ Add» внизу, затем заполните диалог:
   * **Имя провайдера**: Пользовательское имя (например, `APIYI-CLAUDE` для удобной идентификации)
   * **Тип провайдера**: Выберите **Anthropic**
3. После нажатия «OK» для создания заполните настройки в новом канале:
   * **Адрес API**: `https://api.apiyi.com`
   * **Ключ API**: Введите ваш ключ APIYI
4. Добавьте нужные модели Claude (например, `claude-sonnet-4-5-20250929`, `claude-opus-4-5-20251101`)

<Warning>
  **Примечание**: Канал Anthropic поддерживает только модели серии Claude. Для других моделей используйте канал формата, совместимого с OpenAI.
</Warning>

### Когда использовать

* **Непрерывные беседы**: Частые чаты в течение 5 минут дают высокий уровень попаданий в кэш, что позволяет существенно экономить
* **Беседы с большим контекстом**: Чем длиннее контекст, тем больше вы экономите благодаря кэшированию
* **Редкие чаты**: Если вы общаетесь лишь время от времени, формат, совместимый с OpenAI, работает не хуже

## Тип канала Gemini

Нативный формат Gemini поддерживает все эксклюзивные функции Gemini, включая **генерацию изображений по тексту** с помощью `gemini-3-pro-image-preview`, выполнение кода, нативное управление рассуждением и многое другое.

### Шаги настройки

1. Откройте настройки Cherry Studio → Service модели
2. Создайте новый канал, **выберите Google Gemini в качестве типа канала**
3. Заполните конфигурацию:
   * **Адрес API**: `https://api.apiyi.com`
   * **API Key**: Введите ваш ключ APIYI
4. Добавьте нужные модели Gemini (например, `gemini-2.5-flash`, `gemini-3-pro-preview`, `gemini-3-pro-image-preview`)

<Warning>
  **Примечание**: Канал Gemini поддерживает только модели серии Gemini. Для других моделей используйте канал формата, совместимого с OpenAI.
</Warning>

### Особые возможности

* **Текст в изображение**: Используйте модель `gemini-3-pro-image-preview` для прямой генерации изображений в диалогах
* **Выполнение кода**: Модели могут автоматически выполнять код Python для анализа данных
* **Управление рассуждением**: Точно настраивайте глубину рассуждения через `thinking_budget`
* **Поддержка мультимодальности**: Полная поддержка изображений, аудио, видео и других входных данных

## Добавление моделей

После настройки каналов добавьте нужные модели в соответствующем канале:

1. Найдите модели в поле поиска моделей
2. Нажмите значок рядом с названием модели, чтобы выбрать ее или настроить
3. Включите или отключите разные варианты модели по мере необходимости

## Расширенные возможности

### Поддержка изображений

Если вы используете модели, поддерживающие изображения (например, GPT-4V):

1. Включите опцию «Изображение» в настройках
2. Выберите модели с поддержкой vision
3. Загружайте изображения в беседе

### Потоковый вывод

Cherry Studio по умолчанию поддерживает потоковый вывод, обеспечивая более удобный опыт.

## Устранение неполадок

### Ошибка подключения

* Проверьте, верен ли ключ API
* Подтвердите адрес API: `https://api.apiyi.com`
* Проверьте состояние сетевого подключения

### Модель недоступна

* Подтвердите, что баланс аккаунта достаточен
* Проверьте, что модель находится в правильном типе канала (например, модели Claude должны быть в канале OpenAI или Anthropic)
* Попробуйте другие модели

## Советы по использованию

1. **Выбирайте каналы с умом**: выберите подходящий тип канала в зависимости от ваших основных моделей — вы можете настроить несколько каналов одновременно
2. **Выбирайте модели с умом**: выбирайте подходящие модели в соответствии с требованиями задачи
3. **Регулярные обновления**: следите за новыми выпусками моделей
4. **Контролируйте использование**: просматривайте использование через APIYI
