## Расположение серверов

Серверы APIYI расположены в **Лос-Анджелесе, США (US West)** и используют **премиум-сеть BandwagonHost, оптимизированную для Китая**.

<Info>

</Info>

## Как проверить сетевую задержку?

Перед выбором сервера рекомендуем проверить сетевую задержку от вашего сервера до APIYI.

### Способ 1: Ping-тест

```bash theme={null}
# Test latency (ICMP)
ping api.apiyi.com
```

**Ориентировочная задержка**:

* **Материковый Китай**: обычно 50-150ms (оптимизированная премиальная сеть)
* **Западный регион США**: обычно 5-30ms (тот же регион)
* **Европа/Азиатско-Тихоокеанский регион**: обычно 150-300ms (межрегионально)

### Способ 2: Тест задержки cURL

```bash theme={null}
# Single HTTP latency test
curl -o /dev/null -s -w "Connect time: %{time_connect}s\nTotal time: %{time_total}s\n" https://api.apiyi.com

# Multiple tests for average (more accurate)
for i in {1..10}; do
  curl -o /dev/null -s -w "Test $i - Total time: %{time_total}s\n" https://api.apiyi.com
done
```

### Способ 3: Тест фактического вызова API

```bash theme={null}
# Test actual API call latency
time curl -X POST https://api.apiyi.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "Hello"}],
    "max_tokens": 10
  }'
```

<Tip>
  **Рекомендация по оптимизации**: если задержка высокая (свыше 500ms), рассмотрите:

  * Переключение на сервер в дата-центре западного региона США
  * Использование CDN или прокси-ускорения
  * Обращение в службу поддержки для решений по оптимизации сети
</Tip>

## Рекомендации по оптимизации сети

### Для сценариев с высокой задержкой

Если на вашем сервере высокая задержка, попробуйте следующие решения для оптимизации:

<Steps>
  <Step title="Используйте пул соединений">
    Повторно используйте HTTP-соединения, чтобы избежать накладных расходов на частое создание новых соединений
  </Step>

  <Step title="Включите HTTP/2 или HTTP/3">
    Используйте возможности мультиплексирования, чтобы повысить эффективность параллельных запросов
  </Step>

  <Step title="Пакетируйте запросы">
    Объединяйте несколько небольших запросов в пакетные запросы, чтобы сократить число сетевых обменов
  </Step>

  <Step title="Асинхронные вызовы">
    Используйте асинхронные вызовы API, чтобы избежать блокирующих ожиданий
  </Step>

  <Step title="Локальное кэширование">
    Кэшируйте повторяющиеся результаты запросов, чтобы снизить частоту вызовов API
  </Step>
</Steps>

### Для передачи больших изображений

Если вы часто передаете большие изображения (например, генерация изображений, распознавание изображений), мы рекомендуем:

    Уменьшает размер файла, сохраняя качество
  </Card>
</CardGroup>

  <Accordion title="Почему стоит выбрать Запад США вместо других регионов?">
    **Основные причины**:

    1. **Оптимизация премиальной сети**: Запад США является основным выходным узлом для премиальных сетей в направлении Китая, обеспечивая оптимальную маршрутизацию для пользователей из материкового Китая
    2. **Международный узел**: Лос-Анджелес — крупный международный сетевой узел, соединяющий Азиатско-Тихоокеанский регион, Европу, Северную Америку и т. д.
    3. **Преимущество по стоимости**: дата-центры Запада США имеют относительно низкую стоимость пропускной способности и высокую экономическую эффективность
    4. **Стабильность сервиса**: такие провайдеры, как BandwagonHost, имеют большой опыт работы в Западе США и обеспечивают хорошую стабильность
  </Accordion>

  <Accordion title="Будет ли доступ к APIYI из материкового Китая медленным?">
    **Нет!**

    Мы используем **премиальную сеть, оптимизированную для Китая** от BandwagonHost (CN2 GIA и т. д.), специально настроенную для пользователей из материкового Китая.

    **Фактические показатели**:

    * Задержка доступа для пользователей из материкового Китая обычно составляет 50-150 ms
    * Даже при передаче больших изображений в Base64 скорость остается нормальной
    * Настройка proxy или VPN не требуется

    Вы можете проверить фактическую сетевую задержку с помощью методов, описанных выше.
  </Accordion>

  <Accordion title="Как оптимизировать сетевую задержку моего приложения?">
    **Рекомендации по оптимизации**:

    1. **Выбор сервера**: выбирайте серверы в дата-центре Запада США (в том же регионе, что и мы)
    2. **Повторное использование соединений**: используйте пул подключений HTTP, чтобы избежать частого создания новых соединений
    3. **Пакетная отправка запросов**: объединяйте несколько небольших запросов в пакеты
    4. **Асинхронные вызовы**: используйте асинхронные вызовы API, не блокируйте основной поток
    5. **Локальное кэширование**: кэшируйте результаты повторяющихся запросов
    6. **Ускорение через CDN**: используйте CDN для статических ресурсов

    См. раздел «Рекомендации по оптимизации сети» выше для подробностей.
  </Accordion>

  <Accordion title="Планирует ли APIYI развернуть серверы в других регионах?">
    В настоящее время мы сосредоточены на предоставлении **высококачественных и стабильных** серверных услуг в Западе США и используем премиальные сети, чтобы обеспечить хороший сетевой опыт для пользователей по всему миру (особенно для пользователей из материкового Китая).

    В будущем мы оценим возможность развертывания серверов в других регионах (например, в Европе, Азиатско-Тихоокеанском регионе) на основе спроса пользователей и развития бизнеса.

    Если у вас есть особые требования к географическому расположению, пожалуйста, свяжитесь с нашей бизнес-командой, чтобы обсудить индивидуальные решения.
  </Accordion>

  <Accordion title="Мой сервер не находится в Западе США и имеет высокую задержку. Что мне делать?">
    Если у вашего сервера высокая задержка (свыше 500 ms), рассмотрите следующие варианты:

    **Краткосрочные решения**:

    * Используйте proxy или ускорение через CDN
    * Оптимизируйте код приложения (пул подключений, асинхронные вызовы и т. д.)
    * Объединяйте запросы в пакеты, чтобы сократить количество сетевых переходов

    **Долгосрочные решения**:

    * Перенесите сервер в дата-центр Запада США
    * Используйте многорегиональное развертывание, выделив отдельный сервер в Западе США для вызовов APIYI
    * Свяжитесь с нами, чтобы обсудить индивидуальные решения по оптимизации сети
  </Accordion>
