# Trae

> AI-нативная IDE ByteDance с режимами Builder/Chat/Inline Chat. Подключите APIYI через пользовательские записи моделей, чтобы охватить оба протокола OpenAI и Anthropic с более чем 400 ведущими моделями.

## Обзор

**Trae** — это **AI-native IDE**, запущенная ByteDance в январе 2025 года, позиционируется как инструмент продуктивности в стиле «Vibe Coding» для профессиональных разработчиков — опишите, что вы хотите, на естественном языке, и AI выполнит завершение, исправление ошибок, создание каркаса проекта и предпросмотр в один клик. Trae поставляется в двух вариантах: **TRAE CN** (`trae.cn`) и **международная TRAE** (`trae.ai`), а серия **SOLO** (Desktop / App / Web) позволяет агенту взять на себя весь жизненный цикл задачи.

## Основные возможности

### Три режима взаимодействия

* **Режим Builder**: агент берет управление на себя — читает и записывает файлы, выполняет команды, создает каркас проектов
* **Режим Chat**: беседа в боковой панели, похожая на Cursor Chat / Cline, отлично подходит для вопросов и ответов и фрагментов
* **Inline Chat**: `Cmd/Ctrl + I` открывает встроенную в редакторе беседу — самый быстрый путь для завершения и рефакторинга

### MCP и экосистема инструментов

* Встроенная поддержка **MCP (Model Context Protocol)** для внешних tools и API
* Поддержка **Remote-SSH** — удаленная разработка ощущается так же, как локальная
* Файлы `.rules` для AI-поведения на уровне проекта

### Пользовательская модель (основная тема этого руководства)

Международная версия Trae поставляется с пресетами для **Anthropic, OpenAI, Gemini, xAI, OpenRouter, Ollama, DeepSeek, Volcano Engine, Aliyun, Tencent Cloud, SiliconFlow, PPIO, Novita, BytePlus** и других. Каждый пресет позволяет указать **пользовательский ID модели + API key + пользовательский URL запроса** — это и есть точка входа, которую мы будем использовать, чтобы подключить APIYI.

<Tip>
  **Почему стоит маршрутизировать через APIYI**: встроенные модели Trae ограничены по региону и версии, и нет способа разделять использование между несколькими upstream-аккаунтами. С APIYI **один token покрывает и OpenAI, и Anthropic** — переключение между GPT и Claude больше не требует возвращаться в настройки; просто выберите модель в выпадающем списке на верхней панели Trae.
</Tip>

<Warning>
  **⚠️ Совместимость моделей — прочитайте перед настройкой**

  1. **Trae не поддерживает протокол Responses**: у пользовательских моделей есть только два канала — `/v1/chat/completions` (протокол OpenAI) и `/v1/messages` (протокол Anthropic). Начиная с серии GPT-5.4, OpenAI ограничивает «reasoning + вызов tools» эндпоинтом `/v1/responses`, поэтому **`gpt-5.4` / `gpt-5.5` / `gpt-5.6` в сценариях Trae Builder / Chat (with tools) все возвращают 400 — по сути, непригодны к использованию**, даже `gpt-5.4` (подробности см. в FAQ ниже).
  2. **Совместимый с OpenAI режим chat плохо подходит для агентов**: даже с неограниченными моделями GPT поддержка рабочих процессов агента и расширенных разрешений для tools в режиме chat неполная — режим Builder часто зависает, а опыт использования ухудшается.
  3. **В Trae мы рекомендуем семейство Claude**: оно работает через нативный протокол Anthropic `/v1/messages` с полноценным и стабильным вызовом tools в режиме Builder — это наша рекомендация по умолчанию.
  4. **Для моделей, которые Trae не может запускать (последняя серия GPT), переключитесь на приложение [Codex](/ru/scenarios/programming/codex-cli)**: Codex нативно использует протокол Responses, поэтому `gpt-5.6-sol` / `gpt-5.5` работают на полной мощности.
</Warning>

## Краткий старт

### Шаг 1: Установите Trae

<Tabs>
  <Tab title="Международная версия (TRAE)">
    Скачайте с `www.trae.ai` — поддерживает macOS, Windows, Linux. Международная сборка из коробки включает пресеты GPT / Claude / Gemini.
  </Tab>

  <Tab title="Китайская версия (TRAE CN)">
    Скачайте с `www.trae.cn` — поддерживает macOS и Windows. В комплекте идут пресеты Doubao и DeepSeek; вход в аккаунт выполняется по номеру мобильного телефона.
  </Tab>
</Tabs>

### Шаг 2: Получите токен APIYI

1. Перейдите в консоль токенов APIYI: `api.apiyi.com/token`
2. Нажмите "New Token"
3. **Для интенсивного использования Claude**: выберите группу **ClaudeCode** — вызовы Claude получают **скидку 5%**, которая суммируется с бонусом пополнения 10%-20%
4. **Для смешанного использования GPT/Gemini/DeepSeek**: подойдет **группа по умолчанию**
5. Скопируйте ключ с префиксом `sk-`

### Шаг 3: Откройте панель пользовательской модели в Trae

* **Режим IDE**: нажмите значок ⚙️ в правом верхнем углу → **Models** в левом меню → "Add model" / "Custom model"
* **Режим SOLO**: нажмите ⚙️ в правом верхнем углу панели чата → **Models** → Add

### Шаг 4: Добавьте запись с протоколом OpenAI (GPT / Gemini / DeepSeek / Doubao и т. д.)

Заполните, как показано ниже. **Пользовательский URL запроса должен включать полный путь `/v1/chat/completions`** — не только домен:

<img src="https://mintcdn.com/apiyillc/vSACm1ThocKlKALW/images/trae-custom-model-openai.png?fit=max&auto=format&n=vSACm1ThocKlKALW&q=85&s=3b59889c3ae27a374a6da691beca2ffa" alt="Пользовательская модель Trae — подключение по протоколу OpenAI к APIYI с URL запроса https://api.apiyi.com/v1/chat/completions" width="477" height="521" data-path="images/trae-custom-model-openai.png" />

| Поле                             | Значение                                                         | Примечания                                 |
| -------------------------------- | ---------------------------------------------------------------- | ------------------------------------------ |
| **Поставщик**                    | `OpenAI`                                                         | Выберите пресет OpenAI                     |
| **Модель**                       | `Custom Model`                                                   | Последний пункт в выпадающем списке        |
| **ID модели**                    | например, `gpt-5.1`, `deepseek-v4-flash`, `gemini-3-pro-preview` | Полный ID нужной вам модели                |
| **API Key**                      | `sk-...`                                                         | Вставьте токен APIYI из шага 2             |
| **Пользовательский URL запроса** | `https://api.apiyi.com/v1/chat/completions`                      | **Должен включать `/v1/chat/completions`** |

<Warning>
  **Базовый URL должен содержать полный путь**: начиная с версии v3.3.51, поле baseURL для пользовательской модели Trae используется **без изменений** — теперь оно больше не добавляет автоматически `/chat/completions`. Если указать только `https://api.apiyi.com` или `https://api.apiyi.com/v1`, возникнет ошибка.
</Warning>

<Note>
  **Модели, для которых предназначена эта запись**: `gpt-5.1` / `gpt-5.2`, Gemini, DeepSeek, Doubao, Qwen и другие модели, не ограниченные чат-протоколом. **`gpt-5.4` и более новые модели GPT (серии 5.5 / 5.6) здесь НЕ работают** — см. "Model compatibility" выше; для них используйте [приложение Codex](/ru/scenarios/programming/codex-cli).
</Note>

### Шаг 5: Добавьте запись с протоколом Anthropic (семейство Claude)

Если вам также нужны Claude Opus 4.6 / Sonnet 4.6 / Haiku 4.5, добавьте вторую запись поставщика:

<img src="https://mintcdn.com/apiyillc/vSACm1ThocKlKALW/images/trae-custom-model-anthropic.png?fit=max&auto=format&n=vSACm1ThocKlKALW&q=85&s=18c4c41f103b88df7402ab92a99aa059" alt="Пользовательская модель Trae — подключение по протоколу Anthropic к APIYI с URL запроса https://api.apiyi.com/v1/messages" width="476" height="440" data-path="images/trae-custom-model-anthropic.png" />

| Поле                             | Значение                                                           | Примечания                                                                            |
| -------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| **Поставщик**                    | `Anthropic`                                                        | Выберите пресет Anthropic                                                             |
| **Модель**                       | `Claude-Sonnet-4.6` (или другую версию Claude в выпадающем списке) | Используйте официальный пресет — переходить в "Custom model" не нужно                 |
| **API Key**                      | `sk-...`                                                           | Вставьте токен APIYI (желательно из группы ClaudeCode)                                |
| **Пользовательский URL запроса** | `https://api.apiyi.com/v1/messages`                                | **Должен включать `/v1/messages`** — обратите внимание, это НЕ `/v1/chat/completions` |

<Info>
  **Два протокола, два пути**: протокол OpenAI идет через `/v1/chat/completions`; протокол Anthropic идет через `/v1/messages`. APIYI размещает оба эндпоинта, поэтому один и тот же токен можно одновременно привязать к обеим записям поставщика в Trae без конфликта.
</Info>

### Шаг 6: Переключите модели и начните писать код

Вернувшись в редактор, нажмите выпадающий список моделей вверху — там появятся все поставщики и все их модели. Выберите нужную и начните чат или войдите в режим Builder.

## Практические советы

<Steps>
  <Step title="Сохраните обе записи провайдера">
    Добавьте обе записи OpenAI и Anthropic — при переключении GPT/Gemini ↔ Claude больше не нужно редактировать baseURL.
  </Step>

  <Step title="Не можете найти в выпадающем списке самую новую модель?">
    Встроенные пресеты моделей в Trae отстают от фактического предложения APIYI. **Выберите «Custom model» и введите ID вручную** — для канонического ID сверяйтесь с консолью APIYI или страницей рекомендаций по моделям.
  </Step>

  <Step title="Предпочитайте Claude для режима Builder">
    Claude (особенно Sonnet 4.6 / Opus 4.6) заметно надежнее следует инструкциям и выполняет многошаговые вызовы tools в agent workflows.
  </Step>

  <Step title="Добавьте суффикс -thinking для сложных задач">
    Добавьте `-thinking` к ID модели (например, `claude-sonnet-4-6-thinking`), чтобы принудительно включить chain-of-thought. Заметно снижает галлюцинации при архитектурных решениях и аудитах безопасности в режиме Builder.
  </Step>

  <Step title="Разделяйте token по группе">
    Создайте один **token группы ClaudeCode** (95% тарифа) специально для записи Anthropic и один **token группы Default** для GPT/Gemini/DeepSeek. Более понятная тарификация и видимость квоты.
  </Step>
</Steps>

## Часто задаваемые вопросы

<AccordionGroup>
  <Accordion title="TRAE CN и международная версия TRAE — есть ли разница для интеграции с APIYI?">
    **Разницы нет** — обе версии поддерживают пользовательские модели и позволяют одновременно добавлять записи провайдеров OpenAI и Anthropic. Единственное существенное различие — встроенные предустановленные модели (CN ориентирована на Doubao/DeepSeek, международная — на GPT/Claude/Gemini).

    Рекомендация: выбирайте TRAE CN (`trae.cn`), если вы находитесь в материковом Китае, а международную версию TRAE (`trae.ai`) — для глобальных команд или если вам нужны зарубежные предустановленные модели.
  </Accordion>

  <Accordion title="Почему baseURL должен содержать полный путь до /v1/chat/completions?">
    Начиная с **v3.3.51**, Trae изменил обработку baseURL пользовательской модели — теперь он используется в запросе как есть, без автоматического добавления `/chat/completions`.

    Правильно:

    * Протокол OpenAI: `https://api.apiyi.com/v1/chat/completions`
    * Протокол Anthropic: `https://api.apiyi.com/v1/messages`

    Неправильно (приведёт к ошибке 404 или ошибке маршрутизации):

    * ❌ `https://api.apiyi.com`
    * ❌ `https://api.apiyi.com/v1`
  </Accordion>

  <Accordion title="Можно ли выбрать «Пользовательская модель» у провайдера Anthropic и указать любой идентификатор модели?">
    Да. Запись провайдера Anthropic также предлагает вариант «Пользовательская модель» — укажите идентификаторы вроде `claude-opus-4-6` / `claude-sonnet-4-6-thinking` / `claude-haiku-4-5-20251001` напрямую. Эндпоинт `/v1/messages` APIYI полностью совместим с официальными идентификаторами моделей.
  </Accordion>

  <Accordion title="Как получить скидку 5% на Claude?">
    При создании token в `api.apiyi.com/token` **выберите группу ClaudeCode** — вызовы Claude автоматически получают **скидку 5%**, которая суммируется с бонусом 10–20% за пополнение.

    Вставьте token группы ClaudeCode в запись провайдера Anthropic в Trae — скидка применится автоматически.
  </Accordion>

  <Accordion title="Почему я не вижу GPT-5.1 / Claude 4.6 / новейшие модели в Trae?">
    Список предустановленных моделей Trae обновляется позже фактической доступности моделей у вышестоящего провайдера. **Рекомендуемый вариант: выберите «Пользовательская модель» и введите идентификатор вручную** — будет работать любая модель, которую поддерживает серверная часть APIYI, поэтому ждать обновления предустановок в клиенте Trae не нужно.
  </Accordion>

  <Accordion title="Режим конструктора постоянно зависает / вызовы инструментов завершаются ошибкой">
    1. **Отдавайте предпочтение Claude Sonnet 4.6 или Opus 4.6**: они заметно надёжнее работают в сценариях с вызовами инструментов
    2. **Избегайте небольших моделей без рассуждения**: DeepSeek-Chat и уменьшенные варианты Qwen могут зациклиться в режиме конструктора — переключитесь на вариант `thinking`
    3. **Следите за длиной контекста**: для крупных изменений в нескольких файлах переключайтесь на Opus 4.6 (контекст 200K)
    4. **Проверьте текущий статус APIYI**: периодические сбои у вышестоящего провайдера затрагивают все клиенты — убедитесь, что проблема не связана с каналом
  </Accordion>

  <Accordion title="gpt-5.6 / gpt-5.5 / gpt-5.4 завершается ошибкой 400: Function tools with reasoning_effort are not supported?">
    Полный текст ошибки обычно выглядит так: `Function tools with reasoning_effort are not supported for gpt-5.6-sol in /v1/chat/completions. To use function tools, use /v1/responses or set reasoning_effort to 'none'.` (400, `invalid_request_error`).

    Это **официальное ограничение OpenAI, введённое в серии GPT-5.4** — проблема не связана с каналом APIYI: на эндпоинте `/v1/chat/completions` функциональные инструменты нельзя использовать вместе с `reasoning_effort`, отличным от `none`. OpenAI предлагает два решения: переключиться на эндпоинт `/v1/responses` или явно установить `reasoning_effort` в значение `none` (отказавшись от рассуждения). Полная диагностика и инструкции по миграции: [Эндпоинт и миграция](/ru/api-capabilities/openai/responses-migration).

    Trae не поддерживает ни один из этих вариантов: пользовательские модели работают только с `/v1/chat/completions` (протокол OpenAI) и `/v1/messages` (протокол Anthropic) — API Responses не поддерживается, а настройка `reasoning_effort` отсутствует. В режимах конструктора и чата определения инструментов отправляются всегда, поэтому **обходного решения на стороне клиента нет**. JetBrains AI Assistant, opencode и другие клиенты сталкиваются с тем же ограничением на GPT-5.4+.

    Что делать:

    1. **Переключиться в Trae на модель, которую это ограничение не затрагивает**: `gpt-5.1` / `gpt-5.2` (протокол OpenAI) или семейство Claude (протокол Anthropic через `/v1/messages`), Gemini / DeepSeek и т. д.
    2. **Оставаться внутри Trae**: установите плагин [Roo Code](/ru/scenarios/programming/roo-code) в Trae — его провайдер «OpenAI» использует `/v1/responses`, и мы подтвердили, что вызовы инструментов работают внутри Trae, фактически добавляя канал Responses. Обратите внимание: Roo Code прекращён, а список предустановленных моделей заканчивается на `gpt-5.4`
    3. **Если вам нужны рассуждение gpt-5.5 / 5.6 и вызовы инструментов одновременно**: используйте клиент с поддержкой API Responses — [приложение Codex / CLI](/ru/scenarios/programming/codex-cli) или [opencode](/ru/scenarios/programming/opencode); полную таблицу поддержки клиентов см. в [Руководстве по нативному использованию API Responses OpenAI](/ru/api-capabilities/openai/native)
  </Accordion>

  <Accordion title="Что насчёт телеметрии / выгрузки данных Trae?">
    Trae — клиент ByteDance, который загружает данные телеметрии и разговоров в соответствии со своей официальной политикой конфиденциальности. Если вас беспокоит телеметрия на стороне клиента, рассмотрите следующие варианты:

    * Добавить адреса в список разрешённых на корпоративном шлюзе
    * Удалять конфиденциальные фрагменты перед входом в режим конструктора
    * Выбрать альтернативные клиенты с открытым исходным кодом и возможностью аудита, например [Claude Code](/ru/scenarios/programming/claude-code) или [Cline](/ru/scenarios/programming/cline)
  </Accordion>

  <Accordion title="Trae и Cursor / Cline / Claude Code — как выбрать?">
    | Инструмент      | Тип                | Режим агента   | Интеграция с APIYI                       | Лучше всего подходит для                                                 |

  <Accordion title="Как диагностировать ошибки 401 / 403?">
    1. Убедитесь, что API key начинается с `sk-` и не содержит лишних пробелов
    2. Убедитесь, что baseURL указан правильно — особенно конечный путь (`/v1/chat/completions` и `/v1/messages`)
    3. В консоли APIYI проверьте, что token включён, а целевая модель привязана к группе token
    4. Недостаточный баланс также может проявляться как ошибка 401 — повторно проверьте баланс аккаунта
  </Accordion>
