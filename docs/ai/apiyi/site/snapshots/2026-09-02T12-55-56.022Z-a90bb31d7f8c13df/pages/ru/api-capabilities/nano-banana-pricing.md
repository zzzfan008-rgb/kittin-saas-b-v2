# Тарифы серии Nano Banana

> Полное сравнение тарифов для моделей изображений серии Nano Banana (Pro / 2 / 2 Lite / Gen 1), включая тарификацию за запрос, тарификацию по tokens, бонусы за пополнение и руководство по выбору tokens. Всего лишь 30.3% от официальной тарификации.

## Обзор

Серия Nano Banana включает четыре модели генерации изображений, все они доступны через APIYI по ценам значительно ниже официальных тарифов. На этой странице приведены все цены на модели Nano Banana, чтобы помочь вам выбрать лучший план тарификации.

<Info>
  При вызове API используемый вами **тип token** определяет способ тарификации. Nano Banana Pro, 2 и Lite поддерживают два режима тарификации: **за запрос** и **на основе token**. У каждого есть два уровня: стандартный стабильный уровень и корпоративный уровень высокой доступности.
</Info>

| Цена за изображение (\$)   | \$0.09             | \$0.0818        | \$0.075         | \$0.24             |

<Tip>
  Экономьте до **68.75%** на изображениях 4K! Тарификация за запрос не различает разрешение — 4K стоит столько же, сколько 1K, поэтому более высокое разрешение означает более выгодное соотношение цены и качества.
</Tip>

## Тарификация Nano Banana 2 Lite

Модель: `gemini-3.1-flash-lite-image`

Самый быстрый и экономичный уровень — ориентирован на холст 1K, \~4 с на изображение. **Предпочтительна приоритетная оплата по мере использования**: фактическая цена за единицу ниже и предсказуема.

### Тарификация на основе token (рекомендуется)

| Позиция | APIYI           | Официальный Google | по сравнению с официальным |
| ------- | --------------- | ------------------ | -------------------------- |
| Вход    | \$0.10/M tokens | \$0.25/M tokens    | **40%**                    |
| Выход   | \$12/M tokens   | \$30/M tokens      | **40%**                    |

Оценочная стоимость за изображение:

| Разрешение | Оценка APIYI  | Официальный Google |
| ---------- | ------------- | ------------------ |
| 1K         | **\~\$0.018** | \~\$0.034          |

<Info>
  **На практике предсказуемо**: изображение 1K при тарификации на основе token (по token) **в среднем обходится примерно в \~\$0.018 за вызов на практике** (типичный диапазон \~\$0.016–\$0.019, определяется output tokens), что дешевле, чем фиксированная \$0.025/изображение за вызов. Сочетайте с бонусами за пополнение, чтобы снизить стоимость еще больше.
</Info>

### Тарификация за запрос

| Позиция             | APIYI          | Официальный Google    | Примечание                                                            |
| ------------------- | -------------- | --------------------- | --------------------------------------------------------------------- |
| Цена за изображение | \$0.025/запрос | \~\$0.034/изображение | Фиксированная ставка; позже может быть снижена, но пока без изменений |

<Tip>
  **Какой режим тарификации выбрать?** Для Lite **предпочитайте `Pay-as-you-go Priority`** — \~\$0.018 за вызов на практике, дешевле, чем \$0.025 за вызов, и предсказуемо, а один token также покрывает тарификацию за вызов Nano Banana Pro / 2, чтобы запустить всю серию. \$0.025/изображение за вызов — это фиксированная ставка, которую позже могут снизить, но пока она не изменилась.
</Tip>

## Руководство по выбору типа token

<Info>
  При создании token параметр «Billing model» определяет способ тарификации. Выбирайте в зависимости от основного сценария использования:
</Info>

| Модель             | Сценарий использования          | Рекомендуемый тип token     |
| ------------------ | ------------------------------- | --------------------------- |
| Nano Banana Pro    | Смешанное использование 1-4K    | На основе token (приоритет) |
| Nano Banana Pro    | Только 4K                       | За запрос                   |
| Nano Banana 2      | Смешанное использование 0.5K-4K | На основе token (приоритет) |
| Nano Banana 2      | Только 4K                       | За запрос                   |
| Nano Banana 2 Lite | Генерация объемом 1K            | На основе token (приоритет) |

<Tip>
  **Простое правило**: если вы в основном генерируете изображения 4K, выбирайте **тарификацию за запрос** (одна и та же цена независимо от разрешения). При смешанном использовании разрешений **тарификация на основе token** позволяет больше экономить на более низких разрешениях.
</Tip>
