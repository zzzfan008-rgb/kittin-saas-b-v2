切換模型就像修改一個引數一樣簡單：

```python theme={null}
# 使用 GPT-4
response = openai.ChatCompletion.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Hello!"}]
)

# 切換到 Claude 3
response = openai.ChatCompletion.create(
    model="claude-3-opus-20240229",  # 只需修改模型名稱

)
```
