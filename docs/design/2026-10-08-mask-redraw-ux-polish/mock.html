滚轮缩放

以鼠标指针为中心缩放，步进 10%；缩放时蒙版层同步变换（坐标映射保持一致）

双击切换

在「适合画布 ↔ 100%」两个锚点间切换；连续双击可在两状态间快速切换

± 按钮

固定步进 ±10%，两端边界各停；点击缩放 HUD 重置为适合画布

层级关系 — 蒙版层必须与底图同步缩放/平移
层内容随缩放变换
Layer 0底图（原图）scale(zoom) translate(panX, panY)
Layer 1蒙版重绘层（红/透明）必须与底图完全一致的 transform
Layer 2绘制中笔触预览同底图
Layer 3UI 控件（rail、关闭按钮等）不变（固定 viewport）
⚠ 硬性要求：坐标映射契约（违反则画布错位）
screenToImage(screenX, screenY) = (screenX - rect.left - panOffset.x) / zoomScale
蒙版 canvas 必须以原图自然尺寸存储，显示时整体应用 transform: scale(zoomScale) translate(panOffset.x, panOffset.y)，不可重新采样。
缩放范围 25%–400%
步进 ±10%（滚轮/按钮）
默认 适合画布
指示器 右下角 pill + 底部 ± 按钮
