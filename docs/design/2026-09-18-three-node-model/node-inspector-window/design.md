## 1. 原则

1. **窗口是「钻取」,不是「面板」**。它是一次对单个节点的聚焦配置(表面原型 = **Command/Inspect**):打开即焦点、Esc 即离开、不常驻。
2. **白卡浮层,三主题同形**。窗口继承节点卡的白卡语言(纯白表面 + 分层软阴影),三主题里**同一套值**;主题只翻转它下方的画布与「交互强调色」一槽。这与用户已拍板的「节点卡要纯白显干净」同一条审美主张。
3. **一色一义**。accent 只给:选中描边、运行 CTA、聚焦态。warning 用 warn 色、撤销用 error 色、评估状态用 success/warn 徽标——互不借用。
4. **不靠颜色区分**。选中 = 描边 + 形状;状态 = 状态点 + 文字双编码(沿用 NodeFrame `STATUS_TEXT` 纪律);徽标 = 文字 + 底色。
5. **warning 不阻断,撤销必阻断**(R5 / R-39 口径,视觉强度随语义分级:warning 行内低调,撤销整区置顶)。

## 2. 交互规范

### 2.1 打开入口(三个,等效)

| 入口 | 触发 | 说明 |
|---|---|---|
| 节点卡「功能」入口条 | 单击 | 节点卡底部常态可见的胶囊条(图标 ⚙ + 当前功能名 / 未选时「选择功能」),是**主入口**;未选功能时它同时承担「这个节点还没配功能」的自解释 |
| 双击节点体 | 双击 | 快捷路径 |
| 键盘 | `Enter`(选中节点时) / `Esc` 关 | 焦点在节点上时 Enter 打开;窗口内 Esc 关闭并把焦点还给节点 |

**双击节点打开、单击节点只选中**(选中负责序号徽标语境,见 R-38)——打开窗口不改变 R-38 的徽标语境,两者互不干扰。

### 2.2 锚定与几何

- 窗口锚定**节点右侧**,间距与垂直对齐偏移见 `tokens.css`(`--iw-anchor-gap` / `--iw-anchor-offset-top`)。
- 节点右侧空间不足(窗口右缘会超出画布可视区减 `--iw-canvas-edge-flip-margin`)时,**翻转到节点左侧**;上下越界时沿节点垂直方向收拢(贴顶/贴底)。
- 节点被拖动时窗口**跟随**,保持锚定偏移;画布缩放时窗口**不缩放**(它是 UI 层,不是画布层),位置随节点屏幕坐标重算。
- 宽 320px(比现 InspectorPanel 的 256px 宽,容纳 key-value 参数编辑器),内容超出 `--iw-max-h` 时**窗体内滚动**,头部与运行区固定不动。

### 2.3 单例与多节点行为

- **同时只开一个**。对另一个节点执行打开动作 → 旧窗口直接替换为新节点的窗口(无堆叠、无多个)。
- 窗口打开时选中其他节点:窗口**不跟随切换**(它是「打开时锚定的那张卡」的设置,不是全局 Inspector);只有显式的打开动作才换绑。这点与「InspectorPanel 跟随选中」是**有意区分**。
- 画布平移/缩放/连线操作不关闭窗口;点击**画布空白处**关闭;点击其他节点体(未触发打开)不关闭但窗口保持锚定原节点。

### 2.4 关闭与焦点管理

- `Esc` 关闭,焦点还原到节点(供屏幕阅读器与键盘流衔接)。
- 窗口打开时焦点进窗口第一个可操作元素(功能目录第一项);`Tab` 在窗口内循环,不泄漏到画布;窗口 trap 解除于关闭。
- 打开动效 160ms(缩放 .96→1 + 8px 平移),关闭 120ms;`prefers-reduced-motion` 时零动效直接替换(见 `tokens.css` 动效段)。

### 2.5 与现有 InspectorPanel 的关系:**取代,不并存**

| 项 | 口径 |
|---|---|
| 属性编辑(功能/参数/模型/运行) | **迁入悬浮窗口**,InspectorPanel 不再渲染这些字段 |
| InspectorPanel 保留 | 仅「生成记录」视图(`ResultRecordDetail`)与节点名称编辑(名称保留在面板,避免窗口里再放一个低频字段) |
| `PromptPresetPicker` 四键查询 | **退役**。新窗口按「功能目录(只列已发布,R6)」选变体,绑定字段(`promptVariantId/contractHash/evaluationVersion`)不变,由目录选项携带 |
| 迁移路径 | P2-c 单批次切换:节点组件加入口条 + 新 Popover 组件;InspectorPanel 删除属性编辑分支。**不做灰度并存**(两套配置入口 = 双倍认知负担) |

### 2.6 各状态形态(窗口级)

| 状态 | 头部状态点 + 文案 | 运行按钮 | 其他 |
|---|---|---|---|
| 未选功能 | idle 灰点 · 「待配置」 | **禁用**,状态行「请先选择功能」 | 功能目录无选中项 |
| 已选未运行 | idle 灰点 · 「待运行」 | 可用 | — |
| 参数有 warning | idle 灰点 · 「待运行」 | **可用(不阻断)** | 参数区行内 warning + 「自定义参数(未评估)」徽标 |
| 运行中 | running 蓝点 · 「运行中」 | 变「取消」(次按钮态) | 字段全部只读 |
| 成功 | success 绿点 · 「运行成功」 | 「重新运行」 | text 节点额外出现采纳区(§3.5) |
| 失败 | error 红点 · 「运行失败」 | 「重试」 | 错误文案区(复用现有用户可读映射) |
| 功能被撤销 | error 红点 · 「配置失效」 | **禁用**,状态行写明原因 | 撤销条置顶(§3.4) |

## 3. 窗口内容结构(自上而下)

```
┌──────────────────────────────┐
│ ● 节点名 · 状态          ✕   │ ← 头部(固定)
├──────────────────────────────┤
│ [撤销条 · 仅撤销态置顶]        │
│ 功能(系统提示词)  只列已发布  │ ← §3.1
│  出图 / 改款 …分组目录        │
│ 技术参数      [评估状态徽标]  │ ← §3.2
│  key ———— value 行 ×N        │
│  [蒙版条 · 仅 needsMask]     │ ← §3.3
│ 模型                         │ ← 适用性徽标驱动
│  模型行 ×N                   │
│ [采纳区 · 仅 text 节点]      │ ← §3.5
├──────────────────────────────┤
│ [ 运 行 ]                    │ ← 运行区(固定)
│ ● 状态行一句话                │
└──────────────────────────────┘
```

### 3.1 功能选择

- **组织**:按功能族分组(出图 / 改款 / 印花 / 动态 / 文本),组内按发布次新到旧;只列已发布变体(R6),组头右端计数。
- **搜索**:目录上方一个过滤框,按功能名/描述即时过滤;组数 × 变体数超过一屏时搜索是主路径,浏览是辅路径。
- **选中**:单选。选中项 1.5px accent 描边 + 名称加粗;**不预填确认弹窗**(旧 PromptPresetPicker 的「确认应用」弹窗取消——新模型下选择即绑定,参数区实时回显该变体的推荐值)。
- **回显**:选中后参数区用该变体发布时的 `recommendedOptions` **整体替换填充**,并显示「已评估参数」徽标;用户再改 → 徽标变「自定义参数(未评估)」(§3.2)。
- **空态**(三种,文案区分):
  | 情形 | 显示 |
  |---|---|
  | 目录为空(发布链尚无变体) | 「功能目录为空。功能由提示词目录经评估发布后出现在这里。」 |
  | 该节点类型下无已发布变体 | 「当前没有可用于{图片/视频/文本}节点的已发布功能。」 |
  | 搜索无命中 | 「没有匹配『{词}』的已发布功能。」 |

### 3.2 技术参数(R5:推荐值 + 自由 key-value)

- **呈现**:key-value 行编辑器。初始 = 所选变体的 `recommendedOptions` 默认值;key 列等宽字体,值列可编辑;有 `examples` 的 key 值列给 datalist 候选。
- **改值/加键/删键**:值就地编辑;「+ 添加参数」加一行空 key-value(自由键);行尾 ✕ 删除该行。**无硬校验**,失焦即生效。
- **warning 显示(不阻断 ✓)**:`imageModelOptionsError*` 改为返回 warning 数组后,逐条**行内**显示在对应参数行下方(⚠ + 一句,浅底 warn 色变体 `--gc-warn-text`,**白卡上必须用浅底变体**——对比度实测见 §6);多条 warning 平铺不折叠。运行按钮保持可用。
- **评估状态徽标**(runtime.md §5c 的 UI 呈现义务):参数与变体发布推荐值**全等** → 绿色「已评估参数」;**任一差异**(改值/加键/删键)→ 琥珀「自定义参数(未评估)」。纯信息展示,不阻断、不告警升级。

### 3.3 蒙版(needsMask)

- 选中声明 `needsMask` 的功能 → 参数区与模型区之间**插入蒙版条**(缩略图(棋盘底+已涂区域)+ 已涂区域描述 + 羽化值 + 蒙版源 + 「编辑蒙版」按钮)。
- 「编辑蒙版」**复用现有 MaskEditor**(全屏编辑态),保存后回写节点 `mask/maskSourceRef/featherRadius`,缩略图原地更新。
- **未涂蒙版时运行禁用**,状态行「该功能需要先涂蒙版」;目录卡上该功能带「需蒙版」徽标(提前立预期,不藏到选中后)。
- 蒙版源固定 = 参考图 1(`maskSourceRef` 语义沿用);参考图 1 变更时蒙版条标警示(复用 warning 行样式)。

### 3.4 功能被撤销(R-39 口径)

- 撤销条**置顶于窗口内容区第一顺位**(role=alert):图标 + 「所选功能已被撤销,请重新选择。」+ 当前绑定变体 ID(mono)+ 处置说明(数据保留不动 / 运行将被拒绝 / 请改选)。
- 目录中该变体**保留显示但灰显 + 「已撤销」徽标**(让用户看见「我绑的是什么」),不可点;同族现行版本紧随其后作为改选目标。
- 运行按钮禁用,状态行重复拒绝原因(不靠颜色单通道)。
- 变体 ID 保留不自动回退(契约:不自动改用户文档)。

### 3.5 text 节点窗口(Q1=B)

与 image/video **同构**(同一窗口骨架),差异:

| 区 | text 节点形态 |
|---|---|
| 功能目录 | 文本功能族(提示词润色 / 提示词生成…),同分组目录 |
| 参数 | 文本模型参数(temperature 等),同 key-value 编辑器 + 同款徽标 |
| 模型 | 文本模型清单(plan §5.1 推荐:gpt-5.3 主力 / gemini-3.6-flash 轻量) |
| 运行结果 | 运行成功后出现 **outputText 预览区**(只读、限高滚动),下接「复制」(次要,幽灵按钮)+「**采纳进正文**」(主,accent 胶囊) |
| 采纳纪律 | 预览区标题明示「建议,未落笔」;采纳 = 显式动作把 outputText **复制进正文**;采纳前下游节点读取的仍是原正文(runtime.md 统一定义:下游只读 `data.text`)。预览区下固定一行说明,防止「AI 帮我改了」的误解 |

### 3.6 参考图确认(T3/T5/T6 多图参考场景)

- 窗口内**不放**参考图列表(R-39:只读、无手动调序;画布徽标已承担)。但功能目录中每个变体的**描述行回显其提示词正文里的角色声明**(如「按参考图 2 的面料替换主体面料」),与画布上的序号徽标(R-38)交叉印证「第几张是面料/图案/场景」。
- 序号补位导致角色对应变化时,窗口状态行出现一次性提示「顺序已变更,角色对应关系以新顺序为准」(契约 i18n 键 `inspector.orderChanged`,graph-invariants §5)。

## 4. 可访问性

- **键盘可达**:打开(Enter)、关闭(Esc)、窗口内 Tab 循环、目录项方向键上下移动、运行按钮 Tab 可达。
- **焦点管理**:打开时焦点入窗口;关闭时焦点还原节点;窗口存在期间焦点不泄漏到画布(§2.4)。
- **aria**:窗口 `role="dialog"` + `aria-label="{节点名} · 功能设置"`;撤销条 `role="alert"`;状态行 `aria-live="polite"`;warning 行与对应输入 `aria-describedby` 关联;徽标为文字非纯图标。
- **不靠颜色区分**:状态 = 状态点 + 文字;选中 = 描边 + 字重;撤销 = 图标 + 文案 + 灰显 + 徽标(四重编码)。
- **字阶**:label 11px(CJK 下限)/ 正文 13px / UI 12px,沿用 `--gc-font-*`;参数 key 与值用 `--gc-font-mono`。
- **对比度**:程序实测见 §6;`prefers-reduced-motion` 关闭窗口动效。

## 5. 视觉规范(全部数值 → `tokens.css`)

窗口 = 白卡浮层:`--iw-surface` 纯白(三主题同值)、`--iw-radius` 14px(比节点卡大 2px,标记浮层身份)、四层阴影比节点卡多一档「浮起」(`--iw-shadow`)。分区节奏:三区之间 `--iw-section-gap`,字段间 `--iw-field-gap`,横向内边 `--iw-pad-x`。

**与既有语言的接缝**:头部状态点 = `--gc-dot-status` + `--gc-status-*`;运行按钮 = 既有 RunButton 的胶囊几何(accent 底 + `--gc-accent-cta-ink` 字);输入字段底 = `--gc-node-inner` 同值;warning/warn 徽标 = `--gc-warn-text` 浅底变体。

## 9. 待用户确认的开放点

1. **入口条在节点卡上的常驻形态**:原型按「节点卡底部胶囊条(⚙ + 功能名)」呈现;若认为节点卡应更干净,备选是「仅选中态显示入口条 + 双击/Enter 为主」。
2. **InspectorPanel 取代节奏**:本规范按 P2-c 单批次切换(§2.5);若想先并存一个版本观察,需接受双入口并明确下线时间点。
3. **窗口宽度 320px**:比现 Inspector(256px)宽;若画布密集场景嫌占空间,可降到 288px(参数编辑器 key 列会相应压缩)。
