R-38 · 参考图序号徽标(示意原型,供评审)

已按 2026-09-18 晚用户裁定收敛:徽标跟随当前选中的目标显示 —— image/video 节点被选中时,连入它的各源图在图片右上角显示「自己在该目标入边数组中的序号」;未选中目标时不显示任何徽标。除徽标外,节点卡 / handle / 连线 1:1 取自 src/index.css 现有 token。

场景 ①

单目标 · 双参考图 —— 选中显示 / 未选中隐藏

同一个画布的两帧。左帧:目标「面料换色」被选中 → 两张源图右上角出现序号徽标,且用户刚点击提示词里的「参考图 2」,徽标 2 处于对应确认高亮。右帧:未选中任何目标 → 不显示任何徽标(默认态与选中态的区分 = 徽标整体的有无,无歧义)。

场景 ②

一张源图 · 连两个目标 —— 序号随选中目标切换(两帧对照)
