## 批次二：组件迁移（删 !important 反查段）

### VIS-01 [P1] 中性类 + !important 反查 = 第二主题层

**Finding：** `src/index.css` 某段用 `!important` 强制中性色，漏改一条即换肤失效。

**涉及文件（需前端拆包确认）：**
- `src/index.css`（反查段）
- `src/components/nodes/` 各节点组件
- `src/components/panels/` 各面板组件

**改法：** 按文件分批清理，每批：
1. 改 CSS 类名从 `.text-neutral-*` → `text-[var(--gc-text-muted)]` 等语义变量
2. 或改 Tailwind arbitrary value（`text-[#xxx]` → `text-[var(--gc-xxx)]`）
3. 删 `!important`
4. 截图比对通过才准删行

**分包建议（前端实施卡可按文件数再拆）：**
| 子包 | 范围 | 风险 |
|---|---|---|
| VIS-01a | `src/components/nodes/` 节点家族 | 高（换肤核心） |
| VIS-01b | `src/components/panels/` 面板家族 | 中 |
| VIS-01c | `src/components/` 其余组件 | 低 |

**依赖：** tokens.css 批次一已完成（shadow/状态色 token 已就位）

**门禁：** 三主题 1280/1440 截图比对；grep 断言 `src/index.css` 无 `text-neutral-` 残留

### VIS-06 [P2] 小地图/徽章/滚动条硬编码

**Finding：** `MINIMAP_COLORS` / 序号徽章 / 滚动条色值硬编码，非主题变量。

**涉及文件：** `src/components/minimap/`、`src/components/` 徽章相关

**改法：**
1. 新增 `--gc-canvas-mask-*`（遮罩色）与 `--gc-minimap-node`（小地图节点色）token → 入 tokens.css
2. `MINIMAP_COLORS` 改引用变量
3. 配合 D-2 节点色换档（见下）

**D-2 决策点裁定（A 推荐，已在 tokens.css 待追加）：**
| 主题 | `--gc-minimap-node` 取值 | 对比度 |

| 曜黑 (current) | `#9ba1a9` (`--gc-text-muted`) | 6.82:1 PASS |
| 简白 (white) | `rgba(0,0,0,.45)` | 3.30:1 PASS |
| 护眼绿 (eye) | `#47685A` (`--gc-text-muted`) | 5.37:1 PASS |

**门禁：** 小地图/序号徽章/滚动条三件套截图，色值可追溯到 tokens.css

### VIS-08 [P2] 字阶任意值未消费语义字号变量

**Finding：** `text-[11px]` ×44 + `text-[10px]` ×7 散落，tokens.css §0 已定语义变量。

**涉及文件：** `src/components/nodes/`、`src/components/panels/`

**改法：**
- 正文标签 → `text-label`（`11px`，via `var(--gc-font-label)`）
- 纯英文徽章/坐标/时间戳 → `text-meta-en`（`10px`，via `var(--gc-font-meta-en)`）
- 其他正文 → `text-body`（`13px`，via `var(--gc-font-body)`）

**门禁：** `grep -r 'text-\[1[01]px\]' src/` 零结果

## 批次三：交互可访问性

### VIS-07 [P2] 大量可交互元素无可见焦点

**Finding：** 节点内 / 画布可交互元素在 keyboard nav 时无可见焦点环。

**已有资源：** `--gc-focus-ring: 2px` + `outline: var(--gc-focus-ring) solid var(--gc-accent)` 在 tokens.css §7 全局生效。

**改法：** 验证 `--gc-focus-ring` 在节点内/外均覆盖；若节点内被覆盖，需在节点组件加 `:focus-visible` 覆盖。

**门禁：** keyboard nav 三主题截图；WCAG 2.1 AA 三主题均过

---

### VIS-04 [P2] SMIL 动画不受 reduced-motion 约束

**Finding：** PulseEdge 等节点用 `<animate>` SMIL，不受 `prefers-reduced-motion` 约束。

**D-3 裁定（A）：** 把 SMIL `<animate>` 静态化，用 CSS transition/transform 替代；需前端协调（PulseEdge 渲染分支与前端 A/B 方案同根）。

**改法：** 由 frontend 主导，与 VIS-04 实施卡协同；SMIL 替换为 CSS 后，`@media (prefers-reduced-motion)` 自然覆盖。

**门禁：** `prefers-reduced-motion: reduce` 时动画不触发；无动画状态下功能正常

**⚠️ 跨团队：** PulseEdge 组件需 frontend 签字确认渲染分支后再实施。

---

### VIS-05 [P2] 点阵无吸附对齐，行列参差

**D-4 裁定（A）：** `snapGrid=[24,24]` + 开关，默认关。

**涉及文件：** 画布组件（节点拖拽/对齐逻辑）

**改法：**
- 默认 `snapGrid=24`（pixels），开关状态存 UI localStorage（不进入文档）
- 实现后需验证对齐感提升 / 不引入新行为退化

**门禁：** 截图验证对齐效果；开关切换后 drag 行为符合预期
